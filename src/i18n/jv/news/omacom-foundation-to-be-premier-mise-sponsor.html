Sponsor katelu metu! Omacom Foundation dadi sponsor premier mise, lan kanthi mangkono saka jdx, sing wis ngentekake pirang-pirang taun mbangun piranti sing kanthi meneng nggawe ngatur versi Ruby, Node, Go sing beda dadi nyenengake, lan menehi kabeh piranti agenmu saluran upgrade sing bisa nututi cepete pengiriman.

Yen kowe wis nganggo Omarchy, kowe wis nganggo mise, weruh utawa ora. Iki sing ngatur runtime basa, dadi mise use -g ruby menehi kowe Ruby tanpa salarik arkeologi PATH. Nanging bagean sing paling dakgatekake saiki yaiku para agen.

Saben CLI coding-agent gedhe ing Omarchy dikirim minangka stub mise lazy-loading ing ~/.local/bin/. Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - kabeh lungguh ing kana, ora mbayar apa-apa nganti pertama kaline kowe beneran ngetik siji. Banjur iki nginstal dhewe lan kowe kerja. Ora ana paket sing kudu digoleki, ora ana versi sing kudu dipin, ora ana toolchain sing kudu dipikir. omarchy-mise-install <package> mbungkus CLI liyane kanthi cara sing padha, lan omarchy update njaga kabeh tetep anyar.

Iku jalur cepet. Ing Jaman Agen, jurang antarane krungu bab piranti lan mlakokake kudu kira-kira patang detik, lan mise ngirim iku. Ora ana sing kudu ngemas apa-apa kanggo distro dhisik.

Minate mlaku loro arah, uga: trafik menyang mise munggah 24% wiwit Omarchy diluncurake! Akeh wong ketemu piranti iki pertama kaline lewat kita, sing persis jinis barang sing kudu diakoni sponsor tinimbang dianggep lumrah.

Sekali maneh, matur nuwun khusus kanggo Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, lan Peter Steinberger sing ngidini iki kedaden. Yen ora amarga Oligarchy, kita ora bakal bisa ndanani developer open-source kaya iki!
