Apple nggawe hardware sing apik. Mesthi wae (kajaba sing sepisan kae karo keyboard butterfly). Lan akeh wong sing teka menyang Omarchy teka saka Mac. Akeh sing pengin tetep nganggo mesine lan mbuwang sistem operasine. Dadi kita bakal ngrampungake sing diwiwiti Asahi: Omarchy mlaku kanthi endah ing Apple Silicon, kanthi repot setup seminimal mungkin.

Kerja iku wis ana time ing mburine. Dina iki kita resmikake: Omarchy M, tim kita kanggo Mac nganggo Apple Silicon (plus sawetara anggota sing njaga Mac lawas tetep melu).

Idinake aku ngenalake anggotane.

Installer. Marcelo Alcantara lagi nggawe installer Mac asli. Kowe ngundhuh aplikasi ing macOS, iki njupuk rilis Omarchy sing ditandatangani, ngukir partisine, lan nge-boot kowe menyang Omarchy ing sandhinge macOS sing wis ana. Ora perlu USB stick, ora perlu mantra ing terminal. Dheweke uga nggawe build sing nguripi monitor eksternal lewat USB-C.

Omarchy Mac. Naeem Malik wis ngopeni Omarchy Mac setaun, nggawa Omarchy menyang mesin M1 lan M2 suwe sadurunge kabeh iki resmi, lan mbangun komunitas Discord luwih saka 800 wong ing sakupenge. Scott Jones iku separone proyek iku ing sisi Linux instalasi. Dheweke lagi wae nguripi layar M3 Air ing kontroler tampilan hardware Apple, sing ngowahi mesin iku saka ora bisa dianggo dadi bisa dianggo sewengi.

Try Omarchy. Eduardo Martinez nggawe Try Omarchy: desktop Omarchy asli mlaku minangka aplikasi asli sing diakselerasi hardware ing Macmu, kanthi kamera, audio, clipboard, lan folder bareng sing disambungake. Ora ana sing perlu dipartisi. Cukup undhuh lan deloken rame-ramene apa.

Paket. Shun Li mesthekake kabeh sing dibutuhake Omarchy ana minangka paket aarch64, bebarengan karo image disk ARM64 umum kanggo mesin virtual lan guest tools sing nggawe kepenak dianggo.

Driver lan kernel. Ryan Murray lagi nguripi Neo lan mbangun fondasi sing dadi tumpuane tim liyane. Dheweke ngembangake emulator SPTM sing ngidini trace macOS ing chip M4 lan luwih anyar. Trace iku penting kanggo nguripi layar, GPU, audio, nirkabel, lan Bluetooth. Dj lagi nulis driver GPU, lan nguripi Touch ID kanthi omongan langsung karo Secure Enclave. Miguel Cruz spesialis kerja M5: dheweke reverse-engineering chip N1 proprietary Apple lan nguripi Wi-Fi lan Bluetooth ing Linux. Dheweke uga kontribusi encoding lan decoding video hardware, Bluetooth, lan perbaikan desktop ing Neo. Liam lagi nguripi trackpad Neo, manajemen daya, speaker, lan output headphone, kanthi trace macOS saka Ryan minangka fondasi penting. Eryk Wieliczko ngopeni dhukungan M4 lan implementasi clean-room, lan kerja ing integrasi lan packaging. Jaidip Subedi nguripi layar eksternal lewat USB-C ing M2 MacBook Air.

MLX. Joshua Warren lagi nggawe mlx-omarchy, sing nggawa framework machine learning MLX Apple menyang Linux ing GPU Apple lewat Vulkan. Kodemu tetep muni import mlx.core as mx, nanging saiki mlaku ing Omarchy.

Mac lawas. Shawn Yeager duwe tumpukan pull request kanggo MacBook Pro Touch Bar 2016 lan 2017: speaker, Wi-Fi, sensor cahya sekitar, Touch Bar dhewe. Randy lagi reverse-engineering chip keamanan T2 kanggo nggawa Touch ID menyang Mac Intel, lan ndokumentasikake saben perbaikan kanggo MacBook Pro 2019 ing dalane. Jon Kinney nggarap dhukungan ARM kanggo Omarchy setaun kepungkur, lan saiki njaga kabeh tim terkoordinasi sapa nggarap apa.

Bebarengan, dheweke kelompok sing tangguh. Limalas wong sing ora ngenteni ijin, lan sing wis nganggo agen kanggo obah kanthi cepet sing setaun kepungkur bakal katon mokal.

Target rilis pertama yaiku kompatibilitas sampurna karo M1 lan M2, kalebu varian Pro lan Max:

  • Installer sing mulus, karo opsi instal lan coba
  • Dhukungan GPU kebak
  • Monitor eksternal lewat USB-C
  • Touch ID
  • MLX
  • Enkripsi disk

Mesin luwih anyar digarap paralel, nanging M1 lan M2 sing dadi tancepan gendera pertama. Saliyane mesin M, ana jutaan laptop lawas ing kana, akeh sing wis dipensiunake saka ambisi macOS paling anyar Apple, lan saben sijine komputer Omarchy sing apik sing nunggu kedaden.

Kowe ora kudu ngenteni rilis sing wis gilap kanggo miwiti. Try Omarchy bakal nggawe kowe ndeleng desktop asli ing Macmu ing sawetara menit. Lan yen kowe siap komitmen, installer bakal nyelehake Omarchy ing sandhinge macOS ing M1 utawa M2 dina iki.

Pungkasan, panjaluk. Yen kowe wis kerja ing Linux kanggo hardware Apple, apa iku driver kernel, firmware, packaging, installer, utawa machine learning, kita pengin krungu saka kowe. Ana kemungkinan apik kowe wis ngrampungake apa sing isih kita oyak, utawa kosok baline. Hubungi apple@omarchy.org.
