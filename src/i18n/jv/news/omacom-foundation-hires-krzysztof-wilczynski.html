Omacom Foundation lagi wae nggawe rekrutan full-time pertama! Krzysztof Wilczyński gabung kanggo mimpin kerja kita ing Omarchy Kernel. Iki persis sing dadi tujuane yayasan didegake: mbayar wong hebat kanggo nggarap masalah angel kanggo kemaslahatan kabeh wong.

Krzysztof iku developer kernel Linux sing wis suwe. Dheweke melu ngopeni subsistem PCI Endpoint bebarengan karo driver bridge host lan endpoint PCI asli. Iku pipa sing nyambungake Linux menyang GPU, drive NVMe, lan kertu WiFi-mu. Dheweke uga reviewer ing kerja PCI Rust anyar kernel. Sadurunge njero kernel, dheweke ngentekake pirang-pirang taun ing rekayasa sistem, kerja ing Kubernetes lan runtime kontainer.

Saiki dheweke bakal nggawa kabeh pengalaman iku menyang Omarchy Kernel. Fokuse: kinerja, kompatibilitas, lan keamanan. Kita pengin Linux mlayu banter ing laptop paling anyar lan ThinkPad kuna. Kita pengin iki bisa langsung saka box ing luwih akeh mesin. Lan kita pengin iki dikunci rapet.

Krzysztof uga gabung Omarchy Core, dadi dheweke bakal melu nemtokake arah distro sakabehe.

Sugeng rawuh, Krzysztof! Ayo nggawe kernel njerit.
