Omarchy ora mung distribusi Linux sing endah, nyenengake & agentik kanggo sing pungkasane nganggo. Iki uga dibangun kanthi cara iku! Kanthi kaendahan, kesenengan, lan token sing akeh banget. Nyatane, Omarchy Quattro meh kabeh dibangun dening agen. Amarga dheweke pinter banget ing bab kaya bash, QML, lan ndebug masalah Linux.

Kanggo terus nggawe Omarchy luwih apik saiki kita wis narik atusan ewu pangguna lan kokreator, kita kudu njaga token mili. Iki carane kita nyepetake, ndandani, lan ngirim kabeh kontribusi nggumunake sing wis mili. Kita wis duwe backlog 1,600+ PR saka mung sawetara minggu sawise peluncuran! Ora ana sing bisa ngliwati iku tanpa bantuan agentik.

Dadi, aku bungah banget ngumumake yen kita wis ngamanake token sakgunung saka mayoritas lab gedhe kanggo misi iki! Kaping pisan yaiku Meta Superintelligence Labs sing gabung minangka Patron Token Pendiri kanthi 1,5 yuta USD ing token! Model Meta Muse Spark anyare nggawe angka apik kanthi rega nggumunake. Dadi 1,5 yuta USD iku sejatine token tanpa wates! (Kita bakal nyoba ngentekake!)

Nanging kita uga bungah nampani rong lab frontier utama liyane, Anthropic lan OpenAI, minangka Patron Token Pinunjul kanthi donasi token 150,000 USD saben siji. Iki bakal migunani banget nalika dipasangake karo ijin keamanan sing dibutuhake kanggo nyopot guardrail sing kita butuhake kanggo riset lan perbaikan keamanan.

Lan kanggo model bobot-terbuka, aku uga bungah ngumumake Fireworks minangka Patron Token Pinunjul uga kanthi 150,000 USD ing token sing dijanji. Aku wis kerep nganggo model Kimi K utamane, lan luwih-luwih nalika mlaku ing mode cepet. Kita bakal nggunakake token cepet iki kanthi apik uga!

Digabung, iki 1,95 yuta USD maneh sing dijanji kanggo Omacom Foundation. Sing banjur nyelehake total janji kita dadi 14,95 yuta USD. Angka edan kanggo diketik kanggo distro sing pengkritik awal nganggep mung sakumpulan dotfile (sing adil wae ora kabeh salah nalika iku, nanging banjur kita terus ndandani kabeh!).

Kanthi kabeh token iki, kita bisa ndandani kabeh. Lan iku sing bakal kita lakoni!
