Alibaba Cloud מצטרפת ל-Omacom Foundation כפטרונית תאגידית מייסדת, ותורמת $1 מיליון בשנה למשך שלוש שנים! זוהי התחייבות של $3 מיליון, המקבילה לתמיכה של DigitalOcean, לפיתוח, לתחזוקה ולהפצה של Omarchy.

אבל השותפות הזו חורגת הרבה מעבר לכסף. Alibaba Cloud הולכת לעזור לנו לבנות את Omarchy China: ה-CDN המקומי, האירוח, האתר, המפגשים והקהילה שהמשתמשים הסיניים צריכים כדי לאמץ את Omarchy בלי טרחה. הורדת Linux, התקנת חבילות ושמירה על המחשב מעודכן אמורים להיות פשוטים בכל מקום שבו אתם גרים. אנחנו הולכים לעבוד יחד כדי שזה יהיה נכון גם בסין.

והתזמון לא יכול היה להיות טוב יותר. עם ההכרזה על Qwen Book, Alibaba מכניסה לחומרה את השאיפה שלה למחשב הסוכני. אנחנו הולכים לשתף פעולה כדי להפוך את Omarchy למערכת ההפעלה הסוכנית האידיאלית עבור המחשב הזה. שולחן עבודה יפהפה וכיפי של Linux שבו אנשים וסוכנים יכולים לעבוד יחד, ושבו הבעלים נשאר אחראי.

הנה איך Alibaba Cloud מתארת את Qwen Book הקרוב:

Qwen Book שואף ליצור מחשב סוכן AI מקורי. פילוסופיית הליבה שלו, “OS as Harness”, בפשטות, כוללת שילוב עמוק של מודלים, מערכת ההפעלה, יישומים, שירותי ענן וחומרה. זה בונה סביבת מחשוב שהסוכנים יכולים להבין, להפעיל, לזכור ולפעול בה ברציפות, ומשדרג את המחשב מכלי פסיבי לעוזר אישי שמתפתח כל הזמן.

מערכת Qwen Book תואמת לארכיטקטורות ARM ו-x86, כאשר הגרסה הראשונה מבוססת על ארכיטקטורת ARM. ברמת המערכת, בנינו Agent Engine חסכוני בחשמל ו-Continuous Context Engine. עם משפחת מודלי Qwen כבסיס החכם, אנחנו מספקים שירותי מודלים עבור מערכת Qwen Book באמצעות אינטגרציית ענן-מכשיר. אנחנו מצפים לחקור יחד חידושים נוספים עם Omarchy OS בעתיד.

זה אומר לכוונן את Omarchy עבור מודלי Qwen מהקופסה ולעבוד לקראת אינטגרציה מלאה עם השירותים הסיניים שאנשים תלויים בהם. המודלים, מערכת ההפעלה והשירותים אמורים לעבוד יחד מהרגע שבו אתם מדליקים את המחשב. להכין את המחשב לעבודה עם סוכן לא אמור להיות פרויקט בפני עצמו.

זה בדיוק סוג שיתוף הפעולה שאני רוצה שהקרן תאפשר. אנשים שבונים מודלים, אנשים שבונים מחשבים ואנשים שבונים מערכות הפעלה שעובדים יחד כדי לשפר את כל החוויה. יש לנו שאיפה משותפת למה שהמחשב האישי יכול להיות, ועכשיו אנחנו משקיעים בזה משאבים.

Alibaba Cloud מצטרפת ל-DigitalOcean ול-Meta Superintelligence Labs כפטרונית תאגידית מייסדת. ההתחייבות שלהם מביאה את סך התמיכה שלנו לכ-$21.7 מיליון. זה נותן לנו יותר מרחב להשקיע באנשים, בתשתית ובפרויקטי הקוד הפתוח שמאפשרים את Omarchy.

תודה לכולם ב-Alibaba Cloud, ובמיוחד ל-CTO LI feifei, שהפכה את זה לאפשרי. התמיכה שלכם מאפשרת לנו לחשוב בגדול ולהעסיק עוד אנשים כדי להפוך את Linux לטובה יותר עבור כולם.

בואו נבנה את מערכת ההפעלה הסוכנית האידיאלית עבור המחשב הסוכני. בסין ובכל מקום אחר!
