ಮೂರನೇ ಪ್ರಾಯೋಜಕತ್ವ ಹೊರಬಂತು! Omacom ಫೌಂಡೇಶನ್ mise ನ, ಮತ್ತು ಆ ಮೂಲಕ jdx ರ ಪ್ರೀಮಿಯರ್ ಪ್ರಾಯೋಜಕವಾಗುತ್ತಿದೆ. ಅವರು Ruby, Node, Go ನ ವಿಭಿನ್ನ ಆವೃತ್ತಿಗಳನ್ನು ನಿರ್ವಹಿಸುವುದನ್ನು ಮೌನವಾಗಿ ಸಂತೋಷಕರವಾಗಿಸುವ, ಮತ್ತು ನಿಮ್ಮ ಎಲ್ಲಾ ಏಜೆಂಟ್ ಟೂಲಿಂಗ್‌ಗೆ ಬಿಡುಗಡೆಯ ವೇಗದೊಂದಿಗೆ ಹೊಂದಿಕೊಳ್ಳಬಲ್ಲ ಅಪ್‌ಗ್ರೇಡ್ ಚಾನೆಲ್ ನೀಡುವ ಟೂಲ್ ಅನ್ನು ವರ್ಷಗಳ ಕಾಲ ಕಟ್ಟುತ್ತಿದ್ದಾರೆ.

ನೀವು Omarchy ಬಳಸಿದ್ದೀರಿ ಎಂದರೆ, ಗಮನಿಸಿದ್ದೀರೋ ಇಲ್ಲವೋ, ನೀವು mise ಬಳಸಿದ್ದೀರಿ. ಭಾಷೆಯ ರನ್‌ಟೈಮ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸುವುದೇ ಇದು, ಆದ್ದರಿಂದ mise use -g ruby ಒಂದೇ ಸಾಲಿನ PATH ಪುರಾತತ್ವಶಾಸ್ತ್ರವಿಲ್ಲದೆ ನಿಮಗೆ Ruby ನೀಡುತ್ತದೆ. ಆದರೆ ಈಗ ನಾನು ಅತ್ಯಂತ ಕಾಳಜಿ ವಹಿಸುವ ಭಾಗ ಏಜೆಂಟ್‌ಗಳು.

Omarchy ನಲ್ಲಿನ ಪ್ರತಿ ಪ್ರಮುಖ ಕೋಡಿಂಗ್-ಏಜೆಂಟ್ CLI ~/.local/bin/ ನಲ್ಲಿ ಒಂದು ಲೇಜಿ-ಲೋಡಿಂಗ್ mise ಸ್ಟಬ್ ಆಗಿ ಬರುತ್ತದೆ. Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - ಎಲ್ಲವೂ ಅಲ್ಲಿ ಕುಳಿತಿವೆ, ನೀವು ಮೊದಲ ಬಾರಿಗೆ ಒಂದನ್ನು ಟೈಪ್ ಮಾಡುವವರೆಗೆ ಏನೂ ಖರ್ಚಾಗುವುದಿಲ್ಲ. ನಂತರ ಅದು ತಾನಾಗಿಯೇ ಇನ್‌ಸ್ಟಾಲ್ ಆಗುತ್ತದೆ ಮತ್ತು ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುತ್ತೀರಿ. ಹುಡುಕಬೇಕಾದ ಪ್ಯಾಕೇಜ್ ಇಲ್ಲ, ಪಿನ್ ಮಾಡಬೇಕಾದ ಆವೃತ್ತಿ ಇಲ್ಲ, ಯೋಚಿಸಬೇಕಾದ ಟೂಲ್‌ಚೈನ್ ಇಲ್ಲ. omarchy-mise-install <package> ಇನ್ನಾವುದೇ CLI ಅನ್ನೂ ಅದೇ ರೀತಿ ಸುತ್ತುತ್ತದೆ, ಮತ್ತು omarchy update ಪ್ರತಿಯೊಂದನ್ನೂ ಇತ್ತೀಚಿನದಾಗಿಡುತ್ತದೆ.

ಅದೇ ವೇಗದ ಹಾದಿ. ಏಜೆಂಟ್‌ಗಳ ಯುಗದಲ್ಲಿ, ಒಂದು ಟೂಲ್ ಬಗ್ಗೆ ಕೇಳುವುದು ಮತ್ತು ಅದನ್ನು ಚಲಾಯಿಸುವುದರ ನಡುವಿನ ಅಂತರ ಸುಮಾರು ನಾಲ್ಕು ಸೆಕೆಂಡುಗಳಷ್ಟಿರಬೇಕು, ಮತ್ತು mise ಅದನ್ನು ನೀಡುತ್ತದೆ. ಮೊದಲು ಯಾರೂ ಡಿಸ್ಟ್ರೋಗಾಗಿ ಏನನ್ನೂ ಪ್ಯಾಕೇಜ್ ಮಾಡಬೇಕಾಗಲಿಲ್ಲ.

ಆಸಕ್ತಿ ಎರಡೂ ಕಡೆ ಹರಿಯುತ್ತದೆ: Omarchy ಬಿಡುಗಡೆಯಾದಾಗಿನಿಂದ mise ಗೆ ಟ್ರಾಫಿಕ್ 24% ಏರಿದೆ! ಬಹಳಷ್ಟು ಜನರು ನಮ್ಮ ಮೂಲಕ ಈ ಟೂಲ್ ಅನ್ನು ಮೊದಲ ಬಾರಿಗೆ ಭೇಟಿಯಾಗುತ್ತಿದ್ದಾರೆ, ಇದನ್ನೇ ಒಂದು ಪ್ರಾಯೋಜಕತ್ವ ಕಡೆಗಣಿಸುವ ಬದಲು ಗುರುತಿಸಬೇಕು.

ಮತ್ತೊಮ್ಮೆ, ಇದನ್ನು ಸಾಧ್ಯಗೊಳಿಸಿದ್ದಕ್ಕಾಗಿ Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, ಮತ್ತು Peter Steinberger ಗೆ ವಿಶೇಷ ಧನ್ಯವಾದಗಳು. ಒಲಿಗಾರ್ಕಿ ಇಲ್ಲದಿದ್ದರೆ, ಇಂತಹ ಓಪನ್-ಸೋರ್ಸ್ ಡೆವಲಪರ್‌ಗಳಿಗೆ ಧನಸಹಾಯ ನೀಡಲು ನಮಗೆ ಸಾಧ್ಯವಾಗುತ್ತಿರಲಿಲ್ಲ!
