ಮೂರನೇ ಪ್ರಾಯೋಜಕತ್ವ ಹೊರಗೆ! Omacom Foundation mise ನ ಪ್ರಧಾನ ಪ್ರಾಯೋಜಕವಾಗುತ್ತಿದೆ, ಮತ್ತು ಅದರ ಮೂಲಕ jdx ರವರ, ಅವರು Ruby, Node, Go ನ ವಿವಿಧ ಆವೃತ್ತಿಗಳನ್ನು ನಿರ್ವಹಿಸುವುದನ್ನು ಸದ್ದಿಲ್ಲದೆ ಸಂತೋಷವಾಗಿಸುವ ಮತ್ತು ನಿಮ್ಮ ಎಲ್ಲಾ ಏಜೆಂಟ್ ಪರಿಕರಗಳಿಗೆ ರವಾನೆಯ ವೇಗವನ್ನು ಹಿಡಿದಿಡಿಯಬಲ್ಲ ಅಪ್‌ಗ್ರೇಡ್ ಚಾನಲ್ ನೀಡುವ ಪರಿಕರವನ್ನು ವರ್ಷಗಳಿಂದ ಕಟ್ಟಿದ್ದಾರೆ.

ನೀವು Omarchy ಬಳಸಿದ್ದರೆ, ಗಮನಿಸಿರಲಿ ಇಲ್ಲದಿರಲಿ, mise ಬಳಸಿದ್ದೀರಿ. ಅದು ಭಾಷಾ ರನ್‌ಟೈಮ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ mise use -g ruby ಒಂದೇ PATH ಪುರಾತತ್ವ ಸಾಲಿಲ್ಲದೆ Ruby ನೀಡುತ್ತದೆ. ಆದರೆ ಸದ್ಯ ನನಗೆ ಅತ್ಯಂತ ಮುಖ್ಯವಾದ ಭಾಗ ಏಜೆಂಟ್‌ಗಳು.

Omarchy ನಲ್ಲಿ ಪ್ರತಿ ಪ್ರಮುಖ ಕೋಡಿಂಗ್-ಏಜೆಂಟ್ CLI ~/.local/bin/ ನಲ್ಲಿ ಲೇಜಿ-ಲೋಡಿಂಗ್ mise ಸ್ಟಬ್ ಆಗಿ ರವಾನೆಯಾಗುತ್ತದೆ. Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - ಎಲ್ಲವೂ ಅಲ್ಲೇ ಕುಳಿತು, ನೀವು ನಿಜವಾಗಿ ಒಂದನ್ನು ಟೈಪ್ ಮಾಡುವ ಮೊದಲ ಬಾರಿಯವರೆಗೆ ಏನೂ ವೆಚ್ಚ ಮಾಡುವುದಿಲ್ಲ. ನಂತರ ಅದು ತಾನಾಗಿಯೇ ಸ್ಥಾಪನೆಯಾಗುತ್ತದೆ ಮತ್ತು ನೀವು ಕೆಲಸ ಮಾಡುತ್ತೀರಿ. ಹುಡುಕಬೇಕಾದ ಪ್ಯಾಕೇಜ್ ಇಲ್ಲ, ಪಿನ್ ಮಾಡಬೇಕಾದ ಆವೃತ್ತಿ ಇಲ್ಲ, ಯೋಚಿಸಬೇಕಾದ ಟೂಲ್‌ಚೈನ್ ಇಲ್ಲ. omarchy-mise-install <package> ಬೇರೆ ಯಾವುದೇ CLI ಅನ್ನು ಅದೇ ರೀತಿ ಸುತ್ತುತ್ತದೆ, ಮತ್ತು omarchy update ಕೊನೆಯದೊಂದನ್ನೂ ನವೀಕೃತವಾಗಿರಿಸುತ್ತದೆ.

ಅದೇ ವೇಗದ ಹಾದಿ. ಏಜೆಂಟ್‌ಗಳ ಯುಗದಲ್ಲಿ, ಪರಿಕರದ ಬಗ್ಗೆ ಕೇಳುವುದಕ್ಕೂ ಅದನ್ನು ಚಲಾಯಿಸುವುದಕ್ಕೂ ನಡುವಿನ ಅಂತರ ಸುಮಾರು ನಾಲ್ಕು ಸೆಕೆಂಡುಗಳಿರಬೇಕು, ಮತ್ತು mise ಅದನ್ನು ನೀಡುತ್ತದೆ. ಮೊದಲು ಡಿಸ್ಟ್ರೋಗಾಗಿ ಯಾರೂ ಏನನ್ನೂ ಪ್ಯಾಕೇಜ್ ಮಾಡಬೇಕಾಗಿರಲಿಲ್ಲ.

ಆಸಕ್ತಿ ಎರಡೂ ಕಡೆ ಹರಿಯುತ್ತದೆ: Omarchy ಆರಂಭವಾದಂದಿನಿಂದ mise ಗೆ ಟ್ರಾಫಿಕ್ 24% ಏರಿದೆ! ಬಹಳಷ್ಟು ಜನರು ಈ ಪರಿಕರವನ್ನು ಮೊದಲ ಬಾರಿಗೆ ನಮ್ಮ ಮೂಲಕ ಭೇಟಿಯಾಗುತ್ತಿದ್ದಾರೆ, ಪ್ರಾಯೋಜಕತ್ವ ಗುರುತಿಸಬೇಕಾದದ್ದು ನಿಖರವಾಗಿ ಅದನ್ನೇ, ಅದನ್ನು ಸಹಜವೆಂದು ತೆಗೆದುಕೊಳ್ಳುವುದಲ್ಲ.

ಮತ್ತೊಮ್ಮೆ, ಇದನ್ನು ಸಾಧ್ಯವಾಗಿಸಿದ Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston ಮತ್ತು Peter Steinberger ಗೆ ವಿಶೇಷ ಧನ್ಯವಾದಗಳು. Oligarchy ಇಲ್ಲದಿದ್ದರೆ, ಮುಕ್ತ-ಮೂಲ ಡೆವಲಪರ್‌ಗಳಿಗೆ ಹೀಗೆ ಹಣ ನೀಡಲು ಸಾಧ್ಯವಾಗುತ್ತಿರಲಿಲ್ಲ!
