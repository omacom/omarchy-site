Omacom ಫೌಂಡೇಶನ್ ಇದೀಗ ತನ್ನ ಮೊದಲ ಪೂರ್ಣ-ಸಮಯದ ನೇಮಕಾತಿ ಮಾಡಿದೆ! Krzysztof Wilczyński ನಮ್ಮ Omarchy Kernel ಕೆಲಸವನ್ನು ಮುನ್ನಡೆಸಲು ಸೇರುತ್ತಿದ್ದಾರೆ. ಫೌಂಡೇಶನ್ ಸ್ಥಾಪಿಸಿದ್ದೇ ಇದಕ್ಕಾಗಿ: ಎಲ್ಲರ ಒಳಿತಿಗಾಗಿ ಕಷ್ಟದ ಸಮಸ್ಯೆಗಳ ಮೇಲೆ ಕೆಲಸ ಮಾಡಲು ಅತ್ಯುತ್ತಮ ಜನರಿಗೆ ಪಾವತಿಸುವುದು.

Krzysztof ಒಬ್ಬ ದೀರ್ಘಕಾಲದ Linux kernel ಡೆವಲಪರ್. ಅವರು ನೇಟಿವ್ PCI host bridge ಮತ್ತು endpoint ಡ್ರೈವರ್‌ಗಳ ಜೊತೆಗೆ PCI Endpoint subsystem ಅನ್ನು ಸಹ-ನಿರ್ವಹಿಸುತ್ತಾರೆ. ಅದೇ ನಿಮ್ಮ GPU, ನಿಮ್ಮ NVMe ಡ್ರೈವ್, ಮತ್ತು ನಿಮ್ಮ WiFi ಕಾರ್ಡ್ ಅನ್ನು Linux ಗೆ ಸಂಪರ್ಕಿಸುವ ಕೊಳಾಯಿ ಕೆಲಸ. ಅವರು kernel ನ ಹೊಸ Rust PCI ಕೆಲಸದ ರಿವ್ಯೂವರ್ ಕೂಡ. kernel ನಲ್ಲಿ ಆಳವಾಗಿ ತೊಡಗಿಸಿಕೊಳ್ಳುವ ಮೊದಲು, ಅವರು Kubernetes ಮತ್ತು container runtimes ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತಾ ಸಿಸ್ಟಂಸ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನಲ್ಲಿ ವರ್ಷಗಳನ್ನು ಕಳೆದಿದ್ದಾರೆ.

ಈಗ ಅವರು ಆ ಎಲ್ಲಾ ಅನುಭವವನ್ನು Omarchy Kernel ಗೆ ತರುತ್ತಾರೆ. ಗಮನ: ಕಾರ್ಯಕ್ಷಮತೆ, ಹೊಂದಾಣಿಕೆ ಮತ್ತು ಸುರಕ್ಷತೆ. ಹೊಚ್ಚ ಹೊಸ ಲ್ಯಾಪ್‌ಟಾಪ್‌ಗಳಲ್ಲಿ ಮತ್ತು ಪುರಾತನ ThinkPad ಗಳಲ್ಲಿ ಎರಡರಲ್ಲೂ Linux ಹಾರಬೇಕೆಂದು ನಾವು ಬಯಸುತ್ತೇವೆ. ಇನ್ನಷ್ಟು ಯಂತ್ರಗಳಲ್ಲಿ ಇದು ಬಾಕ್ಸ್‌ನಿಂದ ಹೊರಬಂದ ತಕ್ಷಣ ಕೆಲಸ ಮಾಡಬೇಕೆಂದು ನಾವು ಬಯಸುತ್ತೇವೆ. ಮತ್ತು ಇದು ಬಿಗಿಯಾಗಿ ಸುರಕ್ಷಿತವಾಗಿರಬೇಕೆಂದೂ ನಾವು ಬಯಸುತ್ತೇವೆ.
