ພວກເຮົາຮັບ Emir Beganović ເປັນ ຫົວໜ້າໂຄງລ່າງຂອງ Omarchy! ເຂົາເລີ່ມ 1 ພະຈິກ ເປັນຄົນທີສາມຂອງ Omacom Foundation ດ້ວຍການຮັບເຕັມເວລາ, ຮ່ວມ Krzysztof Wilczyński ເທິງ Kernel ແລະ outfoxxed ເທິງ Shell.

ນີ້ແມ່ນວິທີທີ່ Emir ບອກເລົ່າເສັ້ນທາງຂອງໂຕເອງສູ່ Omarchy:

ຄວາມຮັກຂອງຂ້ອຍເທິງ Linux ກັບໄປຫຼາຍກວ່າຊາວປີ. ຂ້ອຍກາຍເປັນນັກພັດທະນາ Ubuntu ຕອນຍັງເປັນໄວລຸ້ນແລະພົວພັນເລິກໃນຊຸມຊົນທ້ອງຖິ່ນ. ອາຊີບຂອງຂ້ອຍພາຂ້ອຍຜ່ານສາມປະເທດ, ເຮັດວຽກຄວາມໜ້າເຊື່ອຖືແລະປະສິດທິພາບໃນ startups ແລະ scaleups ແລະ ນຳພາທີມ. ຂ້ອຍໃຊ້ເວລາເກືອບເຈັດປີໃນແຜນກ SRE ຂອງ Booking.com, ນຳພາວຽກເທິງລະບົບ build ແລະ ໂຄງລ່າງ CI. ຫຼ້າສຸດ, ຂ້ອຍສ້າງ Isorun, ບ່ອນທີ່ຂ້ອຍເຮັດວຽກ microVMs, snapshots, isolation, scheduling, ແລະ disposable compute. ຕອນນີ້ຂ້ອຍເອົາປະສົບການນັ້ນກັບມາສູ່ຮັກທຳອິດຂອງຂ້ອຍ.

ສິ່ງທີ່ຈັບຕາຂ້ອຍແທ້ກ່ຽວກັບ Emir ແມ່ນ TryOmarchy. ເຂົາເອົາເດສກ໌ທັອບ Omarchy, ໃສ່ໄວ້ໃນ browser (ບໍ່ແມ່ນ reimplementation, ແຕ່ຂອງແທ້), ແລະ ໃຫ້ມັນ boot ໄດ້ໃນຫຼາຍວິນາທີເທິງໂຄງລ່າງ CPU ທຳມະດາທີ່ Cloudflare. ພວກເຮົາເລີ່ມເວົ້າກັນເລື່ອງການທົດລອງຕະຫຼົກນັ້ນ, ແລະ ບົດສົນທະນາຂະຫຍາຍໄວສູ່ແລັບທັອບ, ສະຖາປັດຕະຍະກຳໃໝ່, OEMs, ແລະ ໂຄງລ່າງທີ່ພວກເຮົາຕ້ອງການຖ້າ Omarchy ຈະແລ່ນທຸກບ່ອນທີ່ເຮົາຢາກໃຫ້ມັນແລ່ນ. ພວກເຮົາຮູ້ວ່າເຮົາແບ່ງປັນວິໄສທັດດຽວກັນ.

ນັ້ນແມ່ນສິ່ງທີ່ Emir ຂຶ້ນເຮືອມານຳພາ.

ໂຄງລ່າງສຳລັບ Omarchy ໝາຍເຖິງຫຼາຍກວ່າແລ່ນ servers. ມັນແມ່ນສິ່ງທີ່ເຮົາໃຊ້ສ້າງ, ທົດສອບ, ແລະ ຈັດສົ່ງ Omarchy, ແລະ ຮັກສາລະບົບເຮັດວຽກໜ້າເຊື່ອຖືຂະນະຂະຫຍາຍສູ່ຮາດແວຫຼາຍຂຶ້ນແລະສະຖາປັດຕະຍະກຳຫຼາຍຂຶ້ນ. ມັນເຮັດໃຫ້ releases ໜ້າເຊື່ອຖື, ເຮັດໃຫ້ຄວາມລົ້ມເຫລວຜະລິດຄືນໄດ້, ແລະ ມອບພື້ນຖານໝັ້ນໃຫ້ຄົນອື່ນທັງໝົດເທິງໂຄງການເພື່ອໃຫ້ເຂົາເຈົ້າເຄື່ອນທີ່ໄວ.

ແລະ ມີຫຼາຍໃຫ້ສຳຫຼວດ! Omarchy ຄວນເຮັດວຽກງົດງາມເທິງເຄື່ອງທີ່ນັ່ງຢູ່ເທິງໂຕະເຈົ້າ, ແຕ່ບໍ່ມີເຫດທີ່ມັນຄວນຢຸດທີ່ນັ້ນ. TryOmarchy ມອບພາບໃຫ້ເຮົາເຫັນວ່າເກີດຫຍັງເມື່ອເລີ່ມຄອມພິວເຕີ Linux ງ່າຍຄືເປີດໜ້າເວັບ, ເອົາລົດຊາດ Linux ໄວ້ພຽງຄລິກດຽວຫ່າງ. ພວກເຮົາຈະເບິ່ງວ່າມັນນຳໄປໃສ.

ຂອບໃຈ ທຸກຄົນທີ່ສະໜັບສະໜູນທຶນວຽກນີ້, ເຮົາໃຫ້ເວລາຄົນແບບ Emir ໄດ້ທຸ່ມເຕັມທີ່ເທິງ Omarchy. ຜູ້ອຸປະຖຳຂອງເຮົາເຮັດໃຫ້ເປັນໄປໄດ້ທີ່ຈະປ່ຽນການທົດລອງກ້າຫານໃຫ້ເປັນວຽກຍືນຍົງ, ດ້ວຍຄົນເຕັມເວລາອຸທິດໃຫ້ເຮັດໃຫ້ທັງລະບົບດີຂຶ້ນ. ພວກເຮົາຂອບໃຈການອຸປະຖຳຂອງເຂົາເຈົ້າ.

ຍິນດີຕ້ອນຮັບ, Emir! ມາເຮັດໃຫ້ Omarchy ແລ່ນທຸກບ່ອນ.
