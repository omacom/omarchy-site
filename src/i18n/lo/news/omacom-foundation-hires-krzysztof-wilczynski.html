Omacom Foundation ຫາກໍຮັບພະນັກງານເຕັມເວລາຄົນທຳອິດ! Krzysztof Wilczyński ເຂົ້າຮ່ວມນຳພາວຽກຂອງເຮົາເທິງ Omarchy Kernel. ນີ້ແມ່ນແທ້ສິ່ງທີ່ມູນນິທິຕັ້ງຂຶ້ນເພື່ອເຮັດ: ຈ່າຍເງິນໃຫ້ຄົນເກັ່ງເຮັດວຽກບັນຫາຍາກເພື່ອປະໂຫຍດທຸກຄົນ.

Krzysztof ແມ່ນນັກພັດທະນາ Linux kernel ມາດົນ. ເຂົາຮ່ວມດູແລລະບົບຍ່ອຍ PCI Endpoint ພ້ອມ native PCI host bridge ແລະ endpoint drivers. ນັ້ນແມ່ນທໍ່ເຊື່ອມທີ່ຕໍ່ Linux ກັບ GPU, NVMe drive, ແລະ WiFi card ຂອງເຈົ້າ. ເຂົາຍັງເປັນ reviewer ເທິງງານ Rust PCI ໃໝ່ຂອງ kernel. ກ່ອນດຳລົງເລິກເທິງ kernel, ເຂົາໃຊ້ເວລາຫຼາຍປີໃນວຽກ systems engineering, ເຮັດວຽກ Kubernetes ແລະ container runtimes.

ຕອນນີ້ເຂົາຈະເອົາປະສົບການທັງໝົດນັ້ນມາ Omarchy Kernel. ຈຸດເນັ້ນ: ປະສິດທິພາບ, ຄວາມເຂົ້າກັນໄດ້, ແລະ ຄວາມປອດໄພ. ພວກເຮົາຢາກໃຫ້ Linux ບິນເທິງແລັບທັອບໃໝ່ສຸດແລະ ThinkPads ບູຮານຄືກັນ. ພວກເຮົາຢາກໃຫ້ມັນເຮັດວຽກຕັ້ງແຕ່ເປີດກ່ອງເທິງເຄື່ອງຫຼາຍຂຶ້ນ. ແລະ ພວກເຮົາຢາກໃຫ້ມັນລັອກແໜ້ນໜາ.

Krzysztof ຍັງເຂົ້າຮ່ວມ Omarchy Core, ສະນັ້ນເຂົາຈະຊ່ວຍກຳນົດທິດທາງໃຫ້ distro ທັງໝົດ.

ຍິນດີຕ້ອນຮັບ, Krzysztof! ມາເຮັດໃຫ້ kernel ຮ້ອງ.
