ሳልሳይ ስፖንሰርሺፕ ወጻኢ! Omacom Foundation ፕሪምየር ስፖንሰር mise እናኾነ እዩ, በዚ jdx’ውን, ዓመታት መሳርሒ ምህናጽ ዝሰርሐ ጸጥታ Ruby, Node, Go ዝተፈላለዩ ቨርዥናት ምምሕዳር ሕጉስ ዝገብር, agent tooling ኣብ upgrade channel shipping ፍጥነት ምኽታል ዝኽእል ይህብ።

Omarchy ተጠቂምካ mise ተጠቂምካ ምስትውዓል ይኹን ኣይኹን። language runtimes ዝሓልእ እዩ, mise use -g ruby Ruby ሓደ መስመር PATH ቅርስ-ምድህሳስ ብዘይ ይህብ። ግን ክፋል ሕጂ ዝገድሶ ኤጀንትታት እዮም።

ነፍሲ ወከፍ ዓቢ coding-agent CLI Omarchy ከም lazy-loading mise stub ኣብ ~/.local/bin/ ይለኣኽ። Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - ኣብ’ዚ ተቀሚጦም, ቀዳማይ ግዜ ምጽሓፍ እስክትገብር ዋጋ የለን። ገዛእ ርእሱ ምትካል ስራሕ። package ምድላይ የለን, version ምምላስ የለን, toolchain ምሕሳብ የለን። omarchy-mise-install <package> ካልእ CLI እዚ ይኽብብ, omarchy update ኩሉ ሓድሽ ይሓልእ።

ፈጣን መንገድ እዩ። The Age of Agents, ርሕቀት tool ሰሚዕካ ምስራሕ ምስ’ትገብር ኣርባዕተ ሰከንድ ክኸውን ኣለዎ, mise ያብጽሖ። distro ንምትኽኻል ነፍሲ ወከፍ ኣየድልየን።

ትኩረት ክልተ ሸነኽ ይሰርሕ’ውን: ትራፊክ mise 24% ዓሌት Omarchy ምውጻእ ጀሚሩ! ብዙሕ ሰባት tool ቀዳማይ ግዜ ብናትና እናራኸቡ, ብትኽክል sponsorship ምእማን ልሙድ ምሕሳብ ክልተ ንምግባር።

እንደገና, ልዩ ምስጋና Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, Peter Steinberger እዚ ዝከኣል ንምግባር። Oligarchy እንተዘይኰይኑ, open-source developers ምድጋፍ ምግባር ኣይንኽእልን!
