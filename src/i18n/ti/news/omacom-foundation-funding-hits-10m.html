ድጋፍ Omacom Foundation ሕጂ 10 ሚልዮን USD በጺሑ ምስ ክልተ ሓደሽቲ መስራታዊ ደጋፍቲ ተልእኾ ዝተጸንበሩ፡ Drew Houston፣ መስራታዊ-ሓባርን ሓባራዊ-CEO Dropboxን፣ Peter Steinbergerን፣ ፈጣሪ OpenClaw።

ከም’ቶም ኦርጅናል ሽምንተ መስራታዊ ደጋፍቲ፣ Drewን Peterን ነፍሲ ወከፍ 1 ሚልዮን USD የበርክቱ። እዚ ንፋውንዴሽን ዓሰርተ ደጋፍትን ንጹህ 10 ሚልዮን USDን ይህብ ድፍሩት ተልእኾና Linux ኣብ ዴስክቶፕ ብዝዓበየ መንገድ ንምፍጻም ንምድፋእ።

ብፍላይ ጣፋጭ እዩ Drewን Peterን ምስ’ህልዉ ምኽንያቱ ብውልቂ ዓቢ ደጋፊ ክልቲኦምን ውጽኢቶምን ነይረ። ጉይለት ዘለዎ ተጠቃሚ Dropbox ንዳርጋ ክልተ ዓሰርተታት ዓመታት ነይረ፣ ማእከላይ እዩ ከመይ no backup, no cry እናነበርኩ ኮምፒተራት ኩሉ ግዜ እናቐየርኩ ክነብር ከምእኽእል።

ስለዚህ Omarchy ምስ ድንቕ Dropbox ውህደት ካብ ሳንዱቕ ይመጽእ። ጥራይ Install > Service > Dropbox ሂድ፣ file manager ውህደትን ልዩ menu panel ንመቆጻጸሪታትን ክህልወካ እዩ።

OpenClaw ብመሰረቱ መደብ-መንገዲ ሂቡ ንከመይ Omarchy ፈንጂ ዕብየቱ ንምምሕዳር። PR backlogs ድንገት ሰማይ ምስ’ጠቅዑ ከመይ ትገብር? ደሕንነት ከባቢ plugins እንታይ? መገናኛታት ኣብ ስም ፕሮጀክት ከመይ ክሕንብኑ ይግብኦም? ሕጉስ ነይሩኒ ምኽሪ Peterን ተመኩሮኡን ኣብ ብዙሓት እዚ ጉዳያት ንምጥቃም።

ካብ’ዚ ናይላዕሊ፣ ክልቲኦም እቲ ዓይነት ቴክኒካዊ ምናብ ንOmarchy ከባቢ ምስ’ደሊ ይወክሉ። Drew ውልቃዊ ድሌት ፋይላት መንጎ ኮምፒተራት ምንቅስቃስ Dropbox ቆልዑ። Peter ናይ ሰሙን-መወዳእታ ፕሮጀክት OpenClaw ቆልዑ፣ ኣብ መንገድ ኩሉ ከመይ ጥምየት ኣሎ ኮምፒተራት ውልቃዊ፣ ፕሮግራም ዝገብር፣ ዝሕጉስ ዝስምዑ መዘኻኸሪ ሂቡ።

እዚ መንፈስ ድሕሪ Omacom Foundation’ውን እዩ። መሰረተ-ልማት፣ open-source ፕሮጀክታት፣ developers ምድጋፍ ንምግባር ኣብ’ዚ ኢና Linux ዴስክቶፕ ዝሕጉስ ገዛ ንዝመጽእ ወለዶ ተጠቀምቲ ኮምፒተር ንምግባር ዝድሊ።

እንቋዕ ብደሓን መጻእካ፣ Drewን Peter። ዓሰርተ መስራታዊ ደጋፍቲ። ዓሰርተ ሚልዮን USD። ትንቢት ሕጂ 2 ሚልዮን USD ቀረበ!
