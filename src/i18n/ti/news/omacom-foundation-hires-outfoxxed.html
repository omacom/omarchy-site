outfoxxed፣ ፈጣሪ Quickshell፣ ከም ሓላፊ Omarchy Shell እናቈጠርና! Omacom Foundation ሙሉእ-ግዜ ይጽንበር ኣባል Omarchy Core ይኸውን። ሰብ toolkit Quattro ዝከኣል ዝገብር ህንጹ ተጸንቢሩ ሙሉእ ነገር ናብ ጨወርታ ንምልኣኽ ንምሕጋዝ።

እዚ ሰለስተ-ዓመታዊ Quickshell sponsorship August ኣብ ኣወጅና ይትክእ። እቲ sponsorship ብምትካእ፣ outfoxxed ሙሉእ-ግዜ ሰራሕተኛ Omacom Foundation ክኸውን እዩ፣ ስራሕና ኣብ Omarchy Shell እናመራሕ። ፈጣሪ ጥቡቅ ማእከል እንህንጾ እናሓዝና።

Shell መዐንደሪ እዩ ኤጀንታዊ OS እንሰርሕ። ባር እዩ፣ ሜኑታት፣ መፍልጢታት፣ ዊጀታት፣ ንእሽተይ ምትእስሳራት ኩሉ ኮምፒተር ናትካ ዝስምዖ ይገብር። Quickshell ህንጻ ብሎኮች ይህብ ተመኩሮ QML ንምቅራጽ። ኤጀንትታት QML ጽሓፍ ኣዝዮም ጽቡቕ ምስ’ትውህድ፣ ድንገት ዴስክቶፕ ምቕያር ሕተት፣ ሞክር፣ ተካፈል ትኽእል ነገር እዩ።

መረጋገጺ plugins ኣሎ! sponsorship ኣወጅና፣ ማሕበረሰብ ቀድሞ ንላዕሊ ሽሕ Quattro ቀዳማይ ሰሙን ፈጢሩ ነይሩ። ሕጂ catalogue ዳርጋ ሰለስተ ሽሕ plugins ኣለዎ። ጸወታታት ካብ bar ቀጥታ ክትጻወት ትኽእል፣ panels coding agentsካ ዝከታተሉ፣ ሙዚቃ መጻወቲታት፣ እንኳ ድሙስ ኣብ barካ እናዘውር ምሕቅፋፍ እናተጸበየ። ሰባት system ጽኑዕ ዝስምዖ ነይሩ ወሲዶም ናትኦም እናገብሩ። ተዓጻጻፊ ኮምፒተር ሂወት እናመጸ እዩ።

ፈጣሪ Quickshell ምህላው ሙሉእ stack ብሓባር ስራሕ ንምግባር ማለት እዩ። shell ቀልጢፉ ዝያዳ እምነት ዘለዎ ንምግባር። ድንቕ plugin ምህናጽ ቀሊል ንምግባር። መሰረታት ምምሕያሽ plugin author ገደብ ምስ’ይርከብ። ካብ ኤሽሓት experiments እንመሃር ናብ ዝሓሸ ተመኩሮ ንነፍሲ ወከፍ Omarchy boot ዝገብር ንምለውጥ። ሙሉእ ነገር ደሓን ውሑስ ምኳኑ ንምርግጋጽ።

Omarchy Core ምጽንባር፣ outfoxxed መምርሒ distro ሙሉእ ንምውጻእ ክሕግዝ እዩ። Shell ንተመኩሮ ኣዝዩ ማእከላይ ድሕሪ-ሓሳብ ንምኳን። እዚ እዩ ብዙሕ ጽባቔ፣ ሕጉስ፣ ዕድላት ኤጀንታዊ OS ብሓቂ ርእይ ተጠቅም ዝኽእል ነገር ዝኾነሉ።

outfoxxed Omacom Foundation ካልኣይ ሙሉእ-ግዜ ቈጠራ እዩ፣ Krzysztof Wilczyński, ሓላፊ Omarchy Kernelና ተኸቲሉ። ሰባት Kernelን Shellን እናመሩ ምህላው፣ መሰረታት ሙሉእ ተመኩሮ እናውዕልና። ሰራሕተኛታት ፋውንዴሽን ኣብ ሳይት ተራኸብ ትኽእል።

ምቕጣር ብዕድመ ቀጺልና ትኽክል ሰባት ስራሕ ማሕበረሰብ እናረኸብና። (inboxየ CVs እናመልእ ኣይትግበር!)

እዚ እዩ ድጋፍ ፋውንዴሽን ስራሕ ንምግባር ዝፈቅድ፡ ልዩ open-source developers ግዜ ምሉእ ምእታው ንምግባር ምሃብ። ምስጋና እቲ ስራሕ ዝድግፍ ነፍሲ ወከፍ፣ ተወሳኺ ምናብና ናብ ሙሉእ-ግዜ ስራሕ ንምለውጥ።

እንቋዕ ብደሓን መጻእካ፣ outfoxxed! እዚ ኮምፒተር ዝያዳ ተዓጻጻፊ ንግበር!
