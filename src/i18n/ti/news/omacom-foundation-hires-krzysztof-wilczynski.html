Omacom Foundation ሕጂ ቀዳማይ ሙሉእ-ግዜ ቈጠራ ጌሩ! Krzysztof Wilczyński ስራሕና ኣብ Omarchy Kernel ንምምሕዳር ይጽንበር። እዚ እቲ እዩ ፋውንዴሽን ተዳልዩ ንምግባር፡ ድንቕ ሰባት ከበድቲ ጸገማት ንምስራሕ ምኽፋል ንረብሓ ነፍሲ ወከፍ።

Krzysztof ንነዊሕ Linux kernel developer እዩ። PCI Endpoint subsystem ብምትሕብባር ይሓልእ ምስ native PCI host bridgeን endpoint driversን። እዚ ቧንቧ እዩ Linux ንGPUካ፣ NVMe driveካ፣ WiFi cardካ ዝኣስር። reviewer’ውን እዩ ኣብ kernel ሓድሽ Rust PCI ስራሕ። ኣብ kernel ጥልቅ ምኻድ ቅድሚ፣ ዓመታት ኣብ systems engineering እናሰርሐ፣ Kubernetesን container runtimesን እናሰርሐ።

ሕጂ ተመኩሮ ኩሉ ናብ Omarchy Kernel የምጽእ። ትኹረት፡ performance, compatibility, security። Linux ኣብ ሓደሽቲ ላፕቶፖች ጥንታዊ ThinkPads ብፍጥነት ንምስራሕ ንደሊ። ካብ ሳንዱቕ ኣብ ተወሳኺ ማሽናት ስራሕ ንምግባር ንደሊ። ጽኑዕ ደሓን ንምግባር ንደሊ።

Krzysztof Omarchy Core’ውን ይጽንበር፣ መምርሒ distro ሙሉእ ንምውጻእ ክሕግዝ እዩ።
