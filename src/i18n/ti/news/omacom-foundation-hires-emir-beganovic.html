Emir Beganović ከም ሓላፊ መሰረተ-ልማት ንOmarchy እናቈጠርና! November 1 ይጀምር ከም Omacom Foundation ሳልሳይ ሙሉእ-ግዜ ቈጠራ፣ Krzysztof Wilczyński ኣብ Kernelን outfoxxed ኣብ Shellን እናተጸንበረ።

ከምዚ Emir ገዛእ ጉዕዞኡ ናብ Omarchy ይገልጾ፡

ፍቕርየ Linux ንላዕሊ ዓስራይ ዓመታት ይምለስ። Ubuntu developer ኮንኩ ጎርመስቲ እናኾንኩ ኣብ local ማሕበረሰብ ጥልቅ ተሳቲፈ። ስራሕ-ህይወትየ ሰለስተ ሃገራት ወሲዱኒ፣ እምነት-ጥንካሬን ፍጥነትን startupsን scaleupsን እናሰርሕኩ ጉጅለታት እናመራሕኩ። ዳርጋ ሸውዓተ ዓመታት ኣብ Booking.com SRE department እናሰርሕኩ፣ build systemsን CI infrastructureን ስራሕ እናመራሕኩ። ኣብ መወዳእታ Isorun ህንጸ፣ microVMs, snapshots, isolation, scheduling, disposable compute እናሰርሕኩ። ሕጂ ተመኩሮ ናብ ቀዳማይ ፍቕሪይ እናመልስ እየ።

ብሓቂ ትኹረትየ ብዛዕባ Emir TryOmarchy ተታሒዙ። Omarchy ዴስክቶፕ ወሲዱ browser ኣእትዉ (ዳግም-ትግብራ ኣይኰነን፣ ሓቀኛ ነገር ግን)፣ ኣብ ተራ CPU infrastructure Cloudflare ኣብ ውሽጢ ሰከንድታት boot እናገብር ነይሩ። እቲ ንእሽተይ experiment ብዛዕባ ምዝርራብ ጀሚርና፣ ውይይት ቀልጢፉ ሰፍሐ ንላፕቶፖች፣ ሓደሽቲ architectures, OEMs, infrastructure Omarchy ኣብ ዝኾነ ንደልዮ ምስራሕ ንምግባር ንድሊ። ሓደ ራእይ ንካፈል ተረዲእና።

እዚ እዩ Emir ተጸንቢሩ ንምምሕዳር።

መሰረተ-ልማት ንOmarchy servers ምስራሕ ንላዕሊ ብዙሕ ማለት እዩ። Omarchy ምህናጽ፣ ምፍታን፣ ምልኣኽ ንምግባር እንጥቀሞ፣ ሲስተም ብእምነት ስራሕ ንምሕላው ተወሳኺ ሃርድዌርን architecturesን እናስፋሕና። ውጽኣት እምነት ዘለዎም ምግባር፣ ውድቀት ዳግም-ምፍጣር ዝከኣል ምግባር፣ ፕሮጀክት ነፍሲ ወከፍ ካልእ ጠንካራ መሰረት ምሃብ ቀልጢፉ ንምንቅስቃስ።

ተወሳኺ ምድህሳስ ንምግባር ኣሎ! Omarchy ኣብ ማሽን ኣብ deskካ ብጽቡቕ ስራሕ ክገብር ይግብኦ፣ ግን ምኽንያት የለን ኣብ’ዚ ንምቁም። TryOmarchy ሓጺር ርእይት ሂቡና Linux computer ምጅማር ከም web page ምኽፋት ቀሊል ምስ’ኾነ እንታይ ይኸውን፣ ጣዕሚ Linux ጥራይ ሓደ ጠውቕ ርሑቕ እናሓዘ። ኣበይ ከም’የመርሕ ንርኢ ኢና።

ምስጋና ንእዚ ስራሕ ዝድግፍ ነፍሲ ወከፍ፣ ከም Emir ሰባት ግዜ ምሉእ ምእታው ኣብ Omarchy ንምግባር ክንህብ ንኽእል። ደጋፍትና ድፍሩት experiments ናብ ዘለኣለማዊ ስራሕ ንምለውጥ ዝከኣል ይገብሩ፣ ሙሉእ-ግዜ ሰባት ሙሉእ ሲስተም ዝሓይሽ ንምግባር ዝተወፈዩ። ንደጋፎም የቕንየልና።

እንቋዕ ብደሓን መጻእካ፣ Emir! Omarchy ኣብ ዝኾነ ስራሕ ንግበር።
