ዝመና, September 9, 2026: ስፖንሰርሺፕ ተተኪኡ outfoxxed Omacom Foundation ሙሉእ-ግዜ ሓላፊ Omarchy Shell ኣባል Omarchy Core ምጽንባር።

ተወሳኺ ገንዘብ ኣቱ, ተወሳኺ ገንዘብ ወጻኢ! ካልኣይ ዓቢ ስፖንሰርሺፕ Omacom Foundation outfoxxed ድንቕ ስራሕ Quickshell እናኸይድ እዩ። ህዝባዊ ውጽኣት ሰሙን ጥራይ ክፋል ነይሩ, ብሉጽ ግልጽ ዝጎደለ, መዐንደሪ ክፋል ብሓቂ The Malleable Computer ምርካብ።

መረጋገጺ plugins ኣሎ! ሽሕ plugins ንላዕሊ ሰሙን Quattro ወጻኢ ተፈጢሮም። ሙሉእ ብሙሉእ ዝገርም ምስክርነት ቴክኒካዊ ተዓጻጻፍነት Quickshell, ኤጀንትታት QML code ጽሓፍ ፍቕር።

ስፖንሰርሺፕ ስለዚህ outfoxxed ልዑኽ ኣበርክቶ Omarchy ሽልማት, ነዊሕ-ጊዜ መደባት The Age of Agents ርክብ ምጽናሕ ንምሕጋዝ (Bluesky ምልጣፍ ኣይትግበር, ይሓኑ!)። ካብ መጀመርታ ሰለስተ ዓመታት ተቐሚጡ እዩ።

እንደገና, ልዩ ምስጋና Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, Peter Steinberger እዚ ዝከኣል ንምግባር። Oligarchy እንተዘይኰይኑ, open-source developers ምድጋፍ ምግባር ኣይንኽእልን!
