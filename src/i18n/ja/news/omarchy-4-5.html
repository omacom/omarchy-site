Omarchy 4.5（別名 Quattro RS!）は、Quattro以来初の大型機能リリースで、とにかく盛りだくさんです。わずか12週間で180人以上のコントリビューターから740件以上のプルリクエストがマージされました。タイル型がデフォルトの隣に、従来型のデスクトップモードも選べるようになりました。M1/M2/M3/NeoのMacBookにネイティブインストールできます。そして50言語に対応。さらに数え切れないほどの新機能、修正、改善が入っています。すでにOmarchyを使っている方は、Update > Omarchyを実行してください。新しいマシンですか？こちらから入手してください。

ドック付きフローティングワークスペース

Super + Lで、ワークスペースをタイル、スクロール、フローティングの間で切り替えられるようになりました。フローティングワークスペースでは、すべてのウィンドウにテーマカラーのタイトルバーが付き、ドックにはピン留めしたアプリ、実行中のすべてのアプリ、インストール済みのすべてのアプリのグリッドが表示されます。ドラッグで並べ替えやピン留めができ、右クリックでさらに操作でき、Super + Mでウィンドウをドックに最小化できます。

これは、まだタイル型に完全移行する準備ができていない、macOSやWindowsから来た人にとって素晴らしい入口です。ウィンドウを広げて使えるワークスペースを1つだけ持ちたい人にもぴったりです。ワークスペースごとに組み合わせて使え、バーには各ワークスペースがどのレイアウトを使っているかが表示されます。

Apple Silicon上のOmarchy

素晴らしいOmarchy Mチームが、Mac用ネイティブインストーラーをリリースしました。macOSでアプリをダウンロードすれば、M1、M2、M3、NeoのMacBookでmacOSと並べてOmarchyを入れられます。USBメモリも、ターミナルの呪文も不要です。Homebrewがお好みですか？それなら1行です：

brew install omacom/mac/omarchy

これは9月にやろうと決めたこと、つまりAsahiが始めたことを完成させることです。2か月後には、ただダウンロードするだけで使えるようになりました。チームのみんな、本当にすごい仕事です。

そして、ここで止まるつもりはありません。M4、M5、M6にも現在取り組んでいるので、OmarchyがすべてのApple Silicon Macで動くようになるのも、おそらくそう遠くないでしょう。

NVIDIA DGX Spark + N1X向けARMサポート（近日中にSnapdragonにも対応）

Omarchy 4.5では初のARM ISOが登場し、NVIDIAのARMマシンへの予備サポートが加わりました。DGX Sparkデスクトップや、Dell XPS 16 Creator EditionやASUS ProArt P14のようなN1X搭載ノートPCが対象です。さらに近日中には、Snapdragon ARMマシンの全ラインナップにも対応する予定です。まだ初期段階なので、少し荒い部分があるかもしれません。何か壊れたらGitHubで報告してください。

50言語と5つの入力方式

Omarchyは50言語に対応しました。Setup > Languageで選ぶか（またはomarchy language <code>を実行すると）、メニュー、デスクトップ、Omarchyの通知がすぐに切り替わります。システムロケールは次回ログイン時に追随します。

言語を話せるのは半分にすぎません。入力もできなければなりません。そこでOmarchyは、日本語（Mozc）、韓国語（Hangul）、簡体字中国語（Pinyin）、台湾向け（Zhuyin）、香港向け（Cangjie）の適切な入力方式を、インストーラーから、または後からSetup > Keyboardで設定できるようになりました。それぞれの文字形式に合ったフォントが付属し、候補ウィンドウはテーマに追随し、Super + Iで入力言語を切り替えます。Hangul、Zhuyin、Cangjieは、Dvorak、Colemak、AZERTYでラテン文字を入力していても、WindowsやmacOSと同じようにキーが標準位置に保たれます。そしてShiftを単独でタップすると、Sogou、Microsoft Pinyin、macOSのように、入力方式からラテン文字へ抜けて、また戻れます。

キャプティブWi-Fiポータルへのサインイン

ホテル、空港、コーヒーショップのWi-Fiが、ついにそのまま使えるようになりました。ネットワークがオンラインになる前にサインインや規約への同意を求めていることを、Omarchyが検知するようになりました。ネットワークアイコンが警告を表示し、ネットワークパネルには大きなOpen Captive Portalボタンが表示され、ログインページへ直接移動できます。通過すれば、すべて自動的に通常に戻ります。

5つの新しいデフォルトアプリ

Hypeは、1つのMarkdownファイルからプレゼンテーションを作ります。ソースの横にビジュアルなスライドエディターがあり、PDFやPowerPointにエクスポートできます。

Signedは、書類仕事向けにXournal++を置き換えます。PDFを開き、保存済みの署名、テキスト、日付を配置して、署名済みコピーを保存できます。

Disktreeは、ディスクを埋めているものをツリーマップで描き、種類ごとに色分けし、安全に再生成できるキャッシュを指摘して、削除すべきものをマークできます。

Monologueは、キー1つでカメラを録画し、デスクトップに合わせてテーマが適用されます。

GliffはSSH経由のリモートデスクトップを提供します。別のOmarchyマシンに接続し、そのデスクトップ全体を自分のウィンドウから操作でき、マシンごとにタブが分かれます。SSHに乗っているので、追加で設定したり公開したりするものは何もありません。操作される側のマシンでは、バーの中にリモートセッションインジケーターが表示されるので、誰かが接続していることが常に明確です。

そしてElsewhenもあります。バーの時計のすぐ隣に住む世界時計です。地球儀上の都市をタップして自分の場所を設定し、実在の場所を検索し、各都市に住む人々に名前を付けられるので、電話するのにちょうどいい時間かどうかがいつでも分かります。tで12時間と24時間を切り替え、Alt + Tで°Fと°Cを切り替え、Super + Ctrl + Alt + Eでいつでも呼び出せます。

Monologueが録画用、Omacutがトリミング用にあるため、新規インストールにはOBS StudioとKdenliveが同梱されなくなりました。Lazydockerも新規インストールからなくなりましたが、DockerとDocker Composeは引き続き含まれます。すでにいずれかを持っているマシンでは、そのまま残ります。

Microsoft 365

Officeで生きている人たちと仕事をする必要がありますか？Install > Service > Microsoftで、Outlook、Word、Excel、PowerPoint、Teams、OneDriveをWebアプリとして設定できるようになりました。それぞれ専用のウィンドウとランチャーエントリーを持つので、他のすべてと並んでも違和感がありません。職場でOmarchyに切り替えない言い訳は、もうありません！

音声入力のためのSuperwhisper

SuperwhisperがOmarchyのデフォルトの音声入力エンジンになり、最初から設定済みです。Alt + Spaceをタップして話し始め、もう一度タップして止めるか、Right Altを押し続けてプッシュ・トゥ・トークできます。信じられないほど速く、とても正確です。

最初はクラウドで動作するので、インストールした瞬間から使え、最初の10,000語は無料です。でも、完全に無料で、誰にも一言も送らずに完全にローカルで動作する、ダウンロード可能なモデルに切り替えることもできます。別のローカルモデルの方がいい場合は、代替としてVoxtypeも引き続き利用できます。

10秒未満でインストール

Omarchyは以前、約940個のパッケージを1つずつインストールしていました。新しいF1インストーラーは代わりに、ビルド済みのルートイメージを展開し、その上にこのマシン専用のパッケージだけを追加します。これで、どのマシンでもインストール時間がおよそ半分に短縮されます。

そして高速なハードウェアでは、もはや非常識な速さです。AMDのAnush Elangovanさんは、自分のAMDノートPCでOmarchyのフルインストールを7秒で完了し、世界記録を樹立しました。7秒です！5分でさえ野心的な目標に思えた頃を覚えています。

他のあらゆる場所でも高速に

速くなったのはインストーラーだけではありません。起動時にbinfmt登録で止まることがなくなりました。テーマピッカーは0.25秒後ではなく、すぐに開きます。メニューとパネルはHyprlandのショートカットから直接開き、最初にプロセスを起動するのにかかっていた60ミリ秒を省略します。Omarchyメニューの最も遅いチェックは200ミリ秒から16ミリ秒になり、新しいターミナルはプロンプトが30ミリ秒早く表示され、デスクトップ全体がポーリングではなく変化に反応するようになりました。ログアウト、再起動、シャットダウンでさえ、アプリが閉じ終わった瞬間に行われます。

エージェントのアップグレード

OmarchyはエージェントのためのOSであり、4.5ではエージェントと協働するための大規模なアップグレードが入りました。エージェントパネルは6から増えて23のエージェントとプロバイダーを追跡するようになりました。Cursor、OpenCode、GitHub Copilot、Antigravity、Hermes、Amp、Kiro、Devin、Qwen、DeepSeek、OpenRouter、Ollamaなどが含まれます。すべての制限にはリセットまでの時間付きの専用メーターがあり、残りの余裕が正確に分かります。そしてGrokは、ClaudeやCodexと並ぶ正式なプロバイダーになりました。

そして、エージェントはいつでもキー1つで呼び出せます。Super + ~で、暗くしたデスクトップの上にQuake風コンソールが降りてきて、初めて開いたときにはデフォルトのエージェントが起動します。もう一度押せばしまわれ、セッションは離れたときのまま残ります。

複数のサブスクリプションを使い分けている場合は、同じマシン上に複数のClaude、Codex、Grokのログインを保持し、omarchy agent accountを使って新しいセッションがどれで始まるか選べるようになりました。履歴、設定、スキルはそれらの間で共有されるので、切り替えた後もclaude --continueで離れたところからそのまま再開できます。制限に近づくと、Omarchyはワンクリックでの切り替えを提案するか、最も余裕のあるアカウントへ新しいセッションを自動的に移します。そして別のマシンをセットアップするときは、omarchy agent account copyがSSH経由でログインをすべて持ってきてくれるので、すべてに再度サインインする必要がありません。

OpenRouterのエージェントハーネスであるKimiとOriが、Setup > Defaults > Agentの選択肢に加わり、GoogleのAntigravityが旧式のGemini CLIを置き換えます（geminiはエイリアスとして引き続き使えます）。ターミナルよりウィンドウがいいですか？ClaudeとAmpのデスクトップアプリが、Install > AIからクリック1つで使えるようになりました。

通知、生まれ変わりました

通知は送信者ごとに積み重なり、テーマに追随し、同一の繰り返しは折りたたまれます。アクションボタン、認証コード、リンクはすべてカードから直接使えます。Super + Commaは最新のものに作用し（閉じる、開く、またはそのボタンを押す）、Super + Ctrl + Commaはキーボードですべてを操作できるようにします。バーのベルでDo Not Disturbをオンにします。

動画背景とテーマイントロ

背景に動画が使えるようになりました。1つ放り込むだけで、打ち寄せる波でも何でも好きなものでデスクトップが生き生きとし、ロック画面にはその静止フレームが表示されます。そしてテーマが登場演出を持つようになりました。各テーマは、ログインしたときや切り替えたときに、短い無音のイントロを再生できます。（落ち着いた方がいいですか？Appearance > Animationsでイントロをオフにしてください。）

Jade Horseがデフォルトテーマに仲間入り

Jade Horseは霧がかった緑で統一され、彫刻された翡翠の背景でデスクトップ全体が掛け軸の絵のように見えます。同梱テーマの中でOsaka Jadeを置き換え、もう1つの新しいデフォルトテーマであるStarshipとともに加わります。Osaka Jadeを使っている方は自分のコピーをそのまま保持でき、それはサードパーティテーマとして生き続け、新規にインストールしたい人も使えます。

Liftoffが新しいデフォルト背景に

新規インストールでは、Tokyo Nightの新しいデフォルト背景である、美しい夕日の打ち上げ、Liftoffが迎えてくれます。これはTom Ballardさんが作ったもので、最初は自身のLiftoff themeのために作られました。ありがとう、Tom！

ブートメニューが静かになりました

Omarchyは以前、万が一以前のスナップショットにロールバックする必要があった場合に備えて、起動のたびにブートメニューを約6秒間表示していました。でも、実際にそうする人はほとんどいませんでした。そこで今ではLimineは1秒だけ待って静かに起動し、ほとんどの場合はメニューがまったく見えません。

別のエントリーやスナップショットが必要なときは、マシンの起動中に任意のキー（下矢印でも可）を連打し続ければ、メニューで止まります。メニューをずっと長く表示しておきたい場合は、/boot/limine.confに自分でtimeout:を設定してください（例：timeout: 5）。アップデートで、設定したタイムアウトが変更されることはありません。

変更されたホットキー

一部のショートカットが移動しました：

  • 電卓：Super + Ctrl + QがSuper + Shift + Qになりました。
  • アクティビティ：Super + Ctrl + TがSuper + Shift + Tになり、Super + Ctrl + Tはテーマを開きます。
  • ネットワーク：Super + Ctrl + WがSuper + Ctrl + Nになり、Super + Ctrl + Wは背景を開きます。
  • Nightlightにはショートカットがなくなりました（以前はSuper + Ctrl + Nでした）。Trigger > Toggleの中にあります。
  • Super + Alt + Spaceは、AppsメニューではなくドックからAppsを開きます。

通知のショートカットが変更されました：

  • Super + Commaは、最新のカードを閉じるだけではなく、そのカードに作用します（閉じる、開く、またはその1つのボタンを押す）。
  • 最後のものを閉じる操作はSuper + Alt + Commaに移動しました。これは以前は開く操作でした。
  • 無音化はSuper + Ctrl + CommaからSuper + Ctrl + Alt + Commaに移動しました。Super + Ctrl + Commaはキーボード操作を受け渡すようになりました。

いくつかのキーの動作が変わりました：

  • Super + Tab、Super + Shift + Tab、Super + Ctrl + Tab、そしてSuper + スクロールは、モニターごとに独自のワークスペースがあるため、現在のモニターのワークスペース内にとどまります。
  • ターミナルでは、Super + CとSuper + Vが、Ctrl + InsertとShift + Insertの代わりにCtrl + Shift + CとCtrl + Shift + Vを送ります。

自分のバインディングと競合する可能性のある新しいデフォルト：Super + Q（ウィンドウを閉じる、Super + Wと併用）、Super + A（すべて選択）、Super + M（ドックに最小化）、Super + ~とSuper + Shift + ~（Quakeコンソール）、Super + Alt + L（前のレイアウト）、Super + Shift + Ctrl + Arrows（ウィンドウを別のモニターに移動）、Super + Ctrl + Alt + C（スクリーンショット）、Super + Ctrl + Alt + E（世界時計）、Super + Ctrl + Alt + F（フルスクリーンデスクトップ）、そしてプッシュ・トゥ・トーク音声入力のためのRight Alt長押し。
