Omarchyに公式のHackerOneでのバグバウンティプログラムができました！Omacom Foundationが$100,000の報奨金を拠出してくれたので、実際の脆弱性を見つけて非公開で報告してくれたリサーチャーに、その仕事に対して報酬をお支払いできるようになります。

HackerOneは、リサーチャーにとって発見内容を提出したり、修正作業の進捗をフォローしたり、報奨金を受け取ったりするための使い慣れた場所になります。また、Omarchy Security Teamにとっても、寄せられる報告をトリアージするための正式なワークフローになります。HackerOneのアカウントを作りたくない場合は、security@omarchy.orgにメールしていただいても構いません。何を脆弱性とみなすか、報告方法の詳細はセキュリティページにまとめています。

この取り組み全体を率いてもらうため、Mehmet İnceがOmarchy Coreに僕たちのセキュリティ責任者として加わってくれることを発表できてとても嬉しいです！MehmetはこれまでOmarchy Security Teamの中心メンバーとして活躍してきましたが、これからはバグバウンティプログラムの運営から、出荷するすべてのものにセキュリティが組み込まれるようにすることまで、Omarchyを安全に保つための方向性を定めていきます。

パトロンの皆さんのおかげで、Omarchyをセキュアにすることに本物のお金を投じることができます。皆さんのパトロネージに心から感謝します。

Omarchy Coreへようこそ、Mehmet！Omarchyを美しいのと同じくらい安全にしていきましょう。
