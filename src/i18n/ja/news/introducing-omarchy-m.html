Apple は素晴らしいハードウェアを作る。昔からずっとそうだ（あのバタフライキーボードの一件を除けば）。そして Omarchy にやって来る人の多くは Mac からの乗り換え組だ。その多くが「マシンはそのままに、OS だけ入れ替えたい」と思っている。だから Asahi が始めたことを僕らが仕上げる：Apple Silicon 上で Omarchy を美しく動作させ、セットアップの手間は最小限に。

この取り組みにはすでにチームがいる。今日、それを正式なものにする：Omarchy M、Apple Silicon 搭載 Mac のためのチームだ（古い Mac を支え続けるメンバーも数名含めて）。

メンバーを紹介しよう。

インストーラー。 Marcelo Alcantara がネイティブ Mac インストーラーを開発中だ。macOS 上でアプリをダウンロードすると、署名済み Omarchy リリースを取得し、パーティションを切り分け、既存の macOS と並んで Omarchy を起動してくれる。USB メモリも、ターミナルでのおまじないも不要だ。USB-C 経由で外部モニターを点灯させたビルドを作ったのも彼だ。

Omarchy Mac。 Naeem Malik がOmarchy Mac を1年間メンテナンスし、まだ正式になるずっと前から Omarchy を M1 と M2 マシンに載せ、800 人超の Discord コミュニティを育ててきた。Scott Jones はそのプロジェクトの Linux 側インストールを担うもう一人の立役者だ。最近では M3 Air のディスプレイを Apple のハードウェア・ディスプレイ・コントローラー上で動作させ、一晩でそのマシンを使い物にならない状態から使える状態にした。

Try Omarchy。 Eduardo Martinez が作ったTry Omarchy は、本物の Omarchy デスクトップが Mac 上でネイティブのハードウェア・アクセラレーション対応アプリとして動き、カメラ、オーディオ、クリップボード、共有フォルダーまでつながっている。パーティションを切る必要はない。ダウンロードすれば、何が話題なのかすぐに分かる。

パッケージ。 Shun Li が Omarchy に必要なすべてがaarch64 パッケージとして存在するよう整備している。仮想マシン用の汎用 ARM64 ディスクイメージや、それを快適に使うためのゲストツールも含めて。

ドライバーとカーネル。 Ryan Murray が Neo の立ち上げと、チーム全体の土台作りを担っている。M4 以降のチップ上で macOS をトレース可能にする SPTM エミュレーターを開発中だ。そのトレースはディスプレイ、GPU、オーディオ、無線、Bluetooth を動かすために不可欠だ。Dj は GPU ドライバーを書いており、Secure Enclave と直接通信することで Touch ID を動作させた。Miguel Cruz は M5 を専門とし、Apple 独自の N1 チップをリバースエンジニアリングして Linux 上で Wi-Fi と Bluetooth を動かした。Neo 上でのハードウェア・ビデオのエンコード・デコード、Bluetooth、デスクトップ改善にも貢献している。Liam は Neo のトラックパッド、電源管理、スピーカー、ヘッドフォン出力を立ち上げ中で、Ryan の macOS トレースが重要な土台を提供している。Eryk Wieliczko は M4 サポートとクリーンルーム実装をメンテナンスし、統合とパッケージングを担当している。Jaidip Subedi はM2 MacBook Air での USB-C 経由外部ディスプレイを実現した。

MLX。 Joshua Warren が作っているmlx-omarchy は、Apple の MLX 機械学習フレームワークを Vulkan 経由で Apple GPU 上の Linux にもたらす。コードは相変わらず import mlx.core as mx のまま、でも今度は Omarchy 上で動く。

古い Mac。 Shawn Yeager は 2016 年と 2017 年の Touch Bar MacBook Pro 向けに大量のプルリクエストを抱えている：スピーカー、Wi-Fi、環境光センサー、そして Touch Bar 自体。Randy は T2 セキュリティチップをリバースエンジニアリングして Intel Mac に Touch ID をもたらそうとしており、その過程で 2019 MacBook Pro 向けのあらゆる修正を文書化している。Jon Kinney は 1 年前に Omarchy の ARM 対応にこつこつ取り組んでいた人物で、今はチーム全体の誰が何をやっているかの調整役だ。

総じて、恐るべき布陣だ。許可を待たなかった 15 人。エージェントを活用して、1 年前なら馬鹿げていると思えたはずのペースで進んでいる。

最初のリリースの目標は、Pro と Max バリアントを含む M1 と M2 との完全な互換性だ：

  • シームレスなインストーラー（インストールと試用の両オプション付き）
  • 完全な GPU サポート
  • USB-C 経由の外部モニター
  • Touch ID
  • MLX
  • ディスク暗号化

新しいマシンにも並行して取り組んでいるが、まず旗を立てるのは M1 と M2 だ。M マシンに加えて、世の中には何百万台ものビンテージ・ラップトップがあり、その多くはすでに Apple の最新 macOS の対象から外れている。そんな 1 台 1 台が、素晴らしい Omarchy マシンになる日を待っている。

始めるのに洗練されたリリースを待つ必要はない。Try Omarchy なら数分で Mac 上に本物のデスクトップが現れる。本気で行く覚悟ができたら、インストーラーが今日にでも M1 や M2 上に macOS と並んで Omarchy を入れてくれる。

最後にお願いだ。Apple ハードウェア向け Linux に取り組んできた人、カーネルドライバーでも、ファームウェアでも、パッケージングでも、インストーラーでも、機械学習でも、ぜひ連絡してほしい。あなたが解いた問題を僕らがまだ追いかけている可能性は高いし、その逆もある。apple@omarchy.org まで連絡を。

Asahi が始めたことを仕上げよう。
