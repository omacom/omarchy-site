Omarchyをx86の先へ広げるために最も力を尽くしている2人が、Omarchy Coreに加わります：Marcelo AlcantaraとBirk Skyumです！

Marcelo Alcantara

9月にOmarchy Mを紹介したとき、MarceloはネイティブなMacインストーラーを作っている人でした。それ以来、彼は取り組み全体を取りまとめる存在になっています。世界中から集まった16人が、GPUドライバーやディスプレイからTouch ID、インストーラーそのものまで、スタックのさまざまな層にそれぞれ取り組んでいます。みんなが同じ方向を向いて進めるようにするまとめ役が誰か必要ですが、Marceloがまさにその役割を担ってきました。

その成果はOmarchy 4.5でリリースされました。今ではmacOSでアプリをダウンロードする（またはbrew install omacom/mac/omarchyを実行する）だけで、M1、M2、M3、またはNeoのMacBook上で、macOSと並べてOmarchyを導入できます。USBメモリも、ターミナルでの呪文のような操作も不要です。チームの発表からわずか2か月で「ただダウンロードするだけ」までたどり着いたのは、驚くべき速さです。

これはOmarchy Mの全員のおかげです：Scott、Chris、Naeem、Dj、Joshua、Eduardo、Shun、Ryan、Miguel、Liam、Eryk、Jaidip、Shawn、Randy、Jon、そしてMarcelo。みなさんはAsahiが始めたことを完成させ、すでにM4、M5、M6へと取り組みを進めています。ありがとうございます！

Birk Skyum

Birkは9月、Lenovo Yoga Slim 7xを携えてOmarchy Dragonに参加しました。Arch Linux ARM、libcamera、PipeWire、systemd、カーネルへのアップストリームの修正実績を持つ人です。それ以来、Snapdragonラインナップ全体のブリングアップの調整役を担っています。つまり、マシンを集め、それぞれで何が動き、何が動かないかを見極め、修正がみんなの役に立つ形で取り込まれるようにすることです。

4.5のARM関連の取り組みのあちこちに、すでに彼の手の跡が見えます：アップデートのたびに出ていた無意味な再起動の促しがなくなり、SnapdragonノートPCでカメラがログイン時に表示されるようになり、アプリはARMで実際に動作するかどうかによって表示（または非表示）されるようになりました。でも、これはまだ始まりにすぎません。Birkは、サポート対象のすべてのSnapdragonマシンがそのまま動くようになる今後のリリースに向けて取り組みを進めています。スリープ、バッテリー、ビデオ、カメラ、そのすべてです。それが基準であり、彼がその基準を確実にクリアできるようにしているのです。

ようこそ！

Omarchyはあらゆる主要プラットフォームで美しく動作するようになります。そしてCoreには、それを実現している人たちが必要です。MarceloとBirkはまさにそれをやってきました。今回、それが正式になりました。

Omarchy Coreへようこそ、MarceloとBirk！
