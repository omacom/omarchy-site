Omarchy を x86 の先へ進めるために最も尽力している 2 人が、Omarchy Core に加入します：Marcelo Alcantara と Birk Skyum です！

Marcelo Alcantara

9月にOmarchy M を紹介したとき、Marcelo はネイティブな Mac インストーラーを作っていた人物でした。それ以来、彼は取り組み全体をコーディネートする人になりました。世界中から集まった 15 人が、GPU ドライバーやディスプレイから Touch ID やインストーラー自体まで、スタックの異なるレイヤーにそれぞれ取り組んでいます。誰かが全体を同じ方向へ引っ張り続けなければならず、Marcelo がその役を担ってきました。

その成果は Omarchy 4.5 で出荷されました。今では macOS でアプリをダウンロードする（または brew install omacom/mac/omarchy を実行する）だけで、M1、M2、M3、あるいは Neo MacBook 上で macOS と並べて Omarchy を導入できます。USB スティックは不要、ターミナルの呪文も不要です。チーム発表から「ただダウンロードするだけ」まで 2 か月というのは、信じられないペースです。

これは Omarchy M の全員の大きな功績です：Naeem、Scott、Eduardo、Shun、Dj、Ryan、Miguel、Liam、Eryk、Jaidip、Joshua、Shawn、Randy、Jon、そして Marcelo。あなたたちは Asahi が始めたことを完成させ、すでに M4、M5、M6 へと進んでいます。ありがとうございます！

Birk Skyum

Birk は 9月に Omarchy Dragon に参加しました。Lenovo Yoga Slim 7x を携え、Arch Linux ARM、libcamera、PipeWire、systemd、カーネルへの上流修正の実績を持っての参加でした。それ以来、彼は Snapdragon ラインナップ全体のブリングアップのコーディネートを引き受けています。つまり、マシンを集め、それぞれで何が動いて何が動かないかを見極め、修正がみんなの役に立つ形で反映されるようにすることです。

4.5 の ARM 関連の作業のあちこちに、すでに彼の痕跡が見られます：更新のたびに出ていた意味のない再起動プロンプトはなくなり、Snapdragon ノート PC でカメラがログイン時に表示されるようになり、ARM で実際に動くかどうかに基づいてアプリが提示されたり（あるいは隠されたり）します。しかし、これはまだ始まりにすぎません。Birk は、サポートするすべての Snapdragon マシンがそのまま動く今後のリリースに向けて、取り組みを主導しています。スリープ、バッテリー、ビデオ、カメラ、そのすべてです。それが基準であり、彼が私たちがその基準をクリアすることを確実にしているのです。

ようこそ！

Omarchy はすべての主要プラットフォームで美しく動くようになり、Core にはそれを実現している人たちが必要です。Marcelo と Birk はまさにそれをやってきました。今、それが正式になりました。

Omarchy Core へようこそ、Marcelo と Birk！
