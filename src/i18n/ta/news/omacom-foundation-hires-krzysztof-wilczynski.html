Omacom Foundation தனது முதல் முழுநேர ஊழியரை நியமித்துள்ளது! Krzysztof Wilczyński, Omarchy Kernel பணியை வழிநடத்த எங்களுடன் இணைகிறார். அனைவரின் நலனுக்காகக் கடினமான சிக்கல்களில் பணியாற்றச் சிறந்த மனிதர்களுக்கு ஊதியம் வழங்குவதுதான் இந்த அறக்கட்டளை உருவாக்கப்பட்டதன் நோக்கம்.

Krzysztof நீண்டகால Linux kernel உருவாக்குநர். PCI Endpoint துணை அமைப்பையும், native PCI host bridge மற்றும் endpoint இயக்கிகளையும் இணைந்து பராமரிக்கிறார். Linux-ஐ உங்கள் GPU, NVMe இயக்கி, WiFi அட்டை ஆகியவற்றுடன் இணைக்கும் அடித்தளப் பணிகள் இவை. Kernel-இன் புதிய Rust PCI பணிக்கான மதிப்பாய்வாளராகவும் உள்ளார். Kernel பணியில் ஆழமாக ஈடுபடுவதற்கு முன்பு, Kubernetes மற்றும் container runtime-கள் தொடர்பான கணினி அமைப்புப் பொறியியலில் பல ஆண்டுகள் பணியாற்றியுள்ளார்.

இப்போது அந்த அனுபவம் அனைத்தையும் Omarchy Kernel-க்குக் கொண்டுவருகிறார். கவனம்: செயல்திறன், இணக்கத்தன்மை மற்றும் பாதுகாப்பு. புத்தம்புதிய மடிக்கணினிகளிலும் பழைய ThinkPad-களிலும் Linux பறக்க வேண்டும் என்பதே எங்கள் விருப்பம். மேலும் பல கணினிகளில் நிறுவியவுடனேயே இயங்க வேண்டும். பாதுகாப்பும் இறுக்கமாக இருக்க வேண்டும்.

Krzysztof Omarchy Core குழுவிலும் இணைகிறார். எனவே ஒட்டுமொத்த விநியோகத்தின் திசையை நிர்ணயிக்கவும் உதவுவார்.

வரவேற்கிறோம், Krzysztof! Kernel-ஐ அதிவேகமாக்குவோம்.
