Emir Beganović-ஐ Omarchy-க்கான உள்கட்டமைப்புத் தலைவராக நியமிக்கிறோம்! அவர் நவம்பர் 1 அன்று Omacom Foundation-இன் மூன்றாவது முழுநேர நியமனமாக பணியைத் தொடங்குகிறார், Kernel பணியில் Krzysztof Wilczyński-உடனும் Shell பணியில் outfoxxed-உடனும் இணைகிறார்.

Emir தனது Omarchy பயணத்தை எப்படி விவரிக்கிறார் என்பது இங்கே:

Linux மீதான என் காதல் இருபது ஆண்டுகளுக்கும் மேலாகத் தொடர்கிறது. பதின்ம வயதிலேயே Ubuntu developer ஆனேன், உள்ளூர் சமூகத்தில் ஆழமாக ஈடுபட்டிருந்தேன். Startups மற்றும் scaleups நிறுவனங்களில் reliability மற்றும் performance துறையில் பணியாற்றி, குழுக்களை வழிநடத்தி, என் career என்னை மூன்று நாடுகளுக்கு அழைத்துச் சென்றது. Booking.com-இன் SRE துறையில் கிட்டத்தட்ட ஏழு ஆண்டுகள், build systems மற்றும் CI infrastructure பணிகளுக்குத் தலைமை தாங்கினேன். மிக அண்மையில், Isorun-ஐ உருவாக்கினேன், அங்கு microVMs, snapshots, isolation, scheduling மற்றும் disposable compute ஆகியவற்றில் பணியாற்றி வந்தேன். இப்போது அந்த அனுபவத்தை என் முதல் காதலுக்கே திரும்பக் கொண்டு வருகிறேன்.

Emir-ஐப் பற்றி என் கவனத்தை உண்மையில் ஈர்த்தது TryOmarchy தான். அவர் Omarchy desktop-ஐ எடுத்து browser-இல் வைத்தார் (மறுஉருவாக்கம் அல்ல, உண்மையானதே), Cloudflare-இல் சாதாரண CPU infrastructure-இல் சில நொடிகளில் boot ஆகும்படி செய்தார். அந்த வேடிக்கையான சோதனை பற்றிப் பேசத் தொடங்கினோம், உரையாடல் விரைவில் laptop-கள், புதிய architecture-கள், OEM-கள் மற்றும் நாம் விரும்பும் எல்லா இடங்களிலும் Omarchy இயங்க வேண்டுமானால் நமக்குத் தேவைப்படும் infrastructure பற்றி விரிவடைந்தது. நாங்கள் ஒரே vision-ஐப் பகிர்ந்து கொள்வதை உணர்ந்தோம்.

அதற்குத் தலைமை தாங்கத்தான் Emir வருகிறார்.

Omarchy-க்கான infrastructure என்பது server-களை இயக்குவதை விட மிக அதிகம். Omarchy-ஐ build செய்ய, test செய்ய, ship செய்ய நாம் பயன்படுத்துவதும், அதிக hardware மற்றும் அதிக architecture-களுக்கு விரிவடையும்போது system நம்பகமாக இயங்க வைப்பதும் தான். Release-களை நம்பகமானதாக்குவது, தோல்விகளை மீண்டும் உருவாக்கக்கூடியதாக்குவது, மற்றும் project-இல் உள்ள மற்ற அனைவருக்கும் வேகமாகச் செல்ல உறுதியான அடித்தளம் கொடுப்பது தான்.

மேலும் ஆராய ஏராளம் இருக்கிறது! Omarchy உங்கள் மேசையில் உள்ள machine-இல் அழகாக இயங்க வேண்டும், ஆனால் அதோடு நின்றுவிட எந்தக் காரணமும் இல்லை. Linux computer ஒன்றைத் தொடங்குவது web page ஒன்றைத் திறப்பது போல எளிதாகும்போது என்ன நடக்கும் என்பதற்கான ஒரு glimpse-ஐ TryOmarchy எங்களுக்குக் காட்டியது, Linux-இன் சுவையை ஒரே click தொலைவில் வைத்தது. அது எங்கே போகிறது என்று பார்க்கப் போகிறோம்.
