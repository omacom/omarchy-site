Omarchy 4.5 (Quattro RS என்றும் அழைக்கப்படுகிறது!) Quattro-வுக்குப் பிறகு வந்த முதல் பெரிய அம்ச வெளியீடு, இது மிகப் பெரியது: வெறும் பன்னிரண்டு வாரங்களில் 180-க்கும் மேற்பட்ட பங்களிப்பாளர்களிடமிருந்து 740-க்கும் மேற்பட்ட pull request-கள் இணைக்கப்பட்டுள்ளன. இது இப்போது tiling இயல்புநிலைக்கு அருகில் பாரம்பரிய desktop பயன்முறையை வழங்குகிறது. M1/M2/M3/Neo MacBook-களில் இதை நேட்டிவாக நிறுவலாம். மேலும் இது 50 மொழிகள் பேசுகிறது. இன்னும் எண்ணற்ற அம்சங்கள், சரிசெய்தல்கள் மற்றும் மேம்பாடுகள் உள்ளன. ஏற்கனவே Omarchy-இல் இருக்கிறீர்களா? Dock உடன் மிதக்கும் பணியிடங்கள்

Super + L இப்போது எந்தப் பணியிடத்தையும் tiling, scrolling மற்றும் floating இடையே சுழற்றுகிறது. மிதக்கும் பணியிடத்தில், ஒவ்வொரு சாளரத்திற்கும் உங்கள் தீமின் வண்ணங்களில் titlebar கிடைக்கிறது, மேலும் dock உங்கள் pin செய்த செயலிகள், இயங்கிக் கொண்டிருக்கும் அனைத்தும், நிறுவப்பட்ட ஒவ்வொரு செயலியின் grid ஆகியவற்றைக் காட்டுகிறது. மறுவரிசைப்படுத்த அல்லது pin செய்ய இழுக்கவும், மேலும் விருப்பங்களுக்கு வலது கிளிக் செய்யவும், Super + M ஒரு சாளரத்தை dock-க்குள் சிறிதாக்குகிறது.

macOS அல்லது Windows-இலிருந்து வருபவர்களுக்கும், இன்னும் tiling-இல் முழுமையாக இறங்கத் தயாராக இல்லாதவர்களுக்கும் இது அருமையான தொடக்க வழி. அல்லது சாளரங்கள் பரந்து விரியக்கூடிய ஒரு பணியிடம் மட்டும் வேண்டும் என்பவர்களுக்கும். பணியிடத்திற்குப் பணியிடம் கலந்து பயன்படுத்தலாம், ஒவ்வொன்றும் எந்த layout பயன்படுத்துகிறது என்பதை bar காட்டும்.

Apple Silicon-இல் Omarchy

எங்கள் அற்புதமான Omarchy M அணி நேட்டிவ் Mac நிறுவியை வழங்கியுள்ளது. macOS-இல் ஒரு செயலியைப் பதிவிறக்கவும், அது உங்கள் M1, M2, M3 அல்லது Neo MacBook-இல் Omarchy-ஐ அதற்கு அருகிலேயே வைக்கும். USB stick இல்லை, terminal மந்திரங்கள் இல்லை. Homebrew விருப்பமா? அது ஒரே ஒரு வரி:

brew install omacom/mac/omarchy

செப்டம்பரில் நாங்கள் செய்ய நினைத்தது இதுதான்: Asahi தொடங்கியதை முடிப்பது. இரண்டு மாதங்களுக்குப் பிறகு, அதை வெறுமனே பதிவிறக்கலாம். அணியில் உள்ள அனைவரின் அற்புதமான பணி.

அவர்கள் அதோடு நிற்கவில்லை. M4, M5 மற்றும் M6 அனைத்திலும் இப்போது பணி நடந்து கொண்டிருக்கிறது, எனவே Omarchy ஒவ்வொரு Apple Silicon Mac-இலும் இயங்கும் நாள் வெகு தொலைவில் இல்லை.

NVIDIA DGX Spark + RTX Spark-க்கான ARM ஆதரவு (விரைவில் Snapdragon)

Omarchy 4.5 அதன் முதல் ARM ISO-வை வழங்குகிறது, அதனுடன் NVIDIA-வின் ARM கணினிகளுக்கான பூர்வாங்க ஆதரவு வருகிறது: DGX Spark desktop மற்றும் Dell XPS 16 Creator Edition மற்றும் ASUS ProArt P14 போன்ற RTX Spark-இல் உருவாக்கப்பட்ட laptop-கள். விரைவில் Snapdragon ARM கணினிகளின் முழு வரிசைக்கும் ஆதரவு கிடைக்கும். இது இன்னும் ஆரம்ப நாட்கள், எனவே சில கரடுமுரடான இடங்களை எதிர்பார்க்கவும், உடையும் எதையும் GitHub-இல் தெரிவிக்கவும்.

50 மொழிகளும் 5 உள்ளீட்டு முறைகளும்

Omarchy இப்போது 50 மொழிகள் பேசுகிறது. Setup > Language இன் கீழ் ஒன்றைத் தேர்ந்தெடுக்கவும் (அல்லது omarchy language <code> ஐ இயக்கவும்), மெனு, desktop மற்றும் Omarchy-வின் அறிவிப்புகள் உடனடியாக மாறும். அடுத்த உள்நுழைவில் system locale பின்தொடரும்.

ஒரு மொழியைப் பேசுவது அதில் பாதிதான். அதைத் தட்டச்சு செய்யவும் வேண்டும். எனவே Omarchy இப்போது ஜப்பானியம் (Mozc), கொரியம் (Hangul), எளிமைப்படுத்தப்பட்ட சீனம் (Pinyin), தைவான் (Zhuyin) மற்றும் ஹாங்காங் (Cangjie) ஆகியவற்றுக்கான முறையான உள்ளீட்டு முறைகளை நிறுவியிலிருந்தே அல்லது பின்னர் Setup > Keyboard இன் கீழ் அமைக்கிறது. ஒவ்வொன்றும் அதன் எழுத்து வடிவங்களுக்கான சரியான எழுத்துருக்களுடன் வருகிறது, candidate சாளரம் உங்கள் தீமைப் பின்பற்றுகிறது, Super + I உங்கள் உள்ளீட்டு மொழிகளுக்கு இடையே மாற்றுகிறது. நீங்கள் Dvorak, Colemak அல்லது AZERTY-இல் Latin தட்டச்சு செய்தாலும் Hangul, Zhuyin மற்றும் Cangjie அவற்றின் விசைகளை நிலையான இடங்களிலேயே வைத்திருக்கும், Windows மற்றும் macOS-இல் உள்ளது போலவே. Shift-ஐத் தனியாகத் தட்டுவது உள்ளீட்டு முறையிலிருந்து Latin எழுத்துக்களுக்கு வெளியேறி மீண்டும் உள்ளே வரும், Sogou, Microsoft Pinyin மற்றும் macOS செயல்படும் விதம் போலவே.

Captive Wi-Fi போர்டல்களில் உள்நுழையவும்

Hotel, விமான நிலையம் மற்றும் coffee shop Wi-Fi இறுதியாக வெறுமனே வேலை செய்கிறது. நீங்கள் ஆன்லைனில் செல்வதற்கு முன் ஒரு network உள்நுழைய அல்லது அதன் விதிமுறைகளை ஏற்க விரும்பும்போது Omarchy இப்போது கவனிக்கிறது. Network ஐகான் உங்களை எச்சரிக்கிறது, network panel உள்நுழைவுப் பக்கத்திற்கு நேராக அழைத்துச் செல்லும் பெரிய Open Captive Portal பொத்தானைக் காட்டுகிறது. நீங்கள் கடந்து சென்றதும், எல்லாம் தானாகவே இயல்புக்குத் திரும்பும்.

ஐந்து புதிய இயல்புநிலை செயலிகள்

Hype ஒரே Markdown கோப்பிலிருந்து விளக்கக்காட்சிகளை உருவாக்குகிறது, மூலத்திற்கு அருகில் visual slide editor உடன், PDF அல்லது PowerPoint-க்கு ஏற்றுமதி செய்கிறது.

Signed காகித வேலைகளுக்கு Xournal++-ஐ மாற்றுகிறது: PDF-ஐத் திறந்து, சேமித்த கையொப்பம், உரை மற்றும் தேதிகளை வைத்து, கையொப்பமிட்ட நகலைச் சேமிக்கவும்.

Disktree உங்கள் disk-ஐ நிரப்புவதை வகையால் வண்ணமிட்ட treemap ஆக வரைகிறது, பாதுகாப்பாக மீண்டும் உருவாக்கக்கூடிய cache-களைச் சுட்டிக்காட்டுகிறது, நீக்க வேண்டியதைக் குறிக்க உதவுகிறது.

Monologue ஒரே விசையால் உங்கள் camera-வைப் பதிவு செய்கிறது, உங்கள் desktop-க்கு ஏற்ற தீமுடன்.

Gliff SSH வழியாக remote desktop தருகிறது. மற்றொரு Omarchy கணினியுடன் இணைந்து அதன் முழு desktop-ஐ உங்கள் சாளரத்திலிருந்து இயக்கவும், ஒவ்வொரு கணினிக்கும் ஒரு tab உடன். அது SSH-இல் செல்வதால், கூடுதலாக அமைக்கவோ வெளிப்படுத்தவோ எதுவும் இல்லை. கட்டுப்படுத்தப்படும் கணினி bar-இல் remote session குறிகாட்டியைக் காட்டுகிறது, எனவே யாராவது அதில் இருக்கும்போது எப்போதும் தெளிவாகத் தெரியும்.

மேலும் Elsewhen உள்ளது, bar-இல் கடிகாரத்திற்கு அருகிலேயே வாழும் உலகக் கடிகாரம். நீங்கள் இருக்கும் இடத்தை அமைக்க globe-இல் ஒரு நகரத்தைத் தட்டவும், உண்மையான இடங்களைத் தேடவும், ஒவ்வொரு நகரத்திலும் வாழும் மக்களுக்குப் பெயரிடவும், எனவே அழைக்க ஏற்ற நேரமா என எப்போதும் தெரியும். t மூலம் 12 மற்றும் 24 மணிநேரத்திற்கு இடையேயும், Alt + T மூலம் °F மற்றும் °C இடையேயும் மாறவும், Super + Ctrl + Alt + E மூலம் எப்போது வேண்டுமானாலும் அதை அழைக்கவும்.

பதிவுக்கு Monologue மற்றும் trimming-க்கு Omacut உடன், புதிய நிறுவல்கள் இனி OBS Studio மற்றும் Kdenlive-ஐ வழங்காது. Lazydocker-ம் புதிய நிறுவல்களிலிருந்து நீங்கிவிட்டது, ஆனாலும் Docker மற்றும் Docker Compose இன்னும் சேர்க்கப்பட்டுள்ளன. அவற்றில் ஏதேனும் ஏற்கனவே உள்ள கணினிகள் அவற்றை வைத்திருக்கும்.

Dictation-க்கு Superwhisper

Superwhisper இப்போது Omarchy-வின் இயல்புநிலை dictation engine, அது பெட்டியிலிருந்தே அமைக்கப்பட்டுள்ளது. பேசத் தொடங்க Alt + Space ஐத் தட்டவும், நிறுத்த மீண்டும் தட்டவும், அல்லது push-to-talk-க்கு Right Alt ஐப் பிடித்திருக்கவும். இது நம்பமுடியாத அளவுக்கு வேகமானது மற்றும் மிகத் துல்லியமானது.

Boot மெனு இப்போது அமைதியாக

Omarchy முன்பு ஒவ்வொரு தொடக்கத்திலும் சுமார் ஆறு விநாடிகள் boot மெனுவைக் காட்டியது, முந்தைய snapshot-க்குத் திரும்ப வேண்டியிருந்தால் என்பதற்காக. ஆனால் கிட்டத்தட்ட யாரும் அப்படிச் செய்யவில்லை. எனவே இப்போது Limine ஒரே ஒரு விநாடி காத்திருந்து அமைதியாக boot செய்கிறது, பெரும்பாலான நேரங்களில் மெனுவை நீங்கள் பார்க்கவே மாட்டீர்கள்.

வேறு உள்ளீடு அல்லது snapshot தேவைப்படும்போது, கணினி தொடங்கும்போது எந்த விசையையும் (கீழ் அம்புக்குறி வேலை செய்யும்) தட்டிக் கொண்டே இருக்கவும், அது மெனுவில் நிற்கும். மெனுவை நிரந்தரமாக நீண்ட நேரம் வைத்திருக்க விரும்பினால், /boot/limine.conf-இல் உங்கள் சொந்த timeout: ஐ அமைக்கவும் (timeout: 5 போல). நீங்கள் அமைத்த timeout-ஐ updates தனியாக விட்டுவிடும்.

மாற்றப்பட்ட hotkey-கள்

சில shortcut-கள் நகர்ந்தன:

  • கணிப்பான்: Super + Ctrl + Q இப்போது Super + Shift + Q ஆகும்.
  • Activity: Super + Ctrl + T இப்போது Super + Shift + T ஆகும், Super + Ctrl + T தீம்களைத் திறக்கும்.
  • Network: Super + Ctrl + W இப்போது Super + Ctrl + N ஆகும், Super + Ctrl + W பின்னணிகளைத் திறக்கும்.
  • Nightlight-க்கு இனி shortcut இல்லை (அது Super + Ctrl + N ஆக இருந்தது); அது Trigger > Toggle-இல் உள்ளது.
  • Super + Alt + Space Apps மெனுவிற்குப் பதிலாக dock-இலிருந்து Apps-ஐத் திறக்கும்.

அறிவிப்பு shortcut-கள் மாறின:

  • Super + Comma புதிய card-இல் செயல்படும் (அதை நீக்கும், திறக்கும் அல்லது அதன் ஒரு பொத்தானை அழுத்தும்), அதை மட்டும் நீக்குவதற்குப் பதிலாக.
  • கடைசி ஒன்றை நீக்குவது Super + Alt + Comma-க்கு நகர்ந்தது, அது முன்பு அதைத் திறந்தது.
  • அமைதிப்படுத்துவது Super + Ctrl + Comma-இலிருந்து Super + Ctrl + Alt + Comma-க்கு நகர்ந்தது; Super + Ctrl + Comma இப்போது keyboard கட்டுப்பாட்டை உங்களிடம் தரும்.

சில விசைகள் வித்தியாசமாக வேலை செய்கின்றன:

  • Super + Tab, Super + Shift + Tab, Super + Ctrl + Tab மற்றும் Super + scroll தற்போதைய monitor-இன் பணியிடங்களிலேயே இருக்கும், ஏனெனில் ஒவ்வொரு monitor-க்கும் சொந்த பணியிடங்கள் உள்ளன.
  • Terminal-இல், Super + C மற்றும் Super + V Ctrl + Insert மற்றும் Shift + Insert-க்குப் பதிலாக Ctrl + Shift + C மற்றும் Ctrl + Shift + V ஐ அனுப்பும்.

உங்கள் சொந்த binding-களுடன் மோதக்கூடிய புதிய இயல்புநிலைகள்: Super + Q (சாளரத்தை மூடவும், Super + W-க்கு அருகில்), Super + A (அனைத்தையும் தேர்ந்தெடுக்கவும்), Super + M (dock-க்குச் சிறிதாக்கவும்), Super + ~ மற்றும் Super + Shift + ~ (Quake console), Super + Alt + L (முந்தைய layout), Super + Shift + Ctrl + Arrows (சாளரத்தை மற்றொரு monitor-க்கு நகர்த்தவும்), Super + Ctrl + Alt + C (screenshot), Super + Ctrl + Alt + E (உலகக் கடிகாரம்), Super + Ctrl + Alt + F (முழுத் திரை desktop) மற்றும் push-to-talk dictation-க்கு Right Alt ஐப் பிடித்திருத்தல்.
