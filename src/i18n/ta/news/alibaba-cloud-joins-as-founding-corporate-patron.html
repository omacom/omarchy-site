Alibaba Cloud Omacom Foundation அமைப்பில் Founding Corporate Patron ஆக இணைகிறது, மூன்று ஆண்டுகளுக்கு ஆண்டுக்கு $1 மில்லியன் வழங்குகிறது! அது Omarchy-யின் மேம்பாடு, பராமரிப்பு மற்றும் பரவலுக்கான $3 மில்லியன் உறுதிமொழி, DigitalOcean-இன் ஆதரவுக்கு இணையானது.

ஆனால் இந்தக் கூட்டாண்மை பணத்தைத் தாண்டி வெகுதூரம் செல்கிறது. எங்களுடன் சேர்ந்து Omarchy China-வை உருவாக்க Alibaba Cloud உதவப் போகிறது: சீனப் பயனர்கள் தொந்தரவு இல்லாமல் Omarchy-யை ஏற்றுக்கொள்ளத் தேவையான உள்ளூர் CDN, ஹோஸ்டிங், இணையதளம், மீட்அப்கள் மற்றும் சமூகம். நீங்கள் எங்கு வாழ்ந்தாலும் Linux-ஐப் பதிவிறக்குவது, தொகுப்புகளை நிறுவுவது, உங்கள் கணினியைப் புதுப்பித்து வைத்திருப்பது எளிதாக இருக்க வேண்டும். அதைச் சீனாவிலும் உண்மையாக்க ஒன்றாக வேலை செய்யப் போகிறோம்.

இதற்கான நேரம் இதைவிடச் சிறப்பாக அமைய முடியாது. Qwen Book அறிவிப்புடன், agentic கணினிக்கான தன் கனவை Alibaba வன்பொருளில் கொண்டு வருகிறது. அந்தக் கணினிக்கு ஏற்ற சிறந்த agentic இயக்க முறைமையாக Omarchy-யை உருவாக்க நாங்கள் ஒத்துழைக்கப் போகிறோம். மனிதர்களும் agents-ம் சேர்ந்து வேலை செய்யக்கூடிய அழகான, வேடிக்கையான Linux டெஸ்க்டாப், அங்கு உரிமையாளரே பொறுப்பில் இருப்பார்.

வரவிருக்கும் Qwen Book-ஐ Alibaba Cloud எப்படி விவரிக்கிறது என்பது இங்கே:

Qwen Book ஒரு native AI agent கணினியை உருவாக்குவதை நோக்கமாகக் கொண்டுள்ளது. அதன் மையத் தத்துவம், “OS as Harness”, எளிமையாகச் சொன்னால், மாடல்கள், இயக்க முறைமை, பயன்பாடுகள், கிளவுட் சேவைகள் மற்றும் வன்பொருளை ஆழமாக ஒருங்கிணைப்பதாகும். இது agents புரிந்துகொள்ள, அழைக்க, நினைவில் வைக்க, தொடர்ந்து இயங்கக்கூடிய ஒரு கணினிச் சூழலை உருவாக்குகிறது, கணினியைச் செயலற்ற கருவியிலிருந்து தொடர்ந்து பரிணமிக்கும் தனிப்பட்ட உதவியாளராக மேம்படுத்துகிறது.

Qwen Book system ARM மற்றும் x86 கட்டமைப்புகள் இரண்டுடனும் இணக்கமானது, முதல் வெளியீடு ARM கட்டமைப்பை அடிப்படையாகக் கொண்டது. சிஸ்டம் மட்டத்தில், குறைந்த மின் நுகர்வு கொண்ட Agent Engine மற்றும் Continuous Context Engine ஆகியவற்றை உருவாக்கியுள்ளோம். Qwen model family-யை அறிவார்ந்த அடித்தளமாகக் கொண்டு, cloud-device ஒருங்கிணைப்பு மூலம் Qwen Book system-க்கான மாடல் சேவைகளை வழங்குகிறோம். எதிர்காலத்தில் Omarchy OS உடன் இணைந்து மேலும் புதுமைகளை ஆராய ஆவலாக உள்ளோம்.

அதாவது Omarchy-யைப் பெட்டியிலிருந்து எடுத்தவுடனே Qwen models-க்கு ஏற்றவாறு சரிசெய்வது, மக்கள் நம்பியிருக்கும் சீனச் சேவைகளுடன் முழு ஒருங்கிணைப்பை நோக்கி வேலை செய்வது. நீங்கள் இயந்திரத்தை இயக்கிய கணத்திலிருந்தே மாடல்கள், இயக்க முறைமை மற்றும் சேவைகள் ஒன்றாக வேலை செய்ய வேண்டும். உங்கள் கணினியை ஒரு agent உடன் வேலை செய்யத் தயார் செய்வது தனி திட்டமாக இருக்கக்கூடாது.

அறக்கட்டளை சாத்தியமாக்க வேண்டும் என்று நான் விரும்பும் ஒத்துழைப்பு இதுதான். மாடல்களை உருவாக்குபவர்கள், கணினிகளை உருவாக்குபவர்கள், இயக்க முறைமைகளை உருவாக்குபவர்கள் ஒன்றாகச் சேர்ந்து ஒட்டுமொத்த அனுபவத்தையும் மேம்படுத்துவது. தனிப்பட்ட கணினி எதுவாக மாற முடியும் என்பதில் எங்களுக்குப் பகிரப்பட்ட கனவு உள்ளது, இப்போது அதற்குப் பின்னால் வளங்களை வைக்கிறோம்.

Alibaba Cloud, DigitalOcean மற்றும் Meta Superintelligence Labs உடன் Founding Corporate Patron ஆக இணைகிறது. அவர்களின் உறுதிமொழி எங்கள் மொத்த ஆதரவை சுமார் $21.7 million ஆகக் கொண்டு வருகிறது. Omarchy-யைச் சாத்தியமாக்கும் மனிதர்கள், உள்கட்டமைப்பு மற்றும் திறந்த மூல திட்டங்களில் முதலீடு செய்ய இது அதிக இடம் தருகிறது.

Alibaba Cloud-இல் உள்ள அனைவருக்கும் நன்றி, குறிப்பாக இதைச் சாத்தியமாக்கிய CTO LI feifei அவர்களுக்கு. உங்கள் ஆதரவு எங்களைப் பெரிதாகச் சிந்திக்கவும், Linux-ஐ அனைவருக்கும் மேம்படுத்த அதிக மனிதர்களைப் பணியில் அமர்த்தவும் வைக்கிறது.
