ஒவ்வொரு முக்கிய தளத்திற்கும் பொறுப்பான குழுக்கள் இருக்க வேண்டும், Qualcomm-இன் Snapdragon-க்கு நிச்சயம் ஒன்று தேவை! கடந்த வாரம், Apple வன்பொருளுக்கான Omarchy M-ஐ அறிமுகப்படுத்தினோம். இன்று, Omarchy Dragon-ஐ அதிகாரப்பூர்வமாக்குகிறோம்: Snapdragon கணினிகளில் Omarchy அழகாக இயங்க வைக்க உழைக்கும் எங்கள் குழு.

இந்த மெல்லிய, இலகுவான லேப்டாப்களை நம்பகமான அன்றாட Linux இயந்திரங்களாக மாற்றுவதே நோக்கம். டெஸ்க்டாப் boot ஆவது ஒரு தொடக்கம்தான். இயந்திரம் உறக்கத்திற்குச் சென்று, எழுந்து, வீடியோவை திறமையாக இயக்கி, அதன் firmware-ஐ புதுப்பித்து, ஒரு நாள் முழு வேலையையும் தாங்குவதுதான் அதை நீங்கள் நம்பக்கூடிய கணினியாக மாற்றுகிறது.

ஐந்து பேர் ஏற்கனவே இந்தப் பணிகளில் ஈடுபட்டுள்ளனர்:

Jim Martin (GitHub) Snapdragon X2 Elite உடன் கூடிய Surface Laptop 8-இல் Linux-ஐ கொண்டுவரும் பணியில் இருக்கிறார். அவர் DGX Spark-க்கான Omarchy-இல் பணியாற்றி வருகிறார், ஏற்கனவே ARM installer-க்கு graphical disk-unlock திருத்தம் ஒன்றை வழங்கியுள்ளார். Dragon-க்காக, அவர் Surface மற்றும் X2 Elite ஆதரவில் கவனம் செலுத்தி, உண்மையான வன்பொருளில் installation மற்றும் recovery-ஐ சோதித்து, பயனுள்ள ARM திருத்தங்களை பகிரப்பட்ட Omarchy திட்டங்களில் சேர்க்கும் பணியில் இருக்கிறார்.

Birk Skyum (X) ஒரு புவித்தகவல் மற்றும் கிராபிக்ஸ் பொறியாளர், MapLibre-இன் இணை நிறுவனர். அவரது இயந்திரம் Snapdragon X Elite உடன் கூடிய Lenovo Yoga Slim 7x. அவர் Arch Linux ARM-இல் upstream திருத்தங்களை சேர்த்துள்ளார், libcamera, PipeWire மற்றும் systemd ஆகியவற்றுக்கு patch-களை சமர்ப்பித்துள்ளார், மேலும் fan மற்றும் வெப்பநிலை கண்காணிப்புக்கான kernel patch-களில் பணியாற்றியுள்ளார். இப்போது அவர் battery life, நம்பகமான sleep, KVM virtualization, hardware-accelerated வீடியோ, Linux-இலிருந்து BIOS update-கள் மற்றும் USB4 செயல்திறன் ஆகியவற்றை கவனிக்கிறார். Linux-க்கான firmware ஆதரவை மேம்படுத்துவது குறித்து Lenovo-உடனும் தொடர்பில் இருக்கிறார்.

Matt Gilg (GitHub) ஏற்கனவே செயல்படும் Omarchy desktop-ஐ, Hyprland உட்பட அனைத்துடனும், Snapdragon X Yoga மற்றும் DGX Spark-இல் இயக்க வைத்துள்ளார். Omarchy Package Repository-க்கு மாறுவதற்கு முன்பு, அதற்குத் தேவையான aarch64 package-களை உருவாக்கி host செய்தார். Matt SignalRGB-ஐ நடத்துகிறார், மேலும் பல நிறுவன வன்பொருள் இணக்கத்தன்மை, embedded system-கள் மற்றும் low-level Linux பணிகளில் அனுபவம் கொண்டவர். அவர் Snapdragon X2 Elite உடன் கூடிய OmniBook X16-ஐயும் இயக்க வைக்கிறார், குறிப்பாக gaming-இல் ஆர்வத்துடன், மேலும் அதிகமானோர் Windows-இலிருந்து வெளியேற வழி கண்டறிய உதவுகிறார்.

Bob Prendergast (GitHub) ஒரு solution architect மற்றும் Linux அனுபவசாலி, agents மற்றும் Ubuntu kernel-ஐப் பயன்படுத்தி தனது சொந்த Omarchy Snapdragon setup-ஐ உருவாக்கியுள்ளார். அவர் HP EliteBook 14 G1q மற்றும் Lenovo ThinkPad T14s Gen 6 உடன் பணியாற்றுகிறார். அதிக இயந்திரங்கள், அதிக சோதனை, மற்றும் நம்பிக்கைக்குரிய ஒரு தளத்தை மக்கள் install செய்து பயன்படுத்தக்கூடியதாக மாற்றத் தேவையான நடைமுறைப் பணிகள்.

Miguel Cruz (X) ஏற்கனவே Omarchy M-இல் இருக்கிறார், Apple Silicon boot மற்றும் வன்பொருள் இணக்கத்தன்மையில் தனது அனுபவத்தை Qualcomm பக்கத்திற்குக் கொண்டு வருகிறார். அவரது பின்னணி OS internals, reverse engineering மற்றும் embedded system-களை உள்ளடக்கியது, Linux, QEMU மற்றும் Virtio ஆகியவற்றில் பங்களிப்புகளுடன். Snapdragon X2 Elite Extreme-ஆல் இயங்கும் ASUS Zenbook A16 உடன் இந்த முயற்சியில் இணைகிறார், boot மற்றும் firmware bring-up, driver சிக்கல்கள் (குறிப்பாக GPU) மற்றும் உண்மையான வன்பொருளில் திருத்தங்களை சோதிப்பதில் கவனம் செலுத்துகிறார்.

எங்கள் மற்ற ARM பணிகளுடனும் பயனுள்ள ஒன்றுடன் ஒன்று தொடர்பு உள்ளது. ஒரு இயந்திரத்திற்காக உருவாக்கப்பட்ட package-கள், installer மேம்பாடுகள் மற்றும் திருத்தங்கள் மற்றொரு இயந்திரத்திற்கும் உதவும். Jim-மும் Matt-ம் அந்தப் பணியை Raspberry Pi மற்றும் பிற ARM தளங்களுக்கும் விரிவுபடுத்த ஆர்வமாக உள்ளனர்.

Qualcomm-உடன் நேரடித் தொடர்பை ஏற்படுத்தவும் நான் முயன்று வருகிறேன். அங்கு Linux இணக்கத்தன்மையில் பணியாற்றும் ஒரு பொறியாளர் ஏற்கனவே தொடர்பு கொண்டுள்ளார். இந்த முயற்சிக்குப் பின்னால் முறையான ஆதரவைப் பெற முடியுமா என்று பார்ப்போம்.

இது தொடரும் பணி, இணக்கத்தன்மை இயந்திரம் இயந்திரமாக சரி செய்யப்பட்டு வருகிறது. ஆனால் இப்போது அதற்குப் பொறுப்பேற்கும் குழு, உண்மையான வன்பொருளில் சோதித்து, திருத்தங்களை upstream-க்கு அனுப்புகிறது. வருக, Jim, Birk, Matt, Bob மற்றும் Miguel.
