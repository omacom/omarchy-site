两位为 Omarchy 突破 x86 平台限制付出最多努力的人，正在加入 Omarchy Core：Marcelo Alcantara 和 Birk Skyum！

Marcelo Alcantara

当我们在九月推出 Omarchy M 时，Marcelo 是负责开发原生 Mac 安装器的人。从那以后，他成为了协调整个工作的那个人。来自世界各地的十六个人，每个人负责堆栈的不同层级，从 GPU 驱动和显示器到 Touch ID 和安装器本身。总得有人让所有这些工作朝着同一个方向前进，而 Marcelo 一直是那个人。

成果随 Omarchy 4.5 一同发布。现在你可以在 macOS 上下载一个应用（或运行 brew install omacom/mac/omarchy），它就能在你的 M1、M2、M3 或 Neo MacBook 上，与现有系统并存安装 Omarchy。无需 U 盘，无需在终端里念咒。从团队宣布到“直接下载就行”，只用了两个月，这个速度令人难以置信。

这极大地归功于 Omarchy M 的每一位成员：Scott、Chris、Naeem、Dj、Joshua、Eduardo、Shun、Ryan、Miguel、Liam、Eryk、Jaidip、Shawn、Randy、Jon 和 Marcelo。你们完成了 Asahi 开启的工作，而且已经在继续推进到 M4、M5 和 M6 了。谢谢你们！

Birk Skyum

Birk 在九月带着他的 Lenovo Yoga Slim 7x 加入了 Omarchy Dragon，他此前曾在 Arch Linux ARM、libcamera、PipeWire、systemd 和内核中提交过上游修复。从那以后，他承担起了协调整个 Snapdragon 产品线适配工作的职责。这意味着要收集这些机器，弄清楚每台机器上什么能用、什么不能用，并确保修复成果落在能帮助所有人的地方。

在 4.5 的 ARM 工作中，你已经能到处看到他的印记：每次更新后不再有无意义的重启提示，Snapdragon 笔记本上的摄像头在登录时就能显示出来，以及根据 ARM 上实际能运行什么来提供（或隐藏）应用。但这仅仅是开始。Birk 正朝着一个即将到来的版本努力，届时我们支持的每一台 Snapdragon 机器都能直接正常工作。睡眠、电池、视频、摄像头，全部搞定。这就是标准，而他就是确保我们达到这个标准的那个人。

欢迎！

Omarchy 将在每一个主要平台上都流畅运行，而 Core 需要那些正在让这一切成为现实的人。Marcelo 和 Birk 一直在做的正是这件事。现在，它正式官宣了。

欢迎加入 Omarchy Core，Marcelo 和 Birk！
