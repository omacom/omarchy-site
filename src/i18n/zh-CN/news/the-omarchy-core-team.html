Omarchy 的爆炸式增长需要组织化的团队来应对。我们先组建 Omarchy Core 团队。成员将共同承担引领发行版方向、确保持续前进、协助其他贡献者的责任。

请允许我介绍首批 Core 成员：

Ryan Hughes 从第一天起就是我在 Omarchy 的搭档。早期我们一起应对凌晨三点的 AUR 紧急故障，一起筹划自建软件包仓库。Ryan 的贡献横跨发行版每一层：安装、打包、硬件支持、游戏、主题、CLI 工具，如今还有 Quattro。他推动转向 Quickshell、插件系统，以及许多基础设施，将 Omarchy 从精心组装的 Linux 配置变成真正的操作系统。不开发 Omarchy 时，Ryan 是 Oodle 的合伙人。

Tobi Lütke 是唯一加入过我两个 Core 团队的人！作为 2004 年首批 Rails Core 团队成员，他不仅对框架贡献卓著，还编写了 Liquid、Delayed Job 和 Active Merchant。这些工作后来变成一家叫 Shopify 的小公司，听说过吗？如今他也为 Omarchy 大量贡献，包括 try、Omasnap、Wi-Fi 二维码和 Quake 风格智能体控制台。他还是我的赛车搭档，一起驾驶 Shopify Racing 11 号 LMP2 赛车参加 IMSA。

Bjarne Øverli 是 Unite AS CTO，也是内置可视化主题编辑器 Aether 与 TUI 音乐播放器 cliamp 的作者。他通过语义化颜色，以及面向 Neovim、VS Code、btop 等工具生成主题，帮助我们将主题系统从配置文件集合变得更加系统化。Ethereal、Hackerman 和 Lupine 也出自他手。他兼具程序员的严谨和视觉品位，这种难得的组合与 Omarchy 十分契合。

HANCORE 是机械工程师，却不知不觉成为 Omarchy 社区审美的重要力量。他制作了数量惊人的主题，包括默认提供的 Last Horizon 和 Solitude。如今还帮助维护 Quattro 的插件生态。Omarchy 一直坚持电脑要美观也要实用，而 HANCORE 在践行这一理念上走得比几乎任何人都远。

Spencer Bull 是 Dell 杰出工程师，负责 Linux 客户端适配、AI 和平台软件。他为我们连接最新硬件的复杂现实，在常见的 Linux 支持滞后出现前，帮助 Omarchy 在 Panther Lake 和最新 XPS 上正常运行。内核、驱动、显示器、Wi-Fi、扬声器、电源管理：Spencer 工作在软件接触物理世界的那一层。Core 团队能拥有这种专业知识，价值无可估量。

这五位早已在做这些工作，现在只是正式确认。再加上我，是一支出色的首届 Core 团队。不过这不会是唯一的团队，敬请期待 Omarchy Rangers 的公告！

我们将一起把 Omarchy 打造为首选 Linux 发行版，面向那些为智能体时代、可塑电脑，以及美观、现代、有主张的计算体验感到兴奋的人。

飞向宇宙，浩瀚无垠！
