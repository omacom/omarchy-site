Omarchy 4.5（又名 Quattro RS！）是自 Quattro 以来首个大型功能版本，而且是个重磅版本：短短十二周内，合并了来自 180 多位贡献者的 740 多个拉取请求。它现在在默认的平铺模式之外，还提供了一种传统的桌面模式。你可以直接在 M1/M2/M3/Neo MacBook 上原生安装它。它还会说 50 种语言。还有数不清的其他功能、修复和改进。已经在用 Omarchy 了？运行 Update > Omarchy。新机器？在这里获取。

带程序坞的浮动工作区

Super + L 现在可以在平铺、滚动和浮动之间循环切换任意工作区。在浮动工作区中，每个窗口都会获得一个采用你的主题颜色的标题栏，程序坞则会显示你固定的应用、所有正在运行的应用，以及所有已安装应用的网格。拖动即可重新排序或固定，右键点击查看更多选项，Super + M 可以将窗口最小化到程序坞。

对于那些从 macOS 或 Windows 过来、还没准备好完全投入平铺模式的人来说，这是一个很棒的入门方式。或者，对于只是想要一个可以让窗口自由铺开的工作区的人来说也是如此。每个工作区都可以混搭，状态栏会显示每个工作区使用的是哪种布局。

Apple Silicon 上的 Omarchy

我们出色的 Omarchy M 团队已经发布了原生 Mac 安装程序。在 macOS 上下载一个应用，它就会把 Omarchy 直接安装到你的 M1、M2、M3 或 Neo MacBook 上，与之并存。不需要 U 盘，也不需要终端咒语。更喜欢 Homebrew？那只需要一行：

brew install omacom/mac/omarchy

这正是我们九月份着手要做的事情：完成 Asahi 开创的工作。两个月后，你直接下载就能用了。团队里每个人的工作都太出色了。

而且他们还不打算停下来。M4、M5 和 M6 目前都在开发中，所以 Omarchy 可能很快就能运行在每一台 Apple Silicon Mac 上了。

对 NVIDIA DGX Spark + N1X 的 ARM 支持（Snapdragon 也即将到来）

Omarchy 4.5 发布了首个 ARM ISO，随之而来的是对 NVIDIA ARM 机器的初步支持：DGX Spark 台式机，以及基于 N1X 的笔记本电脑，例如 Dell XPS 16 Creator Edition 和 ASUS ProArt P14。而且我们很快也会支持整个 Snapdragon ARM 机器产品线。目前还处于早期阶段，所以预计会有一些粗糙的地方，如有任何问题，请到 GitHub 上报告。

50 种语言和 5 种输入法

Omarchy 现在会说 50 种语言。在 Setup > Language 下选择一种（或运行 omarchy language <code>），菜单、桌面和 Omarchy 的通知就会立即切换。系统区域设置会在你下次登录时跟随变更。

不过，会说一种语言只是成功了一半。你还得能输入它。所以 Omarchy 现在为日语（Mozc）、韩语（Hangul）、简体中文（Pinyin）、台湾（Zhuyin）和香港（Cangjie）设置了合适的输入法，可以直接在安装程序中设置，或之后在 Setup > Keyboard 下设置。每种输入法都配有适合其字形的正确字体，候选窗口会跟随你的主题，Super + I 可以在你的输入语言之间切换。即使你在 Dvorak、Colemak 或 AZERTY 上输入拉丁字母，Hangul、Zhuyin 和 Cangjie 也会将按键保持在标准位置，就像在 Windows 和 macOS 上一样。而单独轻点 Shift 键可以从输入法中暂时切换到拉丁字母，再切回来，就像搜狗、微软拼音和 macOS 的做法一样。

登录 Wi-Fi 强制门户

酒店、机场和咖啡馆的 Wi-Fi 终于能直接用了。Omarchy 现在会注意到某个网络想让你先登录或接受其条款，然后才能让你上网。网络图标会向你发出警告，网络面板会显示一个大大的 Open Captive Portal 按钮，点击即可直接进入登录页面。一旦你通过了，一切都会自行恢复正常。

五款新的默认应用

Hype 可以从单个 Markdown 文件制作演示文稿，源文件旁边有一个可视化幻灯片编辑器，并可导出为 PDF 或 PowerPoint。

Signed 取代了 Xournal++ 来处理文书工作：打开一个 PDF，放置你保存的签名、文本和日期，然后保存一份已签名的副本。

Disktree 会绘制一张树状图，展示是什么在占用你的磁盘，按类型着色，指出可以安全地重新生成的缓存，并让你标记应该删除的内容。

Monologue 只需一个按键就能录制你的摄像头画面，主题与你的桌面相匹配。

Gliff 让你可以通过 SSH 使用远程桌面。连接到另一台 Omarchy 机器，在你自己的窗口中操控它的完整桌面，每台机器一个标签页。而且因为它基于 SSH，所以无需任何额外的设置或暴露。被控制的机器会在状态栏中显示远程会话指示器，所以有人正在使用它时总是清清楚楚。

还有 Elsewhen，一个与状态栏中的时钟比邻而居的世界时钟。点击地球仪上的一个城市来设置你所在的位置，搜索真实的地点，并为住在每个城市的人命名，这样你就总能知道现在打电话是否是个合适的时间。用 t 在 12 小时制和 24 小时制之间切换，用 Alt + T 在 °F 和 °C 之间切换，用 Super + Ctrl + Alt + E 随时召唤它。

有了用于录制的 Monologue 和用于修剪的 Omacut，新安装将不再附带 OBS Studio 和 Kdenlive。Lazydocker 也不再出现在新安装中，不过 Docker 和 Docker Compose 仍会包含在内。已经拥有其中任何一款的机器会保留它们。

Microsoft 365

需要与生活在 Office 中的人一起工作？Install > Service > Microsoft 现在可以将 Outlook、Word、Excel、PowerPoint、Teams 和 OneDrive 设置为网页应用。每一个都有自己的窗口和启动器条目，所以它们在其他一切旁边都显得毫无违和。再也没有不在工作中切换到 Omarchy 的借口了！

用于听写的 Superwhisper

Superwhisper 现在是 Omarchy 的默认听写引擎，并且开箱即用。轻点 Alt + Space 开始说话，再点一次停止，或按住 Right Alt 进行按键通话。它快得令人难以置信，也非常准确。

它最初在云端运行，所以安装后立刻就能工作，前 10,000 个单词免费。但你可以切换到一个可下载的模型，它完全免费、完全在本地运行，不会将一个字发送给任何人。而如果你更愿意使用另一个本地模型，Voxtype 仍然可以作为替代方案提供。

十秒内完成安装

Omarchy 以前会逐个安装大约 940 个软件包。新的 F1 安装程序改为解包一个预构建的根镜像，只在此基础上添加这台机器的软件包。这可将任何机器上的安装时间大致减少一半。

而在快速硬件上，这简直离谱。AMD 的 Anush Elangovan 创下了世界纪录，在他的 AMD 笔记本电脑上以 7 秒完成了 Omarchy 的完整安装。七秒钟！我还记得以前五分钟都似乎是一个雄心勃勃的目标。

其他地方也更快了

不只是安装程序更快了。启动时不再因 binfmt 注册而停顿。主题选择器会立即打开，而不是在四分之一秒之后。菜单和面板直接从 Hyprland 快捷键打开，省去了先启动一个进程所需的 60 ms。Omarchy 菜单中最慢的检查从 200 ms 缩短到了 16 ms，新终端显示提示符的时间提前了 30 ms，整个桌面现在会对变化作出反应，而不是轮询等待变化。甚至注销、重启和关机也会在你的应用关闭完毕后立刻进行。

智能体升级

Omarchy 是智能体操作系统，4.5 带来了一大轮与智能体协作的升级。智能体面板现在跟踪 23 个智能体和提供商，高于之前的 6 个，包括 Cursor、OpenCode、GitHub Copilot、Antigravity、Hermes、Amp、Kiro、Devin、Qwen、DeepSeek、OpenRouter 和 Ollama。每个限额都有自己的仪表，并显示距离重置的时间，这样你就可以确切地看到自己还剩下多少余量。而 Grok 现在也与 Claude 和 Codex 一样，成为了一个完整的提供商。

而且你的智能体始终只需一个按键即可触及。Super + ~ 会在一个变暗的桌面上拉下一个 Quake 风格的控制台，你第一次打开它时，它会启动你的默认智能体。再按一次将其收起，你的会话就在你离开时的地方等着你。

如果你同时使用多个订阅，你现在可以在同一台机器上保留多个 Claude、Codex 和 Grok 登录，并使用 omarchy agent account 选择新会话从哪一个开始。它们之间共享历史记录、设置和技能，所以切换后 claude --continue 会从你离开的地方继续。当接近限额时，Omarchy 可以提供一键切换，或自行将新会话转移到余量最多的账户上。而当你设置另一台机器时，omarchy agent account copy 会通过 SSH 把你的所有登录信息带过来，所以你不必再重新登录所有账户。

Kimi 和 Ori（OpenRouter 的智能体框架）加入了 Setup > Defaults > Agent 下的选择，而 Google 的 Antigravity 取代了过时的 Gemini CLI（gemini 仍然可以作为别名使用）。更喜欢窗口而不是终端？Claude 和 Amp 的桌面应用现在在 Install > AI 下只需点击一下即可获得。

重建的通知

通知现在按发送者堆叠，跟随你的主题，并折叠相同的重复内容。操作按钮、验证码和链接都可以直接在卡片上使用。Super + Comma 可以对最新的一条进行操作（关闭、打开或按下其按钮），Super + Ctrl + Comma 将键盘交给你来操控所有通知。状态栏中的铃铛会打开“请勿打扰”。

视频背景和主题片头

现在背景可以是视频了。放一个进去，你的桌面就会随着滚动的波浪或你喜欢的任何其他东西活起来，而锁定屏幕会显示其中的一帧静止画面。而主题现在会隆重登场：每个主题都可以在你登录或切换到它时播放一段简短、无声的片头。（更喜欢保持安静？在 Appearance > Animations 下关闭片头。）

Jade Horse 加入默认主题

Jade Horse 满是朦胧的绿色，配有雕玉般的背景，让整个桌面看起来像一幅卷轴画。它在捆绑的主题中取代了 Osaka Jade，并与 Starship 一起，成为另一个新的默认主题。如果你正在使用 Osaka Jade，你会保留自己的副本，它将作为一个第三方主题继续存在，供任何想全新安装它的人使用。

Liftoff 成为新的默认背景

新安装现在迎接你的是 Liftoff，一次美不胜收的日落发射，它是 Tokyo Night 的新默认背景。它由 Tom Ballard 制作，他最初为自己的 Liftoff 主题创作了它。谢谢你，Tom！

启动菜单现在安静了

Omarchy 以前每次启动都会显示启动菜单大约六秒钟，以防你万一需要回滚到更早的快照。但几乎从来没有人这么做过。所以现在 Limine 只等待一秒钟就安静地启动，大部分时间你根本看不到菜单。

当你确实需要另一个条目或快照时，在机器启动时持续轻点任意键（下箭头也行），它就会停在菜单处。而如果你更喜欢让菜单始终多停留一会儿，在 /boot/limine.conf 中设置你自己的 timeout:（例如 timeout: 5）。更新会保留你设置的超时时间，不作改动。

已更改的快捷键

部分快捷键已移动：

  • 计算器：Super + Ctrl + Q 现在改为 Super + Shift + Q。
  • 活动：Super + Ctrl + T 现在改为 Super + Shift + T，而 Super + Ctrl + T 会打开主题。
  • 网络：Super + Ctrl + W 现在改为 Super + Ctrl + N，而 Super + Ctrl + W 会打开背景。
  • 夜灯不再有快捷键（以前是 Super + Ctrl + N）；它在 Trigger > Toggle 中。
  • Super + Alt + Space 从程序坞打开 Apps，而不是打开 Apps 菜单。

通知快捷键已更改：

  • Super + Comma 对最新的卡片进行操作（关闭它、打开它，或按下它的唯一按钮），而不仅仅是关闭它。
  • 关闭最后一个的操作移到了 Super + Alt + Comma，它以前用于打开它。
  • 静音已从 Super + Ctrl + Comma 移到 Super + Ctrl + Alt + Comma；Super + Ctrl + Comma 现在将键盘控制权交给你。

有几个按键的工作方式不同了：

  • Super + Tab、Super + Shift + Tab、Super + Ctrl + Tab 和 Super + 滚动会停留在当前显示器的工作区中，因为每个显示器都有自己的工作区。
  • 在终端中，Super + C 和 Super + V 会发送 Ctrl + Shift + C 和 Ctrl + Shift + V，而不是 Ctrl + Insert 和 Shift + Insert。

可能与你自己的绑定冲突的新默认值：Super + Q（关闭窗口，与 Super + W 并用）、Super + A（全选）、Super + M（最小化至程序坞）、Super + ~ 和 Super + Shift + ~（Quake 控制台）、Super + Alt + L（上一个布局）、Super + Shift + Ctrl + Arrows（将窗口移动到另一个显示器）、Super + Ctrl + Alt + C（截图）、Super + Ctrl + Alt + E（世界时钟）、Super + Ctrl + Alt + F（全屏桌面），以及按住 Right Alt 进行按键通话听写。
