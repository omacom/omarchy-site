Omarchy 4.5（又名 Quattro RS!）是自 Quattro 以来第一个大型功能版本，而且是个重磅版本：短短十二周内，合并了来自 180 多位贡献者的 740 多个拉取请求。它现在在默认的平铺模式之外，还提供传统桌面模式。你可以把它原生安装到 M1/M2/M3/Neo MacBook 上。而且它会说 50 种语言。还有数不清的其他功能、修复和改进。已经在用 Omarchy 了？运行 Update > Omarchy。换了新机器？在这里获取。

带程序坞的浮动工作区

Super + L 现在可以在平铺、滚动和浮动之间循环切换任意工作区。在浮动工作区中，每个窗口都会带有你主题配色的标题栏，程序坞会显示你固定的应用、所有正在运行的应用，以及所有已安装应用的网格。拖动即可重新排序或固定，右键点击查看更多选项，按 Super + M 可将窗口最小化到程序坞。

对于那些从 macOS 或 Windows 转过来、还不想完全投入平铺模式的人来说，这是个超棒的上手方式。或者对于只是想拥有一个可以让窗口自由铺展的工作区的人来说也一样。每个工作区都可以混搭，顶栏会显示每个工作区使用的是哪种布局。

Apple Silicon 上的 Omarchy

我们出色的 Omarchy M 团队已经发布了原生 Mac 安装程序。在 macOS 上下载一个应用，它就会把 Omarchy 与 macOS 并排安装到你的 M1、M2、M3 或 Neo MacBook 上。不需要 U 盘，不需要终端咒语。更喜欢 Homebrew？那只需一行：

brew install omacom/mac/omarchy

这正是我们九月时着手要做的事：完成 Asahi 开创的工作。两个月后，你直接下载就行。团队里每个人的工作都太出色了。

而且他们还不打算停步。M4、M5 和 M6 现在都在开发中，所以 Omarchy 可能很快就能在每一台 Apple Silicon Mac 上运行了。

为 NVIDIA DGX Spark + RTX Spark 提供 ARM 支持（很快还有 Snapdragon）

Omarchy 4.5 发布了首个 ARM ISO，并随之初步支持 NVIDIA 的 ARM 机器：DGX Spark 台式机，以及基于 RTX Spark 打造的笔记本电脑，例如 Dell XPS 16 Creator Edition 和 ASUS ProArt P14。而且很快我们还将支持整个 Snapdragon ARM 机器系列。现在还处于早期阶段，所以请预期会有一些粗糙之处，也请在 GitHub 上报告任何出问题的地方。

50 种语言和 5 种输入法

Omarchy 现在会说 50 种语言。在 Setup > Language 下选择一种（或运行 omarchy language <code>），菜单、桌面和 Omarchy 的通知就会立即切换。系统区域设置会在你下次登录时跟随切换。

不过，会说一种语言只是其中一半。你还得能输入它。因此，Omarchy 现在会为日语（Mozc）、韩语（Hangul）、简体中文（拼音）、台湾（注音）和香港（仓颉）设置合适的输入法，可直接在安装程序中设置，之后也可通过 Setup > Keyboard 设置。每种输入法都配有适合其字形的字体，候选窗口会跟随你的主题，按 Super + I 可在你的输入语言之间切换。即使你在 Dvorak、Colemak 或 AZERTY 布局上输入拉丁字母，Hangul、注音和仓颉的按键也会保持在标准位置，就像在 Windows 和 macOS 上一样。而单独轻点 Shift 就能退出输入法切换到拉丁字母，再点一次又切回来，就像搜狗、Microsoft Pinyin 和 macOS 的做法一样。

登录强制 Wi-Fi 门户

酒店、机场和咖啡馆的 Wi-Fi 终于能直接用了。Omarchy 现在会在网络要求你登录或接受条款后才能上网时注意到这一点。网络图标会警告你，网络面板会显示一个大的 Open Captive Portal 按钮，点击即可直达登录页面。一旦通过，一切就会自行恢复正常。

五个新的默认应用

Hype 能从单个 Markdown 文件制作演示文稿，源文件旁边带有可视化幻灯片编辑器，并可导出为 PDF 或 PowerPoint。

Signed 取代 Xournal++ 来处理文书工作：打开 PDF，放置你保存的签名、文本和日期，然后保存一份已签署的副本。

Disktree 会绘制一张树状图，显示是什么占满了你的磁盘，按类型着色，指出可以安全重新生成的缓存，并让你标记应该删除的内容。

Monologue 只需按一个键就能录制你的摄像头，主题与你的桌面相匹配。

Gliff 能让你通过 SSH 使用远程桌面。连接到另一台 Omarchy 机器，在你自己的窗口中操控它的完整桌面，每台机器一个标签页。而且因为它基于 SSH，没有任何额外的东西需要设置或暴露。被控制的机器会在顶栏显示远程会话指示器，所以什么时候有人在上面操作总是清清楚楚。

还有 Elsewhen，一个就住在顶栏时钟旁边的世界时钟。点击地球仪上的城市来设置你所在的位置，搜索真实地点，并为住在每个城市的人命名，这样你总能知道现在打电话是否是个合适的时辰。用 t 在 12 小时制和 24 小时制之间切换，用 Alt + T 在 °F 和 °C 之间切换，任何时候按 Super + Ctrl + Alt + E 即可呼出它。

有了用于录制的 Monologue 和用于修剪的 Omacut，新安装将不再附带 OBS Studio 和 Kdenlive。Lazydocker 也不再出现在新安装中，不过 Docker 和 Docker Compose 仍然包含在内。已经拥有其中任何一个的机器都会保留它们。

Microsoft 365

需要和生活在 Office 里的人一起工作？Install > Service > Microsoft 现在会把 Outlook、Word、Excel、PowerPoint、Teams 和 OneDrive 设置为网页应用。每个应用都有自己的窗口和启动器条目，所以它们和其他所有应用放在一起也感觉很自在。再也没有借口不在工作中切换到 Omarchy 了！

用于听写的 Superwhisper

Superwhisper 现在是 Omarchy 的默认听写引擎，开箱即用地设置好了。轻点 Alt + Space 开始说话，再点一次停止，或者按住 Right Alt 进行按键说话。它的速度快得惊人，而且非常准确。

它一开始使用云端，所以安装完的那一刻就能用，而且前 10,000 个单词免费。但你可以切换到一个可下载的模型，它完全免费、完全在本地运行，不会把一个字发送给任何人。而如果你更愿意使用另一个本地模型，Voxtype 仍然可供选择。

不到十秒完成安装

Omarchy 以前会逐个安装大约 940 个软件包。新的 F1 安装程序改为解开一个预构建的根镜像，只在其之上添加这台机器的软件包。这让任何机器上的安装时间大致减半。

而在快速硬件上，这简直荒谬。来自 AMD 的 Anush Elangovan 创下了世界纪录，在他的 AMD 笔记本电脑上用 7 秒完成了一次完整的 Omarchy 安装。七秒！我还记得五分钟似乎都是个雄心勃勃的目标的年代。

其他地方也更快了

不只是安装程序更快了。启动时不再因 binfmt 注册而停滞。主题选择器立刻打开，而不是等上四分之一秒。菜单和面板直接从 Hyprland 快捷键打开，跳过了先启动一个进程所需的 60 毫秒。Omarchy 菜单最慢的检查从 200 毫秒降到 16 毫秒，新终端的提示符早 30 毫秒出现，整个桌面现在会对变化作出反应，而不是轮询等待变化。甚至注销、重启和关机也会在你的应用完成关闭的那一刻发生。

智能体升级

Omarchy 是智能体操作系统，4.5 为使用智能体工作带来了一大轮升级。智能体面板现在跟踪 23 个智能体和提供商，高于之前的 6 个，包括 Cursor、OpenCode、GitHub Copilot、Antigravity、Hermes、Amp、Kiro、Devin、Qwen、DeepSeek、OpenRouter 和 Ollama。每个限额都有自己的计量条和距离重置的时间，这样你就能清楚地看到自己还剩多少余地。而 Grok 现在与 Claude 和 Codex 一起成为了一个完整的提供商。

而你的智能体永远只需按一个键就能到达。Super + ~ 会在一个变暗的桌面上方拉下一个 Quake 风格的控制台，第一次打开时，它会启动你的默认智能体。再按一次把它收起来，你的会话就在你离开时的原处。

如果你同时使用多个订阅，你现在可以在同一台机器上保留多个 Claude、Codex 和 Grok 登录，并使用 omarchy agent account 选择新会话从哪个开始。它们之间共享历史记录、设置和技能，所以切换后 claude --continue 就会从你离开的地方继续。接近限额时，Omarchy 可以提供一键切换，也可以自行将新会话转移到余地最多的账户。而当你设置另一台机器时，omarchy agent account copy 会通过 SSH 把你的所有登录信息都带过去，这样你就不必重新登录所有服务了。

Kimi 和 Ori，OpenRouter 的智能体框架，加入了 Setup > Defaults > Agent 下的选项，Google 的 Antigravity 取代了已过时的 Gemini CLI（gemini 仍然可作为别名使用）。比起终端更喜欢窗口？Claude 和 Amp 的桌面应用现在只需在 Install > AI 下点击一下即可获得。

通知，重新打造

通知现在按发送者堆叠，跟随你的主题，并折叠相同的重复通知。操作按钮、验证码和链接都可直接从卡片上使用。Super + Comma 可对最新的一条通知进行操作（关闭、打开或按下其按钮），Super + Ctrl + Comma 则把键盘交给你来操控所有通知。顶栏的铃铛可开启勿扰模式。

视频背景和主题开场

背景现在可以是视频了。放一个进来，你的桌面就会随着滚滚波浪或你喜欢的其他任何内容活起来，而锁屏会显示其中一帧静止画面。而且主题现在会登场亮相：每个主题都可以在你登录或切换到它时播放一段简短的无声开场。（更喜欢安安静静？在 Appearance > Animations 下关闭开场。）

Jade Horse 加入默认主题

Jade Horse 满是朦胧的绿色，雕玉般的背景让整个桌面看起来像一幅卷轴画。它取代了捆绑主题中的 Osaka Jade，并与 Starship 一起成为另一个新的默认主题。如果你正在使用 Osaka Jade，你会保留你的副本，它将作为一个第三方主题继续存在，供任何想全新安装它的人使用。

Liftoff 成为新的默认背景

新安装现在会用 Liftoff 来迎接你，这是一幅华丽的日落发射画面，是 Tokyo Night 新的默认背景。它由 Tom Ballard 制作，他最初是为他的 Liftoff theme 创作的。谢谢你，Tom！

启动菜单现在安静了

Omarchy 以前每次启动都会显示启动菜单大约六秒钟，以备你需要回滚到更早的快照。但几乎从来没人这样做过。所以现在 Limine 只等待一秒并安静启动，大多数时候你根本不会看到菜单。

当你确实需要另一个条目或快照时，在机器启动时持续轻点任意键（向下箭头也可以），它就会停在菜单处。而如果你更愿意让菜单一直显示更长时间，在 /boot/limine.conf 中设置你自己的 timeout:（例如 timeout: 5）。更新会保留你设置的超时时间，不去动它。

变更的快捷键

一些快捷键移位了：

  • 计算器：Super + Ctrl + Q 现在改为 Super + Shift + Q。
  • 活动：Super + Ctrl + T 现在改为 Super + Shift + T，而 Super + Ctrl + T 打开主题。
  • 网络：Super + Ctrl + W 现在改为 Super + Ctrl + N，而 Super + Ctrl + W 打开背景。
  • Nightlight 不再有快捷键（以前是 Super + Ctrl + N）；它位于 Trigger > Toggle 中。
  • Super + Alt + Space 从程序坞打开 Apps，而不是打开 Apps 菜单。

通知快捷键变更了：

  • Super + Comma 对最新的卡片进行操作（关闭它、打开它或按下它的唯一按钮），而不是只关闭它。
  • 关闭最后一个的快捷键移到了 Super + Alt + Comma，它以前是用来打开它的。
  • 静音从 Super + Ctrl + Comma 移到了 Super + Ctrl + Alt + Comma；Super + Ctrl + Comma 现在把键盘控制权交给你。

有几个键的工作方式不同：

  • Super + Tab、Super + Shift + Tab、Super + Ctrl + Tab 以及 Super + 滚动会停留在当前显示器的工作区上，因为每个显示器都有自己的工作区。
  • 在终端中，Super + C 和 Super + V 发送 Ctrl + Shift + C 和 Ctrl + Shift + V，而不是 Ctrl + Insert 和 Shift + Insert。

可能与你自己的绑定冲突的新默认快捷键：Super + Q（关闭窗口，与 Super + W 并存）、Super + A（全选）、Super + M（最小化到程序坞）、Super + ~ 和 Super + Shift + ~（Quake 控制台）、Super + Alt + L（上一个布局）、Super + Shift + Ctrl + Arrows（将窗口移动到另一个显示器）、Super + Ctrl + Alt + C（截图）、Super + Ctrl + Alt + E（世界时钟）、Super + Ctrl + Alt + F（全屏桌面），以及按住 Right Alt 进行按键说话听写。
