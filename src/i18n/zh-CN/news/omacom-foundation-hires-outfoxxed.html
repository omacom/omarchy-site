我们聘请了 outfoxxed，Quickshell 的创建者，来担任 Omarchy Shell 负责人！他将全职加入 Omacom 基金会，并成为 Omarchy Core 的一员。正是这位打造了让 Quattro 得以实现的工具包的人，现在加入我们，一起把整个项目送上月球。

这取代了我们在八月份宣布的为期三年的 Quickshell 赞助计划。outfoxxed 将不再以赞助的形式合作，而是成为 Omacom 基金会的全职员工，领导我们在 Omarchy Shell 方面的工作。我们把这位创建者放在了我们所构建事业的正中心。

Shell 对于我们正在打造的智能体操作系统至关重要。它就是状态栏、菜单、通知、小组件，以及所有让电脑感觉真正属于你的细微交互。Quickshell 为我们提供了用 QML 塑造这种体验的基础模块。再加上极其擅长编写 QML 的智能体，突然之间，改变你的桌面就变成了你可以提出要求、尝试并分享的事情。

证明就在插件里！当我们宣布赞助时，社区在 Quattro 发布的第一周就已经创建了一千多个插件。现在插件目录已经有接近三千个插件。有可以直接在状态栏上玩的游戏、有追踪你的编程智能体的面板、有音乐播放器，甚至还有一只会在你的状态栏上闲逛、等着被摸的猫。人们正在把一个曾经感觉固定不变的系统，变成真正属于自己的样子。这就是可塑计算机正在变为现实。

有了 Quickshell 的创建者加入，我们就可以一起打磨整个技术栈。让 Shell 更快、更可靠。让打造出色插件变得更容易。当插件作者遇到瓶颈时，就改进底层基础。把我们从数千次实验中学到的东西，变成让每一位启动 Omarchy 的用户都受益的更好体验。并确保整个系统安全可靠。

而通过加入 Omarchy Core，outfoxxed 还将帮助决定整个发行版的发展方向。Shell 在体验中太核心了，不能只是一个事后补充。智能体操作系统的美感、乐趣和种种可能性，正是在这里变成你能真正看到和使用的东西。

outfoxxed 是 Omacom 基金会的第二位全职员工，上一位是我们的 Omarchy Kernel 负责人 Krzysztof Wilczyński。随着负责 Kernel 和 Shell 的人全部到位，我们正在为整个体验的地基投入。你可以在网站上见到基金会的全体工作人员。

我们将继续通过邀请制招聘，在社区中通过实际贡献找到合适的人。（所以请不要往我的收件箱里狂塞简历！）

这正是基金会的支持让我们能做到的事：让杰出的开源开发者有时间全力以赴。感谢每一位资助这项工作的人，我们正在把更多的抱负变成全职岗位。

欢迎加入，outfoxxed！让我们把这台电脑变得更具可塑性。
