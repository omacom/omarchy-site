Omarchy 不仅对用户而言是美观、有趣、与智能体同行的 Linux 发行版，它也是这样打造出来的！靠美感、乐趣，还有大量 token。实际上，Omarchy Quattro 几乎全部由智能体开发，因为它们特别擅长 bash、QML 和 Linux 排障。

如今吸引了数十万用户与共同创作者，要继续改进 Omarchy，就必须让 token 源源不断。这才能加快处理、完善并交付涌来的精彩贡献。发布仅几周，就已经积压了超过 1,600 个 PR！没有智能体帮忙，谁也处理不完。

因此，我很高兴宣布，我们已从大多数主要实验室获得海量 token，支持这项使命！首先是 Meta Superintelligence Labs，以 150 万美元 token 成为创始 token 赞助人！全新的 Meta Muse Spark 模型以出色价格交出亮眼成绩，150 万美元基本等于无限 token！不过我们还是会努力用完！

我们也很高兴迎来另两家前沿实验室 Anthropic 和 OpenAI，各捐赠 15 万美元 token，成为杰出 token 赞助人。配合安全研究与修复所需的安全限制解除授权，这些 token 将尤其有用。

开放权重模型方面，我同样高兴地宣布，Fireworks 也以 15 万美元 token 成为杰出 token 赞助人。我常用 Kimi K 系列，尤其是高速模式。我们也会好好利用这些飞快的 token！

合计又为 Omacom Foundation 带来 195 万美元承诺，使总承诺额达到 1,495 万美元。一个起初被批评者称为“dotfiles 堆砌”的发行版，竟能写出这样的数字，实在疯狂。当然，当时也不算完全说错，只是我们后来一直在修好一切！

有了这些 token，我们能修好一切。而我们正准备这么做！
