Apple 硬件一直很出色。一直都是（除了蝶式键盘翻车的那一次）。很多来到 Omarchy 的人都是从 Mac 转过来的，他们中不少人都想留着机器、换掉操作系统。所以我们要完成 Asahi 未竟的事业：让 Omarchy 在 Apple Silicon 上漂亮地跑起来，而且安装几乎零折腾。

这项工作背后已经有了一支团队。今天我们正式官宣：Omarchy M，我们负责 Apple Silicon Mac 的团队（还有几位成员负责让老款 Mac 也能继续加入）。

下面介绍一下成员们。

安装程序。Marcelo Alcantara 正在打造 原生 Mac 安装程序。你在 macOS 上下载一个 App，它会自动拉取经过签名的 Omarchy 发行版，分好区，然后让你直接启动进入与现有 macOS 并存的 Omarchy。不用 U 盘，也不用在终端里念咒语。他还搞出了让 USB-C 外接显示器点亮的版本。

Omarchy Mac。Naeem Malik 维护 Omarchy Mac 已有一年，早在这一切官宣之前就把 Omarchy 装上了 M1 和 M2 机型，还围绕它建起了一个 800 多人的 Discord 社区。Scott Jones 是这个项目中负责 Linux 安装部分的另一半。他最近搞定了 M3 Air 在 Apple 硬件显示控制器上的显示，一夜之间让这台机器从没法用变成了能用。

Try Omarchy。Eduardo Martinez 打造了 Try Omarchy：真正的 Omarchy 桌面，以原生、硬件加速 App 的形式跑在你的 Mac 上，摄像头、音频、剪贴板和共享文件夹都已接通。不用分区。下载下来亲自看看它到底好在哪。

软件包。Shun Li 正在确保 Omarchy 所需的一切都有 aarch64 软件包版本，还有用于虚拟机的通用 ARM64 磁盘镜像，以及让虚拟机好用的客户机工具。

驱动和内核。Dj 在写 GPU 驱动，还通过直接与 Secure Enclave 对话搞定了 Touch ID。Miguel Cruz 逆向了 M5 机型中 Apple 自研的 N1 芯片，现在它的 Wi-Fi 和蓝牙在 Linux 下已完全可用。Liam 正在新机型上调通扬声器、触控板和电源管理。Eryk Wieliczko 运营着 Aurora Silicon，正在把所有这些做成可合入上游的 clean-room 实现。Jaidip Subedi 实现了 M2 MacBook Air 上通过 USB-C 的外接显示器。

MLX。Joshua Warren 正在打造 mlx-omarchy，通过 Vulkan 把 Apple 的 MLX 机器学习框架带到 Linux 上的 Apple GPU。你的代码依然是 import mlx.core as mx，但现在它跑在 Omarchy 上了。

老款 Mac。Shawn Yeager 为 2016 和 2017 款 Touch Bar MacBook Pro 提了一堆 pull request：扬声器、Wi-Fi、环境光传感器，还有 Touch Bar 本身。Randy 正在逆向 T2 安全芯片，要把 Touch ID 带到 Intel Mac 上，顺手把 2019 款 MacBook Pro 的每个修复都记录下来。Jon Kinney 一年前就开始一点点啃 Omarchy 的 ARM 支持，现在负责协调整个团队的分工。

他们合在一起是一支相当能打的队伍。十四个人，没等任何许可，用智能体把进度推到了放在一年前会觉得离谱的速度。

首个版本的目标是完美兼容 M1 和 M2，包括 Pro 和 Max 版本：

  • 无缝的安装程序，同时提供安装和试用选项
  • 完整的 GPU 支持
  • 通过 USB-C 的外接显示器
  • Touch ID
  • MLX
  • 磁盘加密

新机型也在同步推进，但我们先在 M1 和 M2 上插旗。除了 M 系列机型，外面还有数以百万计的老款笔记本，其中很多已经被 Apple 最新 macOS 的升级计划抛下，而每一台都是一台等着变身的出色 Omarchy 电脑。

不用等到打磨完善的正式版再上手。Try Omarchy 几分钟就能让你在 Mac 上看到真正的桌面。如果你准备好了要 All in，安装程序今天就能在 M1 或 M2 上把 Omarchy 装到 macOS 旁边。

最后，提个请求。如果你一直在为 Apple 硬件做 Linux 相关工作，无论是内核驱动、固件、打包、安装程序还是机器学习，都欢迎联系我们。很可能你已经解决了我们还在攻关的问题，反之亦然。联系方式：apple@omarchy.org。

让我们一起，把 Asahi 未竟的事业做完。
