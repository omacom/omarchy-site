Files#

Files（Nautilus）是图形文件管理器。Super + Shift + F打开它，Super + Shift + Alt + F则在终端当前所在目录打开，能省不少点击。Ctrl + L可输入路径，在任意文件上按Space即可快速预览而无需打开。

插入U盘或SD卡会自动挂载，直接出现在侧边栏中。更复杂的操作——格式化驱动器、检查SMART健康状态、创建分区——请从应用启动器（Super + Space）启动Disks。

双击遵循合理的默认关联：图片用imv打开，视频用mpv，PDF用Document Viewer，纯文本用Neovim。

Obsidian#

Obsidian是一款免费、高度可扩展的笔记应用，以普通Markdown文件存储。

Obsidian对个人、商业和非营利等所有用途免费。

Obsidian还提供商业同步附加服务，用于与iOS和Android移动应用同步。（https://obsidian.md/pricing）

用Super + Shift + O启动Obsidian。要使用主题同步，需在设置中选择Omarchy主题。

Omawrite#

Omawrite是Omarchy自家的极简Markdown写作应用。没有库，没有插件，只有你和文字。

用Super + Shift + W启动Omawrite。

Pinta#

Pinta是一款基础的图片编辑工具，适合裁剪、缩放等简单处理。别指望它替代Photoshop，但它也有魔棒和图层！

通过应用启动器（Super + Space）启动Pinta。

Aether#

Aether是一款主题应用，能从背景图片提取颜色并生成完整、协调的主题，是制作自己的主题最简单的方式。

通过应用启动器（Super + Space）启动Aether。

LocalSend#

LocalSend可向同一网络中运行该应用的其他设备发送文件，类似Apple的AirDrop，但它是跨平台的：Windows、macOS、Android、iOS，当然还有Linux，都能互传。

用Super + Ctrl + S或Omarchy菜单的Trigger > Share打开分享菜单，其中有四个选项：

  • Clipboard将复制的内容作为文本文件发送。把链接或片段传到手机上，再也不用给自己发邮件。
  • File打开文件选择器，可一次选择多个。
  • Folder发送整个目录。
  • Receive打开完整的LocalSend，让其他设备向你发送内容。

终端中同样可用：omarchy share clipboard、omarchy share file [path]和omarchy share folder [path]。省略路径则会打开选择器。

也可以直接从文件管理器发送：在Nautilus中右键任意选中项，选择Send via LocalSend。

Omarchy的防火墙默认关闭，仅开放LocalSend的端口，所以新装系统上开箱即可使用。参见安全。

LibreOffice#

LibreOffice是一套完整的办公软件，包含文字处理、电子表格、演示、绘图等应用。它兼容Microsoft Office文件，打开Word文档很方便。

通过应用启动器（Super + Space）启动LibreOffice。

Omacalc#

Omacalc是Omarchy自家的极简计算器，以浮动窗口打开。

用Super + Ctrl + Q（或键盘上的计算器键，如果有的话）启动Omacalc。

Signal#

Signal是端到端加密通讯的先驱，对于不想依赖科技巨头的人来说，是极好的通讯选择。

用Super + Shift + G启动Signal。它不在基础安装中，首次按下快捷键时，Omarchy会提议为你安装（也可在Omarchy菜单的Install > Service下安装）。

mpv#

mpv是一款简洁、快速的媒体播放器，几乎能播放任何来源的任何内容，看视频很合适。

通过应用启动器（Super + Space）启动mpv，或直接在文件管理器中双击视频。

OBS Studio#

OBS Studio可从多路输入录制或直播视频，把屏幕录制、摄像头和麦克风混合在一起。Omarchy的演示视频就是用它录制的。

通过应用启动器（Super + Space）启动OBS Studio。

Kdenlive#

Kdenlive是一款出色的视频编辑器，非常适合在分享前处理OBS Studio录制的视频。

通过应用启动器（Super + Space）启动Kdenlive。

Omacut#

Omacut是Omarchy自家的极简视频剪辑器。只需裁掉片段首尾时，它比打开完整的视频编辑器方便得多。

通过应用启动器（Super + Space）启动Omacut。
