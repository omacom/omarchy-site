Omarchy的网络由NetworkManager管理，通过状态栏中的网络图标或Super + Ctrl + W操作。

该面板会扫描Wi-Fi网络、显示信号强度并连接。有线网络什么都不用做——插上就能用。想留在终端里的话，nmtui提供同样的控制，另外还有一组omarchy network命令。

分享Wi-Fi#

与其把一长串密码念出来，不如在连着Wi-Fi时运行Setup > Network > QR Code。屏幕上会显示一个二维码，任何手机相机扫一下就能加入。这类功能一旦知道有，用得会比想象中频繁。

确实需要密码本身时，omarchy network password <interface>会把它打印出来。

DNS#

Omarchy使用网络通过DHCP下发的DNS。可以在Setup > Network > DNS下为整台机器覆盖它，Cloudflare和Google一键可选，选择Custom则可输入自己的服务器。

终端中，omarchy dns显示当前提供商，omarchy dns Cloudflare设置一个。

固定Wi-Fi频段#

如果路由器把2.4GHz、5GHz和6GHz放在同一个网络名下，笔记本有时会死守着慢的那个。omarchy network band显示当前所在频段，omarchy network band 5固定频段，auto则交回自动选择。

这固定的是频段而非具体接入点，所以在各个AP之间照常漫游。

网速有多快？#

Trigger > Speed Test > Network Speed Test用一对仪表盘测量实际的上下行速度。终端中是omarchy network speedtest down或up。（同一菜单里还有磁盘速度测试，用于衡量另一个瓶颈。）

防火墙#

防火墙默认开启，拦截所有入站流量，只有一个例外：53317端口，以便LocalSend开箱即用。

SSH默认关闭，直到你通过Setup > Security > SSHD开启，它会启动守护进程、开放带暴力破解限速的22端口，并授权一个密钥。Docker也被锁住，容器不会意外暴露到外网。完整说明参见安全。

Tailscale#

Tailscale是一款网状VPN，让你通过互联网安全访问所有电脑和服务器变得极为简单。通过Install > Service > Tailscale安装。

安装后状态栏中会出现Tailscale面板，可以连接和断开tailnet、切换账户、选择出口节点——你自己的机器和Mullvad地区都在列表中。它还能浏览你的机器，Taildrop就在这里：选中一台机器，按s向它发送文件，按c、n、d复制其IP、名称或完整DNS名。终端中的对应命令是omarchy tailscale send <machine> [file...]，发给你的文件会自动存入~/Downloads。到达通知会一直等到你点击打开或关闭，所以你不在机器旁时收到的文件，回来后仍在等你处理。

安装后还会添加一个Tailscale管理控制台的Web应用。

网络失灵时#

重启之前，先试着单独重启出问题的那一部分。Update > Hardware下有Wi-Fi、蓝牙、音频和触控板，重新加载其中一项就能解决大多数“五分钟前还好好的”情况。参见故障排除。
