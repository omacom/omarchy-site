日常改动的许多东西其实不是设置，而是模式：开一小时再关掉。熬夜工作时开夜间模式，演示时开勿扰，看视频时开保持唤醒。Omarchy称之为开关，它们的工作方式完全一致——一个快捷键、一个菜单项、一条命令，作用于同一个开关。

开关菜单#

Super + Ctrl + O直接打开Trigger > Toggle，也可以从Omarchy菜单（Super + Space）一路点进去。列表中的每一项都是可以随手拨动的开关，不必关心状态存放在哪里。

在终端中，同样的开关是omarchy toggle <thing>。单独运行omarchy toggle可查看整组。

开关 快捷键 命令
夜间模式 Super + Ctrl + N omarchy toggle nightlight
通知静音 Super + Ctrl + , omarchy toggle notification silencing
保持唤醒（不在空闲时锁定） Super + Ctrl + I omarchy toggle idle
崩溃捕获 - omarchy toggle crash-capture
屏保 - omarchy toggle screensaver
菜单栏 Super + Shift + Space omarchy toggle bar
触控板 XF86TouchpadToggle omarchy toggle touchpad
触摸屏 - omarchy toggle touchscreen
挂起 - omarchy toggle suspend
混合GPU - omarchy toggle hybrid gpu

触控板、触摸屏和混合GPU的开关位于Trigger > Hardware（Super + Ctrl + H）而非Toggle下，因为它们只在确实存在对应硬件时才出现。触控板和触摸屏的开关在Hyprland重新加载后依然有效：被禁用设备的名称会保存到一个小状态文件中，Hyprland启动时读取并再次禁用。

Toggle菜单中还有几项虽然不是omarchy toggle命令，但行为相同：状态栏中的电量百分比、工作区布局（Super + L）、窗口间隙（Super + Shift + Backspace），以及单窗口方形比例（Super + Ctrl + Backspace）。

这些开关大多只是~/.local/state/omarchy/toggles/下的一个标记文件。想在脚本中根据某个开关分支，omarchy-toggle-enabled会直接给出退出码，无需自己去找： 

omarchy-toggle-enabled screensaver-off && echo "screensaver is off"

标记按关闭状态命名——screensaver-off、suspend-off、bar-off——存在即表示该功能已禁用。

状态栏中的指示器#

某个模式开启时，状态栏中间时钟旁会出现一个小图标。那是指示器部件，涵盖语音听写、录屏、待触发的提醒、夜间模式、勿扰和保持唤醒。

未激活的指示器默认隐藏。把鼠标悬停到它们周围，它们会以暗色淡入，这样不知道快捷键也能点击开启；点击已激活的指示器则将其关闭。如果希望始终显示全部，在~/.config/omarchy/shell.json的omarchy.indicators条目上将alwaysShow设为true——状态栏部件的配置方式参见状态栏。

夜间模式#

Super + Ctrl + N将屏幕色温调暖至4000K，再按一次恢复6500K。它由hyprsunset驱动，如果hyprsunset尚未运行，开关会替你启动。

默认情况下，hyprsunset完全不改动屏幕：~/.config/hypr/hyprsunset.conf自带一个恒等配置，正是为了在你要求暖色之前保持显示原样。如果希望按时间自动切换，把它换成时间配置： 

profile {
    time = 20:00
    temperature = 4000
}

然后在~/.config/hypr/autostart.lua中添加o.launch_on_start("hyprsunset")，让hyprsunset随登录启动。开关使用的4000K/6500K这一对是固定的，想要其他色温就去改配置文件。

勿扰#

Super + Ctrl + ,让通知静音。开启期间不会弹出提示，状态栏中会出现一个划掉的铃铛，提醒你桌面为何安静了。

不过什么都不会丢失。被静音的通知会直接写入通知历史，正是你回来后想知道错过了什么时需要的记录。用Super + Shift + Alt + ,打开它。通知的其余内容参见快捷通知。

两类消息仍会通过：Omarchy对你刚做的操作的确认提示（“Theme changed”、“Screenshot saved”），以及从命令行发送的紧急警报。那些把所有消息都标记为紧急、强行挤到你面前的聊天应用，不在此列。

空闲#

空闲行为由Omarchy shell负责，计时位于~/.config/omarchy/shell.json顶层的idle块： 

{
  "version": 1,
  "idle": {
    "screensaver": 150,
    "lock": 300
  }
}

两个数字都是从进入空闲那一刻算起的秒数，而不是彼此的间隔。按默认值，屏保在两分半后出现，锁屏在五分钟时接管，无论屏保是否运行过。保存文件，shell会立即采用新计时。

如果在锁定期限之前退出屏保，这算作活动，待执行的锁定会被取消。你不会因为看了一眼机器就被锁在外面。

要彻底停止空闲锁定，按Super + Ctrl + I——或运行omarchy toggle idle——开启保持唤醒，状态栏中会出现咖啡杯指示器。长时间演示或想盯着的构建开始前，就按它；再按一次恢复正常。脚本中需要时，omarchy toggle idle status会以JSON输出当前状态。

这里说的是锁定和屏保，不涉及电源。挂起和休眠有各自的设置，参见系统睡眠。

屏保#

Omarchy的屏保是随机文字特效中的ASCII艺术，每个显示器一个实例。任何按键或鼠标移动都会退出。

可以从System > Screensaver（Super + Esc）按需启动，即使关闭了空闲屏保也会强制显示。默认没有绑定快捷键。

如果想从工作直接进入锁定，omarchy toggle screensaver可关闭空闲屏保。它需要一个能够配置的终端——Alacritty、Foot、Ghostty或Kitty——如果默认终端是其他程序，它会提示你。

屏保绘制的标志可以在Style > Screensaver下更换：上传png或svg，Omarchy会将其转换为ASCII。参见品牌定制。

锁屏#

Super + Ctrl + L锁定机器。这会运行Omarchy shell的锁屏，熄灭显示，把键盘布局重置为第一个（免得用错误的字母表输入密码），并且——如果1Password正在运行——顺便将其锁定。

锁屏接受密码，设置指纹后也接受指纹。这一点和其他认证方式参见硬件认证。
