Omarchy可以安装到单个分区，与Windows或其他系统共存。

这种安装方式默认同样对分区启用LUKS加密，所以实际上与全盘安装没有区别，只需要磁盘上有可用的空闲空间。

在Windows上腾出空间#

要与Windows共存安装，在开始菜单中输入disk management，选择Create and format hard disk partitions。

找到对应的分区，右键选择Shrink Volume。

输入要压缩的容量。注意，这将是未来Omarchy安装（含启动分区）的大小。

完成后应该会看到类似下图的结果，本例中50GB的区域就是Omarchy的安装位置。

安装Omarchy#

Omarchy的安装过程与平常基本相同。选择磁盘后会出现Free space install选项，选择它以避免抹掉整块磁盘。

确认一切无误后，像平常一样等待安装完成。和全盘安装一样，这里也可以选择不加密安装（不推荐）。

把其他系统加入启动加载器#

Omarchy安装完成后，你会发现Limine启动加载器已成为默认。借此也可以把Windows等其他系统作为选项加入Limine。

运行limine-scan，按提示把想要的条目加入limine配置。之后启动时，除了Omarchy的常规选项，还会看到Windows Boot Manager或其他系统。

Bitlocker#

需要注意，这种安装方式与Bitlocker不兼容，因为它加密的是整块驱动器而非单个分区。如果遇到提示Bitlocker已启用的错误，启动进Windows，前往Settings -> Privacy & Security -> Device encryption关闭Bitlocker。解密驱动器可能需要一些时间。
