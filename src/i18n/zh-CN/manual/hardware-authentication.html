指纹认证#

许多笔记本配有用于认证的指纹传感器。在Omarchy菜单（Super + Space）中运行Setup > Security > Fingerprint即可使用。

它会安装指纹软件包、采集并验证你的指纹，之后就可以用指纹解锁锁屏（Super + Ctrl + L触发）、进入sudo模式，以及授权系统提示。

笔记本盖子合上时会自动跳过指纹提示，直接进入密码提示，而不是等待一个够不着的传感器。如果需要在没有传感器的外接键盘上工作，sudo提示输入指纹时按CTRL + C即可。

在Omarchy菜单的Remove > Security > Fingerprint下可以移除指纹认证。

Fido2认证#

使用Fido2设备的话，可以通过Omarchy菜单（Super + Space）的Setup > Security > Fido2将其设置为sudo认证方式。它覆盖sudo和系统授权提示，但不包括解锁电脑。

在Omarchy菜单的Remove > Security > Fido2下可以移除fido2认证。
