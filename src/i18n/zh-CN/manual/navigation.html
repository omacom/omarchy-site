Omarchy中的一切都通过键盘完成——一切！系统首次启动时，光靠鼠标什么也做不了。但按下Super + Space就能调出Omarchy菜单，从这里几乎可以完成所有操作。

不过大多数时候，Omarchy菜单并不是操作系统的主要方式。我们可以更快！所有最重要的应用都直接绑定了快捷键：Super + Return启动终端，Super + Shift + Return启动浏览器。先后按下试试，你就能看到Hyprland平铺的魔力：

用Super + Arrow切换要激活的窗口。这会转移焦点，并把光标移到新应用的中央。

按Super + Shift + 2，当前聚焦的应用会移到第二个工作区，Super + Shift + 1把它移回来。（Super + Shift + Alt + 2则把当前应用移到第二个工作区，但自己不跟过去。）

按住Super用鼠标点击窗口，可以重新安排它的位置；按住Super并使用鼠标右键，可以自由调整窗口大小。

用Super + W或Super + Q关闭窗口（Ctrl + Alt + Delete关闭所有窗口）。

你还可以用Super + F全屏，用Super + Alt + F仅占满宽度（保留状态栏），或用Super + Ctrl + F在窗口内全屏（看YouTube很合适！）。

Dwindle布局与滚动布局#

Omarchy的默认布局叫dwindle。它让同一工作区内打开的所有窗口始终可见，哪怕不得不把它们缩小。

你也可以把工作区切换成滚动布局：窗口并排排成一行，延伸到屏幕可见范围之外。用Super + L即可将当前工作区切换为这种布局。

这个选择按工作区保存，并且会保留。所以你可以让工作区1用dwindle浏览网页，工作区2用滚动布局写代码，重启后依然如此。（同样的开关也在Omarchy菜单的Trigger > Toggle > Workspace Layout下。）

如果想把滚动布局设为默认，可以在~/.config/hypr/looknfeel.lua中设置： 

hl.config({
  general = {
    layout = "scrolling",
  },
})

窗口分组#

用Super + G可以将窗口分组。进入分组后，在此期间启动的每个窗口都会归入该组。用Super + Ctrl + Arrow Left/Right在组内窗口之间移动，或用Super + Alt + 1/2/3/4按顺序直接跳到组内某个窗口。

用Super + Alt + G把窗口移出分组，或再按一次Super + G解散整个组。最后，Super + Alt + Arrows可以把组外的窗口移进组内。

弹出窗口#

Super + O可以把窗口从所在工作区中弹出，固定为浮动窗口，跟随你去往任何工作区。非常适合视频播放器之类的应用。

便签工作区#

最后，还有一个特殊的便签工作区，会覆盖在当前工作区之上，很像Quake的控制台。用Super + Grave或Super + S切换显示，用Super + Shift + Grave或Super + Alt + S把窗口放进去。

它特别适合运行智能体的终端，或是那些你想随手操作又不想离开当前工作区的控制窗口。要把窗口移出便签工作区，直接用Super + Shift + 1之类的快捷键把它发送到其他工作区即可。

需要一点时间适应！#

用这种方式操作桌面需要一点时间适应，但一旦习惯，就很难再回到传统的鼠标驱动桌面了！
