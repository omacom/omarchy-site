如何切换键盘布局？#

编辑~/.config/hypr/input.lua，加入下面的内容，即可用Left Alt + Right Alt在布局之间切换： 

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",
  },
})

配置了多个布局后，状态栏会自动显示当前键盘布局（点击它也能切换）。

如何把时钟改为12小时制？#

右键点击状态栏中的时钟，可在常用格式（包括12小时制）之间循环切换。也可以直接设置格式： 

omarchy bar set omarchy.clock format "dddd h:mm AP"

这会显示为Sunday 10:55 AM。

如何修改时区？#

在Omarchy菜单中运行Update > Timezone，从列表中选择。如果时区正确但时钟本身走偏了，Update > Time会重新启动时间同步。

如何测试磁盘速度？#

Trigger > Speed Test > Disk Speed Test会实时测量驱动器的读写速度，终端中则是omarchy disk speedtest。

为什么无法在Chromium中登录Google账户？#

纯开源的Chromium构建不附带Google登录所需的OAuth凭据。在Omarchy菜单中运行Install > Service > Chromium Account添加它们，重启浏览器后即可登录。

如何添加打印机？#

打印功能开箱即用，每台打印机由你自己在应用启动器（Super + Space）的Print Settings中添加。

选择Add，稍等片刻让它搜索：通过USB连接的打印机和大多数网络打印机都会被自动找到。如果你的不在列表中，选择Network Printer > Internet Printing Protocol (ipp)并输入地址——打印机自己的屏幕或网页会告诉你地址，通常类似192.168.1.50，队列为ipp/print。接着Forward会提供驱动，新款打印机用免驱动的IPP Everywhere配置效果最好，老机型则需要对应型号的驱动。

右键点击打印机，选择Set as Default决定应用优先使用哪一台，选择Properties设置纸张大小、双面和质量。

自动发现——网络上的打印机无需添加自动出现——在重做期间暂时关闭，所以上面的第一步需要你手动完成。打印到PDF文件不需要任何打印机。

如何修改截图或录屏的保存位置？#

想把截图保存到~/Pictures/Screenshots而不是~/Pictures，可以把下面这行加到~/.config/uwsm/env.d/下的某个文件中（如~/.config/uwsm/env.d/capture）： 

export OMARCHY_SCREENSHOT_DIR="$HOME/Pictures/Screenshots"

录屏同理，使用OMARCHY_SCREENRECORD_DIR。

记得先创建目标目录，并重启Omarchy使其生效。

如何让Apple Studio Display的扬声器和摄像头工作？#

你可能以为插上USB-C就万事大吉，可惜并非如此。我找到的可靠办法是使用WJESOG DisplayPort + USB-A转USB-C线，之后扬声器和摄像头都能正常工作。

记住，Omarchy内置了Apple显示器（Studio和XDR）的亮度控制，用常规的键盘亮度键即可。

如何清掉所有额外的软件？#

不想要Obsidian、LibreOffice或其他预装软件的话，移除起来很容易。

运行Remove > Package查看所有已安装的软件包，用Tab选中想移除的，再按回车开始移除选中的全部。

在Omarchy菜单中用Remove > Web App可以移除不需要的预装Web应用。

也可以运行Remove > Preinstalls，一次清掉所有预装的额外内容——Web应用、TUI和可选应用。启动它们的快捷键也会随之消失，留给你一套干净的键绑定，在~/.config/hypr/bindings.lua中填上自己的。

报错和故障请参见故障排除。
