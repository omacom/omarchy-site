屏幕顶部的那一条是Omarchy状态栏。它不是外挂的状态栏，而是Omarchy shell的一部分——同一个常驻的Quickshell进程还负责绘制菜单、通知、OSD弹窗和锁屏。因此它与其他一切主题完全一致，面板也能即时打开，而无需启动新的应用。

它也是桌面上唯一始终显示的部分，所以值得弄清楚那些小图标各是什么。

默认内容#

状态栏分三个区域。左侧是Omarchy标志（菜单启动器）和工作区指示器；中间是状态指示器、时钟、键盘布局、天气和Omarchy更新标记；右侧是系统托盘、智能体、蓝牙、网络、音频、显示和电源。

其中一些只在有内容时才出现：键盘布局仅在配置了多个布局时显示，更新标记仅在有Omarchy更新等待时显示，智能体图标则在Omarchy首次在这台机器上发现AI编程用量时出现（参见AI）。

点击操作#

几乎每个部件在左键、右键和中键点击时都有动作，不少还响应滚轮。这是大家容易错过的部分——许多好东西都藏在右键和中键里。

面板#

点击状态栏图标会打开一个面板。它是带滑块、列表和键盘导航的正式弹窗，而不是工具提示。每个面板都有快捷键，所以你永远不必去瞄准一个16像素的图标：

快捷键 面板
Super + Ctrl + A 音频
Super + Ctrl + W 网络
Super + Ctrl + B 蓝牙
Super + Ctrl + D 显示
Super + Ctrl + P 电源
Super + Ctrl + Alt + D 日历
Super + Ctrl + 1-9 切换右侧区域的第n个面板

面板不只是信息展示，而是真正操作的地方：

  • 音频提供主音量滑块、输出设备选择和按应用的混音器，可以只调低某个浏览器标签页而不影响其他。
  • 网络扫描Wi-Fi，显示信号强度，连接网络，并可选择DNS提供商。
  • 蓝牙列出设备，支持连接/断开并显示电量。
  • 电源显示电池状态，切换电源模式（会分别记住电池与外接电源下的选择），并显示一些系统信息。
  • 显示提供亮度滑块、文字大小、显示器缩放预设，以及多屏时的逐显示器控制。更多内容参见显示器。
  • 时钟打开带ISO周数的月历，可按月切换。

每个面板都支持键盘和鼠标：方向键移动，Return确认，Tab切换到相邻面板，Escape关闭。

Super + Ctrl + 1-9按右侧区域从左到右计数，跳过没有面板的托盘，因此数字与你要指向的图标一一对应。

Tailscale与Dropbox#

还有两个部件只在通过Install → Service安装对应服务后才会出现，两者都值得了解，因为它们不只是显示状态。

Tailscale面板可以连接和断开tailnet、切换账户、选择出口节点（你自己的机器和Mullvad地区都会出现在列表中）。它还能浏览你的机器：选中一台后，按s即可通过Taildrop向它发送文件，这是把文件传到手机或另一台笔记本最快的方式；c复制该机器的IP，n复制名称，d复制完整DNS名称。每一行也有发送按钮，如果你更愿意点击。终端中对应的命令是omarchy tailscale send <machine> [file...]。

Dropbox面板负责登录，显示已用存储空间，并列出最近同步的文件。

移除任一服务，对应部件也会从状态栏消失。

指示器#

中间那一小簇是指示器部件，显示已开启模式的状态图标：勿扰、夜间模式、待触发的提醒、进行中的录屏、保持唤醒，以及语音听写。模式激活时它们亮起，平时则不碍事——把鼠标悬停在状态栏中间即可看到未激活的那些。点击指示器可切换对应模式。

如果希望它们始终可见，将该部件的alwaysShow设为true。如果只关心其中几个，在items中列出想要的：["Dnd", "Reminder", "NightLight"]。指示器部件可以有多个，不同区域可以显示不同的子集。

重新排列状态栏#

状态栏自己配置自己，移动东西不必打开配置文件。

抓住状态栏中部的一块空白，拖向另一条屏幕边缘，状态栏就会移过去——左、右、上、下都可以，每个部件都会自适应（垂直状态栏会退化为紧凑的纯图标形式）。按住不放同样可以开始拖动。双击同一块空白可切换透明度。拖动任意部件可以重新排序，或把它扔到另一个区域。

如果更愿意从菜单中选择，Style → Menu Bar同时提供位置和透明度设置。

同样的操作也有对应命令，正是配置文件方案需要的： 

omarchy bar position bottom
omarchy bar transparent toggle
omarchy bar move omarchy.clock --section center --index 0
omarchy bar set omarchy.clock format "HH:mm"
omarchy bar defaults          # back to the shipped layout

要彻底添加或移除某个部件，使用插件命令。omarchy plugin list列出shell识别的每个部件及其id，然后： 

omarchy plugin enable omarchy.media --section center
omarchy plugin disable omarchy.weather

隐藏状态栏#

Super + Shift + Space可以关闭再显示状态栏，而不终止shell——面板和快捷键照常工作，你只是拿回了那些像素。菜单中的Trigger → Toggle → Menu Bar也提供同样的开关。

配置文件#

以上一切都存放在~/.config/omarchy/shell.json的bar键下。这是一个精简版本： 

{
  "version": 1,
  "bar": {
    "position": "top",
    "transparent": false,
    "centerAnchor": "omarchy.clock",
    "layout": {
      "left": [{ "id": "omarchy.menu" }, { "id": "omarchy.workspaces" }],
      "center": [{ "id": "omarchy.clock", "format": "HH:mm" }],
      "right": [{ "id": "omarchy.audio" }, { "id": "omarchy.power" }]
    }
  }
}

每个部件都是三个布局数组之一中的一个条目，它的设置直接写在该条目上——没有单独的设置文件，也没有config子对象。时钟的format、formatAlt（右键切换到的格式）和verticalFormat都直接放在{ "id": "omarchy.clock" }上。

centerAnchor指定中间区域中固定在屏幕正中的那一个部件，其余部件分列两侧。这就是为什么天气和更新标记来来去去，时钟依然稳居正中。将它设为空字符串，中间列表就会作为整体居中。

有一条规则值得记住：一旦有了自己的shell.json，它就是唯一依据。在你做任何自定义之前，shell读取Omarchy的默认文件；一旦你拖动了部件、运行了omarchy bar或亲自编辑了文件，它就归你所有——不会进行深度合并，所以未来Omarchy版本新增的默认部件不会自动出现在你的状态栏上。想要重新开始时，omarchy bar defaults会恢复默认布局。

同一文件还在顶层（bar键之外）保存空闲计时：idle.screensaver和idle.lock，都是从进入空闲开始计算的秒数。因此默认屏保在150秒时启动，锁屏在300秒时启动。
