在macOS或Windows上用了多年，你的手指记住了上百个大脑早已忘记学过的动作。本章就是这两者之间的转换层：告诉你这些本能在Omarchy中对应什么。各项功能本身在其他章节有详细介绍，这里只是一张地图。

一切以Super为中心#

你围绕Cmd或Windows键建立的所有肌肉记忆，都转移到了同一个键：Super。在PC键盘上它就是Windows键，也是Omarchy几乎所有快捷键的锚点。

按Spotlight、Raycast或开始菜单的反射动作，变成了Super + Space。它打开Omarchy菜单：启动应用、修改设置、安装软件、截取屏幕，几乎什么都能做。开始输入即可筛选。另有一个只列出应用的菜单，快捷键是Super + Alt + Space。参见窗口导航。

没有Dock，也没有桌面图标#

没有可点击启动程序的东西，也没有可在桌面上排列的图标。应用通过快捷键启动（Super + Return打开终端，Super + Shift + Return打开浏览器，Super + K列出所有已绑定的快捷键），或从菜单启动。唯一常驻的界面元素是状态栏，它承担了以往菜单栏、系统托盘和通知中心的职责，而且上面几乎每个部件在左键、右键、中键点击时都有各自的动作。

窗口自动就位#

最大的观念转变：你不再拖动窗口，也不再把它们贴到半边屏幕。打开一个窗口，它占满整个屏幕；再打开一个，两者平分。窗口从不重叠，所以你永远不必从另一个窗口下面把它翻出来。

确实需要浮动窗口时，Super + T可以把当前窗口从平铺中切出来（再切回去）。但请先给平铺一个真正的机会——它是整个系统的核心。窗口导航会带你熟悉它。

工作区会让你感到熟悉：它们就是macOS的Spaces或Windows的虚拟桌面，只不过你会真正用起来，因为Super + 1/2/3/4直接跳到对应工作区，Super + Shift + 1/2/3/4把当前窗口发送过去。没有动画延迟，只有即时切换。如果你以前习惯多显示器，现在可能根本不需要了。

复制粘贴开箱即用#

在Mac上，你到处使用Cmd + C；在Windows上，到处使用Ctrl + C——除了终端，在那里它会终止程序。Omarchy提供Super + C、Super + X和Super + V，它们在任何地方都有效，包括终端。不必为shell单独学一套反射。

Windows用户：你的Win + V剪贴板历史对应Super + Ctrl + V，而且图片和文本都保存。参见统一剪贴板与历史记录。

有些地方确实不同#

许多设置存放在你编辑的文本文件里，而不是逐层点击的面板中。这听起来原始，直到你意识到：每一处调整都看得见、能复制到下一台机器、能纳入版本控制。Setup菜单会直接带你进入对应文件，编辑完成后自动重启需要重启的进程。

更新只有一条命令——Update > Omarchy——它会更新Omarchy本身和系统中的每个软件包，并先创建快照。没有各个应用随时冒出来的更新提示。参见系统更新。

软件来自包管理器，而不是下载的安装程序。

而且关闭窗口时，应用就真的退出了。没有macOS那种程序没有窗口却仍在运行的中间状态。Super + W——或者Super + Q，如果这是你带来的手指记忆——意味着彻底关闭。

在Mac硬件上#

Omarchy在Intel Mac上运行良好，参见Mac支持。键盘也对你很友好：Omarchy不重映射任何按键，Linux把Command键视为Super，所以Super就在Cmd一直所在的位置。你的拇指察觉不到变化。

给它两周时间#

本能的迁移比你想的更快。把快捷键一章快速浏览一遍，想不起某个绑定时就按Super + K，它会列出全部快捷键。这是你唯一真正需要记住的一个。
