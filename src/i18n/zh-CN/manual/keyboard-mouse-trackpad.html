Hyprland允许你对所有输入设备做非常细致的配置：可以把键盘重复速度调到飞快，也可以让触控板使用自然滚动。这一切都在~/.config/hypr/input.lua中修改，该文件也可通过Omarchy菜单（Super + Space）的Setup > Input打开。在这里设置的任何内容都会替换Omarchy的默认值。

示例如下：

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })

Hyprland wiki上可以查看全部输入选项。

Omarchy默认把CapsLock用作组合键，用于快速表情和其他补全。如果你更想让CapsLock就是大写锁定，修改kb_options中的compose:caps，把组合键挪到别处。比如下面把组合键移到右Alt： 

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

触控板手势#

还可以开启触控板手势，比如三指滑动切换工作区： 

hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

配备触觉反馈触控板的Dell XPS笔记本，还可以在Trigger > Hardware > Touchpad Haptics下把按压力度设为低、中或高。

输入中文、日文及其他语言#

Omarchy在每个会话中都运行fcitx5输入法框架——CapsLock组合序列正是由它驱动的。这意味着非拉丁文字输入的底层设施已经就位：用omarchy pkg add安装一个输入引擎，如fcitx5-mozc（日文）或fcitx5-chinese-addons（中文），再装上fcitx5-configtool，把引擎加入输入法列表并设置切换键即可。

用ALT充当SUPER#

在某些键盘上，用主meta键（Windows/cmd键）充当SUPER并不顺手。可以通过下面的修改改用ALT： 

hl.config({
  input = {
    kb_options = "compose:caps,shift:both_capslock_cancel,altwin:swap_alt_win",
  },
})
