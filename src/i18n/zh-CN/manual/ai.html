Omarchy将AI编程智能体视为一等公民，但不替你选定偏好。相反，每个主要的编程智能体CLI都预先接入，作为按需加载的启动器提供。这些启动器是~/.local/bin/中由mise管理的小型存根，在首次真正运行之前不会下载任何东西。运行其中任意一个，并按提示完成认证：

命令 智能体
claude Claude Code
codex OpenAI Codex
opencode OpenCode
agy Google Antigravity CLI
copilot GitHub Copilot CLI
crush Crush
grok xAI的Grok CLI
pi Mario Zechner的Pi
omp Oh My Pi
ori Ori，OpenRouter的运行环境

ori比较特别：它让其他运行环境跑在OpenRouter的整个模型目录上。ori claude、ori codex或ori opencode会用你指定的模型启动对应智能体，ori code则是Ori自己的智能体。

要以同样方式包装其他CLI，运行omarchy-mise-install <package> [command-name]。运行omarchy update（或mup别名）时，这些存根会与mise管理的其他内容一同更新。

默认智能体#

用omarchy default agent <name>或Omarchy菜单（Super + Space）中的Setup > Defaults > Agent选择默认智能体。如果尚未安装，选择时会先安装。新装的Omarchy会通过一次性通知邀请你做出选择。

选定后，Super + Shift + Ctrl + A会在专用终端窗口中启动默认智能体（尚未选择时则打开选择器）。也可以直接带任务启动：omarchy agent prompt "Review this project"。这样启动的智能体以各自的免确认模式无人值守运行，所以要有心理准备——它们真的会动手！另外，由于智能体拒绝记住对家目录的信任，从$HOME启动会改为在~/Work中启动。

终端中也有快捷方式：a在当前终端内联运行默认智能体，c、cx和cy分别直接启动OpenCode、Claude Code和Codex（同样是自动批准模式）。主题变化也会同步到智能体：切换Omarchy主题时，Claude Code、Pi和OpenCode都会跟着变。

智能体面板#

Omarchy首次在这台机器上发现AI编程用量时，状态栏会出现智能体图标（在此之前它不会现身）。图标背后的面板集中追踪每个订阅：套餐、5小时会话与每周限额的已用百分比（或预付余额），以及按天和按模型统计的token用量。Claude Code、Codex和Fireworks开箱即支持。

左键点击状态栏图标打开面板，右键启动默认智能体。背后的用量记录每15分钟由omarchy agent usage-update重新生成，面板还能通过同步文件夹合并其他机器的用量。完整设置参见$OMARCHY_PATH/shell/plugins/agents/下的README。

崩溃诊断#

Omarchy监视systemd-coredump以捕获进程崩溃。某个程序段错误时，你会收到“Process crashed”通知——点击它，崩溃信息就会连同Omarchy的diagnose-crash技能一起交给默认智能体。该技能引导智能体从核心转储中确认事实，并判断是否值得向上游报告。也可以针对coredumpctl list中的任意PID手动运行：omarchy agent crash <pid>。

监视默认开启。在Trigger > Toggle > Crash Capture下（或用omarchy toggle crash-capture）关闭后，通知即停止；omarchy agent crash <pid>仍可手动使用。

崩溃通知也可以按程序逐个静音，诊断结束时会提供这个选项。omarchy crash mute hyprland仅停止该程序的通知，omarchy crash mute hyprland off恢复，单独运行omarchy crash mute则列出已静音的程序。它同时接受二进制路径和名称，omarchy crash mute /usr/bin/hyprland效果相同；名称含空格时需加引号，如omarchy crash mute 'Some App'。其他程序照常通知，被静音的程序也照常崩溃——这只是隐藏了提醒，并没有修复任何问题。

桌面应用#

Install > AI菜单还提供几款图形化AI应用：ChatGPT桌面应用，以及用于与xAI模型对话的Grok Bot。

本地大模型#

Omarchy推荐两种运行本地大模型的方式：LM Studio和Ollama。LM Studio提供图形界面，用于查找、安装和运行开放权重模型，是轻松上手的好途径；Ollama则以CLI完成类似工作。如果你是本地模型的新手，建议从LM Studio开始。两者都可以在Omarchy菜单的Install > AI下安装。

Omarchy技能#

智能体技能帮助AI以特定方式使用特定工具。Omarchy自带一个用于定制系统的默认技能，涵盖调整Hyprland配置、修改状态栏，乃至从零创建新主题。它被符号链接到Claude Code（~/.claude/skills）、Codex（~/.codex/skills）、Pi（~/.pi/agent/skills）、Antigravity（~/.gemini/config/skills）的技能目录以及通用的~/.agents/skills位置，因此大多数运行环境会自动识别。

但请把这个技能视为实验性功能，不同模型的使用效果各异。最好先在计划模式下运行，了解智能体打算改动什么；同时做好回滚准备，万一智能体把一切搞乱，可以运行omarchy reinstall configs。
