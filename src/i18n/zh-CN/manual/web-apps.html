通过Omarchy菜单（Super + Space）的Install > Web App可以添加自己的Web应用。它会询问应用名称、应用URL，以及无法通过favicon获取时的图标URL。Dashboard Icons提供了许多流行Web应用的高质量PNG图标。

添加后即可通过应用启动器（Super + Space）访问，并使用精美的无边框Web应用窗口。

要移除Web应用，前往Omarchy菜单的Remove > Web App。

建议先用普通浏览器登录所有账户，再使用Web应用快捷方式。轻量的包装框架与1password配合不佳，所以先直接登录更省事。

这些Web应用的键盘快捷键都可以在~/.config/hypr/bindings.lua中修改。

在Web应用中，Shift + Alt + L可将当前URL复制到剪贴板。

Omarchy默认已内置一批Web应用：

HEY#

HEY是一项邮件与日历服务，对厌倦了Gmail、Outlook或Apple Mail的人来说是绝佳替代。它由Omarchy的诞生地37signals出品。

用Super + Shift + E启动HEY Email，Super + Shift + Alt + E直接撰写新邮件，Super + Shift + C启动HEY Calendar。

Basecamp#

Basecamp是一项项目管理服务，帮助小团队更快推进、取得更多进展。与其把Trello、Slack、Asana、Notion之类拼凑在一起，不如用Basecamp把一切集中在一处。它由Omarchy的诞生地37signals出品。

通过应用启动器（Super + Space）启动Basecamp

ChatGPT#

ChatGPT是全球最流行的AI聊天机器人。

用Super + Shift + A启动ChatGPT。

Grok#

Grok是xAI的聊天机器人。

用Super + Shift + Alt + A启动Grok。

WhatsApp#

WhatsApp是全球最流行的即时通讯服务之一，其网页版是Linux上的好选择。

用Super + Shift + Alt + G启动WhatsApp。

Google应用#

Google Messages、Google Photos、Google Maps和Google Contacts也都以Web应用形式内置。

用Super + Shift + Ctrl + G启动Google Messages，Super + Shift + P启动Google Photos，Super + Shift + S启动Google Maps。Google Contacts可通过应用启动器（Super + Space）打开。

X#

X是新闻首发的地方。

用Super + Shift + X启动X，Super + Shift + Alt + X直接撰写新帖子。

YouTube#

YouTube是全球最流行的视频平台。

用Super + Shift + Y启动YouTube。

Zoom#

Zoom是美国最流行的视频会议系统，全球连接质量都很出色，而且无需付费账户即可召开40分钟的会议。Omarchy封装了Zoom的网页客户端，zoom会议链接会直接在其中打开。

通过应用启动器（Super + Space）启动Zoom。

Discord#

Discord是大多数游戏和开源社区的聚集地，包括Omarchy自己的社区。

通过应用启动器（Super + Space）启动Discord。
