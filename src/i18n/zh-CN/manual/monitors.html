Omarchy默认假定你使用的是支持2倍缩放的视网膜级显示器。这是获得清晰锐利的编程字体的前提，几乎所有配备高分辨率屏幕的新款高端笔记本都是为此优化的，也是你在27英寸5K的Apple Studio Display/ProArt PA27JCV/Samsung S9/Kuycon G27P，或32英寸6K的Apple XDR/ProArt PA32QCV/Kuycon G32P上想要的效果。

但如果显示器的PPI达不到218，就需要修改显示器设置。比如27或32英寸的4K屏，可以打开~/.config/hypr/monitors.lua（通过Omarchy菜单的Setup > Monitors），切换为该组合的推荐分数缩放： 

local omarchy_gdk_scale = 2
local omarchy_monitor_scale = 1.6

1080p或1440p显示器通常只需1倍缩放：

local omarchy_gdk_scale = 1
local omarchy_monitor_scale = 1

GDK_SCALE的修改只对之后启动的应用生效（GTK只接受整数，所以取最接近显示器缩放的整数即可）。修改后请退出那些尺寸过大的窗口（或用Ctrl + Alt + Del关闭所有窗口！）。

也可以用Super + /和Super + Alt + /在主要缩放比例（1x、1.25x、1.6x、2x、3x、4x）之间上下切换。使用默认配置时，这些修改在重启后依然保留。

放大或缩小文字#

显示器缩放会改变一切的大小。如果只想让文字变大或变小，有一个专门的旋钮： 

omarchy display text size 14

它接受9到20之间的像素值，同时调整Omarchy shell、GTK应用和终端，让整个桌面保持比例。不带参数运行可查看当前值，omarchy display text size reset恢复默认。Foot是唯一的例外：它无法重新加载配置，所以已打开的终端会保持旧尺寸，直到你开一个新的。

扩展与镜像笔记本显示器#

给笔记本接上外接屏幕时，显示会自动扩展。通过Omarchy菜单的Trigger > Hardware或Super + Ctrl + Alt + Delete可以改为镜像。外接屏幕是投影仪、你想边工作边展示时，这尤其方便。

处于扩展模式时，合上笔记本盖子会自动关闭内置屏幕，打开盖子则重新开启。也可以通过Omarchy菜单的Trigger > Hardware或Super + Ctrl + Delete手动控制。

排列多块屏幕#

Hyprland对多屏支持很好。布局方法参见Hyprland显示器文档，你还可以把特定工作区绑定到特定显示器。在Omarchy中，这些规则以hl.monitor条目的形式写在~/.config/hypr/monitors.lua中——文件自带注释示例，展示如何为某块显示器固定分辨率、位置和旋转。

想用TUI辅助多屏定位的话，也可以看看Hyprmon。

控制亮度#

显示器亮度由专用的亮度增减功能键控制。按住Shift再按这些键，会直接跳到最大或最小亮度。按键作用于当前聚焦的显示器，所以支持DDC/CI的外接显示器与笔记本屏幕的调节方式相同。

Apple显示器#

使用Apple显示器时，只要焦点在它上面，常规的键盘亮度键同样自动可用。这是通过asdcontrol命令实现的。

注意，使用Apple 6K XDR显示器时，hyprctl monitors列表中可能出现一块幻影屏幕。可以通过Setup > Monitors用类似hl.monitor({ output = "DP-2", disabled = true })的设置把它关掉。

Intel机器应使用普通的Thunderbolt线连接Apple显示器。没有Thunderbolt接口的其他机器，通常需要一根DP + USB-A转USB-C线才能正常工作。
