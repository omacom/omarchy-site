更新把系统搞坏了！#

先尝试把系统回滚到最近一次更新之前的版本。如果不行，用omarchy-debug把问题分享到Discord的 #omarchy-help。要是这些都不奏效，可以用omarchy-reinstall重装默认配置和软件包。

为什么有些应用在我的显示器上特别大？#

Omarchy假定使用2倍高分辨率显示器，这需要在~/.config/hypr/monitors.lua中把GDK_SCALE设为2。如果你用的是1倍显示器，把local omarchy_gdk_scale = 2改为1（然后重启所有尺寸过大的应用）。参见显示器一章。

Spotify可以用Ctrl + Minus缩小界面（Ctrl + Plus放大）。

为什么Caps Lock不起作用？#

在Omarchy中，Caps Lock被指定为xcompose键，快速表情和其他自动补全都靠它。如果确实怀念大写锁定，可以编辑~/.config/hypr/input.lua把xcompose键映射到别处，比如右Alt： 

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

Wi-Fi、蓝牙、音频或触控板突然不工作了#

重启之前，先试着单独重启出问题的子系统。Omarchy菜单的Update > Hardware下有Wi-Fi、蓝牙、音频和触控板，重新加载其中一项就能解决大多数“五分钟前还好好的”情况——蓝牙耳机连不上、挂起后触控板失灵、拔掉显示器后声音消失。

为什么外接音箱不出声？#

多半是因为它没被设为主输出。点击状态栏右侧的扬声器图标，会弹出音量面板，在那里选择输出设备（也可以按应用调节音量）。

笔记本扬声器听起来不对劲#

在某些笔记本上，Omarchy会自动应用一套扬声器调音，校正内置扬声器的频率响应。omarchy audio tuning status显示你的机器上是否启用了调音，omarchy audio tuning off关闭它，让扬声器回到原声。

为什么密码正确却无法登录或sudo？#

多半是输错太多次被锁定了。如果发生在锁屏上，按CTRL + ALT + F2打开一个新的TTY，以root登录，然后运行faillock --reset --user [your-username]。锁定即被重置，可以继续使用。

为什么1Password SSH Agent / CLI的授权提示没有出现？#

这可能有两个原因：

要显示完整的审批提示，必须开启Settings > Advanced > Use Hardware Acceleration。注意：需要重启后才生效。

另外，开机后如果还没启动过1Password，提示也不会出现。
