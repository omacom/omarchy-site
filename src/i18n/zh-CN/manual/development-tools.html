其他编辑器#

Omarchy默认内置Neovim，但如果你想要更主流、更熟悉的编辑器，可以打开Omarchy菜单（Super + Space），查看Install > Editor下的选项：VSCode、Cursor、Zed、Sublime Text、Helix、Vim和Emacs都在其中。没找到想要的，可以去Install > Package看看是否有对应的Arch软件包（若没有，再试试Install > AUR查一下AUR）。

VSCode、Cursor、VSCodium和Helix支持主题同步。

全系统默认编辑器在Setup > Defaults > Editor下设置。

开发环境#

通过Omarchy菜单（Super + Space）的Install > Development，可以配置大量开发环境。Ruby on Rails自然在列，还有JavaScript的三大运行时（Node.js、Bun、Deno），以及Laravel、Symfony等流行的PHP框架。此外还有Go、Rust、Python、Java、Elixir（含Phoenix）、.NET、OCaml、Zig、Clojure和Scala。选择非常丰富！

这些环境大多由Mise管理。它可以在同一台机器上安装并运行同一编程语言的多个版本，类似Ruby的rbenv或rvm、Python的virtualenv，但适用于许多不同的环境。

比如要安装Ruby，运行mise use -g ruby，它会安装Ruby并设为全局默认。如果项目中有 .ruby-version文件，在项目根目录运行mise i即可。

Docker#

Docker无需多作介绍。它用于运行隔离的容器，Omarchy安装了运行它所需的一切，包括Docker本身和Docker Compose。

默认情况下，你的用户不在 docker组中。该组实际上等同于免密码的root——组内任何程序都可以通过docker run -v /:/host接管整台机器，否则一个以你身份运行的恶意脚本或依赖，离root就只差一条命令。因此命令行中需要用sudo运行Docker（sudo docker ps、sudo docker compose up），而与守护进程通信的图形工具——Super + Shift + D上的Docker TUI和Windows虚拟机——会在需要时请求授权。如果你理解其中取舍，仍想要回免组的便利，可以在Setup > Security > Sudoless Docker中启用（或运行omarchy-setup-security-sudoless-docker），它会在警告后把你加入docker组；此后docker和d别名无需sudo即可使用。

别忘了试试Lazydocker，用Super + Shift + D在一个漂亮的TUI中管理容器；除非启用了免sudo的Docker，否则它首次运行会请求授权。

通过Omarchy菜单的Install > Development > Docker DB，可以在Docker中配置本地开发常用的数据库。

GitHub CLI#

GitHub CLI可以用GitHub账户认证并克隆私有仓库。它是按需加载的mise存根之一，首次运行gh时会自行安装。运行gh auth login完成认证，然后就可以用gh repo clone org/repo检出私有仓库。

这个命令还能完成许多其他GitHub操作，运行gh即可查看全部功能。

另有一个按需安装的ghui存根，用于在TUI中管理拉取请求。如果也想在TUI中操作git本身，lazygit已经预装。
