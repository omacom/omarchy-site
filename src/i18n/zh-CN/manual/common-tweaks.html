这里收集了一些对Omarchy的常见调整。请注意，系统更新偶尔需要把某些配置恢复为原始状态。发生这种情况时，你的修改不会丢失，而是存入同一目录下的.bak文件。

要是改坏了什么，可以通过Omarchy菜单的Update > Config把单个配置恢复为原始设置。要是真的全搞砸了，可以用omarchy-reinstall重置所有配置。

始终显示所有托盘图标#

默认情况下，Dropbox、1password、Steam之类的托盘图标藏在托盘展开箭头后面，鼠标悬停时才显示。想让它们一直可见，右键点击展开箭头打开托盘图标管理器，然后固定想保持可见的图标（也可以把永远不想看到的隐藏掉）。

圆角窗口#

Omarchy的默认设计是直角，想柔和一点的话，可以修改~/.config/hypr/looknfeel.lua，把圆角设置的注释去掉： 

hl.config({
  decoration = {
    -- Use round window corners.
    rounding = 8,
  },
})

去掉窗口间隙#

在笔记本屏幕上，有些人不想把任何像素浪费在窗口间隙上（甚至连状态栏也不要，可以用Super + Shift + Space关掉）。用Super + Shift + Backspace可以临时关闭所有间隙和边框；要永久去掉，把~/.config/hypr/looknfeel.lua中这一段的注释去掉： 

hl.config({
  general = {
    -- No gaps between windows or borders.
    gaps_in = 0,
    gaps_out = 0,
    border_size = 0,
  },
})
