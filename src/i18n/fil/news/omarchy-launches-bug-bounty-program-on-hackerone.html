May opisyal nang bug bounty program sa HackerOne ang Omarchy! Pinondohan ito ng Omacom Foundation ng $100,000 para sa mga bounty, kaya ang mga researcher na makahanap ng tunay na vulnerability at mag-ulat nito nang pribado ay maaari nang mabayaran para sa kanilang trabaho.

Binibigyan ng HackerOne ang mga researcher ng pamilyar na lugar para isumite ang kanilang mga natuklasan, subaybayan habang inaayos namin ito, at kolektahin ang kanilang bounty. Nagbibigay din ito sa Omarchy Security Team ng maayos na workflow para sa pag-triage ng lahat ng dumarating na ulat. Kung ayaw mong gumawa ng HackerOne account, maaari ka pa ring mag-email sa security@omarchy.org. Nasa pahina ng seguridad ang lahat ng detalye tungkol sa kung ano ang itinuturing naming vulnerability at kung paano mag-ulat ng isa.
