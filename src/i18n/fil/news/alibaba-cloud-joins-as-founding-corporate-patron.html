Alibaba Cloud ay sumasali sa Omacom Foundation bilang isang Founding Corporate Patron, na mag-aambag ng $1 milyon kada taon sa loob ng tatlong taon! Iyan ay $3 milyong komitment, katumbas ng suporta ng DigitalOcean, para sa pagpapaunlad, pagpapanatili, at pagpapalaganap ng Omarchy.

Pero ang partnership na ito ay higit pa sa pera. Tutulungan kami ng Alibaba Cloud na buuin ang Omarchy China: ang lokal na CDN, hosting, website, mga meetup, at komunidad na kailangan ng mga user na Tsino para magamit ang Omarchy nang walang abala. Ang pag-download ng Linux, pag-install ng mga package, at pag-update ng computer mo ay dapat maging simple kahit saan ka nakatira. Magtutulungan kami para maging totoo rin iyan sa Tsina.

At hindi na maaaring maging mas sakto pa ang timing. Sa pag-aanunsyo ng Qwen Book, isinasakatuparan na ng Alibaba sa hardware ang ambisyon nito para sa agentic computer. Makikipagtulungan kami para gawing perpektong agentic operating system ang Omarchy para sa computer na iyon. Isang maganda at masayang Linux desktop kung saan maaaring magtulungan ang mga tao at mga agent, at kung saan ang may-ari pa rin ang masusunod.

Ganito inilalarawan ng Alibaba Cloud ang paparating na Qwen Book:

Layunin ng Qwen Book na lumikha ng isang native AI agent computer. Ang pangunahing pilosopiya nito, ang “OS as Harness,” sa madaling salita, ay ang malalim na pagsasama ng mga model, ng operating system, ng mga application, ng cloud services, at ng hardware. Bumubuo ito ng isang computing environment na mauunawaan, magagamit, matatandaan, at patuloy na tatakbuhan ng mga agent, na inaangat ang computer mula sa pagiging pasibong kasangkapan tungo sa isang patuloy na nagbabagong personal assistant.

Ang sistema ng Qwen Book ay tugma sa parehong ARM at x86 architecture, at ang unang release ay batay sa ARM architecture. Sa antas ng sistema, bumuo kami ng low-power na Agent Engine at Continuous Context Engine. Gamit ang pamilya ng modelong Qwen bilang matalinong pundasyon, nagbibigay kami ng mga serbisyo ng model para sa sistema ng Qwen Book sa pamamagitan ng cloud-device integration. Inaasahan naming tuklasin ang higit pang mga inobasyon kasama ang Omarchy OS sa hinaharap.

Ibig sabihin nito ay itutono ang Omarchy para sa mga Qwen model mula pa sa simula at magsisikap tungo sa ganap na integrasyon sa mga serbisyong Tsino na inaasahan ng mga tao. Ang mga model, ang operating system, at ang mga serbisyo ay dapat gumana nang magkakasama mula sa sandaling buksan mo ang makina. Ang paghahanda sa computer mo para gumana kasama ng isang agent ay hindi dapat maging isang proyekto mismo.

Ito mismo ang uri ng kolaborasyon na nais kong gawing posible ng foundation. Mga taong gumagawa ng mga model, mga taong gumagawa ng mga computer, at mga taong gumagawa ng mga operating system na nagtutulungan upang pagandahin ang buong karanasan. Mayroon kaming iisang ambisyon para sa kung ano ang maaaring maging ng personal computer, at ngayon ay naglalaan na kami ng mga mapagkukunan para rito.

Sumali ang Alibaba Cloud sa DigitalOcean at Meta Superintelligence Labs bilang Founding Corporate Patron. Ang kanilang pangako ay nagdadala sa aming kabuuang suporta sa humigit-kumulang $21.7 milyon. Iyan ay mas malaking pagkakataon upang mamuhunan sa mga tao, imprastruktura, at mga open-source na proyekto na nagpapasulong sa Omarchy.

Salamat sa lahat sa Alibaba Cloud, at lalo na kay CTO LI feifei, na nagbigay-daan dito. Ang inyong suporta ay nagbibigay-daan sa amin na mangarap nang mas malaki at maglagay ng mas maraming tao upang pagbutihin ang Linux para sa lahat.

Bumuo tayo ng perpektong agentic operating system para sa agentic computer. Sa Tsina at saanman!
