Apple က ဟာ့ဒ်ဝဲ ကောင်းတွေ လုပ်တယ်။ အမြဲတမ်း လုပ်ခဲ့တယ် (butterfly keyboard တစ်ကြိမ်ကလွဲရင်)။ Omarchy ဆီ ရောက်လာသူအများအပြားကလည်း Mac ကနေ ရောက်လာတာပါ။ အများစုက စက်ကို ဆက်ထားပြီး operating system ကို လွှတ်ချင်ကြတယ်။ ဒါကြောင့် Asahi စခဲ့တာကို အဆုံးသတ်မယ် — Apple Silicon ပေါ် Omarchy လှလှပပ မောင်းတာ၊ စနစ်တကျဖြစ်မှု အရှုပ်အရှင်း အနည်းဆုံးနဲ့။

အဲဒီလုပ်ငန်းနောက်မှာ အသင်းတစ်သင်း ရှိနှင့်ပြီးသား။ ဒီနေ့ တရားဝင် ဖြစ်စေတယ် — Apple Silicon ပါတဲ့ Mac တွေအတွက် (အသက်ကြီး Mac တွေ အပါဝင်ထိန်းတဲ့ အဖွဲ့ဝင်အနည်းငယ်နဲ့) ကျွန်တော်တို့အသင်း Omarchy M။

အဖွဲ့ဝင်တွေကို မိတ်ဆက်ပေးပါရစေ။

တပ်ဆင်သူ။ Marcelo Alcantara က မူရင်း Mac installer တည်ဆောက်နေတယ်။ macOS ပေါ် အပ်တစ်ခု ဒေါင်းလုဒ်လုပ်၊ လက်မှတ်ထိုးပြီးသား Omarchy release ကို ဆွဲယူ၊ partition တွေ ခွဲ၊ ရှိနေတဲ့ macOS ဘေးမှာ Omarchy ထဲ boot ဝင်စေတယ်။ USB stick မလို၊ တာမီနယ်ထဲ ရွတ်ဆိုချက် မလို။ USB-C ကနေ ပြင်ပ မော်နီတာ လင်းစေတဲ့ build ကိုလည်း သူ ဖြတ်ခဲ့တယ်။

Omarchy Mac။ Naeem Malik က Omarchy Mac ကို တစ်နှစ်လုံး ထိန်းသိမ်းခဲ့တယ်၊ ဒါတွေ တရားဝင် မဖြစ်ခင်ကတည်းက Omarchy ကို M1 နဲ့ M2 စက်တွေပေါ် တင်ပေးပြီး အဲဒီပတ်လည် လူ 800 ကျော် Discord အသိုင်းအဝိုင်း တည်ဆောက်တယ်။ Scott Jones က တပ်ဆင်မှုရဲ့ Linux ဘက်က အဲဒီပရောဂျက်ရဲ့ ကျန်တစ်ဝက်။ Apple ရဲ့ ဟာ့ဒ်ဝဲ display controller ပေါ် M3 Air ရဲ့ display မောင်းနိုင်အောင် မကြာသေးခင် လုပ်ခဲ့တယ်၊ အဲဒီစက်ကို တစ်ညတည်း အသုံးမဝင်တာကနေ အသုံးဝင်တာ ဖြစ်စေခဲ့တယ်။

Omarchy စမ်းကြည့်ပါ။ Eduardo Martinez က Try Omarchy တည်ဆောက်ခဲ့တယ် — Mac ပေါ် မူရင်း၊ ဟာ့ဒ်ဝဲအရှိန်မြှင့်ထားတဲ့ အပ်အဖြစ် မောင်းနေတဲ့ Omarchy ဒက်စ်တော့ အစစ်၊ ကင်မရာ၊ အသံ၊ clipboard၊ မျှဝေဖိုလ်ဒါတို့ ချိတ်ဆက်ပြီးသား။ partition ခွဲစရာ မလို။ ဒေါင်းလုဒ်လုပ်ပြီး ဘာလို့ ပွဲဆူနေလဲ ကြည့်လိုက်ရုံပဲ။

Package များ။ Shun Li က Omarchy လိုသမျှ aarch64 package အဖြစ် ရှိနေအောင် လုပ်နေတယ်၊ virtual machine တွေအတွက် ARM64 disk image တွေနဲ့ သုံးရ အဆင်ပြေစေတဲ့ guest tool တွေနဲ့အတူ။

Driver တွေနဲ့ kernel။ Ryan Murray က Neo ကို နှိုးပြီး ကျန်အသင်း အလုပ်လုပ်တဲ့ အခြေခံအုတ်မြစ်တွေ တည်ဆောက်နေတယ်။ M4 နဲ့ ပိုသစ် chip တွေပေါ် macOS ကို trace လုပ်နိုင်စေတဲ့ SPTM emulator တစ်ခု ဖန်တီးနေတယ်။ အဲဒီ trace တွေက display၊ GPU၊ အသံ၊ wireless၊ Bluetooth တွေ အလုပ်ဖြစ်ဖို့ မရှိမဖြစ်။ Dj က GPU driver တွေ ရေးနေတယ်၊ Secure Enclave နဲ့ တိုက်ရိုက်ပြောပြီး Touch ID မောင်းနိုင်အောင် လုပ်ခဲ့တယ်။ Miguel Cruz က M5 အလုပ် အထူးပြု — Apple ရဲ့ မူပိုင် N1 chip ကို reverse-engineer လုပ်ပြီး Linux မှာ Wi-Fi နဲ့ Bluetooth မောင်းနိုင်အောင် လုပ်ခဲ့တယ်။ Neo ပေါ် ဟာ့ဒ်ဝဲ ဗီဒီယို encode/decode၊ Bluetooth၊ ဒက်စ်တော့ တိုးတက်မှုတွေလည်း ပံ့ပိုးခဲ့တယ်။ Liam က Neo ရဲ့ trackpad၊ ပါဝါ စီမံမှု၊ စပီကာ၊ နားကြပ်ပေါက်တို့ နှိုးနေတယ်၊ Ryan ရဲ့ macOS trace တွေက မရှိမဖြစ် အခြေခံ။ Eryk Wieliczko က M4 ပံ့ပိုးမှုနဲ့ clean-room အကောင်အထည်တွေ ထိန်းသိမ်းပြီး ပေါင်းစပ်မှုနဲ့ ထုပ်ပိုးမှုမှာ လုပ်တယ်။ Jaidip Subedi က M2 MacBook Air ပေါ် USB-C ကနေ ပြင်ပ display ရအောင် လုပ်ပေးခဲ့တယ်။

MLX။ Joshua Warren က mlx-omarchy တည်ဆောက်နေတယ်၊ Apple ရဲ့ MLX machine learning framework ကို Vulkan ကနေ Apple GPU တွေပေါ် Linux ဆီ ယူဆောင်လာတာ။ သင့်ကုဒ်က import mlx.core as mx လို့ပဲ ပြောနေဦးမယ်၊ ဒါပေမယ့် အခု Omarchy ပေါ် မောင်းနေပြီ။

အသက်ကြီး Mac များ။ Shawn Yeager မှာ 2016 နဲ့ 2017 Touch Bar MacBook Pro တွေအတွက် pull request အပုံရှိတယ် — စပီကာ၊ Wi-Fi၊ ပတ်ဝန်းကျင် အလင်း sensor၊ Touch Bar ကိုယ်တိုင်။ Randy က Intel Mac တွေပေါ် Touch ID ယူလာဖို့ T2 လုံခြုံရေး chip ကို reverse-engineer လုပ်နေတယ်၊ လမ်းမှာ 2019 MacBook Pro အတွက် ပြင်ဆင်ချက်တိုင်း မှတ်တမ်းတင်ရင်းနဲ့။ Jon Kinney က လွန်ခဲ့တဲ့ တစ်နှစ်က Omarchy အတွက် ARM ပံ့ပိုးမှု တူးဖော်နေခဲ့တယ်၊ အခု အသင်း ဘယ်သူ ဘာလုပ်လဲ ညှိနှိုင်းပေးတယ်။

အတူတူဆို သူတို့က ကြောက်စရာကောင်းတဲ့ အဖွဲ့ပါ။ ခွင့်ပြုချက် မစောင့်ခဲ့တဲ့ လူ 15 ယောက်၊ လွန်ခဲ့တဲ့ တစ်နှစ်က အဓိပ္ပာယ်မရှိလောက် ထင်ရမယ့် အရှိန်နဲ့ ရွေ့ဖို့ အေးဂျင့်တွေ သုံးနေသူတွေ။

ပထမ release ရဲ့ ပစ်မှတ်က Pro နဲ့ Max variant တွေအပါအဝင် M1 နဲ့ M2 နဲ့ ပြီးပြည့်စုံတဲ့ သဟဇာတဖြစ်မှုပါ။

  • တပ်ဆင်နဲ့ စမ်းကြည့်ရွေးချယ် 2 ခုလုံးပါတဲ့ ချောမွေ့ installer
  • GPU ပံ့ပိုးမှု အပြည့်
  • USB-C ကနေ ပြင်ပ မော်နီတာများ
  • Touch ID
  • MLX
  • Disk encryption

ပိုသစ်စက်တွေကို တစ်ပြိုင်နက် လုပ်နေတယ်၊ ဒါပေမယ့် M1 နဲ့ M2 မှာ အရင် အလံစိုက်တယ်။ M စက်တွေအပြင် အပြင်မှာ vintage လက်ပ်တော့ သန်းပေါင်းများစွာ ရှိတယ်၊ အများစုက Apple ရဲ့ နောက်ဆုံး macOS ရည်မှန်းချက်တွေကနေ အငြိမ်းစားယူပြီးသား၊ တစ်လုံးချင်းစီက ဖြစ်လာဖို့ စောင့်နေတဲ့ အံ့ဩဖွယ် Omarchy ကွန်ပျူတာတွေပါ။

စဖို့ အချောသတ် release ကို စောင့်စရာ မလိုဘူး။ Try Omarchy က မိနစ်ပိုင်းအတွင်း Mac ပေါ် ဒက်စ်တော့အစစ် ကြည့်နေစေမယ်။ ကတိပြုဖို့ အဆင်သင့်ရင် installer က ဒီနေ့ M1 ဒါမှမဟုတ် M2 ပေါ် macOS ဘေး Omarchy တင်ပေးမယ်။

နောက်ဆုံး တောင်းဆိုမှုတစ်ခု။ Apple ဟာ့ဒ်ဝဲအတွက် Linux မှာ လုပ်နေခဲ့ရင် — kernel driver၊ firmware၊ ထုပ်ပိုးမှု၊ installer၊ machine learning ဖြစ်ဖြစ် — သင့်ဆီက ကြားချင်ပါတယ်။ ကျွန်တော်တို့ လိုက်နေတာကို သင် ဖြေရှင်းပြီးသား ဖြစ်နိုင်ခြေ များတယ်၊ ဒါမှမဟုတ် ပြောင်းပြန်ပါ။ apple@omarchy.org ကနေ ဆက်သွယ်ပါ။
