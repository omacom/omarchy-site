outfoxxed (Quickshell ဖန်တီးသူ) ကို Omarchy Shell အကြီးအကဲ အဖြစ် ခန့်နေပါတယ်! Omacom Foundation မှာ အချိန်ပြည့် ပါဝင်ပြီး Omarchy Core အဖွဲ့ဝင် ဖြစ်လာမယ်။ Quattro ဖြစ်စေတဲ့ ကိရိယားအစုံ တည်ဆောက်ခဲ့သူက အရာတစ်ခုလုံး လပေါ် လွှတ်တင်ဖို့ ကူညီဖို့ ပါဝင်လာပြီ။

ဒါ ဩဂုတ်မှာ ကြေညာခဲ့တဲ့ 3 နှစ် Quickshell စပွန်ဆာမှု ကို အစားထိုးတယ်။ အဲဒီစပွန်ဆာမှုအစား outfoxxed က Omacom Foundation ရဲ့ အချိန်ပြည့် ဝန်ထမ်း ဖြစ်မယ်၊ Omarchy Shell လုပ်ငန်း ဦးဆောင်မယ်။ ဖန်တီးသူကို ကျွန်တော်တို့ တည်ဆောက်နေတာရဲ့ အလယ်တည့်တည့် ထားနေတာ။

Shell က ကျွန်တော်တို့ ဖန်တီးနေတဲ့ အေးဂျင့်ဆန်တဲ့ OS အတွက် အဓိကကျတယ်။ ဘား၊ မီနူးတွေ၊ အသိပေးချက်တွေ၊ widget တွေ၊ ကွန်ပျူတာ သင့်ဟာလို ခံစားရစေတဲ့ အပြန်အလှန်သေးသေးလေးတွေ။ Quickshell က QML နဲ့ အဲဒီအတွေ့အကြုံ ပုံဖော်ဖို့ အဆောက်အအုံ တုံးတွေ ပေးတယ်။ QML ရေးရာမှာ မယုံနိုင်လောက် တော်တဲ့ အေးဂျင့်တွေနဲ့ ပေါင်းလိုက်ရင် ဒက်စ်တော့ ပြောင်းတာက တောင်းဆို၊ စမ်း၊ မျှဝေနိုင်တဲ့ အရာ ဖြစ်သွားတယ်။

သက်သေက ပလပ်ဂင်တွေထဲမှာ! စပွန်ဆာမှု ကြေညာချိန် အသိုင်းအဝိုင်းက Quattro ရဲ့ ပထမအပတ်မှာတင် တစ်ထောင်ကျော် ဖန်တီးပြီးသား။ အခု ကတ်တလောက်မှာ ပလပ်ဂင် 3,000 နီးပါး ရှိပြီ။ ဘားကနေပဲ ဆော့လို့ရတဲ့ ဂိမ်းတွေ၊ coding အေးဂျင့်တွေ စောင့်ကြည့်တဲ့ panel တွေ၊ သီချင်းဖွင့်စက်တွေ၊ ဘားအတိုင်း လျှောက်သွားပြီး ပွတ်သပ်ခံဖို့ စောင့်နေတဲ့ ကြောင်တစ်ကောင်တောင်။ လူတွေ အရင်က ခိုင်မာတယ်လို့ ခံစားရတဲ့ စနစ်ကို ယူပြီး ကိုယ့်ဟာကိုယ် ဖြစ်အောင် လုပ်နေတယ်။ ဒါပဲ ပုံသွင်းလို့ရတဲ့ ကွန်ပျူတာ အသက်ဝင်လာတာ။

Quickshell ဖန်တီးသူ ပါဝင်လာတာက stack တစ်ခုလုံး အတူ လုပ်နိုင်စေတယ်။ shell ပိုမြန် ပိုစိတ်ချအောင် လုပ်။ ပလပ်ဂင်ကောင်း ဆောက်ရ ပိုလွယ်အောင် လုပ်။ ပလပ်ဂင် စာရေးသူ ကန့်သတ်ချက်နဲ့ တိုးမိရင် အခြေခံအုတ်မြစ်တွေ တိုးတက်အောင် လုပ်။ ထောင်ပေါင်းများစွာသော စမ်းသပ်မှုတွေက သင်ယူရတာကို Omarchy boot တက်သူတိုင်းအတွက် ပိုကောင်းတဲ့ အတွေ့အကြုံ ဖြစ်အောင် ပြောင်း။ အရာတစ်ခုလုံး လုံခြုံစိတ်ချရအောင် အာမခံ။

Omarchy Core ပါဝင်မှုနဲ့ outfoxxed က distro တစ်ခုလုံးရဲ့ ဦးတည်ချက် ချမှတ်ဖို့ ကူညီမယ်။ Shell က အတွေ့အကြုံရဲ့ အလယ်မှာ ရှိနေလို့ နောက်ဆက်တွဲ အတွေးနဲ့ ထားလို့ မရဘူး။ အေးဂျင့်ဆန်တဲ့ OS ရဲ့ အလှ၊ ပျော်စရာ၊ ဖြစ်နိုင်ခြေအများစုက မြင်သုံး နိုင်စရာ ဖြစ်လာတဲ့ နေရာပါ။

outfoxxed က Omacom Foundation ရဲ့ ဒုတိယမြောက် အချိန်ပြည့် ခန့်အပ်မှု၊ Omarchy Kernel အကြီးအကဲ Krzysztof Wilczyński ရဲ့ နောက်က လိုက်လာတာ။ Kernel နဲ့ Shell 2 ခုလုံး ဦးဆောင်သူတွေ ပါဝင်လာမှုနဲ့ အတွေ့အကြုံ တစ်ခုလုံးရဲ့ အခြေခံအုတ်မြစ်တွေမှာ ရင်းနှီးနေတယ်။ ဆိုက်ပေါ် ဖောင်ဒေးရှင်းဝန်ထမ်းတွေ နဲ့ တွေ့နိုင်တယ်။

အသိုင်းအဝိုင်းထဲ လုပ်ငန်းကနေ မှန်တဲ့လူတွေ တွေ့ရင် ဖိတ်ကြားချက်နဲ့ ဆက်ခန့်မယ်။ (ကျွန်တော့် inbox ထဲ CV တွေ ရေလွှမ်းမိုးမပို့နဲ့နော်!)

ဒါပဲ ဖောင်ဒေးရှင်းထောက်ခံမှု လုပ်နိုင်စေတာ — ထူးချွန် open-source ဒီဗယ်လော်ပါတွေကို အပြည့် အာရုံစိုက်ဖို့ အချိန်ပေးတာ။ အဲဒီလုပ်ငန်း ရန်ပုံငွေထောက်နေသူတိုင်း ကြောင့် ရည်မှန်းချက်တွေ အချိန်ပြည့် အလုပ်တွေ ဖြစ်အောင် ပြောင်းနေတယ်။

ကြိုဆိုပါတယ် outfoxxed! ဒီကွန်ပျူတာ ပိုပုံသွင်းလို့ရအောင် လုပ်ကြစို့။
