Emir Beganović ကို Omarchy အတွက် အခြေခံအဆောက်အအုံ အကြီးအကဲ အဖြစ် ခန့်နေပါတယ်! နိုဝင်ဘာ 1 ရက် စမယ်၊ Omacom Foundation ရဲ့ တတိယမြောက် အချိန်ပြည့် ခန့်အပ်မှု အဖြစ် Kernel ဘက် Krzysztof Wilczyński နဲ့ Shell ဘက် outfoxxed တို့နဲ့ ပေါင်းလိုက်တာ။

Omarchy ဆီ သူ့ခရီးကို Emir ကိုယ်တိုင် ဘယ်လို ဖော်ပြလဲ —

Linux ကို ချစ်တာက နှစ် 20 ကျော်သွားပြီ။ ဆယ်ကျော်သက်အရွယ်မှာပဲ Ubuntu developer ဖြစ်လာပြီး ဒေသအသိုင်းအဝိုင်းမှာ နက်နက်ရှိုင်းရှိုင်း ပါဝင်ခဲ့တယ်။ အလုပ်အကိုင်က နိုင်ငံ 3 နိုင်ငံ ဖြတ်သန်းခဲ့တယ်၊ startup နဲ့ scaleup တွေမှာ ယုံကြည်စိတ်ချရမှုနဲ့ စွမ်းဆောင်ရည် လုပ်ပြီး အသင်းတွေ ဦးဆောင်တယ်။ Booking.com ရဲ့ SRE ဌာနမှာ 7 နှစ်နီးပါး နေခဲ့တယ်၊ build system နဲ့ CI အခြေခံအဆောက်အအုံ လုပ်ငန်း ဦးဆောင်တယ်။ လတ်တလောဆုံး Isorun တည်ဆောက်ခဲ့တယ်၊ microVM၊ snapshot၊ isolation၊ scheduling၊ disposable compute တွေ လုပ်နေခဲ့တာ။ အခု အဲဒီအတွေ့ကို ပထမဆုံး အချစ်ဆီ ပြန်ယူလာတယ်။

Emir နဲ့ ပတ်သက်ပြီး ကျွန်တော့်မျက်စိ ကျသွားတာက TryOmarchy ပါ။ Omarchy ဒက်စ်တော့ကို ယူပြီး browser ထဲ ထည့်လိုက်တယ် (ပြန်ရေးတာ မဟုတ်၊ အစစ်အမှန်)၊ Cloudflare ရဲ့ သာမန် CPU အခြေခံအဆောက်အအုံပေါ် စက္ကန့်ပိုင်းအတွင်း boot တက်စေတယ်။ အဲဒီ ဟာသ စမ်းသပ်မှုအကြောင်း စပြောဖြစ်တယ်၊ စကားက လက်ပ်တော့၊ ဗိသုကာအသစ်၊ OEM၊ Omarchy လိုချင်တဲ့ နေရာတိုင်း မောင်းဖို့ လိုမယ့် အခြေခံအဆောက်အအုံဘက် မြန်မြန် ကျယ်သွားတယ်။ ရူပါရုံအတူ ဆိုတာ သဘောပေါက်လိုက်တယ်။

ဒါပဲ Emir ပါဝင်ပြီး ဦးဆောင်မယ့်အရာ။

Omarchy အတွက် အခြေခံအဆောက်အအုံဆိုတာ ဆာဗာမောင်းတာထက် အများကြီး ပိုတယ်။ Omarchy တည်ဆောက်၊ စမ်းသပ်၊ ပို့ဆောင်ဖို့ သုံးတာ၊ ဟာ့ဒ်ဝဲနဲ့ ဗိသုကာ ပိုများလာတာနဲ့အမျှ စနစ် ယုံကြည်စိတ်ချစွာ အလုပ်လုပ်နေဖို့ပါ။ release တွေ စိတ်ချရအောင် လုပ်တာ၊ ကျရှုံးမှုတွေ ပြန်ဖြစ်အောင် လုပ်နိုင်တာ၊ ပရောဂျက်က ကျန်လူတိုင်း မြန်မြန်ရွေ့နိုင်အောင် ခိုင်မာတဲ့ အခြေခံပေးတာ။

စူးစမ်းစရာ အများကြီးလည်း ရှိသေးတယ်! Omarchy က စားပွဲပေါ်က စက်မှာ လှလှပပ အလုပ်ဖြစ်သင့်တယ်၊ ဒါပေမယ့် အဲဒီမှာ ရပ်စရာ အကြောင်း မရှိဘူး။ Linux ကွန်ပျူတာ စဖွင့်တာ ဝက်ဘ်စာမျက်နှာ ဖွင့်သလောက် လွယ်သွားရင် ဘာဖြစ်မလဲ TryOmarchy က အရိပ်ပြခဲ့တယ်၊ Linux အရသာ တစ်ကလစ်အကွာမှာ။ ဘယ်ဆီ ဦးတည်လဲ ကြည့်မယ်။

ဒီလုပ်ငန်း ရန်ပုံငွေထောက်နေသူတိုင်း ကြောင့် Emir လို လူတွေကို Omarchy ပေါ် အပြည့် အာရုံစိုက်ဖို့ အချိန်ပေးနိုင်တယ်။ ကျွန်တော်တို့ပံ့ပိုးသူတွေက ရဲရင့်တဲ့ စမ်းသပ်မှုတွေ ရေရှည်လုပ်ငန်း ဖြစ်စေဖို့၊ စနစ်တစ်ခုလုံး ပိုကောင်းအောင် အချိန်ပြည့် လူတွေနဲ့ ဖြစ်နိုင်စေတယ်။ သူတို့ပံ့ပိုးမှုအတွက် ကျေးဇူးတင်ပါတယ်။

ကြိုဆိုပါတယ် Emir! Omarchy နေရာတိုင်း မောင်းစေဖို့ လုပ်ကြစို့။
