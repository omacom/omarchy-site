Omarchy ရဲ့ ပေါက်ကွဲတဲ့ ကြီးထွားမှုက တုံ့ပြန်မှုအဖြစ် ဖွဲ့စည်းထားတဲ့ အသင်းတွေ တောင်းဆိုတယ်၊ The Omarchy Core Team ဖွဲ့ပြီး စမယ်။ ဒီအဖွဲ့က distro ရဲ့ ဦးတည်ချက် မောင်းနှင်မှု တာဝန် မျှယူမယ်၊ ဆက်လက် ရှေ့တိုးတာ သေချာစေမယ်၊ တခြား ပံ့ပိုးသူတွေ ကူညီမယ်။

အဖွင့်သစ် Core Team ကို မိတ်ဆက်ပေးပါရစေ။

Ryan Hughes က နေ့တစ်နေ့ကတည်းက Omarchy မှာ ကျွန်တော့် wingman။ အစောပိုင်းရက်တွေ မနက် 3 နာရီ အရေးပေါ် AUR ပြတ်တောက်မှုတွေ အတူ တိုက်ခဲ့တယ်၊ ကိုယ့် package repository တည်ဆောက်ဖို့ အတူ ကြံစည်ခဲ့တယ်။ Ryan ရဲ့ ပံ့ပိုးမှုတွေ distro အလွှာတိုင်း ဖြန့်ကျက်တယ် — တပ်ဆင်မှု၊ ထုပ်ပိုးမှု၊ ဟာ့ဒ်ဝဲ ပံ့ပိုးမှု၊ ဂိမ်းဆော့မှု၊ သီမ်ဆော့မှု၊ CLI ကိရိယာ၊ အခု Quattro။ Quickshell ဆီ ရွေ့မှု၊ ပလပ်ဂင် စနစ်၊ Omarchy ကို ဂရုတစိုက် စုထားတဲ့ Linux စနစ်ကနေ သင့်လျော်တဲ့ operating system ဖြစ်စေတဲ့ အခြေခံအဆောက်အအုံ အများစား မောင်းနှင်ဖို့ ကူညီခဲ့တယ်။ Omarchy မှာ hack မလုပ်ချိန် Ryan က Oodle ရဲ့ ပါတနာ။

Tobi Lütke က ကျွန်တော့် အဓိကအသင်း 2 ခုလုံး ပါဖူးတဲ့ တစ်ဦးတည်းသောသူပါ! 2004 မှာ စတဲ့ ပထမ Rails Core Team အဖွဲ့ဝင်အနေနဲ့ framework ဆီ လေးနက်တဲ့ ပံ့ပိုးမှု မှတ်တမ်း သာမက Liquid၊ Delayed Job၊ Active Merchant ပါ ရေးသားခဲ့တယ်။ အဲဒီလုပ်ငန်းက နောက်ဆုံး Shopify ဆိုတဲ့ ကုမ္ပဏီသေးလေး ဖြစ်လာတယ်၊ ကြားဖူးလား။ အခု try၊ Omasnap၊ Wi-Fi QR code တွေ၊ Quake ပုံစံ အေးဂျင့် console လို ပရောဂျက်တွေနဲ့ Omarchy ကို အကျိုးများများ ပံ့ပိုးသူပါ။ IMSA မှာ ပြိုင်နေတဲ့ နံပါတ် 11 Shopify Racing LMP2 ကား မှာ ကျွန်တော့် ပူးတွဲ ယာဉ်မောင်းလည်း ဖြစ်တယ်။

Bjarne Øverli က Unite AS ရဲ့ CTO၊ Omarchy မှာ ထည့်ပေးတဲ့ visual သီမ် တည်ဆောက်သူ Aether ဖန်တီးသူ၊ TUI အခြေပြု သီချင်းဖွင့်စက် cliamp ဖန်တီးသူပါ။ သီမ် စနစ်ကို config ဖိုင်အစုကနေ semantic အရောင်၊ Neovim၊ VS Code၊ btop၊ ကျန် stack တစ်လျှောက် ထုတ်လုပ်ထားတဲ့ သီမ်တွေနဲ့ အများကြီး စနစ်ကျတဲ့ အရာ ဖြစ်အောင် ကူညီခဲ့တယ်။ Ethereal၊ Hackerman၊ Lupine လို သီမ်တွေအတွက်လည်း သူ တာဝန်ရှိတယ်။ Bjarne မှာ ပရိုဂရမ်မာ တိကျမှုနဲ့ အမြင်အရသာ ရှားပါး ပေါင်းစပ်မှု ရှိတယ်၊ Omarchy နဲ့ အတိအကျ ကိုက်တယ်။

HANCORE က စက်မှု အင်ဂျင်နီယာ၊ ဘယ်လိုမှန်းမသိ Omarchy အသိုင်းအဝိုင်းရဲ့ အဆုံးအဖြတ် အလှတရား အင်အားစုတွေထဲက တစ်ယောက် ဖြစ်လာတယ်။ Omarchy မှာ မူရင်း ပါလာတဲ့ Last Horizon နဲ့ Solitude အပါအဝင် ရယ်စရာကောင်းလောက်တဲ့ သီမ်အရေအတွက် ထုတ်လုပ်ခဲ့တယ်။ အခု Quattro ပတ်လည် ပလပ်ဂင် ဂေဟစနစ် ထိန်းကျောင်းဖို့ ကူညီနေတယ်။ Omarchy က ကွန်ပျူတာ အသုံးဝင်သလောက် လှပရမယ်လို့ အမြဲ အခိုင်အမာ ဆိုတယ်၊ HANCORE က အဲဒီအဆိုကို လူတိုင်းနီးပါးထက် ပိုတွန်းခဲ့တယ်။

Spencer Bull က Linux client enablement၊ AI၊ platform software လုပ်နေတဲ့ Dell ရဲ့ Distinguished Engineer။ အသစ်စက်စက် ဟာ့ဒ်ဝဲရဲ့ ရှုပ်ထွေးတဲ့ အမှန်တရားဘက် ကျွန်တော်တို့တံတားဖြစ်ခဲ့တယ်၊ ပုံမှန် Linux နောက်ကျမှု မဝင်ခင် Panther Lake နဲ့ နောက်ဆုံး XPS စက်တွေပေါ် Omarchy ကောင်းကောင်း အလုပ်ဖြစ်အောင် ကူညီတယ်။ Kernel ပြဿနာ၊ driver၊ display၊ Wi-Fi၊ စပီကာ၊ ပါဝါ စီမံမှု — Spencer က software နဲ့ atom ဆုံတဲ့ အလွှာမှာ လည်ပတ်တယ်၊ အဲဒီကျွမ်းကျင်မှု Core Team ထဲမှာ ရှိတာ တန်ဖိုးဖြတ်မရဘူး။

ဒီ 5 ယောက် အလုပ်ကို လုပ်နေပြီးသား။ ဒါ တရားဝင်ဖြစ်စေရုံပဲ။ ကျွန်တော်နဲ့အတူ အံ့ဩဖွယ် အဖွင့်သစ် Core Team ပါ။ ဒါပေမယ့် တစ်သင်းတည်း ဖြစ်မှာ မဟုတ်ဘူး။ Omarchy Rangers ကြေညာချက် စောင့်ကြည့်ပါ!

အတူတူ Omarchy ကို အေးဂျင့်ခေတ်၊ ပုံသွင်းလို့ရတဲ့ ကွန်ပျူတာ၊ လှပ ခေတ်မီ သဘောထားပြတ်သားတဲ့ computing ကို စိတ်လှုပ်ရှားသူတွေအတွက် အကောင်းဆုံး Linux distribution ဖြစ်အောင် တည်ဆောက်မယ်။

အဆုံးမရှိ အထက်!
