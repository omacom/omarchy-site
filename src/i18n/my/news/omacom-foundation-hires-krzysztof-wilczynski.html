Omacom Foundation ပထမဆုံး အချိန်ပြည့် ခန့်အပ်မှု လုပ်လိုက်ပြီ! Krzysztof Wilczyński က Omarchy Kernel လုပ်ငန်း ဦးဆောင်ဖို့ ပါဝင်လာတယ်။ ဒါ ဖောင်ဒေးရှင်း တည်ထောင်ရတဲ့ အကြောင်းအတိအကျပဲ — တော်တဲ့လူတွေကို ခက်ခဲတဲ့ ပြဿနာတွေ လူတိုင်းအကျိုးအတွက် လုပ်ဖို့ လစာပေးတာ။

Krzysztof က ကာလကြာ Linux kernel developer တစ်ယောက်။ မူရင်း PCI host bridge နဲ့ endpoint driver တွေနဲ့အတူ PCI Endpoint အစိတ်အပိုင်း ပူးတွဲ ထိန်းသိမ်းတယ်။ ဒါ Linux ကို သင့် GPU၊ NVMe drive၊ WiFi ကတ်တို့နဲ့ ဆက်ပေးတဲ့ ပိုက်လိုင်းပါ။ kernel ရဲ့ Rust PCI လုပ်ငန်းသစ်မှာလည်း reviewer လုပ်တယ်။ kernel ထဲ နက်နက်ဝင်မတိုင်ခင် system engineering မှာ နှစ်ပေါင်းများစွာ နေခဲ့တယ်၊ Kubernetes နဲ့ container runtime တွေ လုပ်တယ်။

အခု အဲဒီအတွေ့အားလုံး Omarchy Kernel ဆီ ယူလာမယ်။ အာရုံစိုက်မှု — စွမ်းဆောင်ရည်၊ သဟဇာတဖြစ်မှု၊ လုံခြုံရေး။ အသစ်စက်စက် လက်ပ်တော့တွေရော ရှေးဟောင်း ThinkPad တွေပေါ်ပါ Linux ပျံသန်းစေချင်တယ်။ စက်ပိုများမှာ ဗူးထဲကထုတ်တာနဲ့ အလုပ်ဖြစ်စေချင်တယ်။ တင်းတင်းကျပ်ကျပ် လုံခြုံစေချင်တယ်။

Krzysztof က Omarchy Core ထဲလည်း ဝင်တယ်၊ distro တစ်ခုလုံးရဲ့ ဦးတည်ချက် ချမှတ်ဖို့ ကူညီမယ်။
