DigitalOcean Omacom Foundation tti Deeggaraa Dhaabbata Hundeedaa ta'ee dhufe, 1 million USD waggaa waggaa sadiif gumaachaa! Kun commitment 3 million USD development, kunuunsa, fi babal'ina Omarchy'f. Vote confidence incredible akkam OS bareedaa, fun & agenteessaa nuti ijaarru keessatti!

DigitalOcean Droplets waggaa kudhan olf nan fayyadameera. Karaa wonderfully straightforward Linux machine internet irratti kaa'uu fi waan ijaaruu itti fufuu dha. Isaan contributors.rubyonrails.org hojjechisuuf fayyadamna, site namoota kumaatamaa Rails akka inni ta'e godhuuf gargaaran celebrate godhu. Infrastructure waggaa dheeraaf irraa hirmatame kana, dhaabbatni duuba jiru nu waliin akka dhufu dhagahuu addatti gaarii.

Isaan patron gahaa OS agenteessaaf. DigitalOcean dursee Droplets one-click Hermes fi OpenClaw kenna. Agent manaatti desktop Omarchy kee irratti fi biraa Droplet irratti sa'atii digdamii-afur hojjetu qabaachuu dandeessa.

Garuu kutaan patronage kana dhugumaan na kolfsise ariifata akka hunduma walitti dhufetti. Paddy Srinivasan, CEO DigitalOcean X irratti Wednesday nan quunnadhe. Halkanuma call qabanne. Saturday proposal erge. Sunday hunduma xumurre.

Kun ariifata collaboration X, agents, fi ambition boundless waliin possible! Namoonni carraa waloo arganii waan akka ta'u barbaadan, months yes geessuuf spend gochuuf sababni hin jiru. Pace possibilities fuula keenyatti jiran waliin socho'uu dandeenya.

DigitalOcean Meta Superintelligence Labs waliin Deeggaraa Dhaabbata Hundeedaa ta'ee dhufe, namootaafi dhaabbatonni mission kana maallaqaan deeggaruuf dursee dhufan hunduma bira. Waadni isaanii backing keenya waliigalaa approximately 18.5 million USD geessa. Iddoo dabalataa namoota, pirojektoota, fi infrastructure Omarchy hundumaaf gaarii godhan keessa invest gochuuf.

Namoota ajaa'ibaa dabalataa qacaruu akka! Amma Krzysztof Wilczyński akka Hogganaa Kernel Omarchy fi outfoxxed, uumaa Quickshell, akka Hogganaa Shell Omarchy fidee. Namoota akka kanaaf carraa yeroo guutuu Omarchy ariifataa, reliable, fi capable godhuuf hojjechuu kennuun patrons akka DigitalOcean malee possible miti. Backing isaanii ambitions keenya jobs dhugaa namoota akka ta'u godhuu danda'anitti jijjiira.

Galatoomaa, Paddy fi namoota DigitalOcean hunduma. Backing kana hojiitti kaa'uu egeree Linux bareedaa, fun, agenteessaa haa taasisnu!
