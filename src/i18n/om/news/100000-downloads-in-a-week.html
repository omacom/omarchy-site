Buusaan ISO Omarchy torban darbe keessatti kuma dhibba tokko! Namoonni kuma dhibba tokko kan torban kana Linux yaaluuf (ykn gara isaa deebi'uuf) murteessan. Bosses akkamii!

Bandwidth tiin, torban torban kana keessatti petabyte tokko ergee. Terabyte kuma tokko Linux torban tokko keessatti ISOs fi updates package gidduu!

Kun bara biraa Omarchy diiguu ture. Mirrors ykn torrents barbaachaaf nu fiigsisaa ture (fi bill hosting kaffaluuf mortgage biraa mana irratti barbaaduu yaaduu). Garuu hin barbaanne.

Kun sababii Cloudflare waan hunduma dura taa'u: ISOs, packages Omarchy, fi mirror Arch keenya. Hunduma R2 irratti CDN isaanii duuba. Lamaanuu gonkumaa sweat hincabsne. Kunumti sababa namoonni kuma dhibba tokko buusaa ariifataa, boring, uneventful addunyaa guutuu irraa torban darbe keessatti argatan.

Namoota Cloudflare hundumaaf, Matthew Prince addatti galatoomaa. Matthew Deeggartoota Hundeedaa keessaa tokko, kunis pirojektii kana infrastructure fi maallaqa isaa ofii lamaanuu deeggaru jechuudha. Baay'ee galatoomaa, saa'ib!
