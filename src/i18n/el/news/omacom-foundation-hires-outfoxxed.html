Προσλαμβάνουμε τον outfoxxed, τον δημιουργό του Quickshell, ως Επικεφαλής του Omarchy Shell! Εντάσσεται στο Omacom Foundation με πλήρη απασχόληση και γίνεται μέλος του Omarchy Core. Ο άνθρωπος που έφτιαξε το toolkit που έκανε το Quattro δυνατό έρχεται στην ομάδα για να μας βοηθήσει να εκτοξεύσουμε όλο αυτό το πράγμα στο φεγγάρι.

Αυτό αντικαθιστά την τριετή χορηγία προς το Quickshell που ανακοινώσαμε τον Αύγουστο. Αντί για αυτή τη χορηγία, ο outfoxxed θα είναι υπάλληλος πλήρους απασχόλησης του Omacom Foundation, επικεφαλής της δουλειάς μας πάνω στο Omarchy Shell. Βάζουμε τον δημιουργό ακριβώς στο κέντρο αυτού που χτίζουμε.

Το Shell είναι καθοριστικό για το agentic OS που φτιάχνουμε. Είναι η μπάρα, τα μενού, οι ειδοποιήσεις, τα widgets και όλες οι μικρές αλληλεπιδράσεις που κάνουν τον υπολογιστή να τον νιώθεις δικό σου. Το Quickshell μας δίνει τα δομικά στοιχεία για να διαμορφώσουμε αυτή την εμπειρία σε QML. Συνδύασέ το με agents που είναι απίστευτα καλοί στο να γράφουν QML, και ξαφνικά η αλλαγή του desktop σου γίνεται κάτι που μπορείς να ζητήσεις, να δοκιμάσεις και να μοιραστείς.

Η απόδειξη είναι στα plugins! Όταν ανακοινώσαμε τη χορηγία, η κοινότητα είχε ήδη δημιουργήσει πάνω από χίλια την πρώτη εβδομάδα του Quattro. Τώρα ο κατάλογος έχει κοντά στα τρεις χιλιάδες plugins. Παιχνίδια που μπορείς να παίξεις κατευθείαν από την μπάρα, panels που παρακολουθούν τα coding agents σου, music players, ακόμα και μια γάτα που σουλατσάρει πάνω στην μπάρα σου περιμένοντας να τη χαϊδέψεις. Οι άνθρωποι παίρνουν ένα σύστημα που κάποτε έμοιαζε σταθερό και το κάνουν δικό τους. Αυτός είναι ο εύπλαστος υπολογιστής που ζωντανεύει.

Το να έχουμε τον δημιουργό του Quickshell στην ομάδα σημαίνει ότι μπορούμε να δουλέψουμε μαζί σε όλο το stack. Να κάνουμε το shell πιο γρήγορο και πιο αξιόπιστο. Να κάνουμε πιο εύκολο να φτιάξεις ένα υπέροχο plugin. Να βελτιώνουμε τα θεμέλια όταν ένας δημιουργός plugin συναντά έναν περιορισμό. Να μετατρέπουμε όσα μαθαίνουμε από χιλιάδες πειράματα σε καλύτερη εμπειρία για όλους όσους εκκινούν το Omarchy. Και να διασφαλίζουμε ότι όλο αυτό είναι ασφαλές και προστατευμένο.

Και με την ένταξή του στο Omarchy Core, ο outfoxxed θα βοηθήσει να χαράξουμε την κατεύθυνση για τη διανομή συνολικά. Το Shell είναι πολύ κεντρικό για την εμπειρία για να είναι δευτερεύουσα σκέψη. Είναι εκεί όπου τόση από την ομορφιά, τη διασκέδαση και τις δυνατότητες ενός agentic OS γίνεται κάτι που μπορείς πραγματικά να δεις και να χρησιμοποιήσεις.

Ο outfoxxed είναι η δεύτερη πρόσληψη πλήρους απασχόλησης του Omacom Foundation, μετά τον Krzysztof Wilczyński, τον Επικεφαλής του Omarchy Kernel μας. Με τους ανθρώπους που ηγούνται τόσο του Kernel όσο και του Shell στην ομάδα, επενδύουμε στα θεμέλια όλης της εμπειρίας. Μπορείτε να γνωρίσετε το προσωπικό του ιδρύματος στον ιστότοπο.

Θα συνεχίσουμε να προσλαμβάνουμε κατόπιν πρόσκλησης, καθώς βρίσκουμε τους κατάλληλους ανθρώπους μέσα από τη δουλειά τους στην κοινότητα. (Παρακαλώ μην πλημμυρίσετε τα εισερχόμενά μου με βιογραφικά!)

Αυτό είναι που μας επιτρέπει να κάνουμε η στήριξη του ιδρύματος: να δίνουμε σε εξαιρετικούς προγραμματιστές ανοιχτού κώδικα τον χρόνο να τα δώσουν όλα. Χάρη σε όλους όσους χρηματοδοτούν αυτή τη δουλειά, μετατρέπουμε περισσότερες από τις φιλοδοξίες μας σε θέσεις πλήρους απασχόλησης.

Καλώς ήρθες, outfoxxed! Ας κάνουμε αυτόν τον υπολογιστή ακόμα πιο εύπλαστο.
