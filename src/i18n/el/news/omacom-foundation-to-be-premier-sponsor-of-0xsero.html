Το Omacom Foundation γίνεται κορυφαίος χορηγός του έργου του 0xSero για την τοπική ΤΝ για τα επόμενα τρία χρόνια, μέσω της εταιρείας του Sybil Solutions!

Θα συνεργαστούμε για να κάνουμε τα τοπικά μοντέλα να δουλεύουν υπέροχα από την πρώτη στιγμή στο Omarchy. Η επιλογή ενός μοντέλου που ταιριάζει στο μηχάνημά σου, η ρύθμισή του ώστε να αξιοποιεί στο έπακρο το hardware, και η σύνδεσή του με τους agents σου θα πρέπει να είναι μια εξαιρετική πρώτη εμπειρία. Σήμερα, χρειάζεται ακόμα πολύ ψάξιμο ανάμεσα στην αγορά ενός ισχυρού υπολογιστή και στην αξιοποίηση της νοημοσύνης του. Θέλουμε να γεφυρώσουμε αυτό το κενό.

Ο Sero δουλεύει ήδη ακριβώς πάνω σε αυτά τα προβλήματα. Το Local AI Registry του φέρνει σε ένα μέρος διαμορφώσεις μοντέλων, συνταγές ειδικά για κάθε hardware και μετρήσεις απόδοσης. Αυτό είναι το είδος της πρακτικής γνώσης που πρέπει να μετατρέψουμε σε καλές προεπιλογές. Δεν θα έπρεπε να χρειάζεται να γίνεις μηχανικός inference για να τρέξεις ένα χρήσιμο τοπικό μοντέλο στον δικό σου υπολογιστή.

Και ο δικός σου υπολογιστής δεν χρειάζεται να κάνει όλη τη δουλειά μόνος του. Θέλουμε επίσης να είναι εύκολο να συνδέεις το hardware που έχεις σε ένα πλέγμα νοημοσύνης. Το laptop σου, το ισχυρό desktop στο γραφείο σου, ένα μηχάνημα κάπου στο σπίτι. Άσε τους agents σου να αξιοποιούν τους υπολογιστές που έχεις στη διάθεσή σου, χωρίς να χρειάζεται πρώτα να διαχειριστείς ένα μικρό data center.

Αυτό είναι μεγάλο μέρος του τρόπου με τον οποίο βλέπω να εκπληρώνεται η υπόσχεση του agentic OS. Με hardware όπως το N1x της NVIDIA και το επερχόμενο Qwen Book της Alibaba, κινούμαστε προς έναν κόσμο όπου τα ισχυρά τοπικά μηχανήματα ΤΝ είναι συνηθισμένοι προσωπικοί υπολογιστές. Το λειτουργικό σύστημα θα πρέπει να κάνει αυτή τη δύναμη διαθέσιμη από τη στιγμή που αρχίζεις να το χρησιμοποιείς.

Νομίζω πως πλησιάζουμε στο να έχουν όλοι πρόσβαση σε αξιόπιστη νοημοσύνη στο σπίτι. Μοντέλα που μπορούν να σε βοηθήσουν να γράψεις κώδικα, να δουλέψεις με τα έγγραφά σου και να φέρουν σε πέρας χρήσιμες εργασίες σε hardware που ελέγχεις εσύ. Μια εξαιρετική εναλλακτική στα frontier models και στη νοημοσύνη με συνδρομή, για όλο και περισσότερη από τη δουλειά που κάνουν πραγματικά οι άνθρωποι.

Λατρεύω αυτά που μπορούν να κάνουν τα frontier models, και το Omarchy θα συνεχίσει να τα κάνει εύκολα στη χρήση. Αλλά θέλω επίσης να έχω την επιλογή να τρέχω νοημοσύνη που δεν εξαρτάται από μηνιαία συνδρομή ούτε από την αποστολή της δουλειάς μου στους servers κάποιου άλλου. Το να μπορείς να αγοράσεις έναν υπολογιστή και να συνεχίζεις να τον βάζεις να δουλεύει είναι ένα από τα σπουδαία πράγματα των προσωπικών υπολογιστών. Αυτό θα πρέπει να ισχύει και για τους agents.

Η στήριξη του Sero για τρία χρόνια μάς δίνει χρόνο να δουλέψουμε πάνω σε όλη την εμπειρία: τα μοντέλα, τη ρύθμιση, τις συνδέσεις μεταξύ των μηχανημάτων και τις προεπιλογές που τα κάνουν όλα προσιτά. Ανυπομονώ να δω πόσο καλύτερο μπορούμε να το κάνουμε αυτό μαζί.

Ευχαριστούμε τους υποστηρικτές μας που έκαναν αυτή τη χορηγία δυνατή. Η υποστήριξή τους μάς επιτρέπει να δίνουμε στους developers τον χρόνο και τους πόρους για να δουλέψουν πάνω στο μέλλον που θέλουμε για το Linux. Είμαστε ευγνώμονες για την υποστήριξή τους.

Ας βάλουμε περισσότερη νοημοσύνη στα χέρια των ανθρώπων που έχουν τους υπολογιστές!
