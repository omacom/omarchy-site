Το Omarchy έχει πλέον επίσημο πρόγραμμα bug bounty στο HackerOne! Το Omacom Foundation το έχει χρηματοδοτήσει με $100,000 για bounties, οπότε οι ερευνητές που θα βρουν μια πραγματική ευπάθεια και θα την αναφέρουν ιδιωτικά μπορούν πλέον να πληρωθούν για τη δουλειά τους.

Το HackerOne δίνει στους ερευνητές ένα οικείο μέρος για να υποβάλλουν τα ευρήματά τους, να παρακολουθούν την εξέλιξη καθώς δουλεύουμε πάνω σε μια διόρθωση, και να εισπράττουν την αμοιβή τους. Δίνει επίσης στην Omarchy Security Team μια σωστή ροή εργασίας για τη διαλογή όλων των αναφορών που έρχονται. Αν προτιμάτε να μην δημιουργήσετε λογαριασμό στο HackerOne, μπορείτε απλώς να στείλετε email στο security@omarchy.org. Η σελίδα ασφαλείας έχει όλες τις λεπτομέρειες για το τι θεωρούμε ευπάθεια και πώς να αναφέρετε μία.

Για να ηγηθεί όλης αυτής της προσπάθειας, είμαι ενθουσιασμένος να ανακοινώσω ότι ο Mehmet İnce εντάσσεται στο Omarchy Core ως επικεφαλής ασφαλείας μας! Ο Mehmet υπήρξε βασικό μέλος της Omarchy Security Team, και τώρα θα καθορίζει την κατεύθυνση για το πώς κρατάμε το Omarchy ασφαλές, από τη λειτουργία του bounty προγράμματος μέχρι να διασφαλίζει ότι η ασφάλεια είναι ενσωματωμένη σε όλα όσα κυκλοφορούμε.

Χάρη στους υποστηρικτές μας, μπορούμε να βάλουμε πραγματικά χρήματα για να κάνουμε το Omarchy ασφαλές. Είμαστε ευγνώμονες για την υποστήριξή τους.

Καλώς ήρθες στο Omarchy Core, Mehmet! Ας κάνουμε το Omarchy τόσο ασφαλές όσο είναι όμορφο.
