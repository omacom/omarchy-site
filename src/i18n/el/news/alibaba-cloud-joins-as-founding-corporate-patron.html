Alibaba Cloud γίνεται μέλος του Ιδρύματος Omacom ως Ιδρυτικός Εταιρικός Υποστηρικτής, συνεισφέροντας 1 εκατομμύριο δολάρια τον χρόνο για τρία χρόνια! Πρόκειται για δέσμευση ύψους 3 εκατομμυρίων δολαρίων, ισόποση με την υποστήριξη της DigitalOcean, για την ανάπτυξη, τη συντήρηση και τη διάδοση του Omarchy.

Αλλά αυτή η συνεργασία ξεπερνά κατά πολύ τα χρήματα. Η Alibaba Cloud θα μας βοηθήσει να χτίσουμε Omarchy China: το τοπικό CDN, τη φιλοξενία, τον ιστότοπο, τις συναντήσεις και την κοινότητα που χρειάζονται οι Κινέζοι χρήστες για να υιοθετήσουν το Omarchy χωρίς ταλαιπωρία. Η λήψη του Linux, η εγκατάσταση πακέτων και η ενημέρωση του υπολογιστή σας θα πρέπει να είναι απλή υπόθεση όπου κι αν ζείτε. Θα συνεργαστούμε για να γίνει αυτό πραγματικότητα και στην Κίνα.

Και η χρονική στιγμή δεν θα μπορούσε να είναι καλύτερη. Με την ανακοίνωση του Qwen Book, η Alibaba μετουσιώνει σε hardware τη φιλοδοξία της για τον πρακτορικό υπολογιστή. Θα συνεργαστούμε για να κάνουμε το Omarchy το ιδανικό πρακτορικό λειτουργικό σύστημα για αυτόν τον υπολογιστή. Ένα όμορφο, διασκεδαστικό Linux desktop όπου άνθρωποι και πράκτορες μπορούν να συνεργάζονται, και όπου ο ιδιοκτήτης παραμένει υπεύθυνος.

Το Qwen Book στοχεύει στη δημιουργία ενός εγγενούς υπολογιστή με AI agents. Η βασική του φιλοσοφία, “OS as Harness”, με απλά λόγια, περιλαμβάνει τη βαθιά ενοποίηση μοντέλων, του λειτουργικού συστήματος, των εφαρμογών, των υπηρεσιών cloud και του hardware. Αυτό δημιουργεί ένα υπολογιστικό περιβάλλον που οι πράκτορες μπορούν να κατανοούν, να επικαλούνται, να θυμούνται και στο οποίο μπορούν να εκτελούνται συνεχώς, αναβαθμίζοντας τον υπολογιστή από παθητικό εργαλείο σε έναν συνεχώς εξελισσόμενο προσωπικό βοηθό.

Το σύστημα Qwen Book είναι συμβατό τόσο με αρχιτεκτονικές ARM όσο και με x86, με την πρώτη έκδοση να βασίζεται στην αρχιτεκτονική ARM. Σε επίπεδο συστήματος, έχουμε δημιουργήσει ένα χαμηλής κατανάλωσης Agent Engine και ένα Continuous Context Engine. Με την οικογένεια μοντέλων Qwen ως ευφυές θεμέλιο, παρέχουμε υπηρεσίες μοντέλων για το σύστημα Qwen Book μέσω ενοποίησης cloud-device. Ανυπομονούμε να εξερευνήσουμε περισσότερες καινοτομίες μαζί με το Omarchy OS στο μέλλον.

Αυτό σημαίνει βελτιστοποίηση του Omarchy για μοντέλα Qwen από την πρώτη στιγμή και εργασία προς την πλήρη ενοποίηση με τις κινεζικές υπηρεσίες στις οποίες βασίζονται οι άνθρωποι. Τα μοντέλα, το λειτουργικό σύστημα και οι υπηρεσίες θα πρέπει να συνεργάζονται από τη στιγμή που ξεκινάτε το μηχάνημα. Η προετοιμασία του υπολογιστή σας για να δουλεύει με έναν πράκτορα δεν θα πρέπει να είναι από μόνη της ένα πρότζεκτ.

Αυτό είναι ακριβώς το είδος συνεργασίας που θέλω να καταστήσει δυνατό το ίδρυμα. Άνθρωποι που φτιάχνουν μοντέλα, άνθρωποι που φτιάχνουν υπολογιστές και άνθρωποι που φτιάχνουν λειτουργικά συστήματα να δουλεύουν μαζί για να κάνουν όλη την εμπειρία καλύτερη. Έχουμε ένα κοινό όραμα για το τι μπορεί να γίνει ο προσωπικός υπολογιστής, και τώρα βάζουμε πόρους πίσω από αυτό.

Η Alibaba Cloud γίνεται μέλος των DigitalOcean και Meta Superintelligence Labs ως Ιδρυτικός Εταιρικός Υποστηρικτής. Η δέσμευσή τους ανεβάζει τη συνολική μας υποστήριξη σε περίπου 21,7 εκατομμύρια δολάρια. Αυτό σημαίνει περισσότερο περιθώριο για να επενδύσουμε στους ανθρώπους, τις υποδομές και τα έργα ανοιχτού κώδικα που κάνουν το Omarchy δυνατό.

Ευχαριστώ όλους στην Alibaba Cloud, και ιδιαίτερα τον CTO LI feifei, που το έκανε αυτό δυνατό. Η υποστήριξή σας μας επιτρέπει να σκεφτόμαστε μεγαλύτερα και να βάλουμε περισσότερους ανθρώπους να δουλεύουν για να κάνουν το Linux καλύτερο για όλους.

Ας χτίσουμε το ιδανικό πρακτορικό λειτουργικό σύστημα για τον πρακτορικό υπολογιστή. Στην Κίνα και παντού αλλού!
