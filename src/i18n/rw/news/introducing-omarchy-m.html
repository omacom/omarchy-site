Apple ikora hardware nziza. Ihorana (uretse icyo gihe kimwe na butterfly keyboard). Kandi benshi mu bantu baza kuri Omarchy bava kuri Mac. Benshi muri bo bakunda kugumana machine bagata operating system. Ngwino tugiye kurangiza icyo Asahi yatangiye: Omarchy ikorera neza kuri Apple Silicon, hamwe n’intambwe nke zo kuyitegura.

Uwo murimo usanzwe ufite ikipe inyuma. Uyu munsi tubigize ngombwa: Omarchy M, ikipe yacu ya Macs zifite Apple Silicon (n’abanyamuryango bake bakomeje Macs za kera mu muryango).

Mureke mbamenyekanishe abanyamuryango.

Installer. Marcelo Alcantara arubaka native Mac installer. Upakurura app kuri macOS, ifata signed Omarchy release, igaca partitions, maze ikakwinjiza muri Omarchy iruhande rwa macOS usanganywe. Nta USB stick, nta majambo y’ibanga muri terminal. Yakoze na build yacanye external monitors over USB-C.

Omarchy Mac. Naeem Malik yakomeje Omarchy Mac umwaka, ageza Omarchy kuri M1 na M2 machines mbere yuko ibi bitangazwa ku mugaragaro, kandi yubaka Discord community y’abantu barenga 800 impande zayo. Scott Jones ni ikindi gice cy’uwo mushinga ku ruhande rwa Linux rwa install. Vuba aha yakoresheje display ya M3 Air kuri hardware display controller ya Apple, ibyo byahinduye iyo machine iva aho idakoreshwa iba ikoreshwa mu ijoro rimwe.

Try Omarchy. Eduardo Martinez yubatse Try Omarchy: desktop nyayo ya Omarchy ikorera nka app kavukire, yihutishwa na hardware, kuri Mac yawe, hamwe na camera yawe, audio, clipboard, na shared folder bihujwe. Nta partition. Pakurura gusa maze urebe impamvu y’urujijo.

Packages. Shun Li yemeza ko byose Omarchy ikeneye biri nka aarch64 package, hamwe na disk images rusange za ARM64 za virtual machines na guest tools zituma ziryoshya gukoresha.

Drivers na kernel. Ryan Murray arimo gutuma Neo ikora kandi yubaka foundations ikipe isigaye ikorera. Arimo guteza imbere SPTM emulator ituma bishoboka gukurikirana macOS kuri M4 na chips nshya. Izo traces ni ingenzi kugira ngo displays, GPUs, audio, wireless, na Bluetooth bikore. Dj arandika GPU drivers, maze yakoresheje Touch ID avugana na Secure Enclave ako kanya. Miguel Cruz yihariye umurimo wa M5: yasubiranyije N1 chip bwite ya Apple maze akoresha Wi-Fi na Bluetooth yayo muri Linux. Yatanze umusanzu na hardware video encoding na decoding, Bluetooth, na desktop improvements kuri Neo. Liam arimo gutuma trackpad ya Neo, power management, speakers, na headphone output bikora, na macOS traces za Ryan zitanga foundation ingenzi. Eryk Wieliczko akomeza M4 support na clean-room implementations, kandi akora ku ihuza no gupakira. Jaidip Subedi yashoboje external displays over USB-C kuri M2 MacBook Air.

MLX. Joshua Warren arubaka mlx-omarchy, izana Apple MLX machine learning framework kuri Linux kuri Apple GPUs binyuze muri Vulkan. Code yawe iracyavuga import mlx.core as mx, ariko ubu ikorera kuri Omarchy.

Macs za kera. Shawn Yeager afite stack ya pull requests za 2016 na 2017 Touch Bar MacBook Pros: speakers, Wi-Fi, ambient light sensor, Touch Bar ubwayo. Randy arimo gusubiranya T2 security chip kugira ngo azane Touch ID kuri Intel Macs, kandi abandika buri fix ya 2019 MacBook Pro mu nzira. Jon Kinney yakoraga kuri ARM support ya Omarchy umwaka ushize, kandi ubu akomeza ikipe yose ihuza kuri buri wese ukora iki.

Hamwe, ni itsinda rikomeye. Abantu cumi na batanu batategereje uburenganzira, kandi bamaze gukoresha aba agenti kugenda ku muvuduko wari kuboneka utumvikana umwaka ushize.

Intego ya release ya mbere ni kujyana neza na M1 na M2, harimo ubwoko bwa Pro na Max:

  • Installer yoroshye, hamwe na options zombi zo gushyiraho no kugerageza
  • Inkunga yuzuye ya GPU
  • External monitors over USB-C
  • Touch ID
  • MLX
  • Encryption ya disk

Machines nshya zirakorwaho icyarimwe, ariko M1 na M2 ni ho dushinga ibendera mbere. Usibye M machines, hari millions za laptops za kera hanze, nyinshi zamaze kuvaho muri ambitions nshya za Apple kuri macOS, kandi buri imwe ni mudasobwa nziza ya Omarchy itegereje kubaho.

Ntugomba gutegereza release inoze gutangira. Try Omarchy izakwereka desktop nyayo kuri Mac yawe mu minota. Kandi niba witeguye kwiyemeza, installer izashyira Omarchy iruhande rwa macOS kuri M1 cyangwa M2 uyu munsi.

Amaherezo, icyifuzo. Niba wakoze kuri Linux kuri Apple hardware, yaba kernel drivers, firmware, packaging, installers, cyangwa machine learning, twakunda kumva kuri wowe. Hari amahirwe menshi wakemuye ikintu tukirimo gukurikirana, cyangwa ibinyuranye. Twandikire kuri apple@omarchy.org.
