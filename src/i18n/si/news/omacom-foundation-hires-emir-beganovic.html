අපි Emir Beganović ව Omarchy හි යටිතල පහසුකම් ප්‍රධානියා ලෙස බඳවා ගන්නවා! ඔහු නොවැම්බර් 1 වනදා සිට Omacom Foundation හි තුන්වන පූර්ණකාලීන සේවකයා ලෙස වැඩ ආරම්භ කරනවා, Kernel සඳහා Krzysztof Wilczyński සහ Shell සඳහා outfoxxed සමඟ එකතු වෙමින්.

Emir තමන්ගේ Omarchy දක්වා ආ ගමන ගැන කියන්නේ මෙහෙමයි:

Linux කෙරෙහි මගේ ආදරය අවුරුදු විස්සකටත් වඩා පැරණයි. මම නව යොවුන් වියේදීම Ubuntu developer කෙනෙක් වුණා, ඒ වගේම දේශීය ප්‍රජාව තුළ ගැඹුරින් සම්බන්ධ වුණා. මගේ වෘත්තීය ජීවිතය රටවල් තුනක් හරහා ගලා ගියා, startups සහ scaleups වල reliability සහ performance වෙනුවෙන් වැඩ කරමින්, teams මෙහෙයවමින්. මම Booking.com හි SRE දෙපාර්තමේන්තුවේ වසර හතකට ආසන්න කාලයක් ගත කළා, build systems සහ CI infrastructure පිළිබඳ වැඩ මෙහෙයවමින්. වඩාත්ම මෑතකදී, මම Isorun ගොඩනැගුවා, එහිදී මම microVMs, snapshots, isolation, scheduling, සහ disposable compute ගැන වැඩ කරමින් හිටියා. දැන් මම ඒ අත්දැකීම ආපහු මගේ පළමු ආදරය වෙත ගෙන එනවා.

Emir ගැන මගේ අවධානය ඇත්තටම දිනා ගත්තේ TryOmarchy නිසයි. ඔහු Omarchy desktop එක අරගෙන, browser එකට දැම්මා (ප්‍රතිනිර්මාණයක් නෙවෙයි, ඇත්ත එකම), ඒ වගේම Cloudflare හි සාමාන්‍ය CPU infrastructure මත තත්පර කිහිපයකින් boot වෙන්න සැලැස්සුවා. අපි ඒ විනෝදජනක අත්හදා බැලීම ගැන කතා කරන්න පටන් ගත්තා, ඉන්පසු සංවාදය ඉක්මනින් laptops, නව architectures, OEMs, සහ Omarchy අපට අවශ්‍ය සෑම තැනකම run වෙන්න නම් අපට අවශ්‍ය infrastructure දක්වා පුළුල් වුණා. අපට තේරුණා අපි දෙන්නම එකම දැක්ම බෙදා ගන්නවා කියලා.

Emir මෙහාට එකතු වෙන්නේ ඒකට නායකත්වය දෙන්නයි.

Omarchy සඳහා Infrastructure කියන්නේ servers run කරනවාට වඩා බොහෝ දෙයක්. ඒක තමයි අපි Omarchy build කරලා, test කරලා, ship කරන්න භාවිතා කරන්නේ, ඒ වගේම අපි තවත් hardware සහ තවත් architectures දක්වා ව්‍යාප්ත වන විට system එක විශ්වසනීයව වැඩ කරන ලෙස තබා ගන්නේ. ඒකෙන් releases විශ්වාසදායක කරනවා, failures ප්‍රතිනිෂ්පාදනය කළ හැකි කරනවා, ඒ වගේම ව්‍යාපෘතියේ අනිත් හැමෝටම වේගයෙන් ඉදිරියට යන්න ශක්තිමත් අඩිතාලමක් ලබා දෙනවා.

ඒ වගේම ගවේෂණය කරන්න ගොඩක් දේවල් තියෙනවා! Omarchy ඔබේ මේසය මත තියෙන machine එකේ ලස්සනට වැඩ කළ යුතුයි, නමුත් ඒකෙන් නවතින එකට හේතුවක් නැහැ. Linux computer එකක් පණ ගන්වන එක web page එකක් open කරන තරම් පහසු වුණාම මොකද වෙන්නේ කියලා TryOmarchy අපට දර්ශනයක් ලබා දුන්නා, Linux හි රසයක් එක click එකක දුරින් තබමින්. ඒක අපව කොහටද ගෙන යන්නේ කියලා අපි බලන්න යනවා.

මේ වැඩයට අරමුදල් සපයන හැමෝටම ස්තූතියි, අපට Emir වැනි අයට Omarchy වෙනුවෙන් පූර්ණ ලෙස කැප වෙන්න කාලය ලබා දිය හැකියි. අපේ patrons නිසා අභිලාෂකාමී අත්හදා බැලීම් කල් පවතින වැඩ බවට පත් කිරීම කළ හැකි වෙනවා, මුළු system එකම වඩා හොඳ කරන්න කැප වූ පූර්ණකාලීන අය සමඟ. ඔවුන්ගේ patronage ගැන අපි කෘතඥ වෙනවා.

සාදරයෙන් පිළිගන්නවා, Emir! අපි Omarchy හැමතැනම run කරවමු.
