Omacom Foundation පළමු පූර්ණකාලීන සේවකයා බඳවාගත්තා! Krzysztof Wilczyński Omarchy Kernel වැඩ මෙහෙයවන්න එක්වෙනවා. පදනම පිහිටුවූයේ මේ සඳහාමයි: සැමගේ යහපත වෙනුවෙන් අමාරු ගැටලු විසඳීමට විශිෂ්ට පුද්ගලයන්ට වැටුප් දීම.

Krzysztof දිගුකාලීන Linux කර්නල් සංවර්ධකයෙක්. ඔහු PCI Endpoint උපපද්ධතිය හා native PCI host bridge සහ endpoint ධාවක සම නඩත්තු කරනවා. Linux ඔබේ GPU, NVMe ධාවකය හා WiFi කාඩ්පතට සම්බන්ධ කරන යටිතලය එයයි. කර්නලයේ නව Rust PCI වැඩත් සමාලෝචනය කරනවා. කර්නලයට ගැඹුරින් යාමට පෙර වසර ගණනක් පද්ධති ඉංජිනේරුකරණයේ Kubernetes සහ කන්ටේනර් ධාවන පරිසර මත වැඩ කළා.

දැන් ඒ අත්දැකීම Omarchy Kernelට ගෙන එනවා. අවධානය: කාර්යසාධනය, ගැළපීම සහ ආරක්ෂාව. අලුත්ම ලැප්ටොප්වලත් පැරණි ThinkPadවලත් Linux ඉගිලෙන්න අපට ඕනෑ. වැඩි යන්ත්‍ර ගණනක මුල සිටම වැඩ කරන්න ඕනෑ. තදින් ආරක්ෂිත වෙන්නත් ඕනෑ.

Krzysztof Omarchy Coreටත් එක්වෙන නිසා මුළු බෙදාහැරීමේ දිශාව තීරණය කිරීමට උදව් කරාවි.
