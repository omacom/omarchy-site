අපි outfoxxed ව, Quickshell හි නිර්මාණකරු, Head of Omarchy Shell ලෙස බඳවා ගන්නවා! ඔහු Omacom Foundation එකට පූර්ණකාලීනව එකතු වෙනවා, ඒ වගේම Omarchy Core හි සාමාජිකයෙක් වෙනවා. Quattro හැකි කළ toolkit එක හදපු කෙනාම මේ මුළු වැඩේම සඳටම යවන්න උදව් කරන්න අපිත් එක්ක එකතු වෙනවා.

මේකෙන් අගෝස්තුවේදී අපි නිවේදනය කළ තුන් අවුරුදු Quickshell අනුග්‍රාහකත්වය අභිබවා යනවා. ඒ අනුග්‍රාහකත්වය වෙනුවට, outfoxxed Omacom Foundation හි පූර්ණකාලීන සේවකයෙක් ලෙස Omarchy Shell වෙනුවෙන් අපේ වැඩකටයුතු මෙහෙයවයි. අපි හදන දේවල්වල හරියටම මැදටම නිර්මාණකරු ව තියනවා.

අපි හදන agentic OS එකට Shell තමයි ප්‍රධානම දෙය. ඒ කියන්නේ බාර් එක, මෙනු, නොටිෆිකේෂන්ස්, විජට්ස්, සහ පරිගණකය ඔයාගේම එකක් වගේ දැනෙන්න සලස්වන ඒ පොඩි පොඩි interactions ඔක්කොම. QML වලින් ඒ අත්දැකීම හැඩගස්සවන්න අවශ්‍ය building blocks Quickshell අපට දෙනවා. ඒකට QML ලියන්න පුදුම තරම් දක්ෂ agents ලා එකතු කළාම, එකපාරටම ඔයාගේ desktop එක වෙනස් කරන එක ඉල්ලලා, අත්හදා බලලා, share කරන්න පුළුවන් දෙයක් බවට පත්වෙනවා.

සාක්ෂිය තියෙන්නේ plugins වලම! අපි අනුග්‍රාහකත්වය නිවේදනය කරනකොටම community එක Quattro හි පළවෙනි සතිය ඇතුළත දාහකට වඩා හදලා ඉවරයි. දැන් catalogue එකේ ප්ලගින තුන්දහසකට ආසන්න සංඛ්‍යාවක් තියෙනවා. බාර් එකෙන්ම සෙල්ලම් කරන්න පුළුවන් games, ඔයාගේ coding agents ලා නිරීක්ෂණය කරන panels, music players, ඒ වගේම සුරතල් වෙන්න බලන් බාර් එක දිගේ ඇවිදින පූසෙක් පවා. කලින් වෙනස් කරන්න බැරිව තිබුණා වගේ දැනුණ system එකක් මිනිස්සු දැන් තමන්ගේම එකක් කරගන්නවා. ඒ තමයි හැඩගස්වාගත හැකි පරිගණකය පණ ගැහෙන්නේ.

Quickshell නිර්මාණකරු අපේ කණ්ඩායමේ ඉන්න එකෙන් කියවෙන්නේ අපට මුළු stack එකම එකට වැඩ කරන්න පුළුවන් කියන එක. shell එක වේගවත් සහ විශ්වාසදායක කරන්න. හොඳ plugin එකක් හදන එක ලේසි කරන්න. plugin කතුවරයෙක් සීමාවකට මුහුණ දුන්නම පදනම දියුණු කරන්න. දහස් ගණන් අත්හදා බැලීම්වලින් අපි ඉගෙන ගන්න දේවල් Omarchy boot කරන හැමෝටම වඩා හොඳ අත්දැකීමක් බවට පත් කරන්න. ඒ වගේම මුළු දෙයම ආරක්ෂිතයි කියලා සහතික කරන්න.

ඒ වගේම Omarchy Core එකට එකතු වීමෙන්, distro එකම සමස්තයක් ලෙස ගෙනියන දිශාව තීරණය කරන්න outfoxxed උදව් කරයි. අත්දැකීමට Shell කොතරම් මධ්‍යමද කියනවා නම් ඒක අමතක වෙන පසු සිතුවිල්ලක් වෙන්න බැහැ. agentic OS එකක ලස්සන, විනෝදය, සහ හැකියාවන් බොහොමයක් ඇත්තටම දකින්න සහ පාවිච්චි කරන්න පුළුවන් දෙයක් බවට පත්වෙන්නේ එතනදී.

outfoxxed කියන්නේ Omacom Foundation හි දෙවැනි පූර්ණකාලීන බඳවා ගැනීම, Krzysztof Wilczyński, අපේ Head of Omarchy Kernel ට පස්සේ. Kernel සහ Shell දෙකම මෙහෙයවන අය කණ්ඩායමේ ඉන්න නිසා, අපි මුළු අත්දැකීමේම පදනම්වලට ආයෝජනය කරනවා. site එකේ foundation හි staff එකට ඔයාට හමුවෙන්න පුළුවන්.

community එකේ වැඩ හරහා හරි අය හමුවෙන විදිහට අපි ආරාධනා මගින් බඳවා ගන්න එක දිගටම කරගෙන යනවා. (කරුණාකරලා මගේ inbox එක CV වලින් පුරවන්න එපා!)

foundation හි පිටුබලය අපට කරන්න දෙන්නේ මේකයි: සුවිශේෂී open-source developers ලට මුළුල්ලෙන්ම කැපවෙන්න අවශ්‍ය කාලය දෙන එක. ඒ වැඩයට අරමුදල් සපයන හැමෝටම ස්තූතියි, අපේ අභිලාෂයන් තවත් බොහොමයක් පූර්ණකාලීන රැකියා බවට පත්කරමින් ඉන්නවා.
