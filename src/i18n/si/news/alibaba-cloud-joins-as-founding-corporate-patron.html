Alibaba Cloud අපට Omarchy China ගොඩනැගීමට උදව් කිරීමට යයි: චීන පරිශීලකයින්ට කරදරයකින් තොරව Omarchy භාවිතයට ගැනීමට අවශ්‍ය දේශීය CDN, hosting, වෙබ් අඩවිය, meetups, සහ ප්‍රජාව. ඔබ ජීවත් වන ඕනෑම තැනක Linux බාගත කිරීම, packages ස්ථාපනය කිරීම සහ ඔබේ පරිගණකය යාවත්කාලීනව තබා ගැනීම සරල විය යුතුයි. එය චීනයේදීත් සැබෑවක් කිරීමට අපි එක්ව වැඩ කිරීමට යමු.

තවද මීට වඩා හොඳ කාලයක් විය නොහැකියි. Qwen Book නිවේදනය සමඟ, Alibaba agentic computer සඳහා ඇති සිය අභිලාෂය hardware වෙත ගෙන එයි. එම පරිගණකය සඳහා කදිම agentic operating system එක ලෙස Omarchy සකස් කිරීමට අපි සහයෝගයෙන් වැඩ කිරීමට යමු. මිනිසුන්ට සහ agents ලට එක්ව වැඩ කළ හැකි, අයිතිකරු පාලනය රඳවා ගන්නා, ලස්සන, විනෝදජනක Linux desktop එකක්.

ඉදිරියට එන Qwen Book ගැන Alibaba Cloud විස්තර කරන ආකාරය මෙන්න:

Qwen Book හි අරමුණ native AI agent computer එකක් නිර්මාණය කිරීමයි. එහි මූලික දර්ශනය, “OS as Harness,” සරලව කිවහොත්, models, මෙහෙයුම් පද්ධතිය, applications, cloud services, සහ hardware ගැඹුරින් ඒකාබද්ධ කිරීමයි. මෙය agents ලට තේරුම් ගත හැකි, invoke කළ හැකි, මතක තබා ගත හැකි සහ අඛණ්ඩව ධාවනය විය හැකි computing පරිසරයක් ගොඩනඟයි, පරිගණකය නිෂ්ක්‍රීය මෙවලමක සිට නිරන්තරයෙන් විකාශනය වන පුද්ගලික සහයකයෙකු දක්වා උසස් කරමින්.

Qwen Book පද්ධතිය ARM සහ x86 architectures දෙකටම අනුකූල වන අතර, පළමු නිකුතුව ARM architecture මත පදනම් වේ. System මට්ටමින්, අපි අඩු බලැති Agent Engine එකක් සහ Continuous Context Engine එකක් ගොඩනඟා ඇත්තෙමු. බුද්ධිමත් පදනම ලෙස Qwen model family සමඟ, cloud-device integration හරහා Qwen Book පද්ධතිය සඳහා model services අපි සපයන්නෙමු. අනාගතයේදී Omarchy OS සමඟ එක්ව තවත් නවෝත්පාදන ගවේෂණය කිරීමට අපි බලාපොරොත්තු වෙමු.

එයින් අදහස් වන්නේ Qwen models සඳහා Omarchy මුල සිටම සූදානම් වන ලෙස සකස් කිරීම සහ මිනිසුන් රඳා සිටින චීන සේවාවන් සමඟ පූර්ණ ඒකාබද්ධතාවය වෙත වැඩ කිරීමයි. ඔබ යන්ත්‍රය පණගන්වන මොහොතේ සිට models, මෙහෙයුම් පද්ධතිය සහ සේවාවන් එක්ව ක්‍රියා කළ යුතුයි. agent කෙනෙකු සමඟ වැඩ කිරීමට ඔබේ පරිගණකය සූදානම් කිරීම තවත් ව්‍යාපෘතියක් විය යුතු නැහැ.

foundation එක මඟින් හැකි කළ යුතු යැයි මට අවශ්‍ය සහයෝගීතාව හරියටම මේ වගේ එකක්. models හදන අය, පරිගණක හදන අය සහ මෙහෙයුම් පද්ධති හදන අය මුළු අත්දැකීමම වඩා හොඳ කිරීමට එක්ව වැඩ කිරීම. පුද්ගලික පරිගණකය කෙබඳු විය හැකිද යන්න ගැන අපට හවුල් අභිලාෂයක් තිබෙනවා, සහ දැන් අපි ඒ වෙනුවෙන් සම්පත් යොදනවා.
