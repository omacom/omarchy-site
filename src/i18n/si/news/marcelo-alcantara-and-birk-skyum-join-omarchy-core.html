Marcelo Alcantara

අපි සැප්තැම්බරයේ Omarchy M හඳුන්වා දුන් විට, Marcelo තමයි native Mac installer එක හදමින් හිටියේ. එතැන් පටන්, මුළු උත්සාහයම සම්බන්ධීකරණය කරන කෙනා බවට ඔහු පත් වෙලා තියෙනවා. ලෝකයේ හැම තැනකින්ම ආපු පහළොස් දෙනෙක්, GPU drivers සහ displays වල ඉඳලා Touch ID සහ installer එක දක්වාම, stack එකේ එක එක ස්තරවල වැඩ කරනවා. ඒ හැමදේම එකම දිශාවට ඇදගෙන යන්න කවුරුහරි ඉන්න ඕනේ, Marcelo තමයි ඒ කෙනා වෙලා තියෙන්නේ.

ඒකේ ප්‍රතිඵලය Omarchy 4.5 එකත් එක්ක නිකුත් වුණා. දැන් ඔයාට macOS මත යෙදුමක් බාගත කරන්න පුළුවන් (නැතිනම් brew install omacom/mac/omarchy run කරන්න), එතකොට ඒක ඔයාගේ M1, M2, M3, හෝ Neo MacBook එකේ macOS එකට ළඟින්ම Omarchy දාලා දෙයි. USB stick එකක් නෑ, terminal එකේ මන්තර ජප කරන්න ඕනෙත් නෑ. කණ්ඩායම ප්‍රකාශයට පත් කරලා මාස දෙකකින් “බාගත කරගන්න විතරයි තියෙන්නේ” ගාණට එන එක ඇත්තටම පුදුම වේගයක්.

ඒක Omarchy M කණ්ඩායමේ හැමෝටම ලොකු ගෞරවයක්: Naeem, Scott, Eduardo, Shun, Dj, Ryan, Miguel, Liam, Eryk, Jaidip, Joshua, Shawn, Randy, Jon, සහ Marcelo. ඔයාලා Asahi පටන් ගත්ත වැඩේ ඉවර කළා, ඒ වගේම දැනටමත් M4, M5, සහ M6 දක්වා ඉදිරියට යමින් ඉන්නවා. ස්තූතියි!

Birk Skyum

Birk සැප්තැම්බරයේ තමන්ගේ Lenovo Yoga Slim 7x එකත් එක්ක Omarchy Dragon හා එක් වුණා, Arch Linux ARM, libcamera, PipeWire, systemd, සහ kernel එකේ upstream fixes කරලා තිබුණු හොඳ වාර්තාවකුත් එක්ක. එතැන් පටන්, මුළු Snapdragon පෙළම bring-up කිරීම සම්බන්ධීකරණය කිරීම ඔහු බාර අරගෙන තියෙනවා. ඒ කියන්නේ යන්ත්‍ර ටික එකතු කරන එක, එක එක යන්ත්‍රයේ මොනවද වැඩ කරන්නේ, මොනවද වැඩ නොකරන්නේ කියලා හොයාගන්න එක, සහ ඒ fixes හැමෝටම උදව් වෙන තැන්වලටම ගිහින් වැටෙනවා කියලා සහතික කරන එක.

4.5 එකේ ARM වැඩ පුරාම ඔහුගේ ඇඟිලි සලකුණු ඔයාට දැනටමත් දකින්න පුළුවන්: හැම update එකකටම පස්සේ එන තේරුමක් නැති reboot prompts තවදුරටත් නෑ, Snapdragon laptops වල login වෙනකොටම පේන cameras, සහ ARM මත ඇත්තටම run වෙන දේවල් අනුව පිරිනැමෙන (හෝ සඟවන) apps. ඒත් ඒක ආරම්භය විතරයි. අපි සහාය දක්වන හැම Snapdragon යන්ත්‍රයක්ම නිකම්ම වැඩ කරන ඉදිරි release එකක් දක්වා Birk වැඩේ ඇදගෙන යනවා. Sleep, battery, video, cameras, ඔය ඔක්කොම. ඒක තමයි අපේ ඉලක්කය, ඒක පහු කරනවා කියලා සහතික කරන්නේ ඔහු තමයි.

Omarchy Core වෙත සාදරයෙන් පිළිගනිමු, Marcelo සහ Birk!
