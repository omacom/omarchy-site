Namespace සමාගම Omacom Foundation වෙත සුවිශේෂී ආයතනික අනුග්‍රාහකයෙකු ලෙස සාදරයෙන් පිළිගැනීමට ලැබීම ගැන මම ගොඩක් සතුටු වෙනවා, ඔවුන් වසර තුනක් පුරා වසරකට compute සඳහා $100,000 ක් ලබා දෙනවා, ඒ සියල්ල අපි කෙළින්ම ARM build සහ QA සඳහා යොදවනවා.

Omarchy හැදී වැඩුණේ x86 මතයි. අද අපේ බොහෝ පරිශීලකයින් ඉන්නේ එතනයි, අපේ සියලු පරීක්ෂණ හැදිලා තියෙන්නෙත් ඒ වටායි. නමුත් ARM වේගයෙන් එමින් තිබෙනවා. Omarchy M මගින් Omarchy Apple Silicon වෙත ගෙන එනවා, Omarchy Dragon මගින් Snapdragon ලැප්ටොප් සඳහාත් එයම කරනවා, Alibaba හි Qwen Book මුලින්ම ARM මත දියත් කෙරෙනවා, තවද මඟ එමින් පවතින ARM ලැප්ටොප් රැසක් තියෙනවා, ඒවා සමඟ එන ඕනෑම දෙයකට වඩා හොඳ දෙයක් ඒවාට ලැබිය යුතුයි.

Omarchy මේ අලුත් මැෂින් සේරම මත නියමට වැඩ කරන්න නම්, හැම වෙනසක්ම නිකුත් වෙන්න කලින් ARM මත වැඩ කරනවා කියලා තහවුරු වෙන්න ඕනේ. Compile කරන එක විතරක් මදි. අපි ඇත්තටම ඒක install කරලා boot වෙනවා බලන්නම ඕනේ.

ඒක තමයි කරදරකාරී තැන. Cloud එකෙන් ARM මැෂින් ඕනෑ තරම් rent කරන්න පුළුවන්, ඒවා දවසම ARM software compile කරයි. ඒත් ඒවායින් බොහොමයක් virtual machine එකක් run කරන්න ඉඩ දෙන්නේ නැහැ, ඒ නැතුව installer එකක් test කරන්න බැහැ. ඉතින් මුළු processor එකම software වලින් emulate කරලා කොටු වෙනවා. ඒ විදිහට අපේ ARM ISO එක boot කරන්න මිනිත්තු තුනකට වඩා ගියා. මිනිත්තු තුනක්! Boot වෙන්න විතරක්!

Namespace ළඟ ඊට වඩා ගොඩක් හොඳ උත්තරයක් තියෙනවා: ඔවුන් Apple Silicon මත Linux run කරනවා. ඔවුන්ගේ runner වලදී, ඒ ISO එකම තත්පර හතරකින් boot වෙනවා. හතරයි! සැබෑ රොකට් සමාගමක් පිටුපස ඉන්න distro එකකට අවශ්‍ය වේගය ඒකයි.
