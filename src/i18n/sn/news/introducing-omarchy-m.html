Apple inogadzira hardware yakanaka. Yagara ichidaro (kunze kwekanguva kaya nekhibhodi yebutterfly). Uye vanhu vazhinji vari kuuya kuOmarchy vari kubva kuMac. Vazhinji vavo vangada kuchengeta muchina uye kurasa operating system. Saka tichapedza zvakatangwa naAsahi: Omarchy ichimhanya zvakanaka paApple Silicon, negadziriro shoma.

Basa iri ratova nechikwata seri kwaro. Nhasi tiri kuzviita zviri pamutemo: Omarchy M, chikwata chedu cheMaMac ane Apple Silicon (pamwe nenhengo shoma dzinochengeta maMac ekare ari muchikwata).

Nditenderei kukuzivisai nhengo.

Mugadziri. Marcelo Alcantara ari kuvaka native Mac installer. Unodhawunilodha app pamacOS, inotora yakasainwa Omarchy release, inocheka mapartition, uye inokubhutsira muOmarchy padivi pemacOS yako iripo. Hapana USB stick, hapana mazwi emashiripiti muterminal. Akatemawo build yakabatidza mamonitor ekunze pamusoro peUSB-C.

Omarchy Mac. Naeem Malik akachengeta Omarchy Mac kwegore, achiisa Omarchy pamichina yeM1 neM2 zvisati zvave zviri pamutemo, uye achivaka nharaunda yeDiscord yevanhu vanopfuura 800 yakaitenderedza. Scott Jones ndiye imwe hafu yeprojekiti kudivi reLinux rekuisa. Achangobatidza chiratidziro cheM3 Air pahardware display controller yeApple, izvo zvakatora muchina iwo kubva pakusashandiswa kuenda pakushandiswa muhusiku humwe.

Edza Omarchy. Eduardo Martinez akavaka Try Omarchy: desktop chaiyo yeOmarchy ichimhanya seapp yemuno, ine hardware-acceleration paMac yako, nekamera yako, audio, clipboard, nefolda yakagovaniswa yakabatanidzwa. Hapana chekupatsanura. Ingoidhawunilodha uone kuti mheremhere ndeyei.

Mapackage. Shun Li ari kuona kuti zvese zvinodiwa neOmarchy zviripo seaarch64 package, pamwe chete ne generic ARM64 disk images dzemichina chaiwo nematurusi eguest anoita kuti inakidze kushandisa.

Madhiraivha nekernel. Ryan Murray ari kumutsa Neo uye achivaka nheyo dzinoshandwa nechikwata chose. Ari kugadzira SPTM emulator inoita kuti zvikoneke kutevera macOS pama chips eM4 nezvitsva. Mateki iwayo akakosha kuita kuti zviratidziro, maGPU, audio, wireless, neBluetooth zvishande. Dj ari kunyora madhiraivha eGPU, uye akabatidza Touch ID nekutaura zvakananga neSecure Enclave. Miguel Cruz anonyanya basa reM5: akadzokorora engineering chip yeN1 yeApple uye akabatidza Wi-Fi neBluetooth yayo muLinux. Akapawo hardware video encoding nedecoding, Bluetooth, nekuvandudza desktop paNeo. Liam ari kumutsa trackpad yeNeo, power management, maspika, nekubuda kwemaheadphone, nemateki emacOS aRyan achipa hwaro hwakakosha. Eryk Wieliczko anochengetedza tsigiro yeM4 nekushandisa kwakachena, uye anoshanda pakubatanidza nekurongedza. Jaidip Subedi akagonesa zviratidziro zvekunze pamusoro peUSB-C paM2 MacBook Air.

MLX. Joshua Warren ari kuvaka mlx-omarchy, iyo inounza MLX machine learning framework yeApple kuLinux pamaGPU eApple kuburikidza neVulkan. Code yako ichiri kuti import mlx.core as mx, asi ikozvino inomhanya paOmarchy.

MaMac ekare. Shawn Yeager ane murwi wemapull requests e2016 ne2017 Touch Bar MacBook Pros: maspika, Wi-Fi, ambient light sensor, Touch Bar pachayo. Randy ari kudzosera engineering chip yeT2 kuti aunze Touch ID kumaIntel Mac, uye kunyora gadziriso yega yega ye2019 MacBook Pro munzira. Jon Kinney aishanda parutsigiro rweARM rweOmarchy gore rakapera, uye ikozvino anochengeta chikwata chose chakarongeka kuti ndiani ari kuita chii.

Pamwe chete, iboka rinotyisa. Vanhu gumi nevashanu vasina kumirira mvumo, uye vanga vachishandisa ma-agent kufamba nemwero waizoita seusina musoro gore rakapera.

Chinangwa chekuburitsa kwekutanga kuenderana kwakakwana neM1 neM2, kusanganisira maPro neMax variants:

  • Mugadziri wakapfava, une sarudzo dzekuisa nedzekuedza
  • Rutsigiro rwakazara rweGPU
  • Mamonitor ekunze pamusoro peUSB-C
  • Touch ID
  • MLX
  • Disk encryption

Michina mitsva iri kushandwa yakafanana, asi M1 neM2 ndipo patinodyara mureza kutanga. Pamusoro pemichina yeM, pane mamiriyoni emalaptop ekare kunze uko, mazhinji acho atova akarega basa kubva kuzvishuvo zvemacOS zveApple, uye rimwe nerimwe rawo ikomputa inoshamisa yeOmarchy yakamirira kuitika.

Haudi kumirira kuburitsa kwakakwenenzverwa kuti utange. Try Omarchy ichakuita kuti utarise desktop chaiyo paMac yako mumaminitsi. Uye kana wagadzirira kuzvipira, mugadziri uchiisa Omarchy padivi pemacOS paM1 kana M2 nhasi.
