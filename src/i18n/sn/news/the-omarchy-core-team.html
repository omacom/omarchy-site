Kukura kunoputika kweOmarchy kunoda zvikwata zvakarongeka mukupindura, uye tichatanga nekubatanidza The Omarchy Core Team. Boka iri richagovana mutoro wekufambisa gwara redistro redu, kuona kuti tinoenderera mberi, uye kubatsira vamwe vabatsiri.

Nditenderei kukuzivisai Core Team yekutanga:

Ryan Hughes ave wingman wangu paOmarchy kubvira zuva rekutanga. Takarwa 3am emergency AUR outages pamwe chete mumazuva ekutanga, uye takaronga kuvaka repo yedu yemapackage. Mipiro yaRyan inotenderera layer rega rega redistro: kuisa, kurongedza, tsigiro yehardware, kutamba, theming, CLI tooling, uye ikozvino Quattro. Akabatsira kufambisa kuenda kuQuickshell, plugin system, nezvakawanda zvezvivakwa zvakashandura Omarchy kubva kuLinux setup yakaungwa zvakanaka kuita operating system chaiyo. Kana asiri ku hacker paOmarchy, Ryan ari partner paOodle.

Tobi Lütke ndiye munhu oga akaita zvikwata zvangu zvikuru zviviri! Senhengo yeRails Core Team yekutanga yakatanga muna 2004, akafambisa kwete rekodhi yakakomba yemipiro kuframework chete, asi akanyorawo Liquid, Delayed Job, neActive Merchant. Basa iroro rakazopedzisira rava kambani diki inonzi Shopify, mavanzwa nezvavo? Ikozvino mubatsiri mukuru kuOmarchy nemapurojekiti akaita setry, Omasnap, Wi-Fi QR codes, neQuake-style agent console. Anoitawo kuva co-driver wangu mumotokari ye#11 Shopify Racing LMP2 inomhanya muIMSA.

Bjarne Øverli ndiye CTO weUnite AS uye muvambi weAether, visual theme builder yatinotumira muOmarchy, uye cliamp, music player yedu yeTUI. Akabatsira kushandura theming system yedu kubva kumuunganidzwa wemafaira ekugadzirisa kuita chimwe chinhu chakarongeka, nemavara esemantic nemathematic akagadzirwa muNeovim, VS Code, btop, nezvimwe zvese zestack. Anewo mutoro wematheme akaita seEthereal, Hackerman, neLupine. Bjarne ane musanganiswa usingawanikwe wekuomarara kwemugadziri nekuravira kwekuona kunokodzera Omarchy zvakakwana.

HANCORE ari mechanical engineer akazoita mumwe wemasimba anotsanangura runako munharaunda yeOmarchy. Akagadzira matheme akawanda zvisina musoro, kusanganisira Last Horizon neSolitude, iyo inotumirwa by default muOmarchy. Ikozvino ari kubatsira kutungamira plugin ecosystem yakatenderedza Quattro. Omarchy yagara ichiomesa kuti komputa inofanira kunaka pamwe chete nekubatsira, uye HANCORE asundira pfugwa iyo kupfuura chero munhu.

Spencer Bull ari Distinguished Engineer paDell ari kushanda paLinux client enablement, AI, neplatform software. Ave bhiriji redu muchokwadi chakasviba chehardware itsva, achibatsira Omarchy kushanda zvakanaka paPanther Lake nemichina yeXPS yazvino kusati kwasvika kunonoka kweLinux. Nyaya dzeKernel, madhiraivha, zviratidziro, Wi-Fi, maspika, power management: Spencer anoshanda mulayer inosangana software nemaatomu, uye kuva nehunyanzvi uhwo mukati meCore Team kunokosha zvikuru.
