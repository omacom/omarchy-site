Sponsorship-kii saddexaad ayaa albaabka ka baxay! Aasaaska Omacom waxay noqonaysaa premier sponsor mise, iyo sidaas jdx, oo sannado ku qaatay dhisidda qalabka si aamusan uga dhiga maamulka versions kala duwan ee Ruby, Node, Go mid lagu farxo, oo siiya agent tooling-kaaga upgrade channel la socon kara pace-ka shipping-ka.

Haddii aad isticmaashay Omarchy, waxaad isticmaashay mise, hadday kuu muuqatay iyo hadday kale. Waa waxa maamula language runtimes-ka, markaas mise use -g ruby waxay kuu keentaa Ruby adigoon hal line oo PATH archaeology ah qorin. Laakiin qaybta aan hadda ugu danaynayaa badan waa agents-ka.

Major coding-agent CLI kasta oo Omarchy waxay u soo baxdaa sida lazy-loading mise stub gudaha ~/.local/bin/. Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - dhammaantood halkaas fadhiya, waxba kugu kacaya ilaa first time aad dhab ahaan mid qorto. Markaas is install-gareeyaa waana shaqaynaysaa. Package la raadsado ma jiro, version la pin gareeyo ma jiro, toolchain laga fikiro ma jiro. omarchy-mise-install <package> waxay si la mid ah u duubtaa CLI kale kasta, omarchy update waxay mid kasta current ku haysaa.

Taasi waa fast track-ka. Gudaha The Age of Agents, gap u dhaxeeya maqalka tool iyo orodsiintiisu waxay u baahan tahay inay about four seconds noqoto, mise-na taas ayay keentaa. Qofna lagu ma qasbin in package marka hore distro loo sameeyo.

Danku labada dhinac ayuu u socdaa, sidoo kale: traffic-ka mise wuu koray 24% tan iyo markii Omarchy soo baxday! Dad badan ayaa tool-kan first time naga bartay, taas oo exactly nooca sponsorship waa inay aqoonsato rather than take for granted.

Mar kale, mahad gaar ah Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, iyo Peter Steinberger oo tani suurtogeliyay. Haddii aan Oligarchy jirin, ma awoodno inaan open-source developers sidan u maalgelino!
