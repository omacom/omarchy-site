Kobaca qarxa ee Omarchy wuxuu u baahan yahay kooxo habaysan oo response ah, waxaana bilaabi doonnaa iyadoo la aasaasayo Kooxda Core ee Omarchy. Kooxdan waxay wadaagi doontaa mas'uuliyadda hagida jihada distro-keena, hubinta inaan sii wadno inaan forward riixno, iyo caawinta wax-ku-biiriyayaasha kale.

I ogolaada inaan soo bandhigo Kooxda Core ee ugu horreysa:

Ryan Hughes wuxuu ahaa garabkayga Omarchy tan iyo maalintii koowaad. Waxaan wada la dagaallannay 3am emergency AUR outages early days, waxaana ku heshinnay inaan dhisno repository packages noo gaar ah. Wax-ku-biirintiisu waxay dabooshaa every layer distro: installation, packaging, hardware support, gaming, theming, CLI tooling, iyo hadda Quattro. Wuxuu horseeday u guurista Quickshell, plugin system-ka, iyo infrastructure badan oo Omarchy ka dhigay setup Linux oo si taxadar leh loo soo ururiyay operating system proper ah. Marka uusan ku mashquulin Omarchy, Ryan waa partner at Oodle.

Tobi Lütke waa qofka kaliya ee sameeyay labadayda core teams! Sida xubin first Rails Core Team started in 2004, wuxuu horseeday not only serious record contributions framework, but also authored Liquid, Delayed Job, iyo Active Merchant. Shaqadaas waxay ugu dambayn isu rogtay shirkad yar called Shopify, ma maqasheen? Hadda waa prolific contributor Omarchy iyadoo projects sida try, Omasnap, Wi-Fi QR codes, iyo the Quake-style agent console. Sidoo kale waa co-driver-kayga the #11 Shopify Racing LMP2 car ee ku tartama IMSA.

Bjarne Øverli waa CTO ee Unite AS iyo abuuraha Aether, visual theme builder aan ship Omarchy, iyo cliamp, TUI-based music player-keena. Wuxuu caawiyay in nidaamka theming-keena laga rogo ururin configuration files ah wax aad u systematic ah, iyadoo midabo semantic ah iyo themes la generated ah across Neovim, VS Code, btop, iyo inta kale stack-ka. Sidoo kale wuxuu mas'uul ka yahay themes sida Ethereal, Hackerman, iyo Lupine. Bjarne wuxuu leeyahay isku-dar rare ah oo programmer rigor iyo visual taste oo ku habboon Omarchy si perfect ah.

HANCORE waa mechanical engineer oo si lama filaan ah u noqday mid ka mid ah ciidamada aesthetic ee qeexa community Omarchy. Wuxuu soo saaray themes tiro absurd ah, oo ay ku jiraan Last Horizon iyo Solitude, oo by default la socda Omarchy. Hadda wuxuu caawiyaa maamulka ecosystem-ka plugin-ka ee ku wareegsan Quattro. Omarchy waxay mar walba ku adkaysatay in kombuyuutarku waa inuu beautiful as well as useful, HANCORE-na wuxuu premise-gaas hore u riixay in ka badan almost anyone.

Spencer Bull waa Distinguished Engineer Dell ka shaqeeya Linux client enablement, AI, iyo platform software. Wuxuu ahaa buundadayada xaqiiqda messy ee brand-new hardware, isagoo ka caawinaya Omarchy inay si properly ugu shaqayso Panther Lake iyo latest XPS machines ka hor inta aan usual Linux lag soo gelin. Kernel issues, drivers, displays, Wi-Fi, speakers, power management: Spencer wuxuu ka shaqeeyaa layer-ka software meets atoms, in khibraddaas inside Core Team ay qiimo badan.

Shantan horay waxay wadeen shaqada. Tani waxay kaliya official ka dhigaysaa. Aniga oo la socda, waa phenomenal inaugural Core Team. Laakiin sidoo kale ma noqon doonto kooxda only. La soco announcement Omarchy Rangers!

Wada jir waxaan Omarchy u dhisi doonnaa premier Linux distribution dadka ku faraxsan age agents, malleable computer, iyo beautiful, modern, opinionated computing.

Ilaa infinity iyo beyond!
