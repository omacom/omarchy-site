Apple waxay sameysaa hardware fiican. Waligood way sameeyeen (marka laga reebo halkaas mar butterfly keyboard-ka). Dad badan oo Omarchy imanaya waxay ka imanayaan Mac. Kuwa badan waxay jeclaan lahaayeen inay mashiinka haystaan oo operating system-ka lumiyaan. Markaas waxaan dhammaystiri doonnaa waxa Asahi bilaabay: Omarchy oo si qurux badan ugu shaqaynaya Apple Silicon, iyadoo setup fuss ugu yar.

Shaqadaas horay waxay u haysatay koox ka dambaysa. Maanta waxaan official ka dhigaynaa: Omarchy M, kooxdayada Mac-yada Apple Silicon (iyo xubno yar oo Mac-yadii hore fold-ka ku haya).

I ogolaada inaan xubnaha soo bandhigo.

Installer-ka. Marcelo Alcantara wuxuu dhisayaa native Mac installer-ka. Waxaad macOS ka soo dejisataa app, wuxuu soo qaataa signed Omarchy release-ka, wuxuu gooyaa partitions-ka, wuxuuna kugu boot-gareeyaa Omarchy oo macOS-gaaga jira agtiisa. USB stick ma jiro, incantations terminal-ka ma jiraan. Sidoo kale wuxuu jaray build-kii shiday external monitors USB-C dusheed.

Omarchy Mac. Naeem Malik wuxuu maintain-gareeyay Omarchy Mac sannad, isagoo Omarchy keenay mashiinnada M1 iyo M2 muddo dheer ka hor inta aan waxaas official noqon, wuxuuna dhisay Discord community ka badan 800 qof oo ku wareegsan. Scott Jones waa half-ka kale ee mashruucaas Linux side-ka install-ka. Dhawaan wuxuu shaqeeyay display-ga M3 Air Apple hardware display controller-keeda, taas oo mashiinkaas ka dhigtay mid unusable una rogay usable habeen gudahii.

Try Omarchy. Eduardo Martinez wuxuu dhisay Try Omarchy: desktop-ka dhabta ah ee Omarchy oo u shaqaynaya sida native, hardware-accelerated app Mac-gaaga, iyadoo camera-gaaga, audio-ga, clipboard-ka, iyo shared folder la dhex mariyay. Wax partition ah ma jiro. Kaliya soo deji oo arag waxa fuss-ku ku saabsan yahay.

Packages. Shun Li wuxuu hubinayaa in wax kasta oo Omarchy u baahan tahay ay u jiraan sida aarch64 package, oo ay la socdaan generic ARM64 disk images loogu talagalay virtual machines iyo guest tools-ka ka dhiga pleasant in la isticmaalo.

Drivers iyo kernel-ka. Ryan Murray wuxuu keenayaa Neo wuxuuna dhisayaa foundations-ka kooxda intiisa kale ka shaqayso. Wuxuu horumarinayaa SPTM emulator oo suurtogeliya in macOS lagu trace-gareeyo M4 iyo chips cusub. Traces-gaas waxay muhiim u yihiin in displays, GPUs, audio, wireless, iyo Bluetooth shaqeeyaan. Dj wuxuu qorayaa GPU drivers-ka, wuxuuna shaqeeyay Touch ID isagoo si toos ah ula hadlaya Secure Enclave. Miguel Cruz wuxuu ku takhasusay shaqada M5: wuxuu reverse-engineer-gareeyay Apple N1 chip-keeda proprietary wuxuuna Wi-Fi iyo Bluetooth-keeda ka shaqeeyay Linux. Sidoo kale wuxuu ku biiriyay hardware video encoding iyo decoding, Bluetooth, iyo desktop improvements Neo-ga. Liam wuxuu keenayaa trackpad-ka Neo, power management-ka, speakers-ka, iyo headphone output-ka, iyadoo Ryan macOS traces-kiisu bixinayaan groundwork muhiim ah. Eryk Wieliczko wuxuu maintain-gareeyaa M4 support iyo clean-room implementations, wuxuuna ka shaqeeyaa integration iyo packaging. Jaidip Subedi wuxuu enable-gareeyay external displays USB-C dusheed M2 MacBook Air.

MLX. Joshua Warren wuxuu dhisayaa mlx-omarchy, oo keenta Apple MLX machine learning framework-keeda Linux Apple GPUs dusheed iyadoo Vulkan la marayo. Code-kaagu wuxuu weli leeyahay import mlx.core as mx, laakiin hadda wuxuu ku ordaa Omarchy.

Mac-yadii hore. Shawn Yeager wuxuu leeyahay stack pull requests ah loogu talagalay 2016 iyo 2017 Touch Bar MacBook Pros: speakers, Wi-Fi, ambient light sensor-ka, Touch Bar laftiisa. Randy wuxuu reverse-engineer-garaynayaa T2 security chip-ka si uu Touch ID u keeno Intel Macs, wuxuuna document-garaynayaa fix kasta 2019 MacBook Pro wadada. Jon Kinney wuxuu ARM support u shaqaynayay Omarchy sannad ka hor, hadda wuxuu kooxda oo dhan coordinate-gareeyaa qofka wax qabanaya.

Wada jir, waa koox formidable ah. Shan-iyo-toban qof oo aan permission sugin, oo isticmaalayay agents si ay u dhaqaaqaan pace absurd u muuqan lahayd sannad ka hor.

Target-ka release-kii koowaad waa perfect compatibility M1 iyo M2, oo ay ku jiraan Pro iyo Max variants:

  • Seamless installer, oo leh install iyo try options labadaba
  • Full GPU support
  • External monitors USB-C dusheed
  • Touch ID
  • MLX
  • Disk encryption

Mashiinnada cusub waxaa lagu shaqeeyaa parallel, laakiin M1 iyo M2 waa halka aan flag-ka marka hore dhigno. Waxaa dheer mashiinnada M, waxaa jira millions vintage laptops ah halkaas, kuwa badan horay uga retired ah Apple macOS ambitions-kii ugu dambeeyay, mid kastana waa kombuyuutar Omarchy oo wonderful ah oo sugaya inuu dhaco.

Uma baahnid inaad sugto polished release-ka si aad u bilowdo. Try Omarchy waxay kuu keenaysaa inaad desktop-ka dhabta ah Mac-gaaga ku aragto daqiiqo gudahii. Haddii aad diyaar u tahay inaad commit-gareyso, installer-ka wuxuu Omarchy dhigi doonaa macOS agteeda M1 ama M2 maanta.

Ugu dambayn, codsi. Haddii aad ka shaqaynaysay Linux Apple hardware, ha ahaato kernel drivers, firmware, packaging, installers, ama machine learning, waxaan jeclaan lahayn inaan kaa maqalno. Waxaa jirta fursad fiican inaad xallisay wax aan weli raadineyno, ama vice versa. La xiriir apple@omarchy.org.

Aan dhammaystirno waxa Asahi bilaabay.
