Apple máa ń ṣe hardware ńlá. Wọ́n ti máa ń ṣe bẹ́ẹ̀ nígbà gbogbo (yàtọ̀ sí ìgbà kan náà pẹ̀lú keyboard butterfly). Ọ̀pọ̀lọpọ̀ àwọn ènìyàn tí ń dé sí Omarchy sì ń wá láti Mac. Ọ̀pọ̀lọpọ̀ wọn yóò nífẹ̀ẹ́ láti pa ẹ̀rọ náà mọ́ kí wọ́n sì yọ operating system kúrò. Nítorí náà a máa parí ohun tí Asahi bẹ̀rẹ̀: Omarchy tí ń ṣiṣẹ́ ẹlẹ́wà lórí Apple Silicon, pẹ̀lú ìṣòro ṣíṣètò kékeré.

Iṣẹ́ yìí ti ní ẹgbẹ́ lẹ́yìn rẹ̀. Lónìí a ń sọ ọ́ di òṣìṣẹ́: Omarchy M, ẹgbẹ́ wa fún Macs pẹ̀lú Apple Silicon (pẹ̀lú àwọn ọmọ ẹgbẹ́ díẹ̀ tí ń pa àwọn Macs àtijọ́ mọ́).

Jẹ́ kí n fi àwọn ọmọ ẹgbẹ́ hàn.

Olùfi-sori-ẹrọ. Marcelo Alcantara ń kọ́ olùfi-sori-ẹrọ Mac abínibí. O máa gba app kan sílẹ̀ lórí macOS, ó máa fa ìtújáde Omarchy tí a fọwọ́ sí, ó máa gé àwọn partitions, ó sì máa boot ọ sínú Omarchy lẹ́gbẹ̀ẹ́ macOS tí o ní tẹ́lẹ̀. Kò sí USB stick, kò sí incantations nínú terminal. Ó tún gé build tí ó tan àwọn monitors òde nípa USB-C.

Omarchy Mac. Naeem Malik ti ṣe ìtọ́jú Omarchy Mac fún ọdún kan, ó mú Omarchy wá sí àwọn ẹ̀rọ M1 àti M2 pẹ́ kí ohunkóhun yìí tó di òṣìṣẹ́, ó sì kọ́ àwùjọ Discord ti ju ènìyàn 800 lọ yíká rẹ̀. Scott Jones ni ìdajì kejì iṣẹ́ náà lórí ẹ̀gbẹ́ Linux ti fífi-sori-ẹrọ. Ó ṣẹ̀ṣẹ̀ mú display M3 Air ṣiṣẹ́ lórí olùṣàkóso display hardware ti Apple, èyí tí ó mú ẹ̀rọ náà láti aláìlò sí olùlò ní òru kan.

Dán Omarchy wò. Eduardo Martinez kọ́ Try Omarchy: ojú-iṣẹ́ Omarchy gidi tí ń ṣiṣẹ́ gẹ́gẹ́ bí app abínibí, oní-hardware-acceleration lórí Mac rẹ, pẹ̀lú camera rẹ, ohùn, clipboard, àti folda tí a pín tí a so pọ̀. Kò sí nǹkan láti pín. Gba á sílẹ̀ lásán kí o sì wò ohun tí ariwo náà jẹ́ nípa.

Àwọn packages. Shun Li ń rí i dájú pé ohunkóhun tí Omarchy nílò wà gẹ́gẹ́ bí package aarch64, pẹ̀lú àwọn disk images ARM64 gbogbogbò fún virtual machines àti àwọn guest tools tí ń mú wọn dùn láti lò.

Àwọn drivers àti kernel. Ryan Murray ń mú Neo dàgbà ó sì ń kọ́ ìpìlẹ̀ tí ìyókù ẹgbẹ́ ń ṣiṣẹ́ lé lórí. Ó ń ṣe emulator SPTM tí ó jẹ́ kí ó ṣeé ṣe láti trace macOS lórí M4 àti àwọn chips tuntun. Àwọn traces wọ̀nyí ṣe pàtàkì láti mú displays, GPUs, ohùn, wireless, àti Bluetooth ṣiṣẹ́. Dj ń kọ àwọn drivers GPU, ó sì mú Touch ID ṣiṣẹ́ nípa sísọ̀rọ̀ taara sí Secure Enclave. Miguel Cruz ṣe pàtàkì nínú iṣẹ́ M5: ó reverse-engineered chip N1 abínibí ti Apple ó sì mú Wi-Fi àti Bluetooth rẹ̀ ṣiṣẹ́ nínú Linux. Ó tún ti ṣe ìrànlọ́wọ́ fún hardware video encoding àti decoding, Bluetooth, àti àwọn ìdàgbàsókè ojú-iṣẹ́ lórí Neo. Liam ń mú trackpad Neo, ìṣàkóso agbára, speakers, àti ìjáde headphone dàgbà, pẹ̀lú àwọn traces macOS ti Ryan tí ń pèsè ìpìlẹ̀ pàtàkì. Eryk Wieliczko ń ṣe ìtọ́jú àtìlẹ́yìn M4 àti clean-room implementations, ó sì ń ṣiṣẹ́ lórí integration àti packaging. Jaidip Subedi mu àwọn displays òde nípa USB-C lórí M2 MacBook Air ṣiṣẹ́.

MLX. Joshua Warren ń kọ́ mlx-omarchy, èyí tí ó mú framework MLX machine learning ti Apple wá sí Linux lórí Apple GPUs nípasẹ̀ Vulkan. Kóòdù rẹ ṣì ń sọ import mlx.core as mx, ṣùgbọ́n báyìí ó ń ṣiṣẹ́ lórí Omarchy.

Àwọn Macs àtijọ́. Shawn Yeager ní àkójọ àwọn pull requests fún 2016 àti 2017 Touch Bar MacBook Pros: speakers, Wi-Fi, sensor ìmọ́lẹ̀ ambient, Touch Bar fúnra rẹ̀. Randy ń reverse-engineering chip ààbò T2 láti mú Touch ID wá sí Intel Macs, ó sì ń kọ gbogbo àtúnṣe sílẹ̀ fún 2019 MacBook Pro ní ọ̀nà. Jon Kinney ń ṣe àtúnṣe ARM fún Omarchy ní ọdún kan sẹ́yìn, báyìí ó sì ń pa gbogbo ẹgbẹ́ mọ́ ní ìṣọ̀kan lórí ẹni tí ń ṣe kí ni.

Papọ̀, wọ́n jẹ́ ẹgbẹ́ tó lágbára. Ènìyàn mẹ́ẹ̀ẹ́dógún tí kò dúró de ìyọ̀nda, tí wọ́n sì ti ń lo àwọn agents láti lọ ní ìyára tí yóò ti dàbí aṣiwèrè ní ọdún kan sẹ́yìn.

Àfojúsùn fún ìtújáde àkọ́kọ́ ni ìbáramu pípé pẹ̀lú M1 àti M2, títí kan àwọn Pro àti Max variants:

  • Olùfi-sori-ẹrọ aláìlẹ́gbẹ́, pẹ̀lú àwọn àṣàyàn fi-sori-ẹrọ àti dán-wò méjèèjì
  • Àtìlẹ́yìn GPU kíkún
  • Àwọn monitors òde nípa USB-C
  • Touch ID
  • MLX
  • Ìfipamọ́ disk

A ń ṣiṣẹ́ lórí àwọn ẹ̀rọ tuntun ní ìlọpo, ṣùgbọ́n M1 àti M2 ni ibi tí a gbìn ásíá sí ní àkọ́kọ́. Ní àfikún sí àwọn ẹ̀rọ M, mílíọ̀nù laptops vintage wà níbẹ̀, ọ̀pọ̀lọpọ̀ wọn ti fẹ̀yìntì kúrò nínú àwọn ìfẹ́ macOS tuntun ti Apple, gbogbo wọn sì jẹ́ kọ̀mpútà Omarchy ìyanu tí ń dúró de ṣíṣẹlẹ̀.

O kò ní láti dúró de ìtújáde tí a ti pọ́n kí o tó bẹ̀rẹ̀. Try Omarchy yóò mú ọ wò ojú-iṣẹ́ gidi lórí Mac rẹ ní ìṣẹ́jú. Tí o bá ṣetán láti fi ara rẹ fún un, olùfi-sori-ẹrọ náà yóò fi Omarchy sí lẹ́gbẹ̀ẹ́ macOS lórí M1 tàbí M2 lónìí.

Níkẹyìn, ìbéèrè kan. Tí o bá ti ń ṣiṣẹ́ lórí Linux fún hardware Apple, bóyá àwọn drivers kernel, firmware, packaging, àwọn olùfi-sori-ẹrọ, tàbí machine learning, a bá fẹ́ gbọ́ láti ọ̀dọ̀ rẹ. Ó ṣeé ṣe kí o ti yanjú nǹkan tí a ṣì ń lépa, tàbí ní ìdàkejì. Kàn sí wa ní apple@omarchy.org.

Jẹ́ kí a parí ohun tí Asahi bẹ̀rẹ̀.
