Ìgbọ́wọ́ kẹta jáde! Omacom Foundation ń di ìgbọ́wọ́ premier ti mise, àti bẹ́ẹ̀ ti jdx, ẹni tí ó ti lo ọdún láti kọ́ irinṣẹ́ tí ó ń mú ṣíṣe àkóso àwọn ẹ̀yà Ruby, Node, Go ní ìdùnnú láìsí ariwo, tí ó sì fún gbogbo irinṣẹ́ agent rẹ ní upgrade channel tí ó lè bá ìyára fífi-ránṣẹ́ mu.

Tí o bá ti lo Omarchy, o ti lo mise, bóyá o kíyèsí tàbí o kò kíyèsí. Ó ni ohun tí ó ń ṣàkóso àwọn runtimes èdè, nítorí náà mise use -g ruby fún ọ ní Ruby láìsí ìlà kan ti PATH archaeology. Ṣùgbọ́n apá tí mo bìkítà jù ní báyìí ni àwọn agents.

Gbogbo CLI coding-agent ńlá nínú Omarchy ń kó jáde gẹ́gẹ́ bí stub mise lazy-loading nínú ~/.local/bin/. Claude Code, Codex, OpenCode, Antigravity, Copilot, Crush, Grok, Pi, Oh My Pi - gbogbo wọn dúró níbẹ̀, kò ná ọ ní kankan títí ìgbà àkọ́kọ́ tí o bá tẹ ọ̀kan gangan. Nígbà náà ó máa fi ara rẹ sori ẹrọ ìwọ sì ń ṣiṣẹ́. Kò sí package láti wá, kò sí ẹ̀yà láti pín, kò sí toolchain láti ronú nípa. omarchy-mise-install <package> fi CLI mìíràn yòówù wé bákannáà, omarchy update sì ń pa gbogbo wọn mọ́ ní ìmúdójú.

Èyí ni ọ̀nà kíákíá. Nínú The Age of Agents, àlàfo láàrín gbígbọ́ nípa irinṣẹ́ kan àti ṣíṣiṣẹ́ rẹ̀ nílò láti jẹ́ bí ìṣẹ́jú-àáyá mẹ́rin, mise sì mú èyí ṣẹ. Kò sí ẹnikẹ́ni tí ó nílò láti package nǹkan fún distro ní àkọ́kọ́.

Ìfẹ́ náà ń lọ ní ọ̀nà méjèèjì náà: traffic sí mise ti pọ̀ sí 24% láti ìgbà tí Omarchy bẹ̀rẹ̀! Ọ̀pọ̀lọpọ̀ ènìyàn ń pàdé irinṣẹ́ yìí fún ìgbà àkọ́kọ́ nípasẹ̀ wa, èyí gangan ni irú nǹkan tí ìgbọ́wọ́ yẹ kí ó mọ̀ dípò kí ó gba lọ́fẹ̀ẹ́.

Lẹ́ẹ̀kan síi, ẹ ṣeun pàtàkì fún Tobi Lütke, Patrick Collison, Michael Dell, Jack Dorsey, Matthew Prince, Brendan Iribe, Jason Fried, Drew Houston, àti Peter Steinberger fún ṣíṣe èyí ṣeé ṣe. Tí kì í ṣe fún Oligarchy, a kò ní lè náwó àwọn olùdàgbàsókè open-source báyìí!
