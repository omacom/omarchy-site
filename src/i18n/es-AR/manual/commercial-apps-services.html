Omarchy se enfoca sobre todo en ofrecer software libre y de código abierto, pero no es religioso al respecto. A veces la mejor solución es una oferta comercial, y eso está perfecto. Estas son algunas de las opciones para las que ofrecemos una instalación fácil.

1Password #

Guardar tus contraseñas en un gestor de contraseñas es una buena práctica. Más todavía si trabajás en equipo. Y 1password es una gran solución, que además trae una herramienta de línea de comandos para integrar la búsqueda de claves en tus scripts.

Abrís 1Password con Super + Shift + /. Si todavía no está instalado, ese atajo arranca primero la instalación (también podés usar Install > Service > 1Password desde el menú de Omarchy). El instalador también configura la extensión de 1Password para Chromium.

Bitwarden #

Bitwarden es la alternativa de código abierto en el mundo de los gestores de contraseñas, con un plan gratuito que cubre la mayoría de los usos personales. Instalalo con Install > Service > Bitwarden desde el menú de Omarchy, que también trae la herramienta de línea de comandos de Bitwarden.

Spotify #

Spotify es el servicio de música en streaming más popular del mundo. Y la aplicación para Linux ofrece todo lo que esperás, incluida la reproducción sin conexión.

Abrís Spotify con Super + Shift + M. Igual que con 1Password, el atajo arranca primero la instalación si Spotify todavía no está instalado (o usá Install > Service > Spotify desde el menú de Omarchy).

Dropbox #

Dropbox es una gran forma de sincronizar archivos entre máquinas manteniendo una copia de seguridad en la nube. Para configurarlo, elegí Install > Service > Dropbox desde el menú de Omarchy. Una vez que está corriendo, pasá el mouse por la bandeja arriba a la derecha de la barra y hacé clic derecho en el ícono de Dropbox para terminar la configuración.

Tailscale #

Tailscale es una VPN de malla que hace súper simple y seguro acceder a todas tus computadoras y servidores por internet. Para configurarlo, elegí Install > Service > Tailscale desde el menú de Omarchy.

Trae un panel en la barra, una aplicación web para la consola de administración y Taildrop para mandar archivos entre tus máquinas. Mirá redes.

ONCE #

ONCE es la línea de software de 37signals que comprás una sola vez y corrés en tu propio servidor, como el sistema de chat Campfire. Elegí Install > Service > ONCE desde el menú de Omarchy para instalarlo: eso activa su servicio en segundo plano y te deja en la interfaz de terminal de ONCE para que sigas desde ahí.

NordVPN #

NordVPN es un servicio de VPN convencional que te permite sacar tu tráfico por casi cualquier región del mundo. Para configurarlo, elegí Install > Service > NordVPN desde el menú de Omarchy. Después del reinicio que te pide, ejecutá nordvpn login para autenticarte.
