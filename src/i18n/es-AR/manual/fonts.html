Omarchy usa JetBrainsMono Nerd Font como tipografía predeterminada, tanto para la terminal como para el sistema.

Podés cambiarla desde el menú Style > Font dentro del menú de Omarchy (Super + Space). Eso define la tipografía monoespaciada en todos lados: la terminal, la barra y cualquier otra cosa que la pida.

Podés instalar otras tipografías populares para programar desde Install > Style > Font en el menú de Omarchy: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono e Iosevka están todas a un clic, en sus versiones Nerd Font para que los glifos de la barra y la terminal sigan funcionando. Después de instalar una, elegila en Style > Font.
