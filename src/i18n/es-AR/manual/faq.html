¿Cómo cambio entre distribuciones de teclado? #

Editá tu archivo ~/.config/hypr/input.lua y agregá esto para alternar entre distribuciones con Left Alt + Right Alt: 

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,fr",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",
  },
})

La barra va a mostrar automáticamente tu distribución de teclado actual cuando tengas varias configuradas (y también podés hacerle clic para cambiar).

¿Cómo cambio el formato del reloj a 12 horas? #

Hacé clic derecho en el reloj de la barra para ir pasando por los formatos comunes, incluidos los de 12 horas. También podés definir el formato directamente: 

omarchy bar set omarchy.clock format "dddd h:mm AP"

Eso va a mostrar Sunday 10:55 AM.

¿Cómo cambio mi zona horaria? #

Ejecutá Update > Timezone en el menú de Omarchy y elegí de la lista. Si la zona horaria está bien pero el reloj se corrió, Update > Time reinicia la sincronización de hora por vos.

¿Cómo cambio mi DNS, comparto mi Wi-Fi o mido la velocidad de mi conexión? #

Todo eso está en redes.

¿Cómo mido qué tan rápido es mi disco? #

Trigger > Speed Test > Disk Speed Test mide en vivo la velocidad de lectura y escritura de tu disco, o omarchy disk speedtest desde la terminal.

¿Por qué no puedo iniciar sesión en mi cuenta de Google en Chromium? #

La compilación abierta y simple de Chromium no incluye las credenciales OAuth que Google exige para iniciar sesión con una cuenta. Ejecutá Install > Service > Chromium Account en el menú de Omarchy para agregarlas, reiniciá el navegador y el inicio de sesión va a funcionar.

¿Cómo agrego una impresora? #

La impresión viene configurada y funcionando de entrada, y cada impresora la agregás vos desde Print Settings en el lanzador de aplicaciones (Super + Space).

Elegí Add y dale un momento para que busque: una impresora conectada por USB, y la mayoría de las impresoras de red, se encuentran solas. Si la tuya no aparece en la lista, elegí Network Printer > Internet Printing Protocol (ipp) e ingresá su dirección. La pantalla de la impresora o su página web te va a decir cuál es, normalmente algo como 192.168.1.50 con una cola ipp/print. Después Forward te ofrece un controlador, donde una impresora moderna funciona mejor con el perfil sin controlador IPP Everywhere y una más vieja quiere el controlador propio del modelo.

Hacé clic derecho en una impresora y elegí Set as Default para definir cuál usan primero tus aplicaciones, y Properties para configurar el tamaño del papel, el doble faz y la calidad.

El descubrimiento automático, donde las impresoras de la red aparecen sin que las agregues, está desactivado temporalmente mientras lo rehacen, y por eso el primer paso de arriba es tuyo y no automático. Imprimir a un archivo PDF funciona sin ninguna impresora.

¿Cómo cambio dónde se guardan las capturas o las grabaciones de pantalla? #

Si querés que las capturas se guarden en ~/Pictures/Screenshots y no simplemente en ~/Pictures, podés agregar esto a un archivo dentro de ~/.config/uwsm/env.d/ (como ~/.config/uwsm/env.d/capture): 

export OMARCHY_SCREENSHOT_DIR="$HOME/Pictures/Screenshots"

Podés hacer lo mismo con las grabaciones de pantalla usando OMARCHY_SCREENRECORD_DIR.

Eso sí, acordate de crear el directorio donde querés guardar y de reiniciar Omarchy para que tome efecto.

¿Cómo hago funcionar los parlantes y la webcam de mi Apple Studio Display? #

Uno pensaría que todo debería funcionar con solo enchufar el USB C, pero lamentablemente no es así. La solución que encontré para que ande de forma confiable es usar el cable WJESOG DisplayPort + USB-A => USB-C. Con eso, los parlantes y la webcam funcionan de maravilla.

Acordate de que en Omarchy tenés control de brillo incorporado para las pantallas de Apple (tanto la Studio como la XDR) usando las teclas de brillo normales del teclado.

¿Cómo me saco de encima todo el software extra? #

Si no querés programas como Obsidian o LibreOffice, ni nada de lo demás que viene preinstalado, lo podés quitar muy fácil.

Ejecutá Remove > Package para ver todos los paquetes instalados. Después podés marcar con tab cualquier paquete que quieras eliminar, y empezar a quitar todo lo seleccionado con enter.

Y podés usar Remove > Web App en el menú de Omarchy para eliminar cualquiera de las aplicaciones web preinstaladas que no quieras.

O ejecutá Remove > Preinstalls para barrer de una sola vez todos los extras preinstalados: aplicaciones web, TUI y aplicaciones opcionales. Los atajos que las abrían se van con ellas, así que te queda una pizarra limpia de asignaciones para llenar con las tuyas en ~/.config/hypr/bindings.lua.

Para errores y cosas rotas, mirá la sección de solución de problemas.
