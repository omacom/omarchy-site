Todo lo que podés agarrar de la pantalla cuelga de la tecla Print Screen. La tecla sola saca una foto, y los modificadores sacan una grabación, un color o el texto que hay dentro de una zona. Si tu teclado no tiene tecla Print Screen, Super + Ctrl + C abre el mismo juego de opciones como menú.

Atajo Función
Print Screen Captura de pantalla
Alt + Print Screen Grabar la pantalla (o detener la grabación en curso)
Super + Print Screen Selector de color
Super + Ctrl + Print Screen Extraer el texto de una zona
Super + Ctrl + C Menú de captura
Super + Ctrl + . Convertir una imagen o un video

Capturas de pantalla #

Apretá Print Screen y la pantalla se congela, así nada se mueve debajo mientras apuntás. Arrastrá un recuadro para una zona libre, o hacé un solo clic y la captura se ajusta al rectángulo donde clickeaste: una ventana si caíste sobre una, todo el monitor si caíste en la barra o en un espacio vacío. ¿Cambiaste de idea? Apretá Print Screen otra vez para cerrar el selector.

El resultado va a dos lugares a la vez: un PNG en tu directorio de imágenes y el portapapeles, así que podés pegarlo directo en una ventana de chat con Super + V. Aparece una notificación con una miniatura. Hacele clic (o apretá Super + Alt + , para invocar la última notificación) y la captura se abre en Tensaku, el editor de anotaciones, donde podés dibujarle flechas y recuadros antes de mandarla.

Los archivos caen en ~/Pictures de forma predeterminada, con nombres como screenshot-2026-08-13_14-22-05.png. Si preferís guardarlos en su propia carpeta, definí OMARCHY_SCREENSHOT_DIR, y mirá las preguntas frecuentes para saber dónde poner las variables de entorno de la sesión. Omarchy crea el directorio por vos si no existe. También podés cambiar el editor con OMARCHY_SCREENSHOT_EDITOR.

Desde la terminal, omarchy screenshot saca la misma captura, y podés ser explícito: omarchy capture screenshot region para zona libre solamente, windows para ajustarse a los rectángulos de ventanas y monitores, o fullscreen para saltear el selector por completo y agarrar el monitor enfocado. Un segundo argumento copy deja la captura solo en el portapapeles, y save solo en el disco.

Manejar el selector desde el teclado #

Mientras está abierta la selección, no necesitás usar el mouse para nada:

Tecla Función
Return Capturar la ventana resaltada
Ctrl + Return Capturar toda la pantalla
Tab / Ctrl + Tab Resaltar la ventana siguiente o anterior
Teclas de flecha Resaltar la ventana en esa dirección

Las flechas y el Tab llevan el cursor a la ventana que eligen, así el resaltado los sigue y podés ver qué estás por capturar. Estas asignaciones solo existen mientras hay una selección en pantalla, así que no pueden chocar con nada de tu propia configuración.

Grabación de pantalla #

Alt + Print Screen abre Trigger > Capture > Screenrecord, que te pregunta qué querés en el audio: sin audio, audio del escritorio, escritorio más micrófono, o escritorio más micrófono más webcam. Esa última opción solo aparece si realmente tenés una cámara conectada. Elegí una y vas a tener el mismo selector que en una captura: arrastrá una zona, o hacé clic en una ventana o un monitor.

La grabación corre sobre gpu-screen-recorder, que codifica en la placa de video a 60fps y recurre al procesador si hace falta. El resultado es un MP4 en ~/Videos, con nombres como screenrecording-2026-08-13_14-22-05.mp4. Definí OMARCHY_SCREENRECORD_DIR para cambiarlo, pero ojo: a diferencia del directorio de capturas, este tiene que existir de antes, o la grabación se niega a arrancar.

Mientras estás grabando, aparece un pequeño indicador en la barra. Hacele clic para detenerla. También podés detenerla con Alt + Print Screen otra vez, o con la entrada Stop Screenrecording en Trigger > Capture > Screenrecord, que solo aparece mientras algo está grabando de verdad.

Al detenerla se hace un poco de prolijidad antes de entregarte el archivo: se recorta el primer fotograma, y si hay audio se normaliza a -14 LUFS y se silencia el chasquido de captura de PipeWire del comienzo. Después aparece una notificación con una miniatura de la grabación. Hacele clic para reproducir el archivo en mpv.

La superposición de la webcam #

Cuando grabás con webcam, la cámara aparece como una ventana vertical recortada y fijada en la esquina inferior derecha de lo que estés grabando. Si queda tapando algo que necesitás, cambiale el tamaño al vuelo:

Atajo Función
Super + Alt + [ Hacer más chica la superposición de la webcam
Super + Alt + ] Hacer más grande la superposición de la webcam

Hay tres tamaños, chico, mediano y grande, y los atajos van pasando entre ellos. El mediano es el predeterminado. Son proporcionales a la grabación, así que la cámara ocupa la misma porción del cuadro tanto si grabás un monitor 1080p como uno 6K. Y si grabaste una zona en lugar de una pantalla completa, la superposición se ancla a la esquina de esa zona y no a la del monitor, así queda dentro de la toma.

También podés llamarla directamente con omarchy-capture-webcam-resize small, o reset para volver al mediano.

Texto, códigos QR y colores #

Super + Ctrl + Print Screen selecciona una zona y le hace OCR al portapapeles. Eso está explicado como corresponde en Extracción de texto y dictado.

Trigger > Capture > QR Code hace lo mismo con los códigos QR. Seleccioná la zona donde está el código y el valor decodificado va al portapapeles. Solo busca códigos QR, porque el contenido denso de la pantalla tiende a dar falsos positivos como código de barras. Vale saberlo: el valor decodificado va al portapapeles y a ningún otro lado. No se imprime, no está en la notificación, y se marca como sensible para que no quede dando vueltas en el historial del portapapeles. Los códigos QR habitualmente llevan secretos, por ejemplo el URI otpauth:// detrás de un código de configuración de 2FA, y no querés eso en un registro. Pegar sigue funcionando sin problema.

Super + Print Screen (o Trigger > Capture > Color) convierte el cursor en un cuentagotas. Hacé clic en cualquier cosa de la pantalla y el color queda en el portapapeles. Apretá el atajo de nuevo para salir sin elegir.

Convertir antes de compartir #

Una grabación de pantalla en 4K o un HEIC crudo salido de tu teléfono suelen ser demasiado grandes para mandar así nomás. Super + Ctrl + . (o Trigger > Transcode) resuelve eso. Te ofrece un selector de archivos con búsqueda difusa sobre ~/Pictures y ~/Videos, y después te pregunta formato y tamaño.

Las imágenes van a jpg o png en calidad alta, media o baja, que limitan el ancho a 3160, 2160 y 1080 píxeles. Los videos van a mp4 o a un gif animado en 4k, 1080p o 720p. El archivo convertido se escribe al lado del original con la resolución en el nombre, como demo-1080p.mp4, y la ruta se copia al portapapeles como URI de archivo, así podés pegarla directo en una aplicación que acepte archivos arrastrados.

También funciona desde la terminal, si ya sabés qué querés: omarchy transcode ~/Videos/demo.mov mp4 1080p. También existe omarchy transcode ascii, que convierte una imagen en arte ASCII, aunque eso es más para la identidad visual.

Mandarlo a algún lado #

Una vez que tenés el archivo, Super + Ctrl + S abre el menú de compartir y lo manda a otro dispositivo de tu red con LocalSend. Mirá interfaces gráficas para eso.
