Hyprland te deja configurar todos tus dispositivos de entrada con mucho detalle. Podés hacer que la repetición del teclado sea supersónica o que el trackpad use desplazamiento natural. Todo eso se cambia en ~/.config/hypr/input.lua, al que también llegás desde Setup > Input en el menú de Omarchy (Super + Space). Todo lo que pongas ahí reemplaza los valores predeterminados de Omarchy.

Acá va un ejemplo:

hl.config({
  input = {
    -- Use multiple keyboard layouts and switch between them with Left Alt + Right Alt
    kb_layout = "us,dk",
    kb_options = "compose:caps,shift:both_capslock_cancel,grp:alts_toggle",

    -- Change speed of keyboard repeat
    repeat_rate = 40,
    repeat_delay = 600,

    -- Increase sensitivity for mouse/trackpad (default: 0)
    sensitivity = 0.35,

    touchpad = {
      -- Use natural (inverse) scrolling
      natural_scroll = true,

      -- Use two-finger clicks for right-click instead of lower-right corner
      clickfinger_behavior = true,

      -- Control the speed of your scrolling
      scroll_factor = 0.3,
    },
  },
})

-- Scroll faster in the terminal
o.window("(Alacritty|kitty|foot)", { scroll_touchpad = 1.5 })

Podés ver todas las opciones de entrada en la wiki de Hyprland.

De forma predeterminada, Omarchy usa CapsLock como tecla de composición para los emojis rápidos y otros autocompletados. Si preferís usar CapsLock como Caps Lock, mové la tecla de composición a otro lado cambiando compose:caps en kb_options. Por ejemplo, así la pasás al Alt derecho: 

hl.config({
  input = {
    kb_options = "compose:ralt",
  },
})

Gestos del trackpad #

También podés activar los gestos del touchpad, como deslizar con tres dedos para cambiar de escritorio: 

hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })

En las notebooks Dell XPS con touchpad háptico, también podés ajustar la fuerza del clic a baja, media o alta desde Trigger > Hardware > Touchpad Haptics.

Escribir en chino, japonés y otros idiomas #

Omarchy corre el framework de métodos de entrada fcitx5 en cada sesión: es lo que hace funcionar las secuencias de composición del CapsLock. Eso significa que la infraestructura para escritura no latina ya está lista: instalá un motor de entrada como fcitx5-mozc (japonés) o fcitx5-chinese-addons (chino) con omarchy pkg add, más fcitx5-configtool para agregar el motor a tus métodos de entrada y definir la tecla que alterna entre ellos.

Usar ALT como SUPER #

En algunos teclados no es cómodo usar la tecla meta principal (la de Windows o cmd) como SUPER. Podés cambiarla por ALT con este ajuste: 

hl.config({
  input = {
    kb_options = "compose:caps,shift:both_capslock_cancel,altwin:swap_alt_win",
  },
})
