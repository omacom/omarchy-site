Arch tiene una cantidad impresionante de paquetes disponibles para casi cualquier tipo de software, entre el repositorio oficial y el Arch User Repository (AUR).

Y usarlos no podría ser más fácil. Instalás un paquete nuevo de Arch yendo a Install > Package en el menú de Omarchy (Super + Space) y escribiendo el que querés. Va a filtrar automáticamente la lista completa de paquetes de forma difusa. (También podés hacerlo a mano con omarchy pkg add [package] en la terminal).

Con el AUR es igual, solo usá Install > AUR. Eso sí, acordate de que el AUR no está revisado por el equipo de Arch. Es como RubyGems o npm. Cualquiera puede subir algo.

Si querés eliminar un paquete, podés usar Remove > Package desde el menú de Omarchy. Va a borrar el paquete, los archivos de configuración y las dependencias. (También podés hacerlo a mano con omarchy pkg drop [package]).
