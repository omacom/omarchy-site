Podés instalar Omarchy en una sola partición junto a Windows u otras instalaciones.

Este método de instalación también viene con cifrado LUKS para la partición de forma predeterminada, así que en la práctica no se diferencia del disco completo y solo necesita que haya espacio libre disponible en el disco.

Hacer espacio en Windows #

Para instalar junto a Windows, escribí disk management en el menú de inicio y elegí la opción Create and format hard disk partitions.

Buscá la partición que corresponda, hacé clic derecho y elegí Shrink Volume.

Ingresá cuánto querés reducir el volumen. Tené en cuenta que ese va a ser el tamaño de tu futura instalación de Omarchy, incluida la partición de arranque.

Cuando termines, deberías ver algo así, donde la sección de 50GB es donde vamos a instalar Omarchy en este ejemplo.

Instalar Omarchy #

El proceso de instalación de Omarchy es prácticamente el mismo que el normal. Después de elegir tu disco, te va a aparecer la opción Free space install. Elegí esa opción para no borrar el disco completo.

Confirmá que todo esté bien y esperá a que termine la instalación como siempre. Acá también podés elegir instalar sin cifrado (no recomendado), igual que en una instalación de disco completo.

Agregar otras instalaciones al gestor de arranque #

Cuando termines de instalar Omarchy, vas a notar que ahora el gestor de arranque predeterminado es Limine. Con eso también podés agregarle a Limine opciones para tus otras instalaciones, como Windows.

Para hacerlo, ejecutá limine-scan y seguí las indicaciones para agregar a tu configuración de limine los elementos que quieras. Después, al arrancar, vas a ver tus opciones normales de Omarchy y también Windows Boot Manager u otras.

Bitlocker #

Es importante aclarar que este método de instalación no es compatible con Bitlocker, porque Bitlocker cifra el disco entero y no solo la partición. Si te aparece un error diciendo que Bitlocker está activado, arrancá Windows, andá a Settings -> Privacy & Security -> Device encryption y desactivá Bitlocker. Puede llevar un rato descifrar el disco.
