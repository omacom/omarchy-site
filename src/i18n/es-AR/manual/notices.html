Podés ver rápido la fecha y la hora, el estado de la batería y el clima actual con los avisos rápidos.

Fecha y hora #

Super + Ctrl + Alt + T

Clima #

Super + Ctrl + Alt + W

La ubicación se detecta a partir de tu dirección IP, que suele estar bastante cerca, aunque no siempre. Podés fijarla con omarchy weather location --set Malibu, o ser exacto agregando las coordenadas: omarchy weather location --set Malibu 34.0259,-118.7798. Ejecutá omarchy weather location sin nada más para ver dónde cree que estás, y --clear para volver a la detección automática.

Batería #

Super + Ctrl + Alt + B
