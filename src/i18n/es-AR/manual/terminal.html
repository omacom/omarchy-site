Foot es la terminal predeterminada de Omarchy. Es rápida, liviana y compatible incluso con computadoras viejas. Eso sí, no tiene pestañas ni divisiones nativas.

Si usás Tmux tal vez no te importe, pero si no, también tenemos soporte completo para Alacritty, Ghostty y Kitty. Elegí la tuya en Install > Terminal dentro del menú de Omarchy.

Abrís una terminal nueva con Super + Return. (Este atajo apunta automáticamente a la terminal que hayas instalado desde Install > Terminal, y podés cambiar entre las terminales instaladas en Setup > Defaults > Terminal).

Tmux #

Tmux ofrece una interfaz consistente y programable para paneles, ventanas (o sea, pestañas) y sesiones que podés retomar, sin importar qué terminal uses. Incluso funciona en máquinas remotas, así que cuando entrás por SSH a un servidor podés usar el mismo esquema.

Iniciás una sesión nueva de Tmux en una terminal limpia con Super + Alt + Return, y como Tmux es un proceso persistente, podés retomar tu sesión aunque cierres esa terminal. Apretá Ctrl + Space (la llamada tecla de prefijo) y después s para ver todas tus sesiones activas.

Omarchy viene con una configuración de Tmux optimizada ergonómicamente, que tiene muchos atajos para aprender, así que tené la chuleta a mano.

Funciones de disposición de Tmux #

Como Tmux es programable, podemos usar funciones para crear disposiciones. Omarchy trae cuatro funciones distintas para las disposiciones más comunes entre quienes programan.

tdl [agent] abre una interfaz tipo IDE dividida en tres, con el $EDITOR a la izquierda, el agente de IA que elijas a la derecha (como c para opencode, cx para Claude o codex para OpenAI) y una terminal abajo.
