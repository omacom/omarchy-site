Extracción de texto #

Apretá Super + Ctrl + PrtScr para seleccionar una zona de la pantalla y extraerle el texto. El modelo de OCR de código abierto tesseract convierte enseguida esa selección en texto y lo deja en el portapapeles. Después solo apretás Super + V para pegar.

Es muy útil para sacar direcciones del pie de una imagen o números de teléfono metidos en los titulares de un sitio web.

Dictado #

Omarchy ofrece dictado con IA a través de Voxtype. Lo instalás desde Install > AI > Dictation en el menú de Omarchy. De entrada carga un modelo base en inglés que ocupa 150MB. Pero podés cambiar qué modelo usar ejecutando voxtype setup model en la terminal. Y podés ajustar todas las opciones en ~/.config/voxtype/config.toml.

Una vez instalado, dictás manteniendo apretada F9 o activándolo con Super + Ctrl + X, y el texto dictado aparece en el campo que tengas enfocado.
