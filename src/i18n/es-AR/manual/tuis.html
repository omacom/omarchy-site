Lazygit #

Lazygit es una alternativa encantadora a algo como la aplicación GitHub Desktop, y corre dentro de la terminal.

Podés ejecutarlo directamente: andá a cualquier directorio manejado por git y ejecutá lazygit. O podés usarlo dentro de Neovim, donde lo abrís con Space G G.

Salteás entre los distintos paneles con Tab. En el panel de archivos seleccionás archivos para el área de preparación con Space, y después creás un commit nuevo con c. Podés ver todos los comandos disponibles con ?.

Lazydocker #

Lazydocker está hecho con el mismo espíritu que Lazygit, y también te da una interfaz de terminal para manejar tus contenedores e imágenes.

Lo abrís con Super + Shift + D.

Detenés un contenedor con s, o lo iniciás y reiniciás con r. Mirá todos los comandos con ?.

Btop #

Btop es un hermoso monitor de recursos que muestra el uso de memoria, procesador, disco y red. También lista todos los procesos activos y te deja manejarlos.

Omarchy lo llama Activity, y lo abrís apretando Super + Ctrl + T. Se abre como ventana flotante, que podés acomodar en mosaico con Super + T.

Herdr #

Herdr es un gestor de espacios de trabajo para la terminal que te da espacios, pestañas y paneles, y los mantiene todos corriendo en una sesión persistente de la que podés desconectarte y volver más tarde.

Lo abrís (o te reconectás a tu sesión existente) con Super + Ctrl + Return. Omarchy trae una configuración de Herdr que refleja la de Tmux, así que acá la tecla de prefijo también es Ctrl + Space. Podés recorrer todos los atajos con Super + Ctrl + K.

Fastfetch #

Fastfetch muestra información del sistema, como la versión del kernel, el tiempo encendido, el tema, el procesador, la memoria y más. Es el sucesor de la popular herramienta neofetch.

Omarchy lo empaquetó como About en el menú de Omarchy (Super + Space).

Uso del disco #

Cuando el disco se llena y no tenés idea de qué se lo está comiendo, abrí Disk Usage desde el lanzador de aplicaciones (Super + Space). Es dua en modo interactivo apuntado a todo el sistema de archivos, así que podés bajar hasta el directorio culpable, ordenado de mayor a menor, y borrar desde ahí mismo.

Cliamp #

Cliamp es un reproductor de música retro para la terminal inspirado en Winamp 2.x, con radios integradas de lo-fi incluidas. Abrilo con Super + Shift + Alt + M, o desde el menú de Omarchy en Apps. Apretá ? para la lista completa de atajos.

¿Y el Wi-Fi y el Bluetooth? #

No vas a encontrar TUI para Wi-Fi y Bluetooth: esas tareas le corresponden al shell de Omarchy. Hacé clic en el ícono de Wi-Fi en la barra superior (o apretá Super + Ctrl + W) para ver las redes y conectarte, y clic en el ícono de Bluetooth (o apretá Super + Ctrl + B) para emparejar y conectar dispositivos. Mirá redes para la historia completa.

Agregar las tuyas #

Cualquier programa de terminal puede recibir el tratamiento completo de aplicación. Andá a Install > TUI en el menú de Omarchy (Super + Space), dale un nombre, un comando de arranque, un estilo de ventana y un ícono, y va a aparecer en el lanzador de aplicaciones como cualquier otra. Podés quitarla de nuevo desde Remove > TUI.
