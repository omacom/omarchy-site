Podés agregar tus propias aplicaciones web desde Install > Web App en el menú de Omarchy (Super + Space). Te va a pedir el nombre de la aplicación, su URL y la URL del ícono, si no puede sacarlo del favicon. Podés conseguir muy buenos íconos PNG de muchas aplicaciones web populares en Dashboard Icons.

Después quedan accesibles desde el lanzador de aplicaciones (Super + Space), y usan esa hermosa ventana de aplicación web sin marco.

Si querés eliminar una aplicación web, andá a Remove > Web App en el menú de Omarchy.

Lo mejor es que inicies sesión en todas tus cuentas desde un navegador normal antes de usar los atajos de las aplicaciones web. El marco liviano que las envuelve no se lleva bien con 1password, así que es más fácil estar ya conectado.

Todos los atajos de teclado de estas aplicaciones web se pueden cambiar en ~/.config/hypr/bindings.lua.

Cuando estás dentro de una aplicación web, podés copiar la URL actual al portapapeles con Shift + Alt + L.

De forma predeterminada, Omarchy ya viene con un surtido de aplicaciones:

HEY #

HEY es un servicio de correo y calendario que funciona como una gran alternativa para quienes están cansados de Gmail, Outlook o Apple Mail. Lo hace 37signals, donde nació Omarchy.

Podés abrir HEY Email con Super + Shift + E, ir directo a escribir un correo nuevo con Super + Shift + Alt + E, y abrir HEY Calendar con Super + Shift + C.

Basecamp #

Basecamp es un servicio de gestión de proyectos que ayuda a los equipos chicos a moverse más rápido y avanzar más. En lugar de armar un rejunte de Trello, Slack, Asana, Notion o lo que sea, podés tener todo en un solo lugar con Basecamp. Lo hace 37signals, donde nació Omarchy.

Podés abrir Basecamp desde el lanzador de aplicaciones (Super + Space)

ChatGPT #

ChatGPT es el chatbot de IA más popular del mundo.

Podés abrir ChatGPT con Super + Shift + A.

Grok #

Grok es el chatbot de xAI.

Podés abrir Grok con Super + Shift + Alt + A.

WhatsApp #

WhatsApp es uno de los servicios de mensajería más populares del mundo, y la versión web es una gran opción para Linux.

Podés abrir WhatsApp con Super + Shift + Alt + G.

Aplicaciones de Google #

Google Messages, Google Photos, Google Maps y Google Contacts también vienen incluidas como aplicaciones web.

Podés abrir Google Messages con Super + Shift + Ctrl + G, Google Photos con Super + Shift + P y Google Maps con Super + Shift + S. Google Contacts está disponible desde el lanzador de aplicaciones (Super + Space).

X #

X es donde estallan las noticias.

Podés abrir X con Super + Shift + X e ir directo a escribir una publicación nueva con Super + Shift + Alt + X.

YouTube #

YouTube es la plataforma de video más popular del mundo.

Podés abrir YouTube con Super + Shift + Y.

Zoom #

Zoom es el sistema de videollamadas más usado en Estados Unidos. Muy buenas conexiones en todo el mundo. Y las reuniones de 40 minutos se pueden hacer sin cuenta paga. Omarchy envuelve el cliente web de Zoom, y los enlaces a reuniones de zoom se abren directo ahí.

Abrís Zoom desde el lanzador de aplicaciones (Super + Space).

Discord #

Discord es donde se juntan la mayoría de las comunidades de juegos y de código abierto, incluida la de Omarchy.

Abrís Discord desde el lanzador de aplicaciones (Super + Space).
