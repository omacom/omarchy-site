Todo en Omarchy pasa por el teclado, ¡TODO! Cuando el sistema arranca por primera vez, literalmente no podés hacer nada solo con el mouse. Pero podés apretar Super + Space para abrir el menú de Omarchy, y desde ahí hacés prácticamente todo.

Pero el menú de Omarchy no está pensado ni siquiera como la forma principal de manejar el sistema la mayor parte del tiempo. ¡Podemos ir más rápido! Todas las aplicaciones más importantes están asignadas directamente a atajos individuales. Abrís la terminal con Super + Return y un navegador con Super + Shift + Return. Probá hacer uno después del otro y vas a ver la magia del mosaico de Hyprland en acción:

Después podés apretar Super + J para apilarlas una sobre la otra en lugar de lado a lado:

Apretá Super + J de nuevo para devolverlas a sus posiciones lado a lado. Después probá Super + Shift + Arrow Right estando en el navegador para intercambiar las ventanas.

Ahora probá Super + Ctrl + T para abrir el monitor de actividad. Va a aparecer como ventana flotante. Podés ponerla en mosaico con Super + T (y apretar eso de nuevo para volverla flotante). Ahora apretá Super + Shift + F para abrir el gestor de archivos. Vas a tener un prolijo esquema de cuatro:

Te movés hacia la ventana que querés activar con Super + Arrow. Eso cambia el foco y lleva el cursor al centro de la nueva aplicación.

Si apretás Super + Shift + 2, mandás la aplicación enfocada al segundo escritorio. Super + Shift + 1 la trae de vuelta. (Y Super + Shift + Alt + 2 manda la aplicación enfocada al segundo escritorio sin cambiar a ese escritorio).

Si mantenés apretado Super y usás el mouse para hacer clic en una ventana, vas a poder reubicarla. Si mantenés Super y usás el botón derecho del mouse, podés redimensionar la ventana libremente.

Cerrás una ventana con Super + W o Super + Q (y cerrás todas las ventanas con Ctrl + Alt + Delete).

También podés pasar a pantalla completa con Super + F, o solo a ancho completo (manteniendo la barra superior) con Super + Alt + F, o a pantalla completa dentro de una ventana con Super + Ctrl + F (¡ideal para YouTube!).

Disposición dwindle frente a scrolling #

La disposición predeterminada de Omarchy se llama dwindle. Mantiene visibles todo el tiempo todas las ventanas que abrís en un mismo escritorio, incluso si tiene que achicarlas.

Pero también podés convertir un escritorio a la disposición scrolling, donde las ventanas se alinean lado a lado, más allá del borde visible de la pantalla. Convertís un escritorio a esta disposición con Super + L.

La elección es por escritorio, y queda guardada. Así que podés dejar el escritorio 1 en dwindle para navegar y el escritorio 2 en scrolling para programar, y van a volver así después de reiniciar. (El mismo interruptor está en Trigger > Toggle > Workspace Layout en el menú de Omarchy).

Si querés usar la disposición scrolling como predeterminada, podés configurarlo en ~/.config/hypr/looknfeel.lua: 

hl.config({
  general = {
    layout = "scrolling",
  },
})

Agrupar ventanas #

Las ventanas se pueden agrupar con Super + G. Una vez que estás en un grupo, cada ventana que abras mientras ese grupo esté activo va a pertenecer al grupo. Podés moverte entre esas ventanas agrupadas con Super + Ctrl + Arrow Left/Right, o con Super + Alt + 1/2/3/4 para ir directo a una ventana del grupo por orden.

Podés sacar una ventana del grupo con Super + Alt + G, o desarmar el grupo entero apretando Super + G de nuevo. Y por último, podés meter al grupo ventanas que estén afuera con Super + Alt + Arrows.

Ventanas que sobresalen #

Podés sacar una ventana de su escritorio asignado con Super + O. Eso la fija como ventana flotante que te sigue a cualquier escritorio al que vayas. Ideal para reproductores de video y cosas así.

El escritorio borrador #

Por último, hay un escritorio borrador especial que baja sobre el escritorio en el que estés, muy parecido a la consola de Quake. Mostralo y ocultalo con Super + Grave o Super + S, y poné una ventana ahí con Super + Shift + Grave o Super + Alt + S.

Funciona especialmente bien para una terminal corriendo un agente, o para controles con los que querés interactuar rápido sin salir del escritorio actual. Para sacar una ventana del borrador, mandala directo a otro escritorio con algo como Super + Shift + 1.

¡Lleva un tiempo acostumbrarse! #

Lleva un rato acostumbrarse a navegar el escritorio así, pero una vez que lo hacés, ¡te va a costar volver a la experiencia tradicional de escritorio manejado con el mouse!
