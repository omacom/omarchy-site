Alibaba Cloud ansluter sig till Omacom Foundation som grundande företagssponsor och bidrar med 1 miljon dollar om året i tre år! Det är ett åtagande på 3 miljoner dollar, som matchar DigitalOceans stöd, för utveckling, underhåll och spridning av Omarchy.

Men det här partnerskapet sträcker sig långt bortom pengarna. Alibaba Cloud ska hjälpa oss att bygga Omarchy China: det lokala CDN-nätverket, hostingen, webbplatsen, meetupsen och communityn som kinesiska användare behöver för att kunna använda Omarchy utan krångel. Att ladda ner Linux, installera paket och hålla datorn uppdaterad borde vara enkelt var man än bor. Vi ska jobba tillsammans för att få det att gälla i Kina också.

Och timingen kunde inte vara bättre. Med tillkännagivandet av Qwen Book omsätter Alibaba sin ambition för den agentiska datorn i hårdvara. Vi ska samarbeta för att göra Omarchy till det ideala agentiska operativsystemet för den datorn. Ett vackert, roligt Linux-skrivbord där människor och agenter kan jobba tillsammans, och där ägaren fortfarande har kontrollen.

Så här beskriver Alibaba Cloud den kommande Qwen Book:

Qwen Book syftar till att skapa en inbyggd AI-agentdator. Dess kärnfilosofi, “OS as Harness”, handlar enkelt uttryckt om att djupt integrera modeller, operativsystemet, applikationer, molntjänster och hårdvara. Detta bygger en datormiljö som agenter kan förstå, anropa, minnas och köra i kontinuerligt, och uppgraderar datorn från ett passivt verktyg till en ständigt utvecklande personlig assistent.

Qwen Book-systemet är kompatibelt med både ARM- och x86-arkitekturer, där den första versionen bygger på ARM-arkitekturen. På systemnivå har vi byggt en strömsnål Agent Engine och en Continuous Context Engine. Med Qwen-modellfamiljen som intelligent grund tillhandahåller vi modelltjänster för Qwen Book-systemet genom integration mellan moln och enhet. Vi ser fram emot att utforska fler innovationer tillsammans med Omarchy OS i framtiden.

Det innebär att trimma Omarchy för Qwen-modeller direkt från start och jobba mot full integration med de kinesiska tjänster som folk är beroende av. Modellerna, operativsystemet och tjänsterna ska fungera tillsammans från det ögonblick du startar maskinen. Att göra datorn redo att jobba med en agent borde inte vara ett projekt i sig.

Det här är precis den typ av samarbete som jag vill att stiftelsen ska möjliggöra. Människor som bygger modeller, människor som bygger datorer och människor som bygger operativsystem som jobbar tillsammans för att göra hela upplevelsen bättre. Vi har en gemensam ambition för vad persondatorn kan bli, och nu satsar vi resurser bakom det.

Alibaba Cloud ansluter sig till DigitalOcean och Meta Superintelligence Labs som grundande företagssponsor. Deras löfte tar vårt totala stöd till cirka 21,7 miljoner dollar. Det ger mer utrymme att investera i människorna, infrastrukturen och öppen källkods-projekten som gör Omarchy möjligt.

Tack till alla på Alibaba Cloud, och särskilt till CTO LI feifei, som gjorde detta möjligt. Ert stöd låter oss tänka större och sätta fler människor i arbete med att göra Linux bättre för alla.

Låt oss bygga det ideala agentiska operativsystemet för den agentiska datorn. I Kina och överallt annars!
