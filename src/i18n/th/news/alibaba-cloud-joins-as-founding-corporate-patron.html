Alibaba Cloud กำลังเข้าร่วม Omacom Foundation ในฐานะ Founding Corporate Patron โดยร่วมสมทบ ปีละ 1 ล้านดอลลาร์เป็นเวลาสามปี! นั่นคือความมุ่งมั่นมูลค่า 3 ล้านดอลลาร์ เทียบเท่ากับการสนับสนุนของ DigitalOcean เพื่อการพัฒนา การดูแลรักษา และการเผยแพร่ Omarchy

แต่ความร่วมมือนี้ไปไกลกว่าเรื่องเงินมาก Alibaba Cloud จะช่วยเราสร้าง Omarchy China: ทั้ง CDN ในท้องถิ่น โฮสติ้ง เว็บไซต์ งานมีตอัป และชุมชนที่ผู้ใช้ชาวจีนต้องการเพื่อเริ่มใช้ Omarchy ได้อย่างไร้ยุ่งยาก การดาวน์โหลด Linux การติดตั้งแพ็กเกจ และการดูแลคอมพิวเตอร์ของคุณให้ทันสมัยอยู่เสมอควรเป็นเรื่องง่ายไม่ว่าคุณจะอยู่ที่ไหน เราจะร่วมมือกันเพื่อทำให้สิ่งนั้นเป็นจริงในจีนด้วย

และจังหวะเวลานี้ดีกว่านี้ไม่ได้แล้ว ด้วยการประกาศเปิดตัว Qwen Book Alibaba กำลังใส่ความทะเยอทะยานด้าน agentic computer ลงในฮาร์ดแวร์ เราจะร่วมมือกันทำให้ Omarchy เป็น agentic operating system ที่เหมาะที่สุดสำหรับคอมพิวเตอร์เครื่องนั้น เป็นเดสก์ท็อป Linux ที่สวยงามและสนุก ที่คนและเอเจนต์สามารถทำงานร่วมกันได้ และเจ้าของเครื่องยังคงเป็นผู้ควบคุม

นี่คือวิธีที่ Alibaba Cloud อธิบาย Qwen Book ที่กำลังจะมาถึง:

Qwen Book มุ่งสร้างคอมพิวเตอร์เอเจนต์ AI แบบเนทีฟ ปรัชญาหลักของมันคือ “OS as Harness” พูดง่ายๆ ก็คือการผสานโมเดล ระบบปฏิบัติการ แอปพลิเคชัน บริการคลาวด์ และฮาร์ดแวร์เข้าด้วยกันอย่างลึกซึ้ง สิ่งนี้สร้างสภาพแวดล้อมการประมวลผลที่เอเจนต์สามารถเข้าใจ เรียกใช้ จดจำ และทำงานได้อย่างต่อเนื่อง เปลี่ยนคอมพิวเตอร์จากเครื่องมือที่รอรับคำสั่งให้กลายเป็นผู้ช่วยส่วนตัวที่พัฒนาอยู่ตลอดเวลา

ระบบของ Qwen Book รองรับทั้งสถาปัตยกรรม ARM และ x86 โดยรุ่นแรกจะใช้พื้นฐานสถาปัตยกรรม ARM ในระดับระบบ เราได้สร้าง Agent Engine ที่ใช้พลังงานต่ำและ Continuous Context Engine ขึ้นมา ด้วยตระกูลโมเดล Qwen เป็นฐานความฉลาด เราให้บริการโมเดลสำหรับระบบ Qwen Book ผ่านการผสานคลาวด์และอุปกรณ์ เราหวังว่าจะได้ร่วมสำรวจนวัตกรรมใหม่ๆ กับ Omarchy OS ในอนาคต

นั่นหมายถึงการปรับแต่ง Omarchy ให้พร้อมใช้กับ Qwen models ได้ทันทีตั้งแต่เปิดเครื่อง และการทำงานเพื่อผสานเข้ากับบริการต่างๆ ของจีนที่ผู้คนต้องพึ่งพาอย่างเต็มรูปแบบ โมเดล ระบบปฏิบัติการ และบริการต่างๆ ควรทำงานร่วมกันได้ตั้งแต่วินาทีที่คุณเปิดเครื่อง การเตรียมคอมพิวเตอร์ของคุณให้พร้อมทำงานกับเอเจนต์ไม่ควรเป็นโปรเจกต์ในตัวเอง

นี่คือความร่วมมือแบบที่ผมอยากให้มูลนิธิช่วยทำให้เกิดขึ้นพอดี คนที่สร้างโมเดล คนที่สร้างคอมพิวเตอร์ และคนที่สร้างระบบปฏิบัติการ มาทำงานร่วมกันเพื่อทำให้ประสบการณ์ทั้งหมดดีขึ้น เรามีความทะเยอทะยานร่วมกันว่าคอมพิวเตอร์ส่วนบุคคลจะกลายเป็นอะไรได้ และตอนนี้เรากำลังทุ่มทรัพยากรเพื่อสิ่งนั้น

Alibaba Cloud เข้าร่วมกับ DigitalOcean และ Meta Superintelligence Labs ในฐานะ Founding Corporate Patron คำมั่นของพวกเขาทำให้ยอดการสนับสนุนรวมของเราอยู่ที่ประมาณ $21.7 million นั่นคือพื้นที่มากขึ้นในการลงทุนกับผู้คน โครงสร้างพื้นฐาน และโปรเจกต์โอเพนซอร์สที่ทำให้ Omarchy เป็นไปได้

ขอบคุณทุกคนที Alibaba Cloud และโดยเฉพาะ CTO LI feifei ที่ทำให้สิ่งนี้เป็นไปได้ การสนับสนุนของคุณทำให้เราคิดได้ใหญ่ขึ้นและจ้างคนมาทำงานมากขึ้นเพื่อทำให้ Linux ดีขึ้นสำหรับทุกคน

มาสร้าง agentic operating system ที่เหมาะที่สุดสำหรับ agentic computer กันเถอะ ทั้งในจีนและทุกที่!
