Omacom Foundation จ้างพนักงานเต็มเวลาคนแรกแล้ว! Krzysztof Wilczyński เข้าร่วมนำงาน Omarchy Kernel นี่คือสิ่งที่ตั้งมูลนิธิมาทำ จ่ายให้คนเก่งแก้ปัญหายากเพื่อทุกคน

Krzysztof พัฒนาเคอร์เนล Linux มานาน เขาร่วมดูแลระบบย่อย PCI Endpoint และไดรเวอร์ PCI host bridge กับ endpoint แบบเนทีฟ ซึ่งเชื่อม Linux กับ GPU, NVMe และการ์ด WiFi เขายังทบทวนงาน Rust PCI ใหม่ในเคอร์เนล ก่อนลงลึกเคอร์เนล เขาทำวิศวกรรมระบบหลายปีเกี่ยวกับ Kubernetes และรันไทม์คอนเทนเนอร์

ตอนนี้เขานำประสบการณ์ทั้งหมดมาสู่ Omarchy Kernel เน้นประสิทธิภาพ ความเข้ากันได้ และความปลอดภัย เราอยากให้ Linux บินได้ทั้งบนแล็ปท็อปใหม่และ ThinkPad เก่า ใช้ได้ทันทีบนเครื่องมากขึ้น และป้องกันอย่างแน่นหนา

Krzysztof ยังเข้า Omarchy Core เพื่อช่วยกำหนดทิศทางดิสโทรทั้งหมด

ยินดีต้อนรับ Krzysztof! ทำให้เคอร์เนลแรงสุด ๆ กันเถอะ
