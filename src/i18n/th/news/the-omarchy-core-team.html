การเติบโตระเบิดของ Omarchy ต้องมีทีมที่เป็นระบบ เราจะเริ่มด้วยทีม Omarchy Core กลุ่มนี้แบ่งความรับผิดชอบกำหนดทิศทางดิสโทร ให้เดินหน้าต่อ และช่วยผู้ร่วมพัฒนาคนอื่น

ขอแนะนำ Core รุ่นแรก:

Ryan Hughes เป็นคู่หู Omarchy ของผมตั้งแต่วันแรก เราสู้ AUR ล่มฉุกเฉินตีสามด้วยกัน และวางแผนสร้างคลังแพ็กเกจเอง ผลงาน Ryan ครอบคลุมทุกชั้น ทั้งติดตั้ง แพ็กเกจ ฮาร์ดแวร์ เกม ธีม เครื่องมือ CLI และตอนนี้ Quattro เขาช่วยผลักการย้ายไป Quickshell ระบบปลั๊กอิน และโครงสร้างพื้นฐานมากมายที่เปลี่ยน Omarchy จากชุด Linux ประกอบดีเป็นระบบปฏิบัติการจริง นอกจาก Omarchy เขาเป็นหุ้นส่วน Oodle

Tobi Lütke เป็นคนเดียวที่อยู่ Core ทั้งสองทีมของผม! ใน Rails Core รุ่นแรกปี 2004 เขาไม่เพียงมีผลงานมากมายต่อเฟรมเวิร์ก แต่ยังเขียน Liquid, Delayed Job และ Active Merchant งานนั้นกลายเป็นบริษัทเล็กชื่อ Shopify เคยได้ยินไหม ตอนนี้เขาช่วย Omarchy มากด้วย try, Omasnap, คิวอาร์โค้ด Wi-Fi และคอนโซลเอเจนต์แบบ Quake ยังเป็นนักขับร่วมในรถ LMP2 หมายเลข 11 Shopify Racingที่แข่ง IMSA กับผมด้วย

Bjarne Øverli เป็น CTO Unite AS และผู้สร้าง Aether เครื่องมือธีมแบบภาพใน Omarchy กับ cliamp เครื่องเล่นเพลง TUI เขาช่วยเปลี่ยนระบบธีมจากกองไฟล์ตั้งค่าเป็นระบบมากขึ้น ด้วยสีเชิงความหมายและธีมที่สร้างให้ Neovim, VS Code, btop และที่เหลือ เขายังทำ Ethereal, Hackerman และ Lupine มีทั้งความเคร่งครัดของโปรแกรมเมอร์และรสนิยมภาพที่หาได้ยากและเข้ากับ Omarchy

HANCORE เป็นวิศวกรเครื่องกลที่กลายเป็นแรงกำหนดสุนทรียะของชุมชน เขาผลิตธีมมากเหลือเชื่อ รวม Last Horizon กับ Solitude ที่ติดมาใน Omarchy ตอนนี้ช่วยดูแลระบบนิเวศปลั๊กอินของ Quattro ด้วย Omarchy ยืนยันเสมอว่าคอมพิวเตอร์ควรสวยและมีประโยชน์ HANCORE ผลักแนวคิดนี้ไกลกว่าแทบทุกคน

Spencer Bull เป็น Distinguished Engineer ที่ Dell ทำงานรองรับ Linux ฝั่งลูกข่าย AI และซอฟต์แวร์แพลตฟอร์ม เขาเป็นสะพานสู่โลกยุ่งเหยิงของฮาร์ดแวร์ใหม่ ช่วย Omarchy ทำงานบน Panther Lake และ XPS ใหม่ได้ก่อนความล่าช้า Linux ปกติจะเกิด ปัญหาเคอร์เนล ไดรเวอร์ จอ Wi-Fi ลำโพง พลังงาน: Spencer อยู่ชั้นที่ซอฟต์แวร์พบอะตอม ความรู้แบบนี้ใน Core ประเมินค่าไม่ได้

ทั้งห้าทำงานนี้อยู่แล้ว แค่ทำให้เป็นทางการ เมื่อรวมผมคือ Core แรกที่ยอดเยี่ยม แต่จะไม่ใช่ทีมเดียว รอประกาศ Omarchy Rangers!

เราจะร่วมสร้าง Omarchy เป็นดิสโทร Linux ชั้นนำสำหรับคนที่ตื่นเต้นกับยุคเอเจนต์ คอมพิวเตอร์ปรับเปลี่ยนได้ และการใช้คอมพิวเตอร์ที่สวย ทันสมัย มีจุดยืน

สู่ความเวิ้งว้างอันไกลโพ้น!
