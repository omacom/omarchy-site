ThePrimeagen กำลังเข้าร่วม Omarchy Core เพื่อนำทีม Agentic QA! ชายผู้ทำให้ Vim, terminal และ Linux ดูเหมือนเป็นเรื่องสนุกที่สุดที่คุณจะมีได้กับคอมพิวเตอร์ ตอนนี้จะมารับผิดชอบดูแลให้แน่ใจว่าทุกรีลีสของ Omarchy ได้ผ่านการตรวจสอบโดยฝูงเอเจนต์มาแล้วทั้งหมด

เรื่องนี้เหมือนได้ย้อนกลับมาครบวงจรสำหรับผมเลย เป็น Prime นี่แหละที่พาผมมารู้จักกับ Neovim หลังจากที่ใช้ TextMate มาถึงยี่สิบปี และการตั้งค่า Linux ที่เน้นคีย์บอร์ดเป็นหลักของเขาก็เป็นแรงบันดาลใจสำคัญให้กับ Omarchy โดยรวม Vim tutorials ของเขายังคงเป็นจุดเริ่มต้นที่ยอดเยี่ยมสำหรับใครก็ตามที่อยากเรียนรู้เอดิเตอร์เริ่มต้นของ Omarchy

และเขาไม่ได้มาตัวเปล่า ในช่วงเดือนที่ผ่านมา Prime ได้สร้าง Oligarchy ซึ่งเป็น agent harness แบบเฉพาะตัวที่บูต Omarchy ใน QEMU virtual machines และปล่อยให้เอเจนต์ขับเคลื่อนมันได้เหมือนกับที่คนจริงๆ ใช้งาน พวกมันส่งการกดแป้นพิมพ์ ขยับและคลิกเมาส์ ถ่ายภาพหน้าจอ และบันทึกว่าสิ่งต่างๆ ทำงานตามที่ควรหรือไม่ การทดสอบแต่ละครั้งคือ ticket ที่บูตจากดิสก์ที่สร้างขึ้นมาใหม่ และกลุ่ม automation clients จะมารับงานไปทำแล้วรายงานกลับ เขาได้ วินิจฉัย harness แบบสดๆ และชวนเด็กฝึกงานของเขามา “Brownbaggin, Teabaggin, Lunabaggin, Frodobaggins this AGI” กับเขา แน่นอนล่ะ

นี่คือสิ่งที่ OS แบบ agentic ต้องการอย่างแท้จริง Omarchy จะจัดส่งทั้งบน x86, ฮาร์ดแวร์ Apple, Snapdragon, Nvidia, Pi และทุกแพลตฟอร์มอื่นที่เราหามาได้ พร้อมด้วย plugins นับพัน themes ไม่รู้จบ และชุด native applications ที่เติบโตขึ้นเรื่อยๆ ไม่มีทีม QA ที่เป็นมนุษย์ทีมไหนที่จะคลิกตรวจทั้งหมดนั้นได้ในทุกรีลีส แต่ฝูงเอเจนต์ที่รันอยู่บน DigitalOcean Droplets ที่ขับเคลื่อน pipeline ของเรา ทำได้ พวกมันเดินผ่านตัวติดตั้ง อัปเดตระบบ ลอง keybindings เปิดเมนูต่างๆ และแจ้งว่าอะไรพังก่อนที่คุณจะได้เห็นมันเสียอีก

การนำทีม Agentic QA หมายถึงการเปลี่ยน Oligarchy จากการทดลองสนุกๆ ให้กลายเป็นส่วนประจำของวิธีที่เราสร้าง ทดสอบ และส่งมอบ Omarchy
