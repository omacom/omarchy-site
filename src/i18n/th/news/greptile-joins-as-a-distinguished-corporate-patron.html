ผมตื่นเต้นสุดๆ ที่ได้ต้อนรับ Greptile สู่ Omacom Foundation ในฐานะ ผู้อุปถัมภ์องค์กรกิตติมศักดิ์! พวกเขาร่วมสนับสนุน โทเค็นมูลค่า $150,000 สำหรับบริการรีวิว PR ของพวกเขา เพื่อให้ทุกพูลรีเควสต์ที่ส่งเข้ามาใน Omarchy ยังคงได้รับการตรวจทานอย่างละเอียดจากสายตาอีกคู่หนึ่ง.

และเราก็ไม่ได้เริ่มจากศูนย์หรอกนะ. Greptile ได้รีวิว พูลรีเควสต์เกือบ 1,500 รายการ ให้ Omarchy ไปแล้ว. เกือบทั้งหมดนั้นมาตั้งแต่การเปิดตัว Quattro ในเดือนสิงหาคม และเกือบ 700 รายการแค่ในช่วงครึ่งแรกของเดือนตุลาคมเพียงอย่างเดียว! นี่คือปริมาณงานที่คุณต้องเจอเมื่อ ผู้ใช้หลายแสนคน เริ่มส่งฟิกซ์ของตัวเองเข้ามา และไม่มีทีมนักรีวิวที่เป็นมนุษย์ทีมไหนจะตามทันได้ด้วยตัวเองหรอก.

แต่ปริมาณเยอะก็ไม่มีความหมายอะไรหรอกถ้ารีวิวเป็นแค่เสียงรบกวน. สิ่งที่ทำให้ Greptile เก่งจริงคือมันเจอปัญหาจริงได้บ่อยแค่ไหน. จาก PR 60 รายการที่เมิร์จล่าสุดที่มันรีวิว Greptile ระบุปัญหา 39 รายการที่มันจัดว่าร้ายแรง. และก็ไม่ใช่เรื่องจุกจิกสไตล์ lint ด้วยนะ แต่เป็นบั๊กแบบที่จะสร้างปัญหาให้ผู้ใช้จริงๆ ได้เลย.

อย่างตอนที่ Birk เพิ่มวิธีจับคู่รุ่นแล็ปท็อปด้วย device tree ของมัน แล้ว Greptile ชี้ให้เห็นว่าภายใต้โลแคลตุรกี Bash จะแปลง I เป็นตัวพิมพ์เล็กแบบไม่มีจุดอย่าง ı ดังนั้น MICROSOFT,Denali-OLED จะไม่มีวันตรงกับ microsoft,denali-oled เลย. ใครจะไปจับได้ล่ะเนี่ย?! เรื่องนี้ถูกแก้ก่อนที่จะเมิร์จ. หรือตอนที่ผมเขียนคำสั่งเพื่อรีเซ็ตเวิร์กสเปซว่างๆ ให้กลับไปใช้เลย์เอาต์ค่าเริ่มต้นใหม่ แล้ว Greptile สังเกตว่าถ้า hyprctl เกิดคืนค่าขยะออกมาเมื่อไหร่ สคริปต์ของผมก็จะลบเลย์เอาต์ที่บันทึกไว้ทั้งหมดทิ้งอย่างหน้าตาเฉย รวมถึงอันที่กำลังใช้งานอยู่ด้วย. อันนี้ก็แก้แล้วเหมือนกัน! ไม่มีใครรอดไปได้หรอก โดยเฉพาะผมเนี่ยแหละ.

นี่แหละคือสิ่งที่การรีวิวแบบ agentic ควรให้ความรู้สึก. นักรีวิวที่อ่านทุกบรรทัดของทุก PR ไม่ว่าจะกี่โมง อธิบายอย่างชัดเจนว่าจะเกิดอะไรผิดพลาดและเพราะอะไร และมักจะยื่นแพตช์มาให้แก้ได้เลย. มันไม่ได้มาแทนที่วิจารณญาณของ ทีม Omarchy หรอก แต่มันหมายความว่ากว่ามนุษย์จะมาดู PR ขอบคมๆ ก็มักจะถูกตะไบออกไปหมดแล้ว. นั่นคือวิธีที่เราจัดการกับงานค้างหลายพัน PR โดยที่คุณภาพไม่ตกเลย.

Greptile เข้าร่วมกับ 1Password, 37signals, Four Technologies, Fireworks, OpenAI, OpenRouter, OrcaRouter และ Namespace ในฐานะผู้อุปถัมภ์องค์กรกิตติมศักดิ์. คำมั่นของพวกเขาทำให้ยอดเงินสนับสนุนรวมของเราเป็นประมาณ $23.7 ล้าน. เราซาบซึ้งในการสนับสนุนของพวกเขามาก.
