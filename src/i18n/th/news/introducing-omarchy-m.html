Apple ทำฮาร์ดแวร์ได้ยอดเยี่ยม พวกเขาทำได้ดีมาตลอด (ยกเว้นครั้งเดียวตอนคีย์บอร์ด butterfly) และหลายคนที่ย้ายมา Omarchy ก็ย้ายมาจาก Mac หลายคนอยากเก็บเครื่องเดิมไว้แต่โละระบบปฏิบัติการทิ้ง งั้นเราจะมาสานต่อสิ่งที่ Asahi เริ่มต้นไว้ให้จบ นั่นคือให้ Omarchy รันได้อย่างสวยงามบน Apple Silicon โดยติดตั้งยุ่งยากน้อยที่สุด

งานนี้มีทีมอยู่เบื้องหลังแล้ว วันนี้เราทำให้เป็นทางการเลย: Omarchy M ทีมของเราสำหรับ Mac ที่ใช้ Apple Silicon (บวกสมาชิกอีกไม่กี่คนที่ช่วยดูแล Mac รุ่นเก่าให้ยังอยู่ในกลุ่ม)

ขอแนะนำสมาชิกหน่อย

ตัวติดตั้ง Marcelo Alcantara กำลังสร้าง ตัวติดตั้ง Mac แบบเนทีฟ คุณแค่ดาวน์โหลดแอปบน macOS มันจะไปดึง Omarchy รุ่นที่เซ็นรับรองมาให้ แบ่งพาร์ติชันให้เสร็จ แล้วบูตคุณเข้า Omarchy ควบคู่ไปกับ macOS ตัวเดิมของคุณ ไม่ต้องใช้ USB stick ไม่ต้องร่ายคาถาใน terminal เขายังเป็นคนทำบิลด์ที่ทำให้จอนอกติดผ่าน USB-C ได้ด้วย

Omarchy Mac Naeem Malik ดูแล Omarchy Mac มาหนึ่งปี พา Omarchy ลงเครื่อง M1 กับ M2 ตั้งแต่ก่อนที่ทั้งหมดนี้จะเป็นทางการเสียอีก และสร้างชุมชน Discord ที่มีคนกว่า 800 คนรอบโปรเจกต์นี้ Scott Jones เป็นอีกครึ่งหนึ่งของโปรเจกต์นี้ในฝั่ง Linux ของการติดตั้ง เขาเพิ่งทำให้จอของ M3 Air รันได้บน hardware display controller ของ Apple ซึ่งเปลี่ยนเครื่องนั้นจากใช้ไม่ได้เป็นใช้ได้ในคืนเดียว

Try Omarchy Eduardo Martinez สร้าง Try Omarchy: คือเดสก์ท็อป Omarchy ของจริงที่รันเป็นแอปแบบเนทีฟเร่งด้วยฮาร์ดแวร์บน Mac ของคุณ พร้อมต่อกล้อง เสียง คลิปบอร์ด และโฟลเดอร์ที่แชร์ไว้ให้ครบ ไม่ต้องแบ่งพาร์ติชัน แค่ดาวน์โหลดแล้วมาดูกันว่าเขาตื่นเต้นอะไรกัน

แพ็กเกจ Shun Li รับรองว่าทุกอย่างที่ Omarchy ต้องการมีเป็น แพ็กเกจ aarch64 พร้อมกับดิสก์อิมเมจ ARM64 กลาง ๆ สำหรับ virtual machine และ guest tools ที่ทำให้ใช้งานได้ลื่น

ไดรเวอร์และเคอร์เนล Dj กำลังเขียนไดรเวอร์ GPU และทำให้ Touch ID ใช้งานได้โดยคุยกับ Secure Enclave โดยตรง Miguel Cruz รีเวิร์สเอนจิเนียร์ชิป N1 ที่เป็นกรรมสิทธิ์ของ Apple ในเครื่อง M5 จนตอนนี้ Wi-Fi กับ Bluetooth ใช้งานได้เต็มที่บน Linux Liam กำลังปลุกลำโพง แทร็กแพด และการจัดการพลังงานบนเครื่องรุ่นใหม่ล่าสุด Eryk Wieliczko ดูแล Aurora Silicon และกำลังเปลี่ยนทั้งหมดนี้ให้เป็น clean-room implementation ที่ส่งขึ้น upstream ได้ Jaidip Subedi ทำให้ จอนอกผ่าน USB-C บน M2 MacBook Air ใช้งานได้

MLX Joshua Warren กำลังสร้าง mlx-omarchy ซึ่งพาเฟรมเวิร์กแมชชีนเลิร์นนิง MLX ของ Apple มาลง Linux บน Apple GPU ผ่าน Vulkan โค้ดของคุณยังเขียนว่า import mlx.core as mx เหมือนเดิม แต่ตอนนี้มันรันบน Omarchy ได้แล้ว

Mac รุ่นเก่า Shawn Yeager มี pull request เป็นตั้งสำหรับ MacBook Pro Touch Bar ปี 2016 กับ 2017 ทั้งลำโพง Wi-Fi เซ็นเซอร์แสงรอบข้าง ไปจนถึง Touch Bar เอง Randy กำลังรีเวิร์สเอนจิเนียร์ชิปความปลอดภัย T2 เพื่อพา Touch ID มาลง Intel Mac พร้อมจดทุกวิธีแก้สำหรับ MacBook Pro ปี 2019 ไว้ตลอดทาง Jon Kinney เคยค่อย ๆ ทำ ARM support ให้ Omarchy เมื่อปีก่อน ตอนนี้เขาช่วยประสานทั้งทีมว่าใครทำอะไรอยู่

รวมกันแล้วพวกเขาเป็นกลุ่มที่น่าเกรงขาม สิบสี่คนที่ไม่ได้รอขออนุญาตใคร และใช้ agents ทำงานกันในจังหวะที่เมื่อปีก่อนคงฟังดูบ้าบอ

เป้าหมายของรุ่นแรกคือความเข้ากันได้อย่างสมบูรณ์กับ M1 และ M2 รวมถึงรุ่น Pro กับ Max:

  • ตัวติดตั้งที่ลื่นไหล มีทั้งตัวเลือก install และ try
  • รองรับ GPU เต็มรูปแบบ
  • จอนอกผ่าน USB-C
  • Touch ID
  • MLX
  • การเข้ารหัสดิสก์

เครื่องรุ่นใหม่กว่าก็ทำควบคู่กันไป แต่ M1 กับ M2 คือที่ที่เราจะปักธงก่อน นอกจากเครื่องตระกูล M แล้ว ยังมีแล็ปท็อปรุ่นเก่าอีกหลายล้านเครื่องข้างนอกนั่น หลายเครื่องเกษียณจากความทะเยอทะยาน macOS รุ่นล่าสุดของ Apple ไปแล้ว และทุกเครื่องคือคอมพิวเตอร์ Omarchy ชั้นดีที่รอจะเกิดขึ้น

คุณไม่ต้องรอตัวขัดเกลาแล้วค่อยเริ่ม Try Omarchy จะพาคุณไปเห็นเดสก์ท็อปของจริงบน Mac ของคุณในไม่กี่นาที และถ้าพร้อมจะจัดจริง ตัวติดตั้ง จะวาง Omarchy ไว้ข้าง macOS บน M1 หรือ M2 ให้คุณได้ตั้งแต่วันนี้

สุดท้าย ขออะไรหน่อย ถ้าคุณกำลังทำ Linux สำหรับฮาร์ดแวร์ Apple ไม่ว่าจะเป็นไดรเวอร์เคอร์เนล เฟิร์มแวร์ แพ็กเกจ ตัวติดตั้ง หรือแมชชีนเลิร์นนิง เราอยากได้ยินจากคุณ มีโอกาสดีที่คุณแก้สิ่งที่เรายังไล่ตามอยู่ได้แล้ว หรือกลับกันก็ได้ ติดต่อมาที่ apple@omarchy.org
