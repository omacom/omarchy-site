Apple ผลิตฮาร์ดแวร์ที่ยอดเยี่ยม พวกเขาทำได้ดีมาตลอด (ยกเว้นครั้งนั้นกับคีย์บอร์ด butterfly) และผู้คนจำนวนมากที่ย้ายมาหา Omarchy นั้นย้ายมาจาก Mac หลายคนอยากเก็บเครื่องเดิมไว้แต่เปลี่ยนระบบปฏิบัติการ ดังนั้นเราจะสานต่อสิ่งที่ Asahi เริ่มต้นไว้: Omarchy ที่ทำงานได้อย่างสวยงามบน Apple Silicon โดยแทบไม่ต้องยุ่งยากกับการตั้งค่า

งานนี้มีทีมอยู่เบื้องหลังแล้ว วันนี้เราทำให้เป็นทางการ: Omarchy M ทีมของเราสำหรับ Mac ที่ใช้ Apple Silicon (บวกกับสมาชิกอีกสองสามคนที่ยังดูแล Mac รุ่นเก่าให้อยู่ในกลุ่มด้วย)

ตัวติดตั้ง Marcelo Alcantara กำลังสร้างตัวติดตั้งแบบเนทีฟสำหรับ Mac คุณดาวน์โหลดแอปบน macOS มันจะดึง Omarchy รุ่นที่ลงนามแล้วมาให้ แบ่งพาร์ติชันให้ และบูตคุณเข้าสู่ Omarchy ควบคู่ไปกับ macOS เดิมของคุณ ไม่ต้องใช้ USB stick ไม่ต้องร่ายคาถาใน terminal เขายังเป็นคนทำบิลด์ที่ทำให้จอนอกติดผ่าน USB-C อีกด้วย

Omarchy Mac Naeem Malik ดูแล Omarchy Mac มาหนึ่งปี พา Omarchy ลงเครื่อง M1 และ M2 มานานก่อนที่เรื่องนี้จะเป็นทางการ และสร้างชุมชน Discord กว่า 800 คนรอบโปรเจกต์นี้ Scott Jones เป็นอีกครึ่งหนึ่งของโปรเจกต์นี้ในฝั่ง Linux ของการติดตั้ง เขาเพิ่งทำให้จอของ M3 Air ทำงานบน hardware display controller ของ Apple ได้ ซึ่งเปลี่ยนเครื่องนั้นจากที่ใช้งานไม่ได้ให้ใช้งานได้ในคืนเดียว

Try Omarchy Eduardo Martinez สร้าง Try Omarchy: เดสก์ท็อป Omarchy ของจริงที่ทำงานเป็นแอปแบบเนทีฟที่เร่งด้วยฮาร์ดแวร์บน Mac ของคุณ โดยต่อกล้อง เสียง คลิปบอร์ด และโฟลเดอร์ที่แชร์ไว้ให้พร้อม ไม่ต้องแบ่งพาร์ติชัน แค่ดาวน์โหลดแล้วมาดูกันว่าที่ฮือฮากันนั้นเป็นอย่างไร

แพ็กเกจ Shun Li ดูแลให้ทุกอย่างที่ Omarchy ต้องการมีอยู่ในรูปแบบแพ็กเกจ aarch64 พร้อมกับดิสก์อิมเมจ ARM64 แบบทั่วไปสำหรับ virtual machine และ guest tools ที่ทำให้ใช้งานได้อย่างราบรื่น

ไดรเวอร์และเคอร์เนล Ryan Murray กำลังปลุก Neo ให้ทำงานและสร้างรากฐานที่เหลือของทีมใช้ทำงานต่อ เขากำลังพัฒนา SPTM emulator ที่ทำให้สามารถ trace macOS บนชิป M4 และรุ่นที่ใหม่กว่าได้ trace เหล่านั้นจำเป็นต่อการทำให้จอแสดงผล GPU เสียง ไวร์เลส และ Bluetooth ทำงานได้ Dj กำลังเขียนไดรเวอร์ GPU และทำให้ Touch ID ทำงานได้โดยคุยกับ Secure Enclave โดยตรง Miguel Cruz เชี่ยวชาญงาน M5: เขาทำ reverse-engineer ชิป N1 ที่เป็นกรรมสิทธิ์ของ Apple จนทำให้ Wi-Fi และ Bluetooth ของมันทำงานบน Linux ได้ เขายังช่วยงานเข้ารหัสและถอดรหัสวิดีโอด้วยฮาร์ดแวร์ Bluetooth และการปรับปรุงเดสก์ท็อปบน Neo อีกด้วย Liam กำลังปลุกแทร็กแพด การจัดการพลังงาน ลำโพง และช่องต่อหูฟังของ Neo ให้ทำงาน โดยได้รากฐานสำคัญจาก macOS trace ของ Ryan Eryk Wieliczko ดูแลการรองรับ M4 และงาน clean-room implementation และทำงานด้าน integration และ packaging Jaidip Subedi ทำให้จอนอกผ่าน USB-C บน M2 MacBook Air ใช้งานได้

MLX Joshua Warren กำลังสร้าง mlx-omarchy ซึ่งนำเฟรมเวิร์ก machine learning MLX ของ Apple มาสู่ Linux บน Apple GPU ผ่าน Vulkan โค้ดของคุณยังเขียนว่า import mlx.core as mx เหมือนเดิม แต่ตอนนี้มันรันบน Omarchy

Mac รุ่นเก่า Shawn Yeager มี pull request เป็นตั้งสำหรับ MacBook Pro Touch Bar รุ่น 2016 และ 2017: ลำโพง Wi-Fi เซ็นเซอร์แสงรอบข้าง และ Touch Bar เอง Randy กำลังทำ reverse-engineer ชิปความปลอดภัย T2 เพื่อนำ Touch ID มาสู่ Intel Mac และบันทึกทุกวิธีแก้สำหรับ MacBook Pro รุ่น 2019 ไว้ตลอดทาง Jon Kinney เคยช่วยกันดันการรองรับ ARM สำหรับ Omarchy เมื่อปีที่แล้ว และตอนนี้ช่วยประสานงานให้ทั้งทีมรู้ว่าใครกำลังทำอะไรอยู่

รวมกันแล้ว พวกเขาเป็นกลุ่มที่น่าเกรงขาม คนสิบห้าคนที่ไม่ได้รอขออนุญาต และใช้ agent จนทำงานได้เร็วในระดับที่เมื่อปีที่แล้วคงดู absurd ไปเลย

เป้าหมายสำหรับรุ่นแรกคือความเข้ากันได้อย่างสมบูรณ์กับ M1 และ M2 รวมถึงรุ่น Pro และ Max:

  • ตัวติดตั้งที่ราบรื่น พร้อมทั้งตัวเลือกแบบติดตั้งและแบบลองใช้
  • รองรับ GPU อย่างเต็มรูปแบบ
  • จอนอกผ่าน USB-C
  • Touch ID
  • MLX
  • การเข้ารหัสดิสก์

เครื่องรุ่นใหม่กว่ากำลังทำควบคู่กันไป แต่ M1 และ M2 คือจุดที่เราจะปักธงก่อน นอกจากเครื่อง M แล้ว ยังมีแล็ปท็อปรุ่นเก่านับล้านเครื่องอยู่ข้างนอก หลายเครื่องถูก Apple เลิกดันจากความทะเยอทะยานเรื่อง macOS รุ่นล่าสุดไปแล้ว และทุกเครื่องนั้นคือคอมพิวเตอร์ Omarchy ชั้นดีที่รอจะเกิดขึ้น

คุณไม่ต้องรอรุ่นขัดเกลาเสร็จก็เริ่มได้เลย Try Omarchy จะพาคุณไปเห็นเดสก์ท็อปของจริงบน Mac ของคุณในไม่กี่นาที และถ้าคุณพร้อมจะย้ายจริง ตัวติดตั้ง จะวาง Omarchy ไว้ข้าง macOS บน M1 หรือ M2 ได้ตั้งแต่วันนี้

สุดท้ายนี้ ขออย่างหนึ่ง ถ้าคุณเคยทำงานเกี่ยวกับ Linux สำหรับฮาร์ดแวร์ของ Apple ไม่ว่าจะเป็นไดรเวอร์เคอร์เนล เฟิร์มแวร์ แพ็กเกจ ตัวติดตั้ง หรือ machine learning เราอยากได้ยินจากคุณ มีโอกาสดีที่คุณแก้สิ่งที่เรายังไล่ตามอยู่ได้แล้ว หรือกลับกันก็ได้ ติดต่อมาได้ที่ apple@omarchy.org
