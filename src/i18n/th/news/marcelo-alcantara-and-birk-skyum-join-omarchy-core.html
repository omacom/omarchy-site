สองคนที่ทำมากที่สุดในการพา Omarchy ไปไกลกว่า x86 กำลังเข้าร่วม Omarchy Core: Marcelo Alcantara และ Birk Skyum!

Marcelo Alcantara

ตอนที่เราเปิดตัว Omarchy M ในเดือนกันยายน Marcelo คือคนที่กำลังสร้างตัวติดตั้ง Mac แบบเนทีฟ ตั้งแต่นั้นมา เขาก็กลายเป็นคนที่ประสานงานความพยายามทั้งหมดนี้ ทีม 16 คนจากทั่วทุกมุมโลก แต่ละคนทำงานในชั้นที่แตกต่างกันของสแต็ก ตั้งแต่ไดรเวอร์ GPU และจอแสดงผล ไปจนถึง Touch ID และตัวติดตั้งเอง ต้องมีใครสักคนคอยดูแลให้ทั้งหมดเดินไปในทิศทางเดียวกัน และ Marcelo ก็คือคนคนนั้น

ผลลัพธ์นั้นได้เปิดตัวใน Omarchy 4.5 แล้ว ตอนนี้คุณสามารถดาวน์โหลดแอปบน macOS (หรือรัน brew install omacom/mac/omarchy) แล้วมันจะติดตั้ง Omarchy ควบคู่ไปกับระบบเดิมบน MacBook รุ่น M1, M2, M3 หรือ Neo ของคุณได้เลย ไม่ต้องใช้แฟลชไดรฟ์ USB ไม่ต้องท่องคาถาในเทอร์มินัล จากประกาศเปิดตัวทีมถึงระดับที่ “แค่ดาวน์โหลดก็ใช้ได้เลย” ภายในเวลาเพียงสองเดือน ถือเป็นความเร็วที่น่าทึ่งมาก

นั่นคือเครดิตก้อนใหญ่สำหรับทุกคนใน Omarchy M: Scott, Chris, Naeem, Dj, Joshua, Eduardo, Shun, Ryan, Miguel, Liam, Eryk, Jaidip, Shawn, Randy, Jon และ Marcelo คุณทำสิ่งที่ Asahi เริ่มต้นไว้สำเร็จแล้ว และตอนนี้กำลังเดินหน้าต่อไปยัง M4, M5 และ M6 ขอบคุณมาก!

Birk Skyum

Birk เข้าร่วม Omarchy Dragon ในเดือนกันยายน พร้อมกับ Lenovo Yoga Slim 7x ของเขา และประวัติการส่งการแก้ไขไปยังต้นน้ำใน Arch Linux ARM, libcamera, PipeWire, systemd และเคอร์เนล ตั้งแต่นั้นมา เขาก็รับหน้าที่ประสานงานการทำ bring-up ของไลน์อัป Snapdragon ทั้งหมด นั่นหมายถึงการรวบรวมเครื่องต่าง ๆ ค้นหาว่าอะไรใช้ได้และอะไรใช้ไม่ได้ในแต่ละเครื่อง และดูแลให้การแก้ไขต่าง ๆ ไปถึงจุดที่ช่วยเหลือทุกคนได้

คุณสามารถเห็นร่องรอยผลงานของเขาอยู่ทั่วงาน ARM ในเวอร์ชัน 4.5 แล้ว: ไม่มีการแจ้งเตือนให้รีบูตแบบไม่จำเป็นหลังการอัปเดตทุกครั้งอีกต่อไป กล้องที่พร้อมใช้งานตอนเข้าสู่ระบบบนแล็ปท็อป Snapdragon และแอปที่แสดง (หรือซ่อน) ตามสิ่งที่ใช้งานได้จริงบน ARM แต่นั่นเป็นแค่จุดเริ่มต้นเท่านั้น Birk กำลังผลักดันไปสู่รุ่นที่จะออกในอนาคต ซึ่งเครื่อง Snapdragon ทุกเครื่องที่เรารองรับจะใช้งานได้เลยทันที ทั้งโหมดสลีป แบตเตอรี่ วิดีโอ กล้อง ครบทุกอย่าง นั่นคือมาตรฐานที่ตั้งไว้ และเขาคือคนที่คอยดูแลให้เราทำได้ตามนั้น

ยินดีต้อนรับ!

Omarchy กำลังจะทำงานได้อย่างสวยงามบนทุกแพลตฟอร์มหลัก และ Core ต้องการคนที่กำลังทำให้สิ่งนั้นเกิดขึ้น Marcelo และ Birk ได้ทำสิ่งนั้นมาตลอด ตอนนี้มันเป็นทางการแล้ว

ยินดีต้อนรับสู่ Omarchy Core, Marcelo และ Birk!
