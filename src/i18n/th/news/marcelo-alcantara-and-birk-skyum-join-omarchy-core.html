สองคนที่ทำหน้าที่มากที่สุดในการพา Omarchy ไปไกลกว่า x86 กำลังเข้าร่วม Omarchy Core: Marcelo Alcantara และ Birk Skyum!

Marcelo Alcantara

เมื่อเราเปิดตัว Omarchy M ในเดือนกันยายน Marcelo คือคนที่กำลังสร้างตัวติดตั้ง Mac แบบเนทีฟ ตั้งแต่นั้นมา เขาได้กลายมาเป็นคนที่คอยประสานงานความพยายามทั้งหมดนี้ คนสิบห้าคนจากทั่วทุกมุมโลก แต่ละคนทำงานในชั้นที่แตกต่างกันของสแต็ก ตั้งแต่ไดรเวอร์ GPU และจอแสดงผล ไปจนถึง Touch ID และตัวติดตั้งเอง ต้องมีใครสักคนคอยดูแลให้ทุกอย่างไปในทิศทางเดียวกัน และ Marcelo ก็เป็นคนคนนั้น

ผลลัพธ์ได้เปิดตัวใน Omarchy 4.5 ตอนนี้คุณสามารถดาวน์โหลดแอปบน macOS (หรือรัน brew install omacom/mac/omarchy) แล้วมันจะติดตั้ง Omarchy ไว้ควบคู่กับ macOS บน MacBook M1, M2, M3 หรือ Neo ของคุณ ไม่ต้องใช้แท่ง USB ไม่ต้องร่ายคาถาในเทอร์มินัล จากการประกาศทีมไปจนถึง “แค่ดาวน์โหลดก็ใช้ได้” ภายในเวลาเพียงสองเดือน เป็นจังหวะความคืบหน้าที่น่าทึ่งมาก

นี่เป็นเครดิตก้อนใหญ่สำหรับทุกคนใน Omarchy M: Naeem, Scott, Eduardo, Shun, Dj, Ryan, Miguel, Liam, Eryk, Jaidip, Joshua, Shawn, Randy, Jon และ Marcelo พวกคุณทำสิ่งที่ Asahi เริ่มต้นไว้จนสำเร็จ และกำลังเดินหน้าต่อไปยัง M4, M5 และ M6 แล้ว ขอบคุณ!

Birk Skyum

Birk เข้าร่วม Omarchy Dragon ในเดือนกันยายน พร้อมกับ Lenovo Yoga Slim 7x ของเขา และประวัติการแก้ไขที่ต้นทางใน Arch Linux ARM, libcamera, PipeWire, systemd และเคอร์เนล ตั้งแต่นั้นมา เขารับหน้าที่ประสานงานการเตรียมเครื่อง Snapdragon ทั้งไลน์อัปให้พร้อมใช้งาน นั่นหมายถึงการรวบรวมเครื่องต่าง ๆ การค้นหาว่าอะไรทำงานได้และอะไรทำงานไม่ได้ในแต่ละเครื่อง และการทำให้มั่นใจว่าการแก้ไขจะไปอยู่ในจุดที่ช่วยเหลือทุกคนได้

คุณเห็นร่องรอยผลงานของเขาอยู่ทั่วงาน ARM ใน 4.5 แล้ว: ไม่มีการแจ้งให้รีบูตอย่างไร้จุดหมายหลังการอัปเดตทุกครั้งอีกต่อไป กล้องปรากฏขึ้นตั้งแต่ตอนเข้าสู่ระบบบนแล็ปท็อป Snapdragon และแอปจะถูกนำเสนอ (หรือซ่อนไว้) ตามสิ่งที่รันบน ARM ได้จริง แต่นั่นเป็นแค่จุดเริ่มต้น Birk กำลังผลักดันไปสู่รุ่นถัดไปที่กำลังจะมาถึง ซึ่งเครื่อง Snapdragon ทุกเครื่องที่เรารองรับจะใช้งานได้เลย ทั้งโหมดสลีป แบตเตอรี่ วิดีโอ กล้อง ครบทุกอย่าง นั่นคือมาตรฐานที่ตั้งไว้ และเขาคือคนที่ทำให้มั่นใจว่าเราจะไปถึงมาตรฐานนั้น

ยินดีต้อนรับ!

Omarchy จะทำงานได้อย่างสวยงามบนทุกแพลตฟอร์มหลัก และ Core ต้องการคนที่กำลังทำให้สิ่งนั้นเกิดขึ้น Marcelo และ Birk ทำสิ่งนั้นอยู่พอดี ตอนนี้เป็นทางการแล้ว

ยินดีต้อนรับสู่ Omarchy Core, Marcelo และ Birk!
