เราควรมีทีมที่รับผิดชอบทุกแพลตฟอร์มหลัก และ Snapdragon ของ Qualcomm ก็สมควรมีทีมของตัวเองอย่างแน่นอน! เมื่อสัปดาห์ที่แล้ว เราได้เปิดตัว Omarchy M สำหรับฮาร์ดแวร์ Apple วันนี้ เรากำลังทำให้ Omarchy Dragon เป็นทางการ: ทีมของเราที่ทำงานเพื่อให้ Omarchy ทำงานได้อย่างสวยงามบนคอมพิวเตอร์ Snapdragon

เป้าหมายคือการเปลี่ยนแล็ปท็อปบางเบาเหล่านี้ให้กลายเป็นเครื่อง Linux ที่ไว้ใจได้สำหรับใช้ทุกวัน การทำให้เดสก์ท็อปบูตติดเป็นแค่จุดเริ่มต้น การทำให้เครื่องสลีป ตื่นขึ้นมา เล่นวิดีโอได้อย่างมีประสิทธิภาพ อัปเดตเฟิร์มแวร์ และใช้งานได้ตลอดวันทำงานต่างหาก คือสิ่งที่ทำให้มันเป็นคอมพิวเตอร์ที่คุณพึ่งพาได้

ตอนนี้มีห้าคนที่กำลังทำในส่วนต่างๆ อยู่แล้ว:

Jim Martin (GitHub) กำลังทำให้ Linux ทำงานบน Surface Laptop 8 ที่ใช้ Snapdragon X2 Elite เขาทำงานกับ Omarchy สำหรับ DGX Spark และได้ช่วยแก้ปัญหาการปลดล็อกดิสก์แบบกราฟิกในตัวติดตั้ง ARM แล้ว สำหรับ Dragon เขามุ่งเน้นการรองรับ Surface และ X2 Elite การทดสอบการติดตั้งและการกู้คืนบนฮาร์ดแวร์จริง และการนำการแก้ไข ARM ที่เป็นประโยชน์เข้าสู่โปรเจกต์ Omarchy ส่วนกลาง

Birk Skyum (X) เป็นวิศวกรด้าน geoinformatics และกราฟิก และเป็นผู้ร่วมก่อตั้ง MapLibre เครื่องของเขาเป็น Lenovo Yoga Slim 7x ที่ใช้ Snapdragon X Elite เขาส่งการแก้ไข upstream ใน Arch Linux ARM แล้ว ส่งแพตช์ไปที่ libcamera, PipeWire และ systemd และทำแพตช์เคอร์เนลสำหรับการตรวจสอบพัดลมและอุณหภูมิ ตอนนี้เขากำลังดูเรื่องอายุแบตเตอรี่ การสลีปที่เชื่อถือได้ การจำลองเสมือนด้วย KVM วิดีโอเร่งความเร็วด้วยฮาร์ดแวร์ การอัปเดต BIOS จาก Linux และประสิทธิภาพ USB4 เขายังติดต่อกับ Lenovo เกี่ยวกับการปรับปรุงการรองรับเฟิร์มแวร์สำหรับ Linux ด้วย

Matt Gilg (GitHub) ทำเดสก์ท็อป Omarchy ที่ใช้งานได้แล้ว ทั้ง Hyprland และทุกอย่าง ลงบน Snapdragon X Yoga และ DGX Spark เขาสร้างและโฮสต์แพ็กเกจ aarch64 เองเพื่อให้ไปถึงจุดนั้นก่อนที่จะย้ายไปยัง Omarchy Package Repository Matt บริหาร SignalRGB และมีประสบการณ์ด้านความเข้ากันได้ของฮาร์ดแวร์ข้ามผู้ผลิต ระบบฝังตัว และงาน Linux ระดับล่าง เขายังกำลังทำให้ OmniBook X16 ที่ใช้ Snapdragon X2 Elite ทำงานด้วย โดยสนใจเป็นพิเศษในเรื่องเกมมิ่งและการช่วยให้ผู้คนหาทางออกจาก Windows ได้มากขึ้น

Bob Prendergast (GitHub) เป็น solution architect และผู้มากประสบการณ์ด้าน Linux ที่สร้าง Omarchy Snapdragon setup ของตัวเองโดยใช้ agents และเคอร์เนล Ubuntu เขาทำงานกับ HP EliteBook 14 G1q และ Lenovo ThinkPad T14s Gen 6 ยิ่งมีเครื่องมากขึ้น ก็ยิ่งมีการทดสอบมากขึ้น และยิ่งมีงานภาคปฏิบัติมากขึ้นเพื่อเปลี่ยนแพลตฟอร์มที่มีแววดีให้กลายเป็นสิ่งที่ผู้คนติดตั้งและใช้งานได้จริง

Miguel Cruz (X) เป็นส่วนหนึ่งของ Omarchy M อยู่แล้ว และกำลังนำประสบการณ์ด้านการบูต Apple Silicon และความเข้ากันได้ของฮาร์ดแวร์มาสู่ฝั่ง Qualcomm พื้นฐานของเขาครอบคลุม OS internals, reverse engineering และระบบฝังตัว โดยมีส่วนร่วมใน Linux, QEMU และ Virtio เข้าร่วมความพยายามนี้ด้วย ASUS Zenbook A16 ที่ขับเคลื่อนด้วย Snapdragon X2 Elite Extreme โดยมุ่งเน้นที่การบูตและการนำ firmware ขึ้นมา ปัญหาไดรเวอร์ (โดยเฉพาะ GPU) และการทดสอบการแก้ไขบนฮาร์ดแวร์จริง

นอกจากนี้ยังมีความคาบเกี่ยวกับงาน ARM ส่วนที่เหลือของเราด้วย แพ็กเกจ การปรับปรุงตัวติดตั้ง และการแก้ไขที่พัฒนาสำหรับเครื่องหนึ่งสามารถช่วยอีกเครื่องได้ Jim และ Matt ต่างสนใจที่จะขยายงานนั้นไปยัง Raspberry Pi และแพลตฟอร์ม ARM อื่นๆ ด้วยเช่นกัน

ผมยังกำลังพยายามสร้างช่องทางตรงไปยัง Qualcomm วิศวกรที่ทำงานด้านความเข้ากันได้ของ Linux ที่นั่นได้ติดต่อมาแล้ว มาดูกันว่าเราจะได้รับการสนับสนุนอย่างจริงจังเบื้องหลังความพยายามนี้ได้หรือไม่

นี่เป็นงานที่ยังอยู่ในระหว่างดำเนินการ โดยกำลังไล่แก้ความเข้ากันได้ทีละเครื่อง แต่ตอนนี้เรามีทีมที่รับผิดชอบเรื่องนี้แล้ว ทดสอบบนฮาร์ดแวร์จริง และผลักดันการแก้ไขขึ้น upstream ยินดีต้อนรับ Jim, Birk, Matt, Bob และ Miguel มาสร้าง Linux ที่สวยงาม สนุก & agentic ให้กับ Snapdragon กันเถอะ!
