เราจ้าง outfoxxed ผู้สร้าง Quickshell มาเป็น หัวหน้า Omarchy Shell! เขาจะมาร่วมงานกับ มูลนิธิ Omacom แบบเต็มเวลา และเป็นสมาชิกของ Omarchy Core คนที่สร้างทูลคิตที่ทำให้ Quattro เป็นไปได้นั้นกำลังมาร่วมทีมเพื่อช่วยพาทุกอย่างทะยานไปให้ไกลสุดๆ

เรื่องนี้มาแทนข้อตกลงสปอนเซอร์ Quickshell สามปีที่เราประกาศไปเมื่อเดือนสิงหาคม แทนที่จะเป็นสปอนเซอร์แบบนั้น outfoxxed จะมาเป็นพนักงานเต็มเวลาของมูลนิธิ Omacom เพื่อนำงานของเราในด้าน Omarchy Shell เรากำลังเอาตัวผู้สร้างมานั่งอยู่ตรงกลางของสิ่งที่เรากำลังสร้างเลย

Shell คือหัวใจสำคัญของ agentic OS ที่เรากำลังสร้าง มันคือบาร์ เมนู การแจ้งเตือน วิดเจ็ต และปฏิสัมพันธ์เล็กๆ น้อยๆ ทั้งหมดที่ทำให้คอมพิวเตอร์รู้สึกเหมือนเป็นของคุณจริงๆ Quickshell ให้ชิ้นส่วนพื้นฐานแก่เราเพื่อปั้นประสบการณ์นั้นด้วย QML พอรวมเข้ากับเอเจนต์ที่เก่งสุดๆ ในการเขียน QML ทันใดนั้นการเปลี่ยนเดสก์ท็อปของคุณก็กลายเป็นสิ่งที่แค่เอ่ยปากขอ ลองเล่น และแชร์กันได้เลย

หลักฐานอยู่ในปลั๊กอินนั่นแหละ! ตอนที่เราประกาศสปอนเซอร์ ชุมชนก็สร้างกันไปแล้วกว่าพันตัวภายในสัปดาห์แรกของ Quattro ตอนนี้แค็ตตาล็อกมีปลั๊กอินเกือบสามพันตัวแล้ว ทั้งเกมที่เล่นได้จากบาร์โดยตรง แผงที่คอยติดตาม coding agent ของคุณ เครื่องเล่นเพลง หรือแม้แต่แมวที่เดินไปมาบนบาร์รอให้ลูบหัว ผู้คนกำลังเอาระบบที่เคยรู้สึกว่าตายตัวมาทำให้เป็นของตัวเอง นั่นแหละคือคอมพิวเตอร์ที่ปรับเปลี่ยนได้กำลังมีชีวิตขึ้นมาจริงๆ

การได้ผู้สร้าง Quickshell มาร่วมทีมหมายความว่าเราจะได้ทำงานกับทั้งสแต็กไปด้วยกัน ทำให้เชลล์เร็วขึ้นและเชื่อถือได้มากขึ้น ทำให้การสร้างปลั๊กอินดีๆ สักตัวง่ายขึ้น ปรับปรุงรากฐานเมื่อนักพัฒนาปลั๊กอินเจอข้อจำกัด เปลี่ยนสิ่งที่เราเรียนรู้จากการทดลองนับพันให้กลายเป็นประสบการณ์ที่ดีขึ้นสำหรับทุกคนที่บูต Omarchy และทำให้แน่ใจว่าทุกอย่างปลอดภัยและมั่นคง

และด้วยการเข้าร่วม Omarchy Core ทำให้ outfoxxed จะช่วยกำหนดทิศทางของดิสโทรโดยรวมด้วย Shell นั้นสำคัญเกินกว่าจะเป็นแค่เรื่องรอง มันคือที่ที่ความสวยงาม ความสนุก และความเป็นไปได้มากมายของ agentic OS กลายเป็นสิ่งที่คุณมองเห็นและใช้งานได้จริง

outfoxxed คือพนักงานเต็มเวลาคนที่สองของมูลนิธิ Omacom ต่อจากKrzysztof Wilczyński หัวหน้า Omarchy Kernel ของเรา เมื่อได้คนที่นำทั้ง Kernel และ Shell มาร่วมทีมแล้ว เรากำลังลงทุนกับรากฐานของประสบการณ์ทั้งหมด คุณสามารถพบกับทีมงานของมูลนิธิได้บนเว็บไซต์

เราจะจ้างงานต่อไปแบบเชิญชวน เมื่อเราพบคนที่ใช่ผ่านผลงานของพวกเขาในชุมชน (ได้โปรดอย่าส่ง CV มาถล่มอินบ็อกซ์ผมนะ!)

นี่คือสิ่งที่การสนับสนุนของมูลนิธิทำให้เราทำได้ นั่นคือให้นักพัฒนาโอเพนซอร์สที่ยอดเยี่ยมมีเวลาได้ทุ่มสุดตัว ขอบคุณทุกคนที่ให้ทุนสนับสนุนงานนี้ เรากำลังเปลี่ยนความทะเยอทะยานของเราให้กลายเป็นงานเต็มเวลามากขึ้นเรื่อยๆ

ยินดีต้อนรับขึ้นเรือ outfoxxed! มาทำให้คอมพิวเตอร์เครื่องนี้ปรับเปลี่ยนได้ยิ่งกว่าเดิมกันเถอะ
