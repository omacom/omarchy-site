Omarchy 4.5 (หรือ Quattro RS!) เป็นรุ่นฟีเจอร์ใหญ่รุ่นแรกนับตั้งแต่ Quattro และมันเป็นรุ่นใหญ่จริง ๆ มีพูลรีเควสต์ที่ถูกรวมเข้ามามากกว่า 740 รายการจากผู้ร่วมพัฒนามากกว่า 180 คนในเวลาเพียงสิบสองสัปดาห์ ตอนนี้มีโหมดเดสก์ท็อปแบบดั้งเดิมอยู่ข้างโหมดเรียงหน้าต่างเป็นค่าเริ่มต้น คุณสามารถติดตั้งแบบเนทีฟบน MacBook รุ่น M1/M2/M3/Neo ได้ และมันพูดได้ 50 ภาษา และยังมีฟีเจอร์ การแก้ไข และการปรับปรุงอื่น ๆ อีกมากมาย ใช้ Omarchy อยู่แล้วใช่ไหม เรียกใช้ Update > Omarchy ได้เลย เครื่องใหม่เหรอ ดาวน์โหลดได้ที่นี่

เวิร์กสเปซแบบลอยพร้อมด็อก

ตอนนี้ Super + L จะวนเวิร์กสเปซใดก็ได้ระหว่างโหมดเรียงต่อกัน โหมดเลื่อน และโหมดลอย บนเวิร์กสเปซแบบลอย ทุกหน้าต่างจะมีแถบชื่อเรื่องในสีของธีมของคุณ และด็อกจะแสดงแอปที่ปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของแอปทุกตัวที่ติดตั้งไว้ ลากเพื่อจัดลำดับใหม่หรือปักหมุด คลิกขวาเพื่อดูเพิ่มเติม และ Super + M จะย่อหน้าต่างลงไปที่ด็อก

นี่เป็นทางเริ่มต้นที่ยอดเยี่ยมสำหรับใครก็ตามที่ย้ายมาจาก macOS หรือ Windows และยังไม่พร้อมทุ่มสุดตัวกับโหมดเรียงต่อกัน หรือสำหรับใครก็ตามที่แค่อยากมีเวิร์กสเปซหนึ่งที่หน้าต่างกระจายตัวได้อย่างอิสระ ผสมผสานกันได้ตามเวิร์กสเปซ และแถบจะแสดงว่าแต่ละเวิร์กสเปซใช้เลย์เอาต์แบบใด

Omarchy บน Apple Silicon

ทีม Omarchy M ที่น่าทึ่งของเราได้ส่งมอบตัวติดตั้ง Mac แบบเนทีฟแล้ว ดาวน์โหลดแอป บน macOS และมันจะวาง Omarchy ไว้ข้าง ๆ กันบน MacBook รุ่น M1, M2, M3 หรือ Neo ของคุณ ไม่ต้องใช้แท่ง USB ไม่ต้องร่ายคาถาในเทอร์มินัล ชอบ Homebrew มากกว่าเหรอ แค่บรรทัดเดียว:

brew install omacom/mac/omarchy

นี่คือสิ่งที่เราตั้งใจจะทำในเดือนกันยายน ทำให้สิ่งที่ Asahi เริ่มต้นไว้เสร็จสมบูรณ์ สองเดือนต่อมา คุณก็แค่ดาวน์โหลดมันได้เลย เป็นผลงานที่น่าทึ่งของทุกคนในทีม

และพวกเขายังไม่หยุดแค่นั้น M4, M5 และ M6 กำลังดำเนินการอยู่ตอนนี้ ดังนั้นคงอีกไม่นาน Omarchy ก็จะรันบน Mac ที่ใช้ Apple Silicon ทุกเครื่องได้

การรองรับ ARM สำหรับ NVIDIA DGX Spark + N1X (และ Snapdragon ในเร็ว ๆ นี้)

Omarchy 4.5 ส่งมอบ ISO สำหรับ ARM รุ่นแรก และด้วยสิ่งนี้จึงมีการรองรับเบื้องต้นสำหรับเครื่อง ARM ของ NVIDIA เดสก์ท็อป DGX Spark และแล็ปท็อปที่ใช้ N1X เช่น Dell XPS 16 Creator Edition และ ASUS ProArt P14 และในเร็ว ๆ นี้เราจะรองรับเครื่อง ARM แบบ Snapdragon ทั้งไลน์อัปด้วย ยังเป็นช่วงเริ่มต้น ดังนั้นคาดไว้ได้ว่าอาจมีจุดที่ยังไม่เรียบร้อยบ้าง และโปรดรายงานสิ่งที่เสียหายได้ที่ GitHub

50 ภาษาและ 5 วิธีป้อนข้อมูล

ตอนนี้ Omarchy พูดได้ 50 ภาษา เลือกหนึ่งภาษาได้ที่ Setup > Language (หรือรัน omarchy language <code>) และเมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy จะเปลี่ยนทันที ส่วน locale ของระบบจะตามไปในการเข้าสู่ระบบครั้งถัดไปของคุณ

แต่การพูดภาษาหนึ่งเป็นเพียงครึ่งเดียวเท่านั้น คุณต้องพิมพ์มันได้ด้วย ดังนั้นตอนนี้ Omarchy จึงตั้งค่าวิธีป้อนข้อมูลที่เหมาะสมสำหรับภาษาญี่ปุ่น (Mozc), ภาษาเกาหลี (Hangul), ภาษาจีนตัวย่อ (Pinyin), ไต้หวัน (Zhuyin) และฮ่องกง (Cangjie) ได้เลยจากตัวติดตั้ง หรือภายหลังที่ Setup > Keyboard แต่ละวิธีมาพร้อมแบบอักษรที่ถูกต้องสำหรับรูปแบบตัวอักษรของมัน หน้าต่างตัวเลือกจะตามธีมของคุณ และ Super + I จะสลับระหว่างภาษาสำหรับการป้อนข้อมูลของคุณ Hangul, Zhuyin และ Cangjie จะคงปุ่มไว้ในตำแหน่งมาตรฐานแม้ว่าคุณจะพิมพ์ละตินบน Dvorak, Colemak หรือ AZERTY เหมือนกับบน Windows และ macOS และการแตะ Shift เพียงอย่างเดียวจะก้าวออกจากวิธีป้อนข้อมูลไปเป็นตัวอักษรละตินและกลับมาอีกครั้ง ในแบบที่ Sogou, Microsoft Pinyin และ macOS ทำงาน

ลงชื่อเข้าใช้พอร์ทัล Wi-Fi ที่ต้องเข้าสู่ระบบ

ในที่สุด Wi-Fi ของโรงแรม สนามบิน และร้านกาแฟก็ใช้งานได้เลย ตอนนี้ Omarchy จะสังเกตเห็นเมื่อเครือข่ายต้องการให้คุณลงชื่อเข้าใช้หรือยอมรับข้อกำหนดก่อนอนุญาตให้คุณออนไลน์ ไอคอนเครือข่ายจะเตือนคุณ และแผงเครือข่ายจะแสดงปุ่ม Open Captive Portal ขนาดใหญ่ที่พาคุณตรงไปยังหน้าเข้าสู่ระบบ เมื่อคุณผ่านเข้าไปได้ ทุกอย่างจะกลับเป็นปกติเอง

แอปเริ่มต้นใหม่ห้าแอป

Hype สร้างงานนำเสนอจากไฟล์ Markdown ไฟล์เดียว โดยมีตัวแก้ไขสไลด์แบบภาพอยู่ข้างต้นฉบับ และส่งออกเป็น PDF หรือ PowerPoint ได้

Signed มาแทน Xournal++ สำหรับงานเอกสาร เปิด PDF วางลายเซ็น ข้อความ และวันที่ที่บันทึกไว้ของคุณ และบันทึกสำเนาที่ลงนามแล้ว

Disktree วาดแผนภาพต้นไม้ของสิ่งที่กำลังเติมดิสก์ของคุณ โดยระบายสีตามชนิด เรียก out แคชที่สร้างใหม่ได้อย่างปลอดภัย และให้คุณทำเครื่องหมายสิ่งที่ควรลบออก

Monologue บันทึกกล้องของคุณด้วยปุ่มเดียว โดยมีธีมให้เข้ากับเดสก์ท็อปของคุณ

Gliff ให้เดสก์ท็อประยะไกลผ่าน SSH แก่คุณ เชื่อมต่อกับเครื่อง Omarchy อีกเครื่องและควบคุมเดสก์ท็อปเต็มรูปแบบของมันจากหน้าต่างบนเครื่องของคุณ โดยมีแท็บสำหรับแต่ละเครื่อง และเพราะมันอาศัย SSH จึงไม่มีอะไรต้องตั้งค่าเพิ่มเติมหรือเปิดเผย เครื่องที่ถูกควบคุมจะแสดงตัวบ่งชี้เซสชันระยะไกลในแถบ ดังนั้นจึงชัดเจนเสมอเมื่อมีใครบางคนอยู่บนเครื่องนั้น

และยังมี Elsewhen นาฬิกาโลกที่อยู่ติดกับนาฬิกาในแถบเลย แตะเมืองบนลูกโลกเพื่อตั้งว่าคุณอยู่ที่ไหน ค้นหาสถานที่จริง และตั้งชื่อผู้คนที่อาศัยอยู่ในแต่ละเมือง เพื่อให้คุณรู้เสมอว่าตอนนี้เป็นเวลาที่เหมาะสมที่จะโทรหาหรือไม่ สลับระหว่าง 12 และ 24 ชั่วโมงด้วย t ระหว่าง °F และ °C ด้วย Alt + T และเรียกมันขึ้นมาได้ทุกเมื่อด้วย Super + Ctrl + Alt + E

ด้วย Monologue สำหรับการบันทึกและ Omacut สำหรับการตัดแต่ง การติดตั้งใหม่จะไม่ส่งมอบ OBS Studio และ Kdenlive อีกต่อไป Lazydocker ก็หายไปจากการติดตั้งใหม่ด้วยเช่นกัน แม้ว่า Docker และ Docker Compose จะยังรวมอยู่ เครื่องที่มีสิ่งใด ๆ เหล่านี้อยู่แล้วจะยังคงเก็บไว้

Microsoft 365

ต้องการทำงานกับผู้คนที่อยู่ใน Office เหรอ ตอนนี้ Install > Service > Microsoft จะตั้งค่า Outlook, Word, Excel, PowerPoint, Teams และ OneDrive เป็นเว็บแอป แต่ละอันจะมีหน้าต่างและรายการในตัวเปิดใช้ของตัวเอง ดังนั้นพวกมันจึงรู้สึกเหมือนอยู่บ้านข้าง ๆ ทุกอย่างอื่น ๆ ไม่มีข้อแก้ตัวที่จะไม่เปลี่ยนมาใช้ Omarchy ในที่ทำงานอีกต่อไป!

Superwhisper สำหรับการเขียนตามคำบอก

ตอนนี้ Superwhisper เป็นเครื่องมือเขียนตามคำบอกเริ่มต้นของ Omarchy และตั้งค่ามาให้พร้อมใช้ทันที แตะ Alt + Space เพื่อเริ่มพูดและแตะอีกครั้งเพื่อหยุด หรือกด Right Alt ค้างไว้เพื่อพูดแบบกดเพื่อพูด มันเร็วอย่างไม่น่าเชื่อและแม่นยำมาก

มันเริ่มต้นบนคลาวด์ ดังนั้นจึงใช้งานได้ทันทีที่คุณติดตั้ง และ 10,000 คำแรกฟรี แต่คุณสามารถเปลี่ยนไปใช้โมเดลดาวน์โหลดได้ซึ่งฟรีทั้งหมดและทำงานภายในเครื่องอย่างสมบูรณ์ โดยไม่ส่งคำใด ๆ ไปให้ใคร และถ้าคุณอยากใช้โมเดลภายในเครื่องตัวอื่นมากกว่า Voxtype ก็ยังมีให้เป็นทางเลือก

ติดตั้งในเวลาไม่ถึงสิบวินาที

Omarchy เคยติดตั้งแพ็กเกจประมาณ 940 รายการทีละรายการ ตัวติดตั้ง F1 ใหม่จะแกะอิมเมจรูทที่สร้างไว้ล่วงหน้าแทน และเพิ่มเฉพาะแพ็กเกจของเครื่องนี้ลงไปด้านบน นั่นลดเวลาการติดตั้งลงประมาณครึ่งหนึ่งบนเครื่องใด ๆ

และบนฮาร์ดแวร์ที่เร็ว มันไร้สาระมาก Anush Elangovan จาก AMD สร้างสถิติโลกด้วยการติดตั้ง Omarchy เต็มรูปแบบในเวลา 7 วินาที บนแล็ปท็อป AMD ของเขา เจ็ดวินาที! ผมจำได้ว่าเมื่อห้านาทีดูเหมือนเป็นเป้าหมายที่ทะเยอทะยาน

เร็วขึ้นในที่อื่น ๆ ทุกแห่ง

ไม่ใช่แค่ตัวติดตั้งเท่านั้น การเริ่มต้นจะไม่ค้างกับการลงทะเบียน binfmt อีกต่อไป ตัวเลือกธีมเปิดทันทีแทนที่จะหลังจากหนึ่งในสี่วินาที เมนูและแผงเปิดโดยตรงจากทางลัด Hyprland โดยข้าม 60 ms ที่เคยใช้ในการเริ่มกระบวนการก่อน การตรวจสอบที่ช้าที่สุดของเมนู Omarchy ลดจาก 200 ms เป็น 16 ms เทอร์มินัลใหม่แสดงพรอมต์เร็วขึ้น 30 ms และตอนนี้เดสก์ท็อปทั้งหมดตอบสนองต่อการเปลี่ยนแปลงแทนที่จะสำรวจหามัน แม้แต่การออกจากระบบ การรีบูต และการปิดเครื่องก็เกิดขึ้นทันทีที่แอปของคุณปิดเสร็จ

การอัปเกรดเอเจนต์

Omarchy คือระบบปฏิบัติการพร้อมเอเจนต์สำหรับยุคเอเจนต์ และ 4.5 นำการอัปเกรดครั้งใหญ่สำหรับการทำงานกับเอเจนต์มาให้ ตอนนี้แผงเอเจนต์ติดตามเอเจนต์และผู้ให้บริการ 23 ราย เพิ่มจาก 6 ราย รวมถึง Cursor, OpenCode, GitHub Copilot, Antigravity, Hermes, Amp, Kiro, Devin, Qwen, DeepSeek, OpenRouter และ Ollama ขีดจำกัดทุกอันจะมีมิเตอร์ของตัวเองพร้อมเวลาจนกว่าจะรีเซ็ต ดังนั้นคุณจะเห็นได้อย่างชัดเจนว่าคุณเหลือระยะทางอีกเท่าใด และตอนนี้ Grok เป็นผู้ให้บริการเต็มรูปแบบควบคู่กับ Claude และ Codex

และเอเจนต์ของคุณอยู่ห่างเพียงการกดปุ่มเดียวเสมอ Super + ~ จะดึงคอนโซลสไตล์ Quake ลงมาบนเดสก์ท็อปที่หรี่ลง และครั้งแรกที่คุณเปิดมัน มันจะเริ่มเอเจนต์เริ่มต้นของคุณ กดอีกครั้งเพื่อเก็บมันไว้ และเซสชันของคุณจะอยู่ตรงที่คุณทิ้งไว้

ถ้าคุณสลับไปมาระหว่างการสมัครสมาชิกมากกว่าหนึ่งรายการ ตอนนี้คุณสามารถเก็บการเข้าสู่ระบบ Claude, Codex และ Grok หลายรายการบนเครื่องเดียวกัน และเลือกได้ว่าเซสชันใหม่จะเริ่มด้วยรายการใด โดยใช้ omarchy agent account ประวัติ การตั้งค่า และทักษะจะแชร์กันระหว่างพวกมัน ดังนั้น claude --continue จึงทำต่อจากจุดที่คุณทิ้งไว้หลังการสลับ เมื่อใกล้ถึงขีดจำกัด Omarchy สามารถเสนอการสลับในคลิกเดียว หรือย้ายเซสชันใหม่ไปยังบัญชีที่มีพื้นที่เหลือมากที่สุดเองได้ และเมื่อคุณตั้งค่าเครื่องอื่น omarchy agent account copy จะนำการเข้าสู่ระบบทั้งหมดของคุณผ่าน SSH มา เพื่อให้คุณไม่ต้องลงชื่อเข้าใช้ทุกอย่างอีกครั้ง

Kimi และ Ori ซึ่งเป็นชุดเครื่องมือเอเจนต์ของ OpenRouter เข้าร่วมตัวเลือกที่ Setup > Defaults > Agent และ Antigravity ของ Google มาแทน Gemini CLI ที่ล้าสมัย (gemini ยังใช้งานได้เป็นนามแฝง) ชอบหน้าต่างมากกว่าเทอร์มินัลเหรอ ตอนนี้แอปเดสก์ท็อป Claude และ Amp อยู่ห่างเพียงคลิกเดียวที่ Install > AI

ตอนนี้เมนูบูตเงียบลง

Omarchy เคยแสดงเมนูบูตประมาณหกวินาทีทุกครั้งที่เริ่ม เผื่อในกรณีที่คุณต้องย้อนกลับไปยังสแนปช็อตก่อนหน้า แต่แทบไม่มีใครเคยทำเลย ดังนั้นตอนนี้ Limine รอเพียงหนึ่งวินาทีและบูตอย่างเงียบ ๆ และส่วนใหญ่คุณจะไม่เห็นเมนูเลย

เมื่อคุณต้องการรายการอื่นหรือสแนปช็อต ให้แตะปุ่มใดก็ได้ต่อไป (ลูกศรลงก็ใช้ได้) ขณะที่เครื่องกำลังเริ่ม และมันจะหยุดที่เมนู และถ้าคุณอยากให้เมนูอยู่นานขึ้นอย่างถาวรมากกว่า ให้ตั้งค่า timeout: ของคุณเองใน /boot/limine.conf (เช่น timeout: 5) การอัปเดตจะปล่อยให้ timeout ที่คุณตั้งไว้อยู่ตามเดิม

ปุ่มลัดที่เปลี่ยนไป

ทางลัดบางอย่างย้ายไปแล้ว:

  • เครื่องคิดเลข: Super + Ctrl + Q ตอนนี้เป็น Super + Shift + Q
  • กิจกรรม: Super + Ctrl + T ตอนนี้เป็น Super + Shift + T และ Super + Ctrl + T เปิดธีม
  • เครือข่าย: Super + Ctrl + W ตอนนี้เป็น Super + Ctrl + N และ Super + Ctrl + W เปิดพื้นหลัง
  • Nightlight ไม่มีปุ่มลัดอีกต่อไป (เดิมคือ Super + Ctrl + N); มันอยู่ใน Trigger > Toggle
  • Super + Alt + Space เปิด Apps จากด็อกแทนเมนู Apps

ปุ่มลัดการแจ้งเตือนเปลี่ยนไป:

  • Super + Comma กระทำกับการ์ดใหม่ล่าสุด (ปิดมัน เปิดมัน หรือกดปุ่มเดียวของมัน) แทนที่จะแค่ปิดมันเท่านั้น
  • การปิดการ์ดสุดท้ายย้ายไป Super + Alt + Comma ซึ่งเดิมใช้เปิดมัน
  • การปิดเสียงย้ายจาก Super + Ctrl + Comma ไป Super + Ctrl + Alt + Comma; ตอนนี้ Super + Ctrl + Comma มอบการควบคุมด้วยแป้นพิมพ์ให้คุณ

ปุ่มบางปุ่มทำงานต่างออกไป:

  • Super + Tab, Super + Shift + Tab, Super + Ctrl + Tab และ Super + การเลื่อน จะอยู่บนเวิร์กสเปซของจอภาพปัจจุบัน เนื่องจากจอภาพแต่ละจอมีเวิร์กสเปซของตัวเอง
  • ในเทอร์มินัล Super + C และ Super + V จะส่ง Ctrl + Shift + C และ Ctrl + Shift + V แทน Ctrl + Insert และ Shift + Insert

ค่าเริ่มต้นใหม่ที่อาจชนกับการผูกปุ่มของคุณเอง: Super + Q (ปิดหน้าต่าง ควบคู่กับ Super + W), Super + A (เลือกทั้งหมด), Super + M (ย่อลงด็อก), Super + ~ และ Super + Shift + ~ (คอนโซล Quake), Super + Alt + L (เลย์เอาต์ก่อนหน้า), Super + Shift + Ctrl + Arrows (ย้ายหน้าต่างไปจอภาพอื่น), Super + Ctrl + Alt + C (ภาพหน้าจอ), Super + Ctrl + Alt + E (นาฬิกาโลก), Super + Ctrl + Alt + F (เดสก์ท็อปเต็มจอ) และการกด Right Alt ค้างไว้สำหรับการเขียนตามคำบอกแบบกดเพื่อพูด
