Omarchy 4.5 (หรือ Quattro RS!) เป็นรุ่นฟีเจอร์ใหญ่รุ่นแรกนับตั้งแต่ Quattro และมันใหญ่มาก: มี pull request มากกว่า 740 รายการที่รวมเข้ามาจากผู้ร่วมพัฒนามากกว่า 180 คนในเวลาเพียงสิบสองสัปดาห์ ตอนนี้มีโหมดเดสก์ท็อปแบบดั้งเดิมควบคู่ไปกับโหมดเรียงกระเบื้องที่เป็นค่าเริ่มต้น คุณสามารถติดตั้งแบบเนทีฟบน MacBook รุ่น M1/M2/M3/Neo ได้ และมันพูดได้ 50 ภาษา และยังมีฟีเจอร์ การแก้ไข และการปรับปรุงอื่น ๆ อีกมากมาย ใช้ Omarchy อยู่แล้วใช่ไหม เรียกใช้ Update > Omarchy เครื่องใหม่ใช่ไหม รับได้ที่นี่

พื้นที่ทำงานแบบลอยพร้อมด็อก

ตอนนี้ Super + L จะสลับพื้นที่ทำงานใด ๆ ระหว่างแบบเรียงกระเบื้อง แบบเลื่อน และแบบลอย บนพื้นที่ทำงานแบบลอย ทุกหน้าต่างจะมีแถบชื่อในสีของธีมของคุณ และด็อกจะแสดงแอปที่ปักหมุดไว้ ทุกอย่างที่กำลังทำงานอยู่ และตารางของทุกแอปที่ติดตั้งไว้ ลากเพื่อจัดลำดับใหม่หรือปักหมุด คลิกขวาเพื่อดูเพิ่มเติม และ Super + M จะย่อหน้าต่างลงไปที่ด็อก

นี่เป็นทางเริ่มต้นที่ยอดเยี่ยมสำหรับใครก็ตามที่มาจาก macOS หรือ Windows ซึ่งยังไม่พร้อมจะทุ่มสุดตัวกับแบบเรียงกระเบื้อง หรือสำหรับใครก็ตามที่แค่อยากมีพื้นที่ทำงานหนึ่งแห่งที่หน้าต่างสามารถแผ่ขยายได้ ผสมผสานกันได้ตามแต่ละพื้นที่ทำงาน และแถบจะแสดงว่าแต่ละแห่งใช้เลย์เอาต์แบบใด

Omarchy บน Apple Silicon

ทีม Omarchy M ที่น่าทึ่งของเราได้ส่งมอบตัวติดตั้ง Mac แบบเนทีฟแล้ว ดาวน์โหลดแอป บน macOS แล้วมันจะติดตั้ง Omarchy ไว้ควบคู่กันบน MacBook รุ่น M1, M2, M3 หรือ Neo ของคุณ ไม่ต้องใช้แท่ง USB ไม่ต้องใช้คาถาในเทอร์มินัล ชอบ Homebrew มากกว่าไหม ใช้เพียงบรรทัดเดียว:

brew install omacom/mac/omarchy

นี่คือสิ่งที่เราตั้งใจจะทำในเดือนกันยายน: ทำสิ่งที่ Asahi เริ่มต้นไว้ให้เสร็จ สองเดือนต่อมา คุณก็แค่ดาวน์โหลดมันได้เลย เป็นผลงานที่น่าทึ่งของทุกคนในทีม

และพวกเขายังไม่หยุดแค่นี้ M4, M5 และ M6 กำลังอยู่ระหว่างการพัฒนาทั้งหมดในตอนนี้ ดังนั้นอีกไม่นาน Omarchy น่าจะรันได้บน Mac ที่ใช้ Apple Silicon ทุกเครื่อง

การรองรับ ARM สำหรับ NVIDIA DGX Spark + RTX Spark (และเร็ว ๆ นี้สำหรับ Snapdragon)

Omarchy 4.5 มาพร้อม ISO สำหรับ ARM ชุดแรก และพร้อมกันนั้นก็มีการรองรับเบื้องต้นสำหรับเครื่อง ARM ของ NVIDIA: เดสก์ท็อป DGX Spark และแล็ปท็อปที่สร้างบน RTX Spark อย่าง Dell XPS 16 Creator Edition และ ASUS ProArt P14 และเร็ว ๆ นี้เราจะรองรับเครื่อง ARM ตระกูล Snapdragon ทั้งหมดด้วยเช่นกัน ตอนนี้ยังอยู่ในช่วงเริ่มต้น ดังนั้นคาดว่าจะมีจุดที่ยังไม่ราบรื่นอยู่บ้าง และโปรดรายงานสิ่งที่พังบน GitHub

50 ภาษา และวิธีป้อนข้อความ 5 แบบ

ตอนนี้ Omarchy พูดได้ 50 ภาษา เลือกภาษาหนึ่งที่ Setup > Language (หรือเรียกใช้ omarchy language <code>) แล้วเมนู เดสก์ท็อป และการแจ้งเตือนของ Omarchy จะเปลี่ยนทันที โลแคลของระบบจะตามมาเมื่อคุณเข้าสู่ระบบครั้งถัดไป

แต่การพูดภาษาหนึ่งได้เป็นเพียงครึ่งเดียวเท่านั้น คุณต้องพิมพ์ภาษานั้นได้ด้วย ดังนั้นตอนนี้ Omarchy จึงตั้งค่าวิธีป้อนข้อความที่เหมาะสมสำหรับภาษาญี่ปุ่น (Mozc), ภาษาเกาหลี (Hangul), ภาษาจีนตัวย่อ (Pinyin), ไต้หวัน (Zhuyin) และฮ่องกง (Cangjie) ตั้งแต่ในตัวติดตั้งหรือภายหลังที่ Setup > Keyboard แต่ละวิธีมาพร้อมฟอนต์ที่ถูกต้องสำหรับรูปแบบอักขระของมัน หน้าต่างตัวเลือกจะตามธีมของคุณ และ Super + I จะสลับระหว่างภาษาสำหรับป้อนข้อความของคุณ Hangul, Zhuyin และ Cangjie จะคงปุ่มไว้ในตำแหน่งมาตรฐานแม้ว่าคุณจะพิมพ์อักษรละตินบน Dvorak, Colemak หรือ AZERTY เช่นเดียวกับบน Windows และ macOS และการแตะ Shift เพียงอย่างเดียวจะก้าวออกจากวิธีป้อนข้อความไปเป็นอักษรละตินและกลับมาอีกครั้ง แบบเดียวกับที่ Sogou, Microsoft Pinyin และ macOS ทำงาน

เข้าสู่ระบบพอร์ทัล Wi-Fi แบบแคปทีฟ

ในที่สุด Wi-Fi ของโรงแรม สนามบิน และร้านกาแฟก็ใช้งานได้เลย Omarchy จะสังเกตเห็นเมื่อเครือข่ายต้องการให้คุณเข้าสู่ระบบหรือยอมรับข้อกำหนดก่อนอนุญาตให้คุณออนไลน์ ไอคอนเครือข่ายจะเตือนคุณ และแผงเครือข่ายจะแสดงปุ่ม Open Captive Portal ขนาดใหญ่ที่จะพาคุณตรงไปยังหน้าเข้าสู่ระบบ เมื่อคุณผ่านเข้าไปได้ ทุกอย่างจะกลับเป็นปกติเอง

แอปเริ่มต้นใหม่ห้าแอป

Hype สร้างงานนำเสนอจากไฟล์ Markdown ไฟล์เดียว โดยมีตัวแก้ไขสไลด์แบบภาพอยู่ข้างต้นฉบับ และส่งออกเป็น PDF หรือ PowerPoint ได้

Signed มาแทน Xournal++ สำหรับงานเอกสาร: เปิด PDF วางลายเซ็นที่บันทึกไว้ ข้อความ และวันที่ของคุณ แล้วบันทึกสำเนาที่ลงนามแล้ว

Disktree วาดแผนภาพทรีแมปว่าอะไรกำลังเติมเต็มดิสก์ของคุณ โดยใส่สีตามชนิด ชี้ให้เห็นแคชที่สร้างใหม่ได้อย่างปลอดภัย และให้คุณทำเครื่องหมายสิ่งที่ควรลบออก

Monologue บันทึกกล้องของคุณด้วยปุ่มเดียว โดยมีธีมให้เข้ากับเดสก์ท็อปของคุณ

Gliff ให้คุณใช้เดสก์ท็อประยะไกลผ่าน SSH เชื่อมต่อกับเครื่อง Omarchy อีกเครื่องและควบคุมเดสก์ท็อปทั้งหมดของมันจากหน้าต่างบนเครื่องของคุณ โดยมีแท็บสำหรับแต่ละเครื่อง และเพราะมันวิ่งอยู่บน SSH จึงไม่มีอะไรเพิ่มเติมที่ต้องตั้งค่าหรือเปิดเผย เครื่องที่ถูกควบคุมจะแสดงตัวบ่งชี้เซสชันระยะไกลในแถบ ดังนั้นจึงชัดเจนเสมอเมื่อมีใครอยู่บนเครื่องนั้น

และยังมี Elsewhen นาฬิกาโลกที่อยู่ติดกับนาฬิกาในแถบ แตะเมืองบนลูกโลกเพื่อตั้งว่าคุณอยู่ที่ไหน ค้นหาสถานที่จริง และตั้งชื่อผู้คนที่อาศัยอยู่ในแต่ละเมือง เพื่อให้คุณรู้เสมอว่าเป็นเวลาที่เหมาะสมที่จะโทรหาหรือไม่ สลับระหว่าง 12 และ 24 ชั่วโมงด้วย t ระหว่าง °F และ °C ด้วย Alt + T และเรียกมันขึ้นมาได้ทุกเมื่อด้วย Super + Ctrl + Alt + E

ด้วย Monologue สำหรับการบันทึกและ Omacut สำหรับการตัดแต่ง การติดตั้งใหม่จะไม่มาพร้อม OBS Studio และ Kdenlive อีกต่อไป Lazydocker ก็หายไปจากการติดตั้งใหม่เช่นกัน แม้ว่า Docker และ Docker Compose จะยังคงรวมอยู่ เครื่องที่มีตัวใดตัวหนึ่งอยู่แล้วจะยังคงเก็บไว้

Microsoft 365

ต้องทำงานกับผู้คนที่อยู่ใน Office ใช่ไหม ตอนนี้ Install > Service > Microsoft จะตั้งค่า Outlook, Word, Excel, PowerPoint, Teams และ OneDrive เป็นเว็บแอป แต่ละตัวจะมีหน้าต่างและรายการในตัวเปิดใช้ของตัวเอง ดังนั้นจึงรู้สึกเหมือนอยู่บ้านควบคู่ไปกับทุกอย่างอื่น ไม่มีข้อแก้ตัวที่จะไม่เปลี่ยนมาใช้ Omarchy ในที่ทำงานอีกต่อไป!

Superwhisper สำหรับการพูดเพื่อพิมพ์

ตอนนี้ Superwhisper เป็นเครื่องมือพูดเพื่อพิมพ์เริ่มต้นของ Omarchy และตั้งค่าพร้อมใช้ทันที แตะ Alt + Space เพื่อเริ่มพูดและแตะอีกครั้งเพื่อหยุด หรือกด Right Alt ค้างไว้สำหรับ push-to-talk มันรวดเร็วอย่างเหลือเชื่อและแม่นยำมาก

มันเริ่มต้นบนคลาวด์ ดังนั้นจึงใช้งานได้ทันทีที่คุณติดตั้ง และ 10,000 คำแรกฟรี แต่คุณสามารถเปลี่ยนไปใช้โมเดลที่ดาวน์โหลดได้ซึ่งฟรีทั้งหมดและทำงานในเครื่องทั้งหมด โดยไม่ต้องส่งคำใด ๆ ไปให้ใคร และถ้าคุณอยากใช้โมเดลในเครื่องอีกตัว Voxtype ก็ยังมีให้เป็นทางเลือก

ติดตั้งในเวลาไม่ถึงสิบวินาที

เดิม Omarchy เคยติดตั้งแพ็กเกจราว 940 รายการทีละตัว ตัวติดตั้ง F1 ใหม่จะแตกอิมเมจ root ที่สร้างไว้ล่วงหน้าแทน และเพิ่มเฉพาะแพ็กเกจของเครื่องนี้ไว้ด้านบน นั่นลดเวลาในการติดตั้งลงประมาณครึ่งหนึ่งบนเครื่องใด ๆ

และบนฮาร์ดแวร์ที่เร็ว มันไร้สาระมาก Anush Elangovan จาก AMD ทำสถิติโลกด้วยการติดตั้ง Omarchy เต็มรูปแบบใน 7 วินาที บนแล็ปท็อป AMD ของเขา เจ็ดวินาที! ฉันยังจำได้ตอนที่ห้านาทีดูเหมือนเป็นเป้าหมายที่ทะเยอทะยาน

เร็วขึ้นในทุกที่อื่น

ไม่ใช่แค่ตัวติดตั้งเท่านั้น การเริ่มต้นจะไม่สะดุดกับการลงทะเบียน binfmt อีกต่อไป ตัวเลือกธีมเปิดทันทีแทนที่จะหลังจากหนึ่งในสี่วินาที เมนูและแผงเปิดตรงจากปุ่มลัด Hyprland โดยข้าม 60 ms ที่เคยใช้ในการเริ่มกระบวนการก่อน การตรวจสอบที่ช้าที่สุดของเมนู Omarchy ลดจาก 200 ms เหลือ 16 ms เทอร์มินัลใหม่แสดงพรอมต์เร็วขึ้น 30 ms และตอนนี้เดสก์ท็อปทั้งหมดตอบสนองต่อการเปลี่ยนแปลงแทนที่จะคอยสำรวจหามัน แม้แต่การออกจากระบบ การรีบูต และการปิดเครื่องก็เกิดขึ้นทันทีที่แอปของคุณปิดเสร็จ

การอัปเกรดเอเจนต์

Omarchy เป็นระบบปฏิบัติการพร้อมเอเจนต์ และ 4.5 มาพร้อมการอัปเกรดครั้งใหญ่สำหรับการทำงานกับเอเจนต์ ตอนนี้แผงเอเจนต์ติดตามเอเจนต์และผู้ให้บริการ 23 ราย เพิ่มจาก 6 ราย รวมถึง Cursor, OpenCode, GitHub Copilot, Antigravity, Hermes, Amp, Kiro, Devin, Qwen, DeepSeek, OpenRouter และ Ollama ทุกลิมิตจะมีมิเตอร์ของตัวเองพร้อมเวลาจนกว่าจะรีเซ็ต ดังนั้นคุณจึงเห็นได้อย่างชัดเจนว่าคุณเหลือระยะทางอีกเท่าใด และตอนนี้ Grok เป็นผู้ให้บริการเต็มรูปแบบควบคู่ไปกับ Claude และ Codex

และเอเจนต์ของคุณอยู่ห่างเพียงการกดปุ่มเดียวเสมอ Super + ~ จะดึงคอนโซลสไตล์ Quake ลงมาบนเดสก์ท็อปที่หรี่ลง และครั้งแรกที่คุณเปิดมัน มันจะเริ่มเอเจนต์เริ่มต้นของคุณ กดอีกครั้งเพื่อเก็บมันไป และเซสชันของคุณจะอยู่ตรงที่คุณทิ้งไว้

ถ้าคุณสลับไปมาหลายการสมัครสมาชิก ตอนนี้คุณสามารถเก็บการเข้าสู่ระบบ Claude, Codex และ Grok หลายรายการไว้บนเครื่องเดียวกัน และเลือกว่ารายการใดที่เซสชันใหม่จะเริ่มต้นด้วย โดยใช้ omarchy agent account ประวัติ การตั้งค่า และสกิลจะใช้ร่วมกันระหว่างรายการเหล่านั้น ดังนั้น claude --continue จะสานต่อจากจุดที่คุณค้างไว้หลังจากสลับ ใกล้ถึงลิมิต Omarchy สามารถเสนอการสลับในคลิกเดียว หรือย้ายเซสชันใหม่ไปยังบัญชีที่มีพื้นที่เหลือมากที่สุดเอง และเมื่อคุณตั้งค่าเครื่องอีกเครื่อง omarchy agent account copy จะนำการเข้าสู่ระบบทั้งหมดของคุณมาผ่าน SSH ดังนั้นคุณจึงไม่ต้องเข้าสู่ระบบทุกอย่างอีกครั้ง

Kimi และ Ori ซึ่งเป็นฮาร์เนสเอเจนต์ของ OpenRouter เข้าร่วมตัวเลือกที่ Setup > Defaults > Agent และ Antigravity ของ Google มาแทน Gemini CLI ที่ล้าสมัย (gemini ยังทำงานเป็นนามแฝงได้) ชอบหน้าต่างมากกว่าเทอร์มินัลไหม ตอนนี้แอปเดสก์ท็อป Claude และ Amp อยู่ห่างเพียงคลิกเดียวที่ Install > AI

เมนูบูตเงียบลงแล้ว

เดิม Omarchy เคยแสดงเมนูบูตประมาณหกวินาทีทุกครั้งที่เริ่ม เผื่อในกรณีที่คุณต้องย้อนกลับไปยังสแนปชอตก่อนหน้า แต่แทบจะไม่มีใครเคยทำเลย ดังนั้นตอนนี้ Limine จะรอเพียงหนึ่งวินาทีและบูตอย่างเงียบ ๆ และส่วนใหญ่คุณจะไม่เห็นเมนูเลย

เมื่อคุณต้องการรายการอื่นหรือสแนปชอตจริง ๆ ให้แตะปุ่มใด ๆ ต่อไป (ปุ่มลูกศรลงก็ใช้ได้) ขณะที่เครื่องกำลังเริ่ม แล้วมันจะหยุดที่เมนู และถ้าคุณอยากให้เมนูอยู่ต่อไปนาน ๆ ให้ตั้ง timeout: ของคุณเองใน /boot/limine.conf (เช่น timeout: 5) การอัปเดตจะปล่อยค่า timeout ที่คุณตั้งไว้ตามเดิม

ปุ่มลัดที่เปลี่ยนแปลง

ปุ่มลัดบางรายการย้ายที่:

  • เครื่องคิดเลข: ตอนนี้ Super + Ctrl + Q เป็น Super + Shift + Q
  • กิจกรรม: ตอนนี้ Super + Ctrl + T เป็น Super + Shift + T และ Super + Ctrl + T เปิดธีม
  • เครือข่าย: ตอนนี้ Super + Ctrl + W เป็น Super + Ctrl + N และ Super + Ctrl + W เปิดพื้นหลัง
  • Nightlight ไม่มีปุ่มลัดอีกต่อไป (เดิมคือ Super + Ctrl + N); มันอยู่ใน Trigger > Toggle
  • Super + Alt + Space เปิด Apps จากด็อกแทนเมนู Apps

ปุ่มลัดการแจ้งเตือนเปลี่ยนแปลง:

  • Super + Comma ดำเนินการกับการ์ดใหม่ล่าสุด (ปิดมัน เปิดมัน หรือกดปุ่มเดียวของมัน) แทนที่จะปิดมันเท่านั้น
  • การปิดการ์ดสุดท้ายย้ายไปเป็น Super + Alt + Comma ซึ่งเดิมใช้เปิดมัน
  • การปิดเสียงย้ายจาก Super + Ctrl + Comma ไปเป็น Super + Ctrl + Alt + Comma; ตอนนี้ Super + Ctrl + Comma จะส่งการควบคุมด้วยคีย์บอร์ดให้คุณ

ปุ่มบางปุ่มทำงานต่างออกไป:

  • Super + Tab, Super + Shift + Tab, Super + Ctrl + Tab และ Super + การเลื่อนจะอยู่บนพื้นที่ทำงานของจอปัจจุบัน เพราะทุกจอมีพื้นที่ทำงานของตัวเอง
  • ในเทอร์มินัล Super + C และ Super + V จะส่ง Ctrl + Shift + C และ Ctrl + Shift + V แทน Ctrl + Insert และ Shift + Insert

ค่าเริ่มต้นใหม่ที่อาจชนกับการผูกปุ่มของคุณเอง: Super + Q (ปิดหน้าต่าง ควบคู่กับ Super + W), Super + A (เลือกทั้งหมด), Super + M (ย่อลงด็อก), Super + ~ และ Super + Shift + ~ (คอนโซล Quake), Super + Alt + L (เลย์เอาต์ก่อนหน้า), Super + Shift + Ctrl + Arrows (ย้ายหน้าต่างไปอีกจอหนึ่ง), Super + Ctrl + Alt + C (ภาพหน้าจอ), Super + Ctrl + Alt + E (นาฬิกาโลก), Super + Ctrl + Alt + F (เดสก์ท็อปเต็มจอ) และการกด Right Alt ค้างไว้สำหรับการพูดเพื่อพิมพ์แบบ push-to-talk
