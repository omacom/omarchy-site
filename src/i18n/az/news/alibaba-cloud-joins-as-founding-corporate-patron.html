Alibaba Cloud üç il ərzində ildə $1 milyon töhfə verərək Omacom Foundation-a Təsisçi korporativ himayədar kimi qoşulur! Bu, Omarchy-nin inkişafına, dəstəklənməsinə və yayılmasına DigitalOcean-ın dəstəyi ilə eyni həcmdə, $3 milyonluq öhdəlikdir.

Amma bu tərəfdaşlıq puldan çox genişdir. Alibaba Cloud bizə Omarchy China-nı qurmağa kömək edəcək: Çin istifadəçilərinin Omarchy-ni əziyyətsiz mənimsəməsi üçün lazım olan yerli CDN, hostinq, sayt, görüşlər və icma. Linux endirmək, paket quraşdırmaq və kompüterinizi güncəl saxlamaq harada yaşamağınızdan asılı olmayaraq sadə olmalıdır. Bunun Çində də belə olması üzərində birlikdə işləyəcəyik.

Vaxt da bundan yaxşı ola bilməzdi. Qwen Book-un elanı ilə Alibaba agentli kompüterə dair iddiasını avadanlığa çevirir. Omarchy-ni həmin kompüter üçün ideal agentli əməliyyat sisteminə çevirmək üzərində birlikdə çalışacağıq. İnsanların və agentlərin birlikdə işləyə biləcəyi, sahibinin isə idarəni əlində saxladığı gözəl, əyləncəli Linux masaüstü.

Alibaba Cloud yaxınlaşan Qwen Book-u belə təsvir edir:

Qwen Book doğma süni intellekt agenti kompüteri yaratmağı hədəfləyir. Onun əsas fəlsəfəsi olan “OS as Harness”, sadə dillə, modellərin, əməliyyat sisteminin, tətbiqlərin, bulud xidmətlərinin və avadanlığın dərindən inteqrasiyasını nəzərdə tutur. Bu, agentlərin anlaya, çağıra, yadda saxlaya və davamlı işləyə biləcəyi hesablama mühiti qurur və kompüteri passiv alətdən daim inkişaf edən şəxsi köməkçiyə yüksəldir.

Qwen Book sistemi həm ARM, həm də x86 arxitekturaları ilə uyğundur; ilk buraxılış ARM arxitekturası əsasındadır. Sistem səviyyəsində az enerji sərf edən Agent Engine və Continuous Context Engine qurmuşuq. İntellektual təməl kimi Qwen model ailəsi ilə, bulud-cihaz inteqrasiyası vasitəsilə Qwen Book sistemi üçün model xidmətləri təqdim edirik. Gələcəkdə Omarchy OS ilə birlikdə daha çox yenilik kəşf etməyi səbirsizliklə gözləyirik.

Bu o deməkdir ki, Omarchy qutudan çıxan kimi Qwen modelləri üçün köklənəcək və insanların asılı olduğu Çin xidmətləri ilə tam inteqrasiyaya doğru işləyəcəyik. Modellər, əməliyyat sistemi və xidmətlər maşını işə saldığınız andan birlikdə işləməlidir. Kompüterinizi agentlə işləməyə hazırlamaq özü-özlüyündə bir layihə olmamalıdır.

Fondun mümkün etməsini istədiyim əməkdaşlıq məhz budur. Model quranlar, kompüter quranlar və əməliyyat sistemi quranlar bütöv təcrübəni yaxşılaşdırmaq üçün birlikdə çalışır. Fərdi kompüterin nəyə çevrilə biləcəyinə dair ortaq iddiamız var və indi onun arxasına resurs qoyuruq.

Alibaba Cloud Təsisçi korporativ himayədar kimi DigitalOcean və Meta Superintelligence Labs-a qoşulur. Onların öhdəliyi ümumi dəstəyimizi təxminən $21.7 milyona çatdırır. Bu isə Omarchy-ni mümkün edən insanlara, infrastruktura və açıq mənbəli layihələrə daha çox investisiya imkanı deməkdir.

Alibaba Cloud-dakı hər kəsə, xüsusilə bunu mümkün edən CTO LI feifei-yə təşəkkür edirik. Dəstəyiniz bizə daha böyük düşünməyə və Linux-u hamı üçün yaxşılaşdırmaq işinə daha çox insan cəlb etməyə imkan verir.

Gəlin agentli kompüter üçün ideal agentli əməliyyat sistemini quraq. Çində və hər yerdə!
