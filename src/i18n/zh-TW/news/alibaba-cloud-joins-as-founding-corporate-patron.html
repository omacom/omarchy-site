Alibaba Cloud 正在加入 Omacom Foundation，成為創始企業贊助者，捐助連續三年、每年 100 萬美元！這是一筆 300 萬美元的承諾，與 DigitalOcean 的贊助相當，將用於 Omarchy 的開發、維護與推廣。

但這次合作的意義遠遠超出資金本身。Alibaba Cloud 將協助我們打造Omarchy China：包括在地 CDN、主機代管、網站、聚會與社群，讓中國的使用者能毫無負擔地採用 Omarchy。無論你住在哪裡，下載 Linux、安裝套件、讓電腦保持更新，都應該是簡單直接的事。我們要一起努力，讓這件事在中國也能實現。

而且時機再好不過。隨著Qwen Book 的發表，Alibaba 正在把對代理式電腦的雄心落實為硬體。我們將攜手合作，讓 Omarchy 成為那台電腦上最理想的代理式作業系統。一個漂亮又有趣的 Linux 桌面，讓人類與代理能一起工作，而擁有者依然掌握主導權。

以下是 Alibaba Cloud 對即將推出的 Qwen Book 的描述：

Qwen Book 的目標是打造一台原生 AI 代理電腦。其核心理念「OS as Harness」，簡單來說，就是深度整合模型、作業系統、應用程式、雲端服務與硬體。這將打造出一個代理能夠理解、呼叫、記住並持續運行的運算環境，把電腦從被動的工具，升級為不斷進化的個人助理。

Qwen Book 系統同時相容於 ARM 與 x86 架構，首發版本將以 ARM 架構為基礎。在系統層級，我們打造了低功耗的 Agent Engine 與 Continuous Context Engine。以 Qwen 模型家族作為智慧基礎，我們透過雲端與裝置整合，為 Qwen Book 系統提供模型服務。我們期待未來與 Omarchy OS 一起探索更多創新。

這代表 Omarchy 將開箱即為 Qwen 模型做好最佳化調校，並致力於與人們日常依賴的中國服務完整整合。模型、作業系統與服務，應該從你啟動機器的那一刻起就協同運作。讓你的電腦準備好與代理一起工作，本身不該成為一項工程。

這正是我希望基金會能促成的那種合作。打造模型的人、打造電腦的人，與打造作業系統的人攜手合作，讓整體體驗變得更好。我們對個人電腦的未來有著共同的願景，現在更要投入資源去實現它。

Alibaba Cloud 與 DigitalOcean 及 Meta Superintelligence Labs 一同成為創始企業贊助者。他們的承諾讓我們的總贊助金額來到約 2,170 萬美元。這讓我們有更多空間，去投資那些成就 Omarchy 的人才、基礎設施與開源專案。

感謝 Alibaba Cloud 的每一位成員，特別是讓這一切成真的 CTO LI feifei。你們的支持讓我們能想得更大，並投入更多人力，讓 Linux 對每個人都更好。
