阿里雲以創始企業贊助人身分加入 Omacom Foundation，連續三年、每年捐助 100 萬美元！這是 300 萬美元的承諾，和 DigitalOcean 的支持規模相同，將投入 Omarchy 的開發、維護與推廣。

但這次合作不只是錢。阿里雲會幫我們打造 Omarchy China：中國使用者順利採用 Omarchy 所需要的在地 CDN、主機代管、網站、聚會和社群。不管你住在哪裡，下載 Linux、安裝套件、讓電腦保持最新都應該簡單直接。我們會一起讓這件事在中國也做得到。

時機也再好不過。隨著 Qwen Book 發表，阿里巴巴正把對 Agent 電腦的企圖心落實到硬體上。我們會合作讓 Omarchy 成為這台電腦上理想的 Agent 作業系統：一個美觀、有趣的 Linux 桌面，人和 Agent 可以在上面一起工作，而掌控權始終在電腦主人手上。

以下是阿里雲對即將推出的 Qwen Book 的介紹：

Qwen Book 的目標是打造原生 AI Agent 電腦。它的核心理念「OS as Harness」，簡單說就是把模型、作業系統、應用程式、雲端服務和硬體深度整合，建構一個 Agent 能夠理解、呼叫、記住並持續執行的運算環境，讓電腦從被動的工具，升級為不斷進化的個人助理。

Qwen Book 系統相容 ARM 和 x86 兩種架構，首發版本採用 ARM 架構。在系統層面，我們打造了低功耗的 Agent Engine 和 Continuous Context Engine。以 Qwen 模型家族為智慧基礎，透過雲端與裝置的整合為 Qwen Book 系統提供模型服務。期待未來與 Omarchy OS 一起探索更多創新。

這代表要讓 Omarchy 開箱就為 Qwen 模型調校好，並朝著完整整合人們日常依賴的中國在地服務努力。模型、作業系統和服務應該從你開機那一刻起就協同運作。讓電腦準備好跟 Agent 一起工作，本來就不該是一項工程。

這正是我希望基金會促成的合作。做模型的人、做電腦的人、做作業系統的人一起合作，把整體體驗做得更好。我們對個人電腦能變成什麼樣子有共同的企圖心，現在我們要投入實際的資源。

阿里雲與 DigitalOcean、Meta Superintelligence Labs 一同成為創始企業贊助人。這筆承諾讓我們的總支持金額達到約 2,170 萬美元，讓我們有更多空間投資在成就 Omarchy 的人、基礎設施和開源專案上。

感謝阿里雲的每一位同仁，特別是促成這件事的 CTO 李飛飛。有你們的支持，我們才敢想得更大，投入更多人力讓 Linux 對每個人都更好。
