Omacom Foundation 迎來了首位全職員工！Krzysztof Wilczyński 將加入並領導 Omarchy Kernel 的工作。這正是成立基金會的目的：付錢讓優秀的人解決難題，讓所有人受益。

Krzysztof 是資深 Linux 核心開發者，共同維護 PCI Endpoint 子系統、原生 PCI 主橋及端點驅動。這些底層設施將 Linux 連線到 GPU、NVMe 硬碟和 WiFi 網路卡。他也是核心新 Rust PCI 工作的審查者。在深入核心之前，他曾多年從事系統工程，研究 Kubernetes 和容器執行時。

現在，他將把這些經驗帶到 Omarchy Kernel。重點是效能、相容性與安全。我們希望 Linux 在全新筆記本和老舊 ThinkPad 上都飛快執行，在更多電腦上開箱即用，並獲得嚴密保護。

Krzysztof 也將加入 Omarchy Core，參與確定整個發行版的方向。

歡迎加入，Krzysztof！讓核心跑出轟鳴聲吧。
