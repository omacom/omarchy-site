Omacom Foundation第一位全職員工報到！Krzysztof Wilczyński 加入，領軍 Omarchy 核心工作。這正是基金會成立的目的：付錢請厲害的人解難題，造福所有人。

Krzysztof 是資深 Linux 核心開發者，共同維護 PCI Endpoint 子系統，以及原生 PCI host bridge 與 endpoint 驅動。那是連接 Linux 與你的 GPU、NVMe 硬碟、WiFi 網卡的水管。他也是核心新的 Rust PCI 工作的審查者。深耕核心之前，他在系統工程打滾多年，做 Kubernetes 與容器執行環境。

現在他把全部經驗帶來 Omarchy 核心。重點：效能、相容、安全。我們要 Linux 在全新筆電和老 ThinkPad 上都飛起來，開箱支援更多機器，還要鎖得緊緊的。

Krzysztof 也加入Omarchy Core，為整個發行版定方向。

歡迎上船，Krzysztof！讓核心尖叫吧。
