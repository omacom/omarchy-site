Omarchy 不僅對使用者而言是美觀、有趣、擁有 Agent 的 Linux 發行版，它也是這樣打造出來的！靠美感、樂趣，還有大量 token。實際上，Omarchy Quattro 幾乎全部由 Agent 開發，因為它們特別擅長 bash、QML 和 Linux 疑難排解。

如今吸引了數十萬使用者與共同創作者，要繼續改進 Omarchy，就必須讓 token 源源不斷。這才能加快處理、完善並交付湧來的精彩貢獻。發布僅幾週，就已經積壓了超過 1,600 個 PR！沒有 Agent 幫忙，誰也處理不完。

因此，我很高興宣佈，我們已從大多數主要實驗室獲得海量 token，支持這項使命！首先是 Meta Superintelligence Labs，以 150 萬美元 token 成為創始 token 贊助人！全新的 Meta Muse Spark 模型以出色價格交出亮眼成績，150 萬美元基本等於無限 token！不過我們還是會努力用完！

我們也很高興迎來另兩家前沿實驗室 Anthropic 和 OpenAI，各捐贈 15 萬美元 token，成為傑出 token 贊助人。配合安全研究與修復所需的安全限制解除授權，這些 token 將尤其有用。

開放權重模型方面，我同樣高興地宣佈，Fireworks 也以 15 萬美元 token 成為傑出 token 贊助人。我常用 Kimi K 系列，尤其是高速模式。我們也會好好利用這些飛快的 token！

合計又為 Omacom Foundation 帶來 195 萬美元承諾，使總承諾額達到 1,495 萬美元。一個起初被批評者稱為「dotfiles 堆砌」的發行版，竟能寫出這樣的數字，實在瘋狂。當然，當時也不算完全說錯，只是我們後來一直在修好一切！

有了這些 token，我們能修好一切。而我們正準備這麼做！
