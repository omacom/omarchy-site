有兩位在將 Omarchy 推向 x86 之外付出最多的人，正在加入 Omarchy Core：Marcelo Alcantara 和 Birk Skyum！

Marcelo Alcantara

當我們在九月介紹 Omarchy M 時，Marcelo 就是那個在打造原生 Mac 安裝程式的人。從那時起，他就成了協調整個計畫的人。來自世界各地的十五個人，每個人負責堆疊中不同的一層，從 GPU 驅動程式和顯示器，到 Touch ID 和安裝程式本身。總得有人讓所有這些工作朝同一個方向前進，而 Marcelo 就是那個人。

成果已隨 Omarchy 4.5 一起推出。你現在可以在 macOS 上下載一個應用程式（或是執行 brew install omacom/mac/omarchy），它就會把 Omarchy 直接安裝在你的 M1、M2、M3 或 Neo MacBook 上，與 macOS 並存。不需要 USB 隨身碟，也不需要在終端機念咒語。從團隊公布到「直接下載就行」，只花了兩個月，速度快得驚人。

這要大大歸功於 Omarchy M 的每一位成員：Naeem、Scott、Eduardo、Shun、Dj、Ryan、Miguel、Liam、Eryk、Jaidip、Joshua、Shawn、Randy、Jon 和 Marcelo。你們完成了 Asahi 展開的工作，而且已經繼續朝 M4、M5 和 M6 推進。謝謝你們！

Birk Skyum

Birk 在九月加入 Omarchy Dragon，當時帶著他的 Lenovo Yoga Slim 7x，以及在 Arch Linux ARM、libcamera、PipeWire、systemd 和 kernel 上提交上游修復的紀錄。從那時起，他接下了協調整個 Snapdragon 產品線導入工作的重任。那意味著要收集各種機型、弄清楚每台機器上哪些功能可用、哪些不行，並確保修復成果能落在對所有人都有幫助的位置。

在 4.5 的 ARM 工作中，已經到處都能看到他的身影：更新後不再出現沒意義的重新開機提示、Snapdragon 筆電上的相機在登入時就能出現，以及根據在 ARM 上實際能執行的情況來提供（或隱藏）應用程式。但這只是開始。Birk 正努力推動即將到來的版本，讓我們支援的每一台 Snapdragon 機器都能直接運作。睡眠、電池、影片、相機，全部都要。那就是標準，而他正是確保我們達到標準的人。

歡迎！

Omarchy 將在每個主要平台上都美妙地運行，而 Core 需要那些讓這件事成真的人。Marcelo 和 Birk 一直以來做的正是這件事。現在，這正式生效了。

歡迎加入 Omarchy Core，Marcelo 和 Birk！
