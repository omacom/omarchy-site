有兩位對將 Omarchy 推向 x86 之外貢獻最大的人，正在加入 Omarchy Core：Marcelo Alcantara 和 Birk Skyum！

Marcelo Alcantara

當我們在九月介紹 Omarchy M 時，Marcelo 就是負責打造原生 Mac 安裝程式的那個人。從那時起，他已經成為協調整個專案的人。來自世界各地的十六個人，每個人負責堆疊的不同層面，從 GPU 驅動程式和顯示器到 Touch ID 和安裝程式本身。總得有人讓所有這些工作朝著同一個方向前進，而 Marcelo 一直就是那個人。

成果隨著 Omarchy 4.5 一起推出。你現在可以在 macOS 上下載一個應用程式（或是執行 brew install omacom/mac/omarchy），它就會把 Omarchy 直接安裝在你的 M1、M2、M3 或 Neo MacBook 上，與現有系統並存。不需要 USB 隨身碟，也不用唸什麼終端機咒語。從團隊宣布到「直接下載就能用」只花了兩個月，這個速度實在驚人。

這是 Omarchy M 全體成員的巨大功勞：Scott、Chris、Naeem、Dj、Joshua、Eduardo、Shun、Ryan、Miguel、Liam、Eryk、Jaidip、Shawn、Randy、Jon 和 Marcelo。你們完成了 Asahi 開始的工作，而且已經在繼續推進到 M4、M5 和 M6。謝謝你們！

Birk Skyum

Birk 在九月加入了 Omarchy Dragon，帶著他的 Lenovo Yoga Slim 7x，以及在 Arch Linux ARM、libcamera、PipeWire、systemd 和核心中提交上游修復的豐富紀錄。從那時起，他開始負責協調整個 Snapdragon 產品線的導入工作。這代表要收集這些機器、弄清楚每台機器上哪些功能可以運作、哪些不行，並確保這些修復能落在對所有人都有幫助的地方。

你已經可以在 4.5 的 ARM 工作中到處看到他的身影：不再於每次更新後都出現毫無意義的重新開機提示、Snapdragon 筆記型電腦上的相機在登入時就能出現，以及根據 ARM 上實際能運行的情況來提供（或隱藏）應用程式。但這只是開始。Birk 正在努力推動一個即將到來的版本，讓我們支援的每一台 Snapdragon 機器都能直接正常運作。睡眠、電池、影片、相機，全部都是。這就是標準，而他就是確保我們能達到這個標準的人。

歡迎！

Omarchy 將在每個主要平台上都運行得非常出色，而 Core 需要那些正在讓這件事發生的人。Marcelo 和 Birk 一直在做的正是這件事。現在這件事正式確定了。

歡迎加入 Omarchy Core，Marcelo 和 Birk！
