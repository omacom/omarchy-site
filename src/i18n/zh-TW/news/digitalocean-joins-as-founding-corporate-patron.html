DigitalOcean 以創始企業贊助人的身分加入 Omacom Foundation，連續三年、每年捐助 100 萬美元！也就是為 Omarchy 的開發、維護與推廣承諾 300 萬美元。對我們正在做的這套美觀、有趣、擁有 Agent 的作業系統，這是一張分量十足的信任票。

DigitalOcean Droplets 我用了十幾年。要把一台 Linux 機器放上網路然後專心做東西，它是好用到不行的做法。contributors.rubyonrails.org 就跑在上面，那個站是用來紀念幾千位把 Rails 變成今天這樣的人。這是我靠了很多年的基礎設施，所以背後那家公司願意加入，感覺格外好。

而且對一套有 Agent 的作業系統來說，他們是再合適不過的贊助人。DigitalOcean 已經提供 Hermes 和 OpenClaw 的一鍵 Droplet。你可以在家裡的 Omarchy 桌面上放一個 Agent，另一個在 Droplet 上全天不停地做事。

不過這次贊助真正讓我笑出來的，是它成形的速度。我星期三在 X 上找 DigitalOcean 執行長 Paddy Srinivasan，當天晚上就通了電話，星期六送出提案，星期天全部談定。

這就是有 Agent、有無窮野心，再加上在 X 上談事情之後，合作可以跑出來的速度！雙方看到同一個機會、都想把它做成，就沒有理由花好幾個月才點頭。我們可以照眼前那些可能性的節奏前進。

DigitalOcean 與 Meta Superintelligence Labs 同列創始企業贊助人，也和所有已經站出來資助這項使命的個人與公司並肩。這筆認捐讓我們的支持總額來到約 1,850 萬美元。要投資那些讓 Omarchy 對每個人都更好的人、專案和基礎設施，空間又更大了。

比如多請一些厲害的人！我們剛請到領導 Omarchy Kernel 的 Krzysztof Wilczyński，以及 Quickshell 的作者 outfoxxed，出任 Omarchy Shell 負責人。要讓這種人有機會全職去把 Omarchy 做得更快、更可靠、更能幹，得有 DigitalOcean 這樣的贊助人才辦得到。他們的支持把我們的野心，變成真的付得出薪水的工作，交到做得到的人手上。

謝謝 Paddy，也謝謝 DigitalOcean 的每一位。我們把這份支持化為行動，讓那個美觀、有趣、擁有 Agent 的 Linux 未來真的發生！
