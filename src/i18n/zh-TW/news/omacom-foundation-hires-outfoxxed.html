我們請到 outfoxxed 了——Quickshell 的作者——出任 Omarchy Shell 負責人！他全職加入 Omacom Foundation，同時成為 Omarchy Core 的一員。做出那套讓 Quattro 得以成真的工具箱的人上船了，接下來我們要把整件事送上月球。

這也取代了我們八月宣布的三年期 Quickshell 贊助。不走贊助那條路，outfoxxed 會是 Omacom Foundation 的全職員工，領導 Omarchy Shell 的工作。我們把作者本人放進我們正在做的東西的正中央。

Shell 對我們在做的 Agent 作業系統是關鍵。它就是狀態列、選單、通知、小工具，還有那些讓電腦感覺像是你的的小互動。Quickshell 給我們用 QML 塑造那套體驗的積木。再配上寫 QML 特別強的 Agent，改造你的桌面忽然變成一件你可以開口要、動手試、然後分享出去的事。

證據就在外掛上！我們宣布贊助的時候，社群在 Quattro 的第一週就已經做了超過一千款。現在目錄裡快要三千款外掛了。可以直接從狀態列玩的遊戲、盯著你的程式設計 Agent 的面板、音樂播放器，甚至還有一隻在你狀態列上晃來晃去、等人摸的貓。大家正把一套本來感覺動不了的系統，變成自己的。這就是可塑電腦活起來的樣子。

Quickshell 的作者在船上，我們就能一起動整個堆疊。讓 shell 更快、更可靠。讓做出好外掛這件事更容易。外掛作者撞到限制時，就去改底層。把幾千次實驗學到的東西，變成每個開機進 Omarchy 的人都感受得到的體驗。並且確保整套東西安全無虞。

加入 Omarchy Core 之後，outfoxxed 也會參與決定整個發行版的方向。Shell 在體驗裡太核心了，不能當成事後才補的東西。Agent 作業系統的美感、樂趣和各種可能，很多都是在這一層才變成你真的看得到、用得到的東西。

outfoxxed 是 Omacom Foundation 第二位全職員工，前一位是領導 Omarchy Kernel 的 Krzysztof Wilczyński。Kernel 和 Shell 的負責人都到齊了，我們是在投資整個體驗的地基。基金會的成員可以在專職團隊頁看到。

我們會繼續用邀請的方式找人，從社群裡的實際作品去認識合適的人。（拜託不要用履歷淹沒我的信箱！）

這就是基金會的支持能做到的事：讓傑出的開源開發者有時間全力投入。謝謝每一位資助這件事的人，我們正把更多野心變成真正的全職工作。

歡迎上船，outfoxxed！我們把這台電腦變得更能捏。
