我們要聘請outfoxxed，Quickshell 的創造者，擔任 Omarchy Shell 主管！他全職加入Omacom Foundation，並成為Omarchy Core 成員。打造出讓 Quattro 成為可能的工具包的人，上船帶我們把整件事射向月球。

這取代了八月宣布的三年 Quickshell 贊助。outfoxxed 不拿贊助，直接成為 Omacom Foundation 全職員工，領軍 Omarchy Shell。創造者本人坐鎮正中央。

Shell 是我們打造的代理式 OS 的樞紐：狀態列、選單、通知、小工具，以及讓電腦像你的那些小互動。Quickshell 給我們建材，用 QML 形塑體驗。加上超會寫 QML 的代理，改桌面變成開口要、試試看、分享出去的事。

證據在外掛裡！宣布贊助時，社群在 Quattro 第一週就生出一千多個外掛。現在目錄裡快三千個了：狀態列上能玩的遊戲、追蹤 coding agent 的面板、音樂播放器，甚至有隻貓在狀態列上晃等你摸。大家把以前硬邦邦的系統捏成自己的。可塑電腦活過來了。

Quickshell 創造者上船，我們能整棧一起打：讓 shell 更快更可靠，讓好外掛更好寫，外掛作者撞牆就改善根基，把數千次實驗的學到變成每個開機 Omarchy 的人的更好體驗。還要全程安全。

加入 Omarchy Core，outfoxxed 也為整個發行版定方向。Shell 太靠近體驗核心，不該是事後才想。代理式 OS 的美、趣與可能，多半在這裡變成看得到、用得到的東西。

outfoxxed 是 Omacom Foundation 第二位全職員工，前一位是Omarchy 核心主管 Krzysztof Wilczyński。核心與 Shell 主帥都到齊，我們在為整個體驗的地基投資。網站上有基金會員工介紹。

我們會繼續以邀請制聘人，在社群作品中找對的人。（拜託別拿 CV 灌爆我信箱！）

這就是基金會後援能做的事：給傑出的開源開發者全心投入的時間。謝謝資助這份工作的每個人，我們把更多野心變成全職工作。

歡迎上船，outfoxxed！讓這台電腦更可塑吧。
