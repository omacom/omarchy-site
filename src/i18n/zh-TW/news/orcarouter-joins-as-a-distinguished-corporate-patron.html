很高興歡迎 OrcaRouter 以傑出企業贊助人身分加入 Omacom Foundation！他們捐出價值 150,000 美元的 token 到我們的戰略 token 儲備（現在很大了，非常智慧）。

這些 token 主要會在 OrcaRouter 上用於他們針對資安調校的模型，特別是用來協助我們的資安和核心團隊。第一個上場的是 OrcaCyber Zero 1.0，一個針對漏洞分析、重現和資安研究做過後訓練的程式碼模型。

根據 OrcaRouter 的數據，Zero 1.0 在 CyberGym Level 1 中第一次嘗試就重現了 1,507 個真實漏洞中的 1,478 個，這個基準測試取材自 188 個開源專案，通過率 98.07%。我們很期待看它在我們團隊手上的資安和核心問題上表現如何。

以下是 OrcaRouter 團隊對自家工作的介紹：

OrcaRouter 是資安優先的 AI 閘道器，也是 AI Agent 的執行層。它透過自適應路由為每種工作負載挑選合適的模型，同時提供防護機制、針對工具／MCP 呼叫與對外流量的 Agent 防火牆、ZDR／隱私控制，以及涵蓋雲端與本機 Agent 執行的端到端可觀測性。

OrcaRouter 也是開放權重資安模型的主要發布者，過去 30 天在 Hugging Face 上的下載量超過 150 萬次。旗艦資安模型 OrcaCyber Zero 1.0 目前處於封閉測試階段，提供給可信任的資安研究、漏洞分析與重現，以及紅隊工作流程使用。
