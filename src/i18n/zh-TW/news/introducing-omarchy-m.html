Apple 的硬體一直都很出色（蝶式鍵盤那次除外）。來到 Omarchy 的人，很多是從 Mac 過來的。其中不少人想留下這台機器，換掉作業系統。所以我們要完成 Asahi 開始的事：讓 Omarchy 在 Apple Silicon 上跑得漂亮，安裝設定越省事越好。

這項工作背後已經有一支團隊。今天我們正式宣布：Omarchy M，負責 Apple Silicon Mac 的團隊（另外還有幾位成員負責讓舊款 Mac 也不被落下）。

來介紹一下成員。

安裝程式。Marcelo Alcantara 正在打造原生 Mac 安裝程式。你在 macOS 上下載一個 App，它會抓取簽署過的 Omarchy 版本、切好分割區，讓你保留原本的 macOS，同時可以開機進 Omarchy。不需要隨身碟，也不用在終端機裡念咒語。透過 USB-C 點亮外接螢幕的那個版本，也是他搞定的。

Omarchy Mac。Naeem Malik 維護 Omarchy Mac 已經一年，早在這一切正式化之前，就已經把 Omarchy 裝上 M1 和 M2 機型，還圍繞它建立了一個 800 多人的 Discord 社群。Scott Jones 是這個專案負責 Linux 安裝的另一半。他最近讓 M3 Air 的螢幕透過 Apple 的硬體顯示控制器跑起來，一夜之間把這台機器從不能用變成能用。

Try Omarchy。Eduardo Martinez 做了 Try Omarchy：把真正的 Omarchy 桌面當成原生、硬體加速的 App 在你的 Mac 上執行，攝影機、音訊、剪貼簿和共用資料夾都接通了。不用切分割區，下載下來就能看看大家到底在熱衷什麼。

套件。Shun Li 正在確保 Omarchy 需要的一切都有 aarch64 套件，另外還有給虛擬機器用的通用 ARM64 磁碟映像檔，以及讓虛擬機器好用的客體工具。

驅動程式與核心。Ryan Murray 正在點亮 Neo，並打造整個團隊賴以工作的基礎。他在開發一個 SPTM 模擬器，讓我們能在 M4 以後的晶片上追蹤 macOS。這些追蹤資料是搞定螢幕、GPU、音訊、無線網路和藍牙的關鍵。Dj 在寫 GPU 驅動程式，並透過直接和 Secure Enclave 溝通，讓 Touch ID 可以用了。Miguel Cruz 專攻 M5：他逆向了 Apple 自家的 N1 晶片，讓它的 Wi-Fi 和藍牙在 Linux 上跑起來，也為 Neo 貢獻了硬體影片編解碼、藍牙和桌面改進。Liam 正在點亮 Neo 的觸控板、電源管理、喇叭和耳機輸出，Ryan 的 macOS 追蹤資料是這些工作的重要基礎。Eryk Wieliczko 維護 M4 支援和 clean-room 實作，也負責整合與打包。Jaidip Subedi 在 M2 MacBook Air 上做出了透過 USB-C 的外接螢幕。

MLX。Joshua Warren 正在打造 mlx-omarchy，透過 Vulkan 把 Apple 的 MLX 機器學習框架帶到 Apple GPU 上的 Linux。你的程式碼一樣是 import mlx.core as mx，但現在可以在 Omarchy 上跑了。

舊款 Mac。Shawn Yeager 已經為 2016 和 2017 年的 Touch Bar MacBook Pro 送出一疊 pull request：喇叭、Wi-Fi、環境光感測器，還有 Touch Bar 本身。Randy 正在逆向 T2 安全晶片，想讓 Intel Mac 也能用 Touch ID，一路上還把 2019 年 MacBook Pro 的每個修正都記錄下來。Jon Kinney 一年前就開始默默替 Omarchy 做 ARM 支援，現在負責協調整個團隊的分工。

加起來，這是一支很強的隊伍。十五個人，沒有等誰批准，還靠著 Agent 用一年前看來很荒謬的速度往前推。

第一個版本的目標是完整支援 M1 和 M2，包括 Pro 和 Max：

  • 無縫的安裝程式，可以選擇安裝或試用
  • 完整的 GPU 支援
  • 透過 USB-C 的外接螢幕
  • Touch ID
  • MLX
  • 磁碟加密

較新的機型也在同步進行，但我們會先在 M1 和 M2 插旗。除了 M 系列機型，外面還有數百萬台舊款筆電，很多已經被 Apple 最新 macOS 的企圖心淘汰，而每一台都是等著變身的出色 Omarchy 電腦。

不用等到正式版推出才開始用。Try Omarchy 幾分鐘內就能讓你在 Mac 上看到真正的桌面。如果你已經準備好認真用，安裝程式今天就能把 Omarchy 裝進你的 M1 或 M2，和 macOS 並存。

最後，有個請求。如果你一直在做 Apple 硬體上的 Linux，不管是核心驅動程式、韌體、打包、安裝程式還是機器學習，歡迎和我們聯絡。你很可能已經解決了我們還在處理的問題，反過來也一樣。來信請寄 apple@omarchy.org。

一起完成 Asahi 開始的事吧。
