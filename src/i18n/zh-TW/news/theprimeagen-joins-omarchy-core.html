ThePrimeagen 加入 Omarchy Core，負責領導 Agentic QA！這位讓 Vim、終端機和 Linux 看起來像是用電腦最好玩的一件事的人，現在要負責確保每個 Omarchy 版本都經過一群 Agent 從頭到尾檢查過。

對我來說，這真是繞了一整圈。我用了二十年 TextMate，是 Prime 讓我改用 Neovim。他以鍵盤為核心的 Linux 設定，也給整個 Omarchy 帶來很大的啟發。他的 Vim 教學到今天仍是想學 Omarchy 預設編輯器的人最好的入門。

而且他可不是空手來的。過去一個月，Prime 一直在打造 Oligarchy，一套客製的 Agent 測試框架。它會在 QEMU 虛擬機器裡啟動 Omarchy，讓 Agent 像真人一樣操作：送出按鍵、移動並點擊滑鼠、截圖，然後記錄一切是否照預期運作。每個測試都是一張工單，從一顆全新建立的磁碟開機，再由一群自動化客戶端領取任務、回報結果。他一直在直播除錯這套測試框架，還邀請他的實習生們一起來「Brownbaggin, Teabaggin, Lunabaggin, Frodobaggins this AGI」跟他一起。果然是他。

這正是一個 Agent 作業系統需要的東西。Omarchy 將會支援 x86、Apple 硬體、Snapdragon、Nvidia、Pi，以及其他我們拿得到的平台，還有上千個外掛、數不清的主題，和持續增加的原生應用程式。沒有哪個人工 QA 團隊能在每次發布時把這些全部點過一遍。但跑在驅動我們流水線的 DigitalOcean Droplets 上的一群 Agent 可以。它們可以走完安裝程式、更新系統、試快捷鍵、打開選單，在你看到之前就把壞掉的地方標出來。

領導 Agentic QA，就是要把 Oligarchy 從一個好玩的實驗，變成我們建置、測試和發布 Omarchy 的日常流程。

歡迎加入 Omarchy Core，Prime！是你幫我走到今天。現在，一起把它做到堅不可摧吧。
