我們聘請 Emir Beganović 擔任 Omarchy 基礎架構負責人！他將於 10月1日 上任，成為 Omacom Foundation的第三位 全職成員，與 負責 Kernel 的 Krzysztof Wilczyński 和 負責 Shell 的 outfoxxed 並肩作戰。

以下是 Emir 親自描述他加入 Omarchy 的歷程：

我對 Linux 的熱愛已超過二十年。我十幾歲時就成為 Ubuntu 開發者，並深入參與當地社群。我的職涯橫跨三個國家，在新創公司和成長型公司中負責可靠度與效能工作，並帶領團隊。我在 Booking.com 的 SRE 部門待了近七年，主導建置系統和 CI 基礎架構的工作。最近，我打造了 Isorun，在那裡我一直投入於 microVMs、快照、隔離、排程和拋棄式運算。現在，我要把這些經驗帶回我的初戀。

真正讓我注意到 Emir 的是 TryOmarchy。他把 Omarchy 桌面放進瀏覽器裡（不是重新實作，而是貨真價實的本尊），並讓它在 Cloudflare 上一般的 CPU 基礎架構上於幾秒鐘內開機。我們從那個有點傻氣的實驗開始聊起，對話很快就擴展到筆電、新架構、OEM，以及如果 Omarchy 要在我們希望的每個地方運行所需的基礎架構。我們發現彼此有著相同的願景。

這就是 Emir 加入要來領導的工作。

Omarchy 的基礎架構遠不只是維運伺服器。它是我們用來建置、測試和發布 Omarchy 的一切，也是我們在擴展到更多硬體和更多架構時，保持系統穩定可靠運作的關鍵。它讓發布值得信賴、讓故障可以重現，並為專案中的其他每個人提供穩固的基礎，讓他們能快速前進。

而且還有很多值得探索的地方！Omarchy 應該要在你桌上的那台電腦上漂亮地運行，但沒有理由就停在那裡。TryOmarchy 讓我們瞥見了當啟動一台 Linux 電腦變得像打開網頁一樣簡單時會發生什麼，讓你只需一次點擊就能嚐到 Linux 的滋味。我們要看看這條路會通往哪裡。

多虧了 贊助這項工作的每個人，我們才能讓像 Emir 這樣的人有時間全心投入 Omarchy。我們的贊助者讓我們得以把雄心勃勃的實驗轉化為長久的工作，有全職的人專心讓整個系統變得更好。我們非常感謝他們的贊助。

歡迎加入，Emir！讓我們一起讓 Omarchy 隨處運行。
