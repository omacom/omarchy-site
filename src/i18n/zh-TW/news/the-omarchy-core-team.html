Omarchy 的爆炸式增長需要組織化的團隊來應對。我們先組建 Omarchy Core 團隊。成員將共同承擔引領發行版方向、確保持續前進、協助其他貢獻者的責任。

請允許我介紹首批 Core 成員：

Ryan Hughes 從第一天起就是我在 Omarchy 的搭檔。早期我們一起應對凌晨三點的 AUR 緊急故障，一起籌劃自建軟體包倉庫。Ryan 的貢獻橫跨發行版每一層：安裝、打包、硬體支援、遊戲、主題、CLI 工具，如今還有 Quattro。他推動轉向 Quickshell、外掛系統，以及許多基礎設施，將 Omarchy 從精心組裝的 Linux 環境變成真正的作業系統。不開發 Omarchy 時，Ryan 是 Oodle 的合夥人。

Tobi Lütke 是唯一加入過我兩個 Core 團隊的人！作為 2004 年首批 Rails Core 團隊成員，他不僅對框架貢獻卓著，還編寫了 Liquid、Delayed Job 和 Active Merchant。這些工作後來變成一家叫 Shopify 的小公司，聽說過嗎？如今他也為 Omarchy 大量貢獻，包括 try、Omasnap、Wi-Fi 二維碼和 Quake 風格 Agent 控制台。他還是我的賽車搭檔，一起駕駛 Shopify Racing 11 號 LMP2 賽車參加 IMSA。

Bjarne Øverli 是 Unite AS CTO，也是內建視覺化主題編輯器 Aether 與 TUI 音樂播放器 cliamp 的作者。他透過語義化顏色，以及面向 Neovim、VS Code、btop 等工具生成主題，幫助我們將主題系統從設定檔集合變得更加系統化。Ethereal、Hackerman 和 Lupine 也出自他手。他兼具程式設計師的嚴謹和視覺品位，這種難得的組合與 Omarchy 十分契合。

HANCORE 是機械工程師，卻不知不覺成為 Omarchy 社群審美的重要力量。他製作了數量驚人的主題，包括預設提供的 Last Horizon 和 Solitude。如今還幫助維護 Quattro 的外掛生態。Omarchy 一直堅持電腦要美觀也要實用，而 HANCORE 將這個前提推得比幾乎任何人都遠。

Spencer Bull 是 Dell 傑出工程師，負責 Linux 客戶端適配、AI 和平台軟體。他為我們連線最新硬體的複雜現實，在常見的 Linux 支援滯後出現前，幫助 Omarchy 在 Panther Lake 和最新 XPS 上正常執行。核心、驅動、顯示器、Wi-Fi、揚聲器、電源管理：Spencer 工作在軟體接觸物理世界的那一層。Core 團隊能擁有這種專業知識，價值無可估量。

這五位早已在做這些工作，現在只是正式確認。再加上我，是一支出色的首屆 Core 團隊。不過這不會是唯一的團隊，敬請期待 Omarchy Rangers 的公告！

我們將一起把 Omarchy 打造為首選 Linux 發行版，面向那些為 Agent 時代、可塑電腦，以及美觀、現代、有主張的計算體驗感到興奮的人。

飛向宇宙，浩瀚無垠！
