Omarchy 4.5（又稱 Quattro RS！）是自 Quattro 以來第一個大型功能版本，而且份量十足：短短十二週內，合併了來自超過 180 位貢獻者的 740 多個 pull request。它現在在平鋪預設模式之外，還提供傳統桌面模式。你可以直接在 M1/M2/M3/Neo MacBook 上原生安裝。而且它會說 50 種語言。還有數不清的其他功能、修復與改進。已經在用 Omarchy 了嗎？執行 Update > Omarchy。新機器嗎？在這裡取得。

帶有 dock 的浮動工作區

Super + L 現在會讓任何工作區在平鋪、捲動與浮動之間循環切換。在浮動工作區上，每個視窗都會有一個採用你的佈景主題色彩的標題列，還有一個 dock 會顯示你釘選的應用程式、所有正在運行的應用程式，以及所有已安裝應用程式的格狀列表。拖曳即可重新排序或釘選，右鍵點擊查看更多選項，而 Super + M 會把視窗最小化到 dock。

這對於任何從 macOS 或 Windows 過來、還沒準備好全心投入平鋪模式的人來說，是很棒的入門方式。或者對於只是想要一個可以讓視窗自由鋪開的工作區的人也一樣。可以針對每個工作區混搭使用，而頂欄會顯示每一個工作區使用的版面配置。

在 Apple Silicon 上的 Omarchy

我們出色的 Omarchy M 團隊已經推出原生 Mac 安裝程式。在 macOS 上下載一個應用程式，它就會在你的 M1、M2、M3 或 Neo MacBook 上，把 Omarchy 放在它旁邊一起安裝。不需要 USB 隨身碟，也不需要終端機咒語。偏好 Homebrew？那只要一行：

brew install omacom/mac/omarchy

這就是我們在九月立志要做的事：完成 Asahi 開始的工作。兩個月後，你直接下載就可以。團隊每個人的工作都太出色了。

而且他們還不會停在這裡。M4、M5 與 M6 現在都在開發中，所以可能用不了多久，Omarchy 就能在每一台 Apple Silicon Mac 上運行。

支援 NVIDIA DGX Spark + RTX Spark 的 ARM（以及即將支援 Snapdragon）

Omarchy 4.5 推出它的第一個 ARM ISO，隨之而來的是對 NVIDIA ARM 機器的初步支援：DGX Spark 桌上型電腦，以及建立在 RTX Spark 之上的筆電，就像 Dell XPS 16 Creator Edition 與 ASUS ProArt P14。而且很快我們也會支援整個 Snapdragon ARM 機器系列。它還在早期階段，所以請預期會有一些粗糙的地方，也請在 GitHub 上回報任何出問題的地方。

50 種語言與 5 種輸入法

Omarchy 現在會說 50 種語言。在 Setup > Language 下挑一種（或執行 omarchy language <code>），選單、桌面與 Omarchy 的通知就會立即切換。系統地區設定會在你下次登入時跟上。

不過，會說一種語言只是其中一半。你也需要能打出來。所以 Omarchy 現在會直接從安裝程式或之後在 Setup > Keyboard 下，為日文（Mozc）、韓文（Hangul）、簡體中文（Pinyin）、台灣（Zhuyin）與香港（Cangjie）設定好合適的輸入法。每一個都附有適合其字形的字型，候選字視窗會跟隨你的佈景主題，而 Super + I 會在你的輸入語言之間切換。即使你在 Dvorak、Colemak 或 AZERTY 上輸入拉丁字母，Hangul、Zhuyin 與 Cangjie 也會把按鍵保持在標準位置，就像在 Windows 與 macOS 上一樣。而單獨輕點 Shift 會跳出輸入法進入拉丁字母，再點一下又回來，就像 Sogou、Microsoft Pinyin 與 macOS 的運作方式。

登入 Wi-Fi 強制門戶頁面

飯店、機場與咖啡店的 Wi-Fi 終於可以直接用了。Omarchy 現在會注意到某個網路在讓你上網之前，要你先登入或接受它的條款。網路圖示會警告你，而網路面板會顯示一個大大的 Open Captive Portal 按鈕，帶你直達登入頁面。一旦通過，一切就會自己恢復正常。

五個新的預設應用程式

Hype 讓你從單一 Markdown 檔案製作簡報，原始碼旁邊有一個視覺化投影片編輯器，並可匯出為 PDF 或 PowerPoint。

Signed 取代了 Xournal++ 來處理文書工作：打開 PDF，放置你保存的簽名、文字與日期，然後保存一份已簽名的副本。

Disktree 會畫出正在佔滿你磁碟空間的樹狀圖，依種類著色，指出可以安全重新產生的快取，並讓你標記應該刪除的東西。

Monologue 只要一個按鍵就能錄製你的攝影機畫面，佈景主題與你的桌面相配。

Gliff 讓你透過 SSH 使用遠端桌面。連接到另一台 Omarchy 機器，從你自己的視窗驅動它完整的桌面，每台機器一個分頁。而且因為它走 SSH，不需要額外設定或暴露任何東西。被控制的機器會在頂欄顯示遠端工作階段指示器，所以有人正在使用它時，永遠一清二楚。

還有 Elsewhen，一個就住在頂欄時鐘旁邊的世界時鐘。點選地球儀上的一座城市來設定你所在的位置，搜尋真實地點，並為住在每座城市的人命名，這樣你永遠都知道現在是不是適合打電話的時間。用 t 在 12 小時與 24 小時之間切換，用 Alt + T 在 °F 與 °C 之間切換，並隨時用 Super + Ctrl + Alt + E 召喚它。

有了用來錄製的 Monologue 與用來修剪的 Omacut，新安裝不再附帶 OBS Studio 與 Kdenlive。Lazydocker 也從新安裝移除，雖然 Docker 與 Docker Compose 仍包含在內。已經擁有其中任何一個的機器都會保留它們。

Microsoft 365

需要與住在 Office 裡的人一起工作？Install > Service > Microsoft 現在會把 Outlook、Word、Excel、PowerPoint、Teams 與 OneDrive 設定為網頁應用程式。每一個都有自己的視窗與啟動器項目，所以它們待在其他所有東西旁邊，感覺就像在家一樣。在工作上再也沒有不切換到 Omarchy 的藉口了！

用 Superwhisper 聽寫

Superwhisper 現在是 Omarchy 的預設聽寫引擎，而且開箱即設定好。輕點 Alt + Space 開始說話，再點一次停止，或按住 Right Alt 進行按住說話。它快得不可思議，而且非常準確。

它一開始在雲端運作，所以你安裝好的那一刻就能用，而且前 10,000 個字免費。但你可以切換到完全免費、可下載且完全在本機運行的模型，不會把任何一個字送給任何人。而如果你更想用另一個本機模型，Voxtype 仍作為替代方案提供。

不到十秒就安裝完成

Omarchy 以前會一個一個安裝大約 940 個套件。新的 F1 安裝程式改為解開預先建置的根映像，並在其上只加入這台機器的套件。那讓任何機器上的安裝時間大約縮短一半。

而在快速硬體上，它荒謬到不行。AMD 的 Anush Elangovan 用他的 AMD 筆電在 7 秒 內完成了完整的 Omarchy 安裝，創下世界紀錄。七秒！我還記得五分鐘似乎是個雄心勃勃的目標。

其他地方也更快

不只是安裝程式。啟動不再卡在 binfmt 註冊上。佈景主題選擇器立刻打開，而不是四分之一秒之後。選單與面板直接從 Hyprland 快捷鍵打開，省去了先啟動行程所花的 60 ms。Omarchy 選單最慢的檢查從 200 ms 降到 16 ms，新終端機早 30 ms 顯示提示字元，整個桌面現在會對變化做出反應，而不是輪詢它們。就連登出、重新開機與關機，也在你的應用程式一完成關閉的那一刻就發生。

代理升級

Omarchy 是代理時代的代理式作業系統，而 4.5 為與代理一起工作帶來一大輪升級。代理面板現在追蹤 23 個代理與提供者，從 6 個增加，包括 Cursor、OpenCode、GitHub Copilot、Antigravity、Hermes、Amp、Kiro、Devin、Qwen、DeepSeek、OpenRouter 與 Ollama。每一個額度都有自己的量表，並顯示距離重置的時間，所以你可以準確看見自己還剩多少餘裕。而且 Grok 現在與 Claude 和 Codex 一起成為完整提供者。

而你的代理永遠只要一個按鍵就到。Super + ~ 會在變暗的桌面上放下一個 Quake 風格的控制台，而你第一次打開它時，它會啟動你的預設代理。再按一次把它收起來，而你的工作階段就在你離開時的位置。

如果你同時玩轉多個訂閱，你現在可以在同一台機器上保留數個 Claude、Codex 與 Grok 登入，並用 omarchy agent account 選擇新工作階段一開始要用哪一個。它們之間共用歷史記錄、設定與技能，所以切換後 claude --continue 會從你離開的地方接手。當接近額度限制時，Omarchy 可以提供一鍵切換，或自行把新工作階段移到有最多餘裕的帳戶。而當你設定另一台機器時，omarchy agent account copy 會透過 SSH 把你所有的登入都帶過來，所以你不必再登入所有東西一次。

Kimi 與 Ori，OpenRouter 的代理 harness，加入了 Setup > Defaults > Agent 下的選擇，而 Google 的 Antigravity 取代了過時的 Gemini CLI（gemini 仍可作為別名使用）。偏好視窗而非終端機？Claude 與 Amp 桌面應用程式現在在 Install > AI 下只要點一下就到。

通知，重建

通知現在會依寄件者堆疊、跟隨你的佈景主題，並把相同的重複內容摺疊起來。動作按鈕、驗證碼與連結全部都能直接從卡片上運作。Super + Comma 會對最新的一張採取動作（關閉、打開或按下它的按鈕），而 Super + Ctrl + Comma 把鍵盤交給你來驅動它們全部。頂欄的鈴鐺會開啟勿擾模式。

影片背景與佈景主題開場

背景現在可以是影片了。放一個進來，你的桌面就會隨著滾動的波浪或你喜歡的任何東西活起來，而鎖定畫面會顯示它的一個靜止畫面。而佈景主題現在會登場：每一個都可以在你登入或切換到它時，播放一段短短的無聲開場。（比較喜歡保持平靜？在 Appearance > Animations 下關閉開場。）

Jade Horse 加入預設佈景主題

Jade Horse 滿是朦朧的綠色，帶有雕刻玉石般的背景，讓整個桌面看起來像一幅捲軸畫。它在內附的佈景主題中取代了 Osaka Jade，並與 Starship 一起成為另一個新的預設佈景主題。如果你用的是 Osaka Jade，你會保留你的副本，而它會作為第三方佈景主題繼續存在，供任何想全新安裝它的人使用。

Liftoff 是新的預設背景

新安裝現在會用 Liftoff 迎接你，一個華麗的日落發射場景，是 Tokyo Night 的新預設背景。它由 Tom Ballard 製作，他最初為他的 Liftoff theme 創作它。謝謝你，Tom！

開機選單現在安靜了

Omarchy 以前每次啟動都會顯示大約六秒的開機選單，以防你需要回滾到較早的快照。但幾乎從來沒有人那樣做。所以現在 Limine 只等一秒並安靜開機，而且大多數時候你根本不會看到選單。

當你確實需要不同的開機項目或快照時，在機器啟動時持續輕點任何按鍵（向下箭頭就可以），它就會停在選單。而如果你更想讓選單永久保持更久，在 /boot/limine.conf 中設定你自己的 timeout:（像 timeout: 5）。更新會放著你設定的 timeout 不管。

已變更的快捷鍵

有些快捷鍵移動了：

  • 計算機：Super + Ctrl + Q 現在是 Super + Shift + Q。
  • 活動：Super + Ctrl + T 現在是 Super + Shift + T，而 Super + Ctrl + T 會打開佈景主題。
  • 網路：Super + Ctrl + W 現在是 Super + Ctrl + N，而 Super + Ctrl + W 會打開背景。
  • Nightlight 不再有快捷鍵（它原本是 Super + Ctrl + N）；它在 Trigger > Toggle 中。
  • Super + Alt + Space 會從 dock 打開 Apps，而不是 Apps 選單。

通知快捷鍵已變更：

  • Super + Comma 會對最新的卡片採取動作（關閉它、打開它或按下它唯一的按鈕），而不是只關閉它。
  • 關閉最後一張已移到 Super + Alt + Comma，它以前會打開它。
  • 靜音從 Super + Ctrl + Comma 移到 Super + Ctrl + Alt + Comma；Super + Ctrl + Comma 現在把鍵盤控制權交給你。

有幾個按鍵的運作方式不同：

  • Super + Tab、Super + Shift + Tab、Super + Ctrl + Tab 與 Super + 捲動會留在目前螢幕的工作區，因為每台螢幕都有自己的工作區。
  • 在終端機中，Super + C 與 Super + V 會送出 Ctrl + Shift + C 與 Ctrl + Shift + V，而不是 Ctrl + Insert 與 Shift + Insert。

可能與你自己的綁定衝突的新預設：Super + Q（關閉視窗，與 Super + W 並列）、Super + A（全選）、Super + M（最小化到 dock）、Super + ~ 與 Super + Shift + ~（Quake console）、Super + Alt + L（上一個版面配置）、Super + Shift + Ctrl + Arrows（把視窗移到另一台螢幕）、Super + Ctrl + Alt + C（截圖）、Super + Ctrl + Alt + E（世界時鐘）、Super + Ctrl + Alt + F（全螢幕桌面），以及按住 Right Alt 進行按住說話聽寫。
