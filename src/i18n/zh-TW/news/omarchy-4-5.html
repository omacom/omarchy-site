Omarchy 4.5（又稱 Quattro RS！）是自 Quattro 以來第一個大型功能版本，而且份量十足：僅僅十二週內，就合併了來自 180 多位貢獻者的 740 多個 pull requests。它現在在預設的平鋪模式之外，也提供傳統桌面模式。你可以將它原生安裝在 M1/M2/M3/Neo MacBook 上。而且它會說 50 種語言。還有數不清的其他功能、修復與改進。已經在用 Omarchy 了嗎？執行 Update > Omarchy。新機器？在這裡取得。

附 Dock 的浮動工作區

Super + L 現在可以讓任何工作區在平鋪、捲動與浮動之間循環切換。在浮動工作區上，每個視窗都會有以你佈景主題顏色呈現的標題列，Dock 則會顯示你釘選的應用程式、所有正在執行的程式，以及所有已安裝應用程式的格狀清單。拖曳即可重新排序或釘選，右鍵點按查看更多，Super + M 則可將視窗最小化到 Dock。

對於從 macOS 或 Windows 過來、還沒準備好完全投入平鋪模式的人來說，這是很好的入門方式。或是給任何只想要一個能讓視窗自由鋪展的工作區的人。你可以依工作區混搭使用，頂欄也會顯示每個工作區使用的版面配置。

Apple Silicon 上的 Omarchy

我們出色的 Omarchy M 團隊已經推出了原生 Mac 安裝程式。在 macOS 上下載一個 app，它就會在你的 M1、M2、M3 或 Neo MacBook 上，將 Omarchy 與 macOS 並排安裝。不需要 USB 隨身碟，也不需要終端機咒語。偏好 Homebrew？只要一行：

brew install omacom/mac/omarchy

這正是我們九月立下的目標：完成 Asahi 開始的工作。兩個月後，你直接下載就能用。團隊所有人都做得太棒了。

而且他們還沒停下來。M4、M5 和 M6 目前全部都在開發中，所以 Omarchy 可能很快就能在每一台 Apple Silicon Mac 上執行。

支援 NVIDIA DGX Spark + N1X 的 ARM（不久後也將支援 Snapdragon）

Omarchy 4.5 推出第一個 ARM ISO，並初步支援 NVIDIA 的 ARM 機器：DGX Spark 桌機，以及搭載 N1X 的筆電，例如 Dell XPS 16 Creator Edition 與 ASUS ProArt P14。不久後，我們也將支援整個 Snapdragon ARM 機器系列。目前仍是早期階段，所以請預期會有一些粗糙邊角，若有任何損壞，請到 GitHub 回報。

50 種語言與 5 種輸入法

Omarchy 現在會說 50 種語言。在 Setup > Language 底下選一種（或執行 omarchy language <code>），選單、桌面與 Omarchy 的通知就會立即切換。系統地區設定會在你下次登入時跟著變更。

不過，會說一種語言只是其中一半。你還必須能輸入它。所以 Omarchy 現在會直接從安裝程式或之後在 Setup > Keyboard 底下，為日語（Mozc）、韓語（Hangul）、簡體中文（Pinyin）、臺灣（Zhuyin）與香港（Cangjie）設定好適當的輸入法。每種輸入法都搭配適合其字形的正確字體，候選字視窗會跟隨你的佈景主題，Super + I 可在你的輸入語言之間切換。即使你在 Dvorak、Colemak 或 AZERTY 上輸入拉丁字母，Hangul、Zhuyin 與 Cangjie 的鍵位仍會保持在標準位置，就像在 Windows 與 macOS 上一樣。而單獨輕點 Shift 就能脫離輸入法進入拉丁字母模式，再點一次返回，就像 Sogou、Microsoft Pinyin 與 macOS 的運作方式。

登入強制式 Wi-Fi 入口網站

飯店、機場與咖啡店的 Wi-Fi 終於可以直接用了。Omarchy 現在會注意到某個網路在讓你上線之前，要你先登入或接受其條款。網路圖示會向你發出警告，網路面板則會顯示一個大大的 Open Captive Portal 按鈕，直接帶你到登入頁面。一旦通過，一切就會自行恢復正常。

五款新的預設應用程式

Hype 能從單一 Markdown 檔案製作簡報，原始碼旁就有視覺化投影片編輯器，還能匯出為 PDF 或 PowerPoint。

Signed 取代了處理文書工作的 Xournal++：打開 PDF，放置你儲存的簽名、文字與日期，然後儲存已簽名的副本。

Disktree 會繪製一張樹狀圖，顯示什麼東西塞滿了你的磁碟，依種類以顏色標示，指出可以安全重新生成的快取，並讓你標記應該刪除的內容。

Monologue 只需一個按鍵就能用你的攝影機錄影，並以佈景主題配合你的桌面。

Gliff 讓你透過 SSH 使用遠端桌面。連線到另一台 Omarchy 機器，從你這台上的視窗操控它完整的桌面，每台機器一個分頁。又因為它走 SSH，沒有其他需要設定或暴露的東西。被控制的機器會在頂欄顯示遠端工作階段指示器，所以有人在上面操作時總是一清二楚。

還有 Elsewhen，一個世界時鐘，就住在頂欄的時鐘旁邊。輕點地球儀上的一座城市來設定你所在的位置，搜尋真實地點，並為住在每座城市的人命名，這樣你隨時都知道現在打電話過去是否合適。用 t 在 12 與 24 小時制之間翻轉，用 Alt + T 在 °F 與 °C 之間翻轉，並隨時用 Super + Ctrl + Alt + E 召喚它。

由於有了錄影用的 Monologue 與修剪用的 Omacut，新安裝不再附帶 OBS Studio 與 Kdenlive。Lazydocker 也從新安裝中移除，不過 Docker 與 Docker Compose 仍有包含。已經裝有其中任何一個的機器會繼續保留。

Microsoft 365

需要與生活在 Office 裡的人一起工作嗎？Install > Service > Microsoft 現在會將 Outlook、Word、Excel、PowerPoint、Teams 與 OneDrive 設定為網頁應用程式。每個應用程式都有自己的視窗與啟動器項目，所以它們待在其他程式旁邊就像在家一樣自在。再也沒有不在工作中改用 Omarchy 的藉口了！

用於聽寫的 Superwhisper

Superwhisper 現在是 Omarchy 的預設聽寫引擎，且開箱即設定完成。輕點 Alt + Space 開始說話，再點一次停止，或按住 Right Alt 進行按住說話。它快得不可思議，也非常準確。

它一開始在雲端運作，所以安裝後立刻就能使用，前 10,000 個字免費。但你可以切換到可下載的模型，完全免費且完全在本地執行，不會把任何一個字傳送給任何人。而如果你更想使用另一種本地模型，Voxtype 仍作為替代方案提供。

十秒內安裝完成

Omarchy 以往會逐一安裝約 940 個套件。新的 F1 安裝程式則會解開預先建置的 root 映像，並只在上面加入這台機器的套件。這讓任何機器上的安裝時間大約縮短一半。

而在快速硬體上，這簡直荒謬。來自 AMD 的 Anush Elangovan 在他的 AMD 筆電上，以 7 秒完成完整的 Omarchy 安裝，創下世界紀錄。七秒！ 我還記得五分鐘似乎是個雄心勃勃的目標的時候。

其他地方也更快了

不只是安裝程式更快。啟動不再因 binfmt 註冊而卡住。佈景主題選擇器會立刻打開，而不是等四分之一秒後。選單與面板直接從 Hyprland 捷徑打開，省下先啟動處理程序所需的 60 ms。Omarchy 選單最慢的檢查從 200 ms 降到 16 ms，新的終端機會提早 30 ms 顯示提示字元，整個桌面現在會對變更作出反應，而不是輪詢等待變更。甚至登出、重新開機與關機，也會在你的應用程式關閉完成的那一刻發生。

代理升級

Omarchy 是代理式作業系統，4.5 為與代理一起工作帶來了一大輪升級。代理面板現在追蹤 23 個代理與供應商，從 6 個增加，包括 Cursor、OpenCode、GitHub Copilot、Antigravity、Hermes、Amp、Kiro、Devin、Qwen、DeepSeek、OpenRouter 與 Ollama。每個限額都有自己的計量表與重置前的剩餘時間，所以你可以確切知道自己還剩多少可用空間。而 Grok 現在與 Claude 及 Codex 並列，成為完整的供應商。

而且你的代理永遠只差一次按鍵。Super + ~ 會在變暗的桌面上拉下一個 Quake 風格的控制台，第一次打開時，它會啟動你的預設代理。再按一次把它收起來，你的工作階段就正好停在你離開的地方。

如果你同時處理多個訂閱，現在可以在同一台機器上保留多個 Claude、Codex 與 Grok 登入，並使用 omarchy agent account 選擇新工作階段要以哪一個開始。它們之間共享歷史記錄、設定與技能，所以切換後 claude --continue 會正好從你離開的地方接續。接近限額時，Omarchy 可以提供一鍵切換，或自行將新工作階段移到餘額最多的帳號。而當你設定另一台機器時，omarchy agent account copy 會透過 SSH 把你所有的登入都帶過來，所以你不必再把所有東西重新登入一次。

Kimi 與 Ori（OpenRouter 的代理框架）加入 Setup > Defaults > Agent 底下的選項，Google 的 Antigravity 取代了過時的 Gemini CLI（gemini 仍可作為別名使用）。比起終端機更喜歡視窗嗎？Claude 與 Amp 桌面應用程式現在在 Install > AI 底下，點一下就能取得。

通知，重建完成

通知現在會依寄件者堆疊、跟隨你的佈景主題，並折疊相同的重複通知。動作按鈕、驗證碼與連結全都可以直接從卡片上操作。Super + Comma 會對最新的一則進行操作（關閉、開啟或按下其按鈕），Super + Ctrl + Comma 則把鍵盤交給你來操控全部通知。頂欄的鈴鐺會開啟勿擾模式。

影片背景與佈景主題開場

背景現在可以是影片。放一部進來，你的桌面就會隨著滾動的波浪或你喜歡的其他任何內容活起來，而鎖定畫面則會顯示其中的一幀靜止畫面。而佈景主題現在會隆重登場：每一個都可以在你登入或切換到它時，播放一段短小無聲的開場。（比較喜歡平靜一點嗎？在 Appearance > Animations 底下關閉開場。）

Jade Horse 加入預設佈景主題

Jade Horse 全是霧濛濛的綠色，配上雕刻翡翠般的背景，讓整個桌面看起來像一幅捲軸畫。它取代了內建佈景主題中的 Osaka Jade，並與 Starship 一同成為另一個新的預設佈景主題。如果你正在使用 Osaka Jade，你會保留你的副本，它也會作為第三方佈景主題繼續存在，供任何想要全新安裝它的人使用。

Liftoff 是新的預設背景

新安裝現在會以 Liftoff 迎接你，這是一幅華麗的日落發射畫面，也是 Tokyo Night 的新預設背景。它由 Tom Ballard 製作，他最初為自己的 Liftoff 佈景主題創作了它。謝謝你，Tom！

開機選單現在安靜了

Omarchy 以往每次啟動都會顯示開機選單約六秒，以防你需要回滾到較早的快照。但幾乎沒有人真的這麼做。所以現在 Limine 只等待一秒並安靜開機，大多數時候你根本不會看到選單。

當你真的需要不同的項目或快照時，在機器啟動時持續輕點任何按鍵（向下方向鍵也可以），它就會停在選單。而如果你希望選單一直保留更久，在 /boot/limine.conf 中設定你自己的 timeout:（例如 timeout: 5）。更新會保留你設定的 timeout 不動。

變更的快速鍵

一些快速鍵移位了：

  • 計算機：Super + Ctrl + Q 現在改為 Super + Shift + Q。
  • 活動：Super + Ctrl + T 現在改為 Super + Shift + T，而 Super + Ctrl + T 會開啟佈景主題。
  • 網路：Super + Ctrl + W 現在改為 Super + Ctrl + N，而 Super + Ctrl + W 會開啟背景。
  • 夜燈不再有快速鍵（原本是 Super + Ctrl + N）；它位於 Trigger > Toggle。
  • Super + Alt + Space 會從 Dock 開啟 Apps，而不是 Apps 選單。

通知快速鍵變更：

  • Super + Comma 會對最新的卡片進行操作（關閉它、開啟它或按下它唯一的按鈕），而不再只是關閉它。
  • 關閉最後一則移到 Super + Alt + Comma，這原本是用來開啟它。
  • 靜音從 Super + Ctrl + Comma 移到 Super + Ctrl + Alt + Comma；Super + Ctrl + Comma 現在會把鍵盤控制權交給你。

有幾個按鍵的運作方式不同：

  • Super + Tab、Super + Shift + Tab、Super + Ctrl + Tab 與 Super + 捲動會停留在目前螢幕的工作區，因為每個螢幕都有自己的工作區。
  • 在終端機中，Super + C 與 Super + V 會傳送 Ctrl + Shift + C 與 Ctrl + Shift + V，而不是 Ctrl + Insert 與 Shift + Insert。

可能會與你自己的綁定衝突的新預設：Super + Q（關閉視窗，與 Super + W 並列）、Super + A（全選）、Super + M（最小化到 Dock）、Super + ~ 與 Super + Shift + ~（Quake 控制台）、Super + Alt + L（上一個版面配置）、Super + Shift + Ctrl + Arrows（將視窗移到另一台螢幕）、Super + Ctrl + Alt + C（截圖）、Super + Ctrl + Alt + E（世界時鐘）、Super + Ctrl + Alt + F（全螢幕桌面），以及按住 Right Alt 進行按住說話聽寫。
