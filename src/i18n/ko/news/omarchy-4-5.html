Omarchy 4.5(일명 Quattro RS!)는 Quattro 이후 첫 대규모 기능 릴리스이며, 정말 엄청납니다: 단 12주 만에 180명이 넘는 기여자로부터 740개가 넘는 pull request가 병합됐습니다. 이제 tiling 기본값 옆에 전통적인 데스크톱 모드를 제공합니다. M1/M2/M3/Neo MacBook에 네이티브로 설치할 수 있습니다. 그리고 50개 언어를 구사합니다. 그 밖에도 수많은 기능, 수정, 개선이 있습니다. 이미 Omarchy를 사용 중이신가요? Update > Omarchy를 실행하세요. 새 기기인가요? 여기에서 받으세요.

독을 갖춘 플로팅 워크스페이스

Super + L을 누르면 이제 모든 워크스페이스가 tiling, scrolling, floating 사이를 순환합니다. 플로팅 워크스페이스에서는 모든 창에 테마 색상의 titlebar가 생기고, 독에는 고정된 앱, 실행 중인 모든 것, 설치된 모든 앱의 그리드가 표시됩니다. 드래그해서 순서를 바꾸거나 고정하고, 마우스 오른쪽 버튼을 클릭하면 더 많은 옵션을 볼 수 있으며, Super + M을 누르면 창이 독으로 최소화됩니다.

이는 macOS나 Windows에서 넘어온 사람 중 아직 tiling에 완전히 뛰어들 준비가 되지 않은 사람에게 훌륭한 진입로입니다. 또는 창을 마음껏 펼칠 수 있는 워크스페이스가 하나쯤 필요한 사람에게도 좋습니다. 워크스페이스별로 섞어 쓸 수 있고, 바에는 각 워크스페이스가 어떤 레이아웃을 사용하는지 표시됩니다.

Apple Silicon에서의 Omarchy

놀라운 저희 Omarchy M 팀이 네이티브 Mac 설치 프로그램을 출시했습니다. macOS에서 앱을 다운로드하면 M1, M2, M3, Neo MacBook에서 macOS와 나란히 Omarchy를 설치해 줍니다. USB 스틱도, 터미널 주문도 필요 없습니다. Homebrew를 선호하시나요? 한 줄이면 됩니다:

brew install omacom/mac/omarchy

이것이 바로 9월에 우리가 해내려던 일입니다: Asahi가 시작한 일을 마무리하는 것이죠. 두 달 후, 이제 그냥 다운로드하면 됩니다. 팀원 모두 정말 대단한 일을 해냈습니다.

그리고 여기서 멈추지 않습니다. M4, M5, M6 모두 지금 작업 중이니, Omarchy가 모든 Apple Silicon Mac에서 실행될 날도 머지않을 것 같습니다.

NVIDIA DGX Spark + N1X를 위한 ARM 지원 (그리고 곧 Snapdragon도)

Omarchy 4.5는 첫 ARM ISO와 함께 NVIDIA ARM 기기를 위한 예비 지원을 제공합니다: DGX Spark 데스크톱과 Dell XPS 16 Creator Edition, ASUS ProArt P14 같은 N1X 기반 노트북입니다. 그리고 곧 전체 Snapdragon ARM 기기 라인업도 지원할 예정입니다. 아직 초기 단계라 거친 부분이 있을 수 있으니, 문제가 생기면 GitHub에 보고해 주세요.

50개 언어와 5가지 입력 방식

Omarchy는 이제 50개 언어를 구사합니다. Setup > Language에서 하나를 선택하거나(또는 omarchy language <code>를 실행하면), 메뉴, 데스크톱, Omarchy 알림이 즉시 전환됩니다. 시스템 로케일은 다음 로그인 때 따라 바뀝니다.

언어를 구사하는 것은 절반에 불과합니다. 입력할 수 있어야 하죠. 그래서 Omarchy는 이제 설치 프로그램에서 바로, 또는 나중에 Setup > Keyboard에서 일본어(Mozc), 한국어(Hangul), 중국어 간체(Pinyin), 대만(Zhuyin), 홍콩(Cangjie)을 위한 적절한 입력 방식을 설정합니다. 각 방식에는 문자 형태에 맞는 글꼴이 함께 제공되고, 후보 창은 테마를 따르며, Super + I를 누르면 입력 언어 사이를 전환합니다. Windows와 macOS에서처럼, Dvorak, Colemak, AZERTY로 라틴 문자를 입력하더라도 Hangul, Zhuyin, Cangjie는 표준 위치에 키가 유지됩니다. 그리고 Shift만 살짝 누르면 Sogou, Microsoft Pinyin, macOS가 하는 방식처럼 입력 방식에서 라틴 문자로 빠져나갔다가 다시 돌아옵니다.

종속형 Wi-Fi 포털에 로그인하기

호텔, 공항, 커피숍 Wi-Fi가 마침내 그냥 작동합니다. Omarchy는 이제 네트워크가 온라인 접속 전에 로그인이나 약관 동의를 요구할 때 이를 알아챕니다. 네트워크 아이콘이 경고를 표시하고, 네트워크 패널에는 로그인 페이지로 바로 이동하는 큰 Open Captive Portal 버튼이 표시됩니다. 통과하고 나면 모든 것이 저절로 정상으로 돌아옵니다.

다섯 가지 새로운 기본 앱

Hype는 하나의 Markdown 파일로 프레젠테이션을 만들며, 소스 옆에 시각적 슬라이드 편집기가 있고, PDF나 PowerPoint로 내보냅니다.

Signed는 서류 작업을 위해 Xournal++를 대체합니다: PDF를 열고, 저장된 서명, 텍스트, 날짜를 배치한 뒤 서명된 사본을 저장하세요.

Disktree는 디스크를 무엇이 채우고 있는지 종류별로 색상을 입힌 treemap으로 그려주며, 안전하게 재생성할 수 있는 캐시를 알려주고, 삭제할 항목을 표시할 수 있게 합니다.

Monologue는 한 번의 키 입력으로 카메라를 녹화하며, 데스크톱에 맞게 테마가 적용됩니다.

Gliff는 SSH를 통한 원격 데스크톱을 제공합니다. 다른 Omarchy 기기에 연결해 내 기기의 창에서 그 전체 데스크톱을 조작할 수 있으며, 기기마다 탭이 하나씩 있습니다. 그리고 SSH를 타고 가기 때문에 추가로 설정하거나 노출할 것이 없습니다. 제어되는 기기는 바에 원격 세션 표시기가 나타나므로, 누군가 접속 중일 때 항상 알 수 있습니다.

그리고 바의 시계 바로 옆에 사는 세계 시계 Elsewhen도 있습니다. 지구본에서 도시를 눌러 현재 위치를 설정하고, 실제 장소를 검색하고, 각 도시에 사는 사람들의 이름을 붙여두면 전화하기 괜찮은 시간인지 항상 알 수 있습니다. t로 12시간제와 24시간제를 전환하고, Alt + T로 °F와 °C를 전환하며, Super + Ctrl + Alt + E로 언제든 불러올 수 있습니다.

녹화용 Monologue와 편집용 Omacut가 있어, 신규 설치에는 더 이상 OBS Studio와 Kdenlive가 포함되지 않습니다. Lazydocker도 신규 설치에서 사라졌지만, Docker와 Docker Compose는 여전히 포함됩니다. 이미 어느 하나라도 가지고 있는 기기는 그대로 유지합니다.

Microsoft 365

Office 환경에서 일하는 사람들과 협업해야 하나요? Install > Service > Microsoft가 이제 Outlook, Word, Excel, PowerPoint, Teams, OneDrive를 웹 앱으로 설정합니다. 각 앱마다 자체 창과 실행기 항목이 생겨, 다른 모든 앱 옆에서 자연스럽게 어울립니다. 직장에서 Omarchy로 전환하지 않을 변명은 이제 없습니다!

받아쓰기를 위한 Superwhisper

Superwhisper가 이제 Omarchy의 기본 받아쓰기 엔진이며, 처음부터 바로 사용할 수 있게 설정되어 있습니다. Alt + Space를 눌러 말하기를 시작하고 다시 눌러 멈추거나, Right Alt를 누르고 있어 push-to-talk로 사용하세요. 믿을 수 없을 만큼 빠르고 매우 정확합니다.

처음에는 클라우드에서 시작하므로 설치하는 순간 바로 작동하고, 처음 10,000단어는 무료입니다. 하지만 완전히 무료이고 누구에게도 단어를 보내지 않으며 전적으로 로컬에서 실행되는 다운로드 가능한 모델로 전환할 수 있습니다. 다른 로컬 모델을 선호한다면, 대안으로 Voxtype도 여전히 제공됩니다.

10초 미만에 설치하기

Omarchy는 예전에 약 940개의 패키지를 하나씩 설치했습니다. 새로운 F1 설치 프로그램은 대신 미리 빌드된 루트 이미지를 풀고 그 위에 이 기기에만 필요한 패키지만 추가합니다. 덕분에 어떤 기기에서든 설치 시간이 대략 절반으로 줄어듭니다.

그리고 빠른 하드웨어에서는 터무니없을 정도입니다. AMD의 Anush Elangovan은 자신의 AMD 노트북에서 전체 Omarchy 설치를 7초 만에 마쳐 세계 기록을 세웠습니다. 7초! 5분이 야심 찬 목표처럼 보였던 때가 기억납니다.

다른 모든 곳도 더 빠르게

설치 프로그램만 빨라진 게 아닙니다. 시작 시 더 이상 binfmt 등록 때문에 멈추지 않습니다. 테마 선택기는 0.25초를 기다리는 대신 바로 열립니다. 메뉴와 패널은 Hyprland 단축키에서 바로 열리며, 먼저 프로세스를 시작하는 데 걸리던 60ms를 건너뜁니다. Omarchy 메뉴에서 가장 느린 검사는 200ms에서 16ms로 줄었고, 새 터미널은 프롬프트를 30ms 더 빨리 표시하며, 전체 데스크톱은 이제 폴링하는 대신 변화에 반응합니다. 로그아웃, 재부팅, 종료도 앱이 닫히기를 마치자마자 일어납니다.

에이전트 업그레이드

Omarchy는 에이전트 OS이며, 4.5는 에이전트와 함께 작업하기 위한 대규모 업그레이드를 가져옵니다. 에이전트 패널은 이제 6개에서 늘어난 23개의 에이전트와 제공업체를 추적하며, 여기에는 Cursor, OpenCode, GitHub Copilot, Antigravity, Hermes, Amp, Kiro, Devin, Qwen, DeepSeek, OpenRouter, Ollama가 포함됩니다. 모든 한도마다 초기화까지 남은 시간을 보여주는 자체 미터가 있어, 얼마나 여유가 남았는지 정확히 볼 수 있습니다. 그리고 Grok이 이제 Claude와 Codex와 함께 완전한 제공업체가 됐습니다.

그리고 에이전트는 항상 키 한 번이면 닿습니다. Super + ~를 누르면 어두워진 데스크톱 위로 Quake 스타일 콘솔이 내려오고, 처음 열면 기본 에이전트가 시작됩니다. 다시 누르면 사라지고, 세션은 떠났던 자리 그대로 있습니다.

여러 구독을 오가며 사용한다면, 이제 같은 기기에 Claude, Codex, Grok 로그인을 여러 개 유지하고 omarchy agent account를 사용해 새 세션이 어떤 로그인으로 시작할지 선택할 수 있습니다. 히스토리, 설정, 스킬은 로그인 간에 공유되므로, 전환 후에도 claude --continue가 떠났던 자리에서 바로 이어집니다. 한도에 가까워지면 Omarchy가 클릭 한 번으로 전환을 제안하거나, 새 세션을 여유가 가장 많은 계정으로 저절로 옮길 수 있습니다. 다른 기기를 설정할 때는 omarchy agent account copy가 SSH를 통해 모든 로그인을 가져오므로, 모든 것에 다시 로그인할 필요가 없습니다.

OpenRouter의 에이전트 하네스인 Kimi와 Ori가 Setup > Defaults > Agent의 선택지에 합류하고, Google의 Antigravity가 구식 Gemini CLI를 대체합니다(gemini는 여전히 별칭으로 작동합니다). 터미널보다 창을 선호하시나요? Claude와 Amp 데스크톱 앱을 이제 Install > AI에서 클릭 한 번으로 사용할 수 있습니다.

알림, 새로 구축

알림은 이제 보낸 사람별로 쌓이고, 테마를 따르며, 동일한 반복은 접힙니다. 액션 버튼, 인증 코드, 링크 모두 카드에서 바로 작동합니다. Super + Comma는 가장 새 알림에 동작하고(닫기, 열기, 또는 버튼 누르기), Super + Ctrl + Comma는 키보드로 모든 알림을 조작할 수 있게 해줍니다. 바의 종 아이콘은 방해 금지를 켭니다.

동영상 배경과 테마 인트로

배경은 이제 동영상이 될 수 있습니다. 하나를 넣으면 데스크톱이 출렁이는 파도나 원하는 다른 무엇으로 살아나고, 잠금 화면에는 그 동영상의 정지 프레임이 표시됩니다. 그리고 테마는 이제 등장 연출을 합니다: 각 테마는 로그인하거나 그 테마로 전환할 때 짧고 소리 없는 인트로를 재생할 수 있습니다. (차분하게 유지하고 싶으신가요? Appearance > Animations에서 인트로를 끄세요.)

Jade Horse가 기본 테마에 합류

Jade Horse는 온통 안개 낀 녹색으로, 전체 데스크톱을 두루마리 그림처럼 보이게 하는 조각된 옥 배경을 갖추고 있습니다. 번들 테마 중 Osaka Jade를 대체하며, 또 다른 새 기본 테마인 Starship과 함께합니다. Osaka Jade를 사용 중이라면 사본을 그대로 유지하며, 새로 설치하려는 사람을 위한 서드파티 테마로 계속 살아갑니다.

Liftoff가 새 기본 배경

신규 설치에서는 이제 Tokyo Night의 새 기본 배경인 멋진 일몰 발사 장면 Liftoff가 여러분을 맞이합니다. Tom Ballard가 만들었고, 그는 자신의 Liftoff 테마를 위해 처음 만들었습니다. 고마워요, Tom!

이제 조용해진 부팅 메뉴

Omarchy는 예전에 혹시 이전 스냅샷으로 롤백해야 할 경우를 대비해 시작할 때마다 약 6초 동안 부팅 메뉴를 표시했습니다. 하지만 거의 아무도 그러지 않았습니다. 그래서 이제 Limine은 단 1초만 기다리고 조용히 부팅하며, 대부분의 경우 메뉴를 전혀 보지 못할 것입니다.

다른 항목이나 스냅샷이 필요할 때는 기기가 시작되는 동안 아무 키(아래쪽 화살표도 됩니다)나 계속 누르면 메뉴에서 멈춥니다. 메뉴를 계속 더 오래 띄워두고 싶다면, /boot/limine.conf에 자신만의 timeout:을 설정하세요(timeout: 5처럼요). 업데이트는 여러분이 설정한 timeout을 그대로 둡니다.

변경된 단축키

일부 단축키가 이동했습니다:

  • 계산기: Super + Ctrl + Q가 이제 Super + Shift + Q입니다.
  • Activity: Super + Ctrl + T가 이제 Super + Shift + T이며, Super + Ctrl + T는 테마를 엽니다.
  • Network: Super + Ctrl + W가 이제 Super + Ctrl + N이며, Super + Ctrl + W는 배경을 엽니다.
  • Nightlight는 더 이상 단축키가 없습니다(예전에는 Super + Ctrl + N이었습니다); Trigger > Toggle에 있습니다.
  • Super + Alt + Space는 Apps 메뉴 대신 독에서 Apps를 엽니다.

알림 단축키가 변경됐습니다:

  • Super + Comma는 가장 새 카드에 대해 닫기만 하는 대신 닫기, 열기, 또는 그 하나의 버튼 누르기를 수행합니다.
  • 마지막 카드를 닫는 동작은 Super + Alt + Comma로 이동했으며, 이 키는 예전에 카드를 열었습니다.
  • 무음 처리는 Super + Ctrl + Comma에서 Super + Ctrl + Alt + Comma로 이동했습니다; Super + Ctrl + Comma는 이제 키보드 제어를 넘겨줍니다.

몇 가지 키는 다르게 작동합니다:

  • Super + Tab, Super + Shift + Tab, Super + Ctrl + Tab, 그리고 Super + 스크롤은 모든 모니터마다 자체 워크스페이스가 있으므로 현재 모니터의 워크스페이스에 머무릅니다.
  • 터미널에서는 Super + C와 Super + V가 Ctrl + Insert와 Shift + Insert 대신 Ctrl + Shift + C와 Ctrl + Shift + V를 보냅니다.

여러분이 직접 만든 바인딩과 충돌할 수 있는 새 기본값: Super + Q(창 닫기, Super + W와 함께), Super + A(모두 선택), Super + M(독으로 최소화), Super + ~와 Super + Shift + ~(Quake 콘솔), Super + Alt + L(이전 레이아웃), Super + Shift + Ctrl + Arrows(창을 다른 모니터로 이동), Super + Ctrl + Alt + C(스크린샷), Super + Ctrl + Alt + E(세계 시계), Super + Ctrl + Alt + F(전체 화면 데스크톱), 그리고 push-to-talk 받아쓰기를 위한 Right Alt 누르고 있기.
