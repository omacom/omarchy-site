Omarchy 4.5(일명 Quattro RS!)는 Quattro 이후 첫 대규모 기능 릴리스이며, 정말 어마어마합니다. 단 12주 만에 180명이 넘는 기여자로부터 740개가 넘는 풀 리퀘스트가 병합됐습니다. 이제 기본 타일링 방식 옆에 전통적인 데스크톱 모드도 제공합니다. M1/M2/M3/Neo MacBook에 네이티브로 설치할 수 있습니다. 그리고 50개 언어를 구사합니다. 그 밖에도 수많은 기능, 수정, 개선 사항이 담겼습니다. 이미 Omarchy를 쓰고 있나요? Update > Omarchy를 실행하세요. 새 컴퓨터인가요? 여기에서 받으세요.

독을 갖춘 플로팅 워크스페이스

Super + L을 누르면 이제 어느 워크스페이스든 타일링, 스크롤링, 플로팅 사이를 순환할 수 있습니다. 플로팅 워크스페이스에서는 모든 창에 테마 색상의 타이틀바가 생기고, 독에는 고정해 둔 앱, 실행 중인 모든 앱, 설치된 모든 앱의 그리드가 표시됩니다. 드래그해 순서를 바꾸거나 고정하고, 마우스 오른쪽 버튼을 클릭해 더 많은 작업을 할 수 있으며, Super + M을 누르면 창을 독으로 최소화합니다.

macOS나 Windows에서 막 넘어와 아직 타일링에 완전히 뛰어들 준비가 되지 않은 분들에게 훌륭한 입문 경로입니다. 아니면 그냥 창을 마음껏 펼칠 수 있는 워크스페이스 하나를 원하는 분에게도 좋습니다. 워크스페이스마다 섞어 쓰면, 바에 각 워크스페이스가 어떤 레이아웃을 사용하는지 표시됩니다.

Apple Silicon 위의 Omarchy

놀라운 Omarchy M 팀이 네이티브 Mac 설치 프로그램을 출시했습니다. macOS에서 앱을 다운로드하면 M1, M2, M3 또는 Neo MacBook에서 macOS와 나란히 Omarchy를 설치합니다. USB 스틱도, 터미널 주문도 필요 없습니다. Homebrew를 선호하시나요? 한 줄이면 됩니다:

brew install omacom/mac/omarchy

이것이 바로 우리가 9월에 하기로 했던 일입니다. Asahi가 시작한 일을 마무리하는 것이죠. 두 달 후, 이제 그냥 다운로드하기만 하면 됩니다. 팀의 모든 분들, 정말 놀라운 작업입니다.

그리고 여기서 멈추지 않습니다. M4, M5, M6도 모두 지금 작업 중이니, 아마 오래지 않아 Omarchy가 모든 Apple Silicon Mac에서 실행될 것입니다.

NVIDIA DGX Spark + RTX Spark용 ARM 지원 (그리고 곧 Snapdragon도)

Omarchy 4.5는 첫 ARM ISO를 출시하며, 이를 통해 NVIDIA의 ARM 기기에 대한 초기 지원을 제공합니다. DGX Spark 데스크톱과 Dell XPS 16 Creator Edition, ASUS ProArt P14 같은 RTX Spark 기반 노트북이 그 대상입니다. 그리고 곧 Snapdragon ARM 기기 전체 라인업도 지원할 예정입니다. 아직 초기 단계라 거친 부분이 조금 있을 수 있으니, 문제가 발생하면 GitHub에 알려 주세요.

50개 언어와 5가지 입력 방식

Omarchy는 이제 50개 언어를 구사합니다. Setup > Language에서 하나를 선택하거나(또는 omarchy language <code>를 실행하면), 메뉴, 데스크톱, Omarchy의 알림이 즉시 바뀝니다. 시스템 로캘은 다음 로그인 때 따라 바뀝니다.

하지만 언어를 구사하는 것은 절반에 불과합니다. 입력할 수 있어야 하죠. 그래서 Omarchy는 이제 일본어(Mozc), 한국어(Hangul), 중국어 간체(Pinyin), 대만(Zhuyin), 홍콩(Cangjie)에 맞는 입력 방식을 설치 프로그램에서 바로, 또는 나중에 Setup > Keyboard에서 제대로 설정합니다. 각 입력 방식에는 문자 형태에 맞는 글꼴이 함께 제공되고, 후보 창은 테마를 따르며, Super + I로 입력 언어 사이를 전환합니다. Hangul, Zhuyin, Cangjie는 Windows와 macOS에서처럼, Dvorak, Colemak, AZERTY로 라틴 문자를 입력하더라도 키가 표준 위치에 그대로 있습니다. 그리고 Shift를 단독으로 살짝 누르면 Sogou, Microsoft Pinyin, macOS가 동작하는 방식처럼 입력 방식에서 라틴 문자로 빠져나갔다가 다시 돌아옵니다.

캡티브 Wi-Fi 포털에 로그인하기

호텔, 공항, 커피숍 Wi-Fi가 마침내 그냥 됩니다. 이제 Omarchy는 네트워크가 온라인 접속 전에 로그인하거나 약관에 동의하라고 요구하는 것을 알아챕니다. 네트워크 아이콘이 경고를 표시하고, 네트워크 패널에는 로그인 페이지로 바로 이동하는 커다란 Open Captive Portal 버튼이 나타납니다. 통과하고 나면 모든 것이 저절로 정상으로 돌아갑니다.

새로운 기본 앱 5가지

Hype는 하나의 Markdown 파일로 프레젠테이션을 만들며, 소스 옆에 비주얼 슬라이드 편집기가 있고, PDF나 PowerPoint로 내보낼 수 있습니다.

Signed는 서류 작업에서 Xournal++를 대체합니다. PDF를 열고, 저장해 둔 서명과 텍스트, 날짜를 배치한 뒤, 서명된 사본을 저장하세요.

Disktree는 디스크를 무엇이 채우고 있는지를 종류별로 색상을 입힌 트리맵으로 그려 주고, 안전하게 재생성할 수 있는 캐시를 짚어 주며, 지울 항목을 표시할 수 있게 합니다.

Monologue는 키 하나로 카메라를 녹화하며, 데스크톱에 어울리게 테마가 적용됩니다.

Gliff는 SSH를 통한 원격 데스크톱을 제공합니다. 다른 Omarchy 컴퓨터에 연결해 당신의 창에서 그 전체 데스크톱을 조종할 수 있으며, 컴퓨터마다 탭이 하나씩 생깁니다. 그리고 SSH를 타고 가기 때문에 추가로 설정하거나 노출할 것이 없습니다. 제어받는 컴퓨터는 바에 원격 세션 표시기를 나타내므로, 누군가 접속해 있을 때 언제나 분명히 알 수 있습니다.

그리고 바의 시계 바로 옆에 사는 세계 시계, Elsewhen이 있습니다. 지구본에서 도시를 눌러 현재 위치를 설정하고, 실제 장소를 검색하고, 각 도시에 사는 사람들의 이름을 붙이면, 전화하기에 괜찮은 시간인지 언제나 알 수 있습니다. t로 12시간제와 24시간제를 오가고, Alt + T로 °F와 °C를 오가며, Super + Ctrl + Alt + E로 언제든지 불러낼 수 있습니다.

녹화용 Monologue와 다듬기용 Omacut이 있어, 새 설치에는 더 이상 OBS Studio와 Kdenlive가 함께 제공되지 않습니다. Lazydocker도 새 설치에서 사라졌지만, Docker와 Docker Compose는 여전히 포함됩니다. 이미 어느 것이든 갖고 있는 컴퓨터는 그대로 유지합니다.

Microsoft 365

Office에서 사는 사람들과 함께 일해야 하나요? Install > Service > Microsoft를 이용하면 이제 Outlook, Word, Excel, PowerPoint, Teams, OneDrive를 웹 앱으로 설정합니다. 각 앱마다 자체 창과 런처 항목이 생겨, 다른 모든 앱 옆에서 집에 있는 것처럼 편안하게 느껴집니다. 직장에서 Omarchy로 전환하지 못할 변명은 이제 없습니다!

받아쓰기를 위한 Superwhisper

Superwhisper는 이제 Omarchy의 기본 받아쓰기 엔진이며, 처음부터 바로 쓸 수 있게 설정되어 있습니다. Alt + Space를 눌러 말하기를 시작하고 다시 눌러 멈추거나, Right Alt를 누르고 있어 푸시 투 토크로 쓰세요. 놀라울 만큼 빠르고 매우 정확합니다.

처음에는 클라우드에서 시작하므로 설치하는 순간 바로 동작하고, 처음 10,000단어는 무료입니다. 하지만 완전히 무료이고 누구에게도 단 한 단어도 보내지 않으며 전적으로 로컬에서 실행되는, 다운로드 가능한 모델로 전환할 수도 있습니다. 그리고 다른 로컬 모델을 쓰고 싶다면 대안으로 Voxtype도 여전히 제공됩니다.

10초도 안 걸리는 설치

Omarchy는 예전에는 약 940개의 패키지를 하나씩 설치했습니다. 새로운 F1 설치 프로그램은 대신 미리 빌드된 루트 이미지를 풀고 그 위에 이 컴퓨터만의 패키지만을 더합니다. 덕분에 어떤 컴퓨터에서든 설치 시간이 대략 절반으로 줄어듭니다.

그리고 빠른 하드웨어에서는 터무니없을 정도입니다. AMD의 Anush Elangovan은 자신의 AMD 노트북에서 전체 Omarchy 설치를 7초 만에 마쳐 세계 기록을 세웠습니다. 7초라니요! 5분이 야심 찬 목표처럼 느껴지던 때가 기억납니다.

그 밖의 모든 곳도 더 빠르게

설치 프로그램만 그런 것이 아닙니다. 시작 시 binfmt 등록에서 더 이상 멈추지 않습니다. 테마 선택기는 0.25초를 기다린 뒤가 아니라 바로 열립니다. 메뉴와 패널은 먼저 프로세스를 시작하는 데 걸리던 60ms를 건너뛰고 Hyprland 단축키에서 바로 열립니다. Omarchy 메뉴에서 가장 느린 확인 작업은 200ms에서 16ms로 줄었고, 새 터미널은 프롬프트를 30ms 더 빨리 표시하며, 전체 데스크톱은 이제 폴링하는 대신 변화에 반응합니다. 로그아웃, 재부팅, 종료조차 앱이 모두 닫히는 순간 일어납니다.

에이전트 업그레이드

Omarchy는 에이전트 OS이며, 4.5는 에이전트와 함께 작업하기 위한 대규모 업그레이드를 가져옵니다. 에이전트 패널은 이제 Cursor, OpenCode, GitHub Copilot, Antigravity, Hermes, Amp, Kiro, Devin, Qwen, DeepSeek, OpenRouter, Ollama를 포함해 6개에서 늘어난 23개의 에이전트와 제공업체를 추적합니다. 모든 한도마다 재설정까지 남은 시간을 보여주는 자체 미터가 생겨, 남은 여유가 정확히 얼마나 되는지 볼 수 있습니다. 그리고 Grok은 이제 Claude, Codex와 나란히 완전한 제공업체가 되었습니다.

그리고 당신의 에이전트는 언제나 키 하나만 누르면 됩니다. Super + ~를 누르면 어두워진 데스크톱 위에 Quake 스타일 콘솔이 내려오고, 처음 열면 기본 에이전트가 시작됩니다. 다시 누르면 치워지며, 세션은 떠났던 그 자리에 그대로 있습니다.

구독을 여러 개 저글링하고 있다면, 이제 같은 컴퓨터에 여러 Claude, Codex, Grok 로그인을 유지하고 omarchy agent account를 이용해 새 세션을 어떤 것으로 시작할지 선택할 수 있습니다. 기록, 설정, 스킬은 그들 사이에 공유되므로, 전환한 뒤에도 claude --continue가 떠났던 곳에서 바로 이어집니다. 한도에 가까워지면 Omarchy는 원클릭 전환을 제안하거나, 새 세션을 여유가 가장 많은 계정으로 저절로 옮길 수 있습니다. 그리고 또 다른 컴퓨터를 설정할 때, omarchy agent account copy가 모든 로그인을 SSH를 통해 가져오므로 모든 것에 다시 로그인할 필요가 없습니다.

OpenRouter의 에이전트 하네스인 Kimi와 Ori가 Setup > Defaults > Agent 아래의 선택지에 합류하고, Google의 Antigravity가 구식이 된 Gemini CLI를 대체합니다(gemini는 여전히 별칭으로 동작합니다). 터미널보다 창을 선호하시나요? Claude와 Amp 데스크톱 앱이 이제 Install > AI 아래에서 한 번의 클릭으로 닿을 수 있습니다.

새로 만든 알림

알림은 이제 보낸 사람별로 쌓이고, 테마를 따르며, 동일한 반복은 접힙니다. 액션 버튼, 인증 코드, 링크가 모두 카드에서 바로 동작합니다. Super + Comma는 가장 최신 알림에 대해 동작하고(닫기, 열기, 또는 버튼 누르기), Super + Ctrl + Comma는 키보드를 건네 모든 알림을 조종할 수 있게 합니다. 바의 종은 방해 금지를 켭니다.

비디오 배경과 테마 인트로

이제 배경은 비디오가 될 수 있습니다. 하나를 넣어 두면, 출렁이는 파도든 그 밖에 당신이 좋아하는 무엇이든으로 데스크톱이 살아 움직이고, 잠금 화면은 그 비디오의 정지 프레임을 보여줍니다. 그리고 테마는 이제 등장합니다. 각 테마는 로그인하거나 그 테마로 전환할 때 짧고 소리 없는 인트로를 재생할 수 있습니다. (차분하게 유지하고 싶으신가요? Appearance > Animations 아래에서 인트로를 끄세요.)

기본 테마에 합류한 Jade Horse

Jade Horse는 온통 안개 낀 녹색이며, 조각된 옥 같은 배경 덕분에 전체 데스크톱이 두루마리 그림처럼 보입니다. 함께 제공되는 테마 중 Osaka Jade를 대체하고, 다른 새 기본 테마인 Starship과 함께합니다. Osaka Jade를 사용 중이라면 당신의 사본은 유지되며, 새로 설치하고 싶은 분들을 위해 서드파티 테마로 계속 살아 있습니다.

Liftoff가 새 기본 배경입니다

새 설치는 이제 Tokyo Night의 새 기본 배경인, 멋진 일몰 발사 장면 Liftoff로 당신을 맞이합니다. 이 배경은 Tom Ballard가 만들었으며, 그는 처음에 자신의 Liftoff 테마를 위해 이 배경을 만들었습니다. 고마워요, Tom!

이제 조용해진 부팅 메뉴

Omarchy는 예전에는 혹시 이전 스냅샷으로 롤백해야 할 경우를 대비해 시작할 때마다 약 6초 동안 부팅 메뉴를 표시했습니다. 하지만 그런 일을 하는 사람은 거의 아무도 없었습니다. 그래서 이제 Limine은 단 1초만 기다린 뒤 조용히 부팅하며, 대부분의 경우 메뉴를 전혀 보지 못할 것입니다.

다른 항목이나 스냅샷이 필요할 때는 컴퓨터가 시작되는 동안 아무 키(아래 화살표도 됩니다)나 계속 누르고 있으면 메뉴에서 멈출 것입니다. 그리고 메뉴를 더 오래 떠 있게 하고 싶다면, /boot/limine.conf에 자신만의 timeout:(예: timeout: 5)을 설정하세요. 업데이트는 당신이 설정한 시간 제한을 그대로 둡니다.

변경된 단축키

일부 단축키가 이동했습니다:

  • Calculator: Super + Ctrl + Q가 이제 Super + Shift + Q입니다.
  • Activity: Super + Ctrl + T가 이제 Super + Shift + T이며, Super + Ctrl + T는 테마를 엽니다.
  • Network: Super + Ctrl + W가 이제 Super + Ctrl + N이며, Super + Ctrl + W는 배경을 엽니다.
  • Nightlight에는 더 이상 단축키가 없습니다(이전에는 Super + Ctrl + N이었습니다). Trigger > Toggle에 있습니다.
  • Super + Alt + Space는 Apps 메뉴 대신 독에서 Apps를 엽니다.

알림 단축키가 변경됐습니다:

  • Super + Comma는 가장 최신 카드에 대해, 단순히 닫는 대신 동작합니다(닫거나, 열거나, 그 하나의 버튼을 누릅니다).
  • 마지막 알림 닫기는 Super + Alt + Comma로 이동했습니다. 이 키는 이전에 알림을 열었습니다.
  • 음소거는 Super + Ctrl + Comma에서 Super + Ctrl + Alt + Comma로 이동했습니다. Super + Ctrl + Comma는 이제 키보드 제어권을 건넵니다.

몇 가지 키는 다르게 동작합니다:

  • Super + Tab, Super + Shift + Tab, Super + Ctrl + Tab, 그리고 Super + 스크롤은 현재 모니터의 워크스페이스에 머무릅니다. 모니터마다 자체 워크스페이스가 있기 때문입니다.
  • 터미널에서는 Super + C와 Super + V가 Ctrl + Shift + C와 Ctrl + Shift + V를 보내며, 이는 이전의 Ctrl + Insert와 Shift + Insert를 대신합니다.

당신의 자체 바인딩과 충돌할 수 있는 새 기본값: Super + Q(창 닫기, Super + W와 함께), Super + A(모두 선택), Super + M(독으로 최소화), Super + ~와 Super + Shift + ~(Quake console), Super + Alt + L(이전 레이아웃), Super + Shift + Ctrl + Arrows(창을 다른 모니터로 이동), Super + Ctrl + Alt + C(스크린샷), Super + Ctrl + Alt + E(세계 시계), Super + Ctrl + Alt + F(전체 화면 데스크톱), 그리고 받아쓰기를 위한 푸시 투 토크로서 Right Alt 누르고 있기.
