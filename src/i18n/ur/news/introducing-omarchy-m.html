Apple شاندار hardware بناتا ہے۔ وہ ہمیشہ سے بناتا آیا ہے (بس butterfly keyboard والا ایک قصہ چھوڑ کر)۔ اور Omarchy کی طرف آنے والے بہت سے لوگ Mac سے آ رہے ہیں۔ ان میں سے کئی چاہیں گے کہ مشین تو وہی رہے لیکن operating system سے جان چھڑا لیں۔ تو ہم وہ کام مکمل کرنے جا رہے ہیں جو Asahi نے شروع کیا تھا: Apple Silicon پر Omarchy کو خوبصورتی سے چلانا، setup کی کم سے کم جھنجھٹ کے ساتھ۔

اس کام کے پیچھے پہلے سے ایک ٹیم موجود ہے۔ آج ہم اسے باضابطہ کر رہے ہیں: Omarchy M، Apple Silicon والے Macs کے لیے ہماری ٹیم (ساتھ میں چند اراکین جو پرانے Macs کو بھی ساتھ رکھے ہوئے ہیں)۔

Drivers اور kernel. Ryan Murray Neo کو اوپر لا رہا ہے اور وہ بنیادیں بنا رہا ہے جن پر باقی ٹیم کام کرتی ہے۔ وہ ایک SPTM emulator تیار کر رہا ہے جس سے M4 اور نئی chips پر macOS کو trace کرنا ممکن ہوتا ہے۔ یہ traces displays، GPUs، audio، wireless، اور Bluetooth کو چلانے کے لیے ضروری ہیں۔ Dj GPU drivers لکھ رہا ہے، اور Secure Enclave سے براہِ راست بات کر کے Touch ID چلا دیا۔ Miguel Cruz M5 کے کام کا ماہر ہے: اس نے Apple کی proprietary N1 chip کو reverse-engineer کیا اور اس کی Wi-Fi اور Bluetooth کو Linux میں چلا دیا۔ اس نے Neo پر hardware video encoding اور decoding، Bluetooth، اور desktop بہتریوں میں بھی حصہ ڈالا ہے۔ Liam Neo کا trackpad، power management، speakers، اور headphone output چلا رہا ہے، جس میں Ryan کے macOS traces بنیادی مدد فراہم کر رہے ہیں۔ Eryk Wieliczko M4 support اور clean-room implementations کو سنبھالتا ہے، اور integration اور packaging پر کام کرتا ہے۔ Jaidip Subedi نے M2 MacBook Air پر USB-C کے ذریعے external displays چلا دیے۔

پرانے Macs. Shawn Yeager کے پاس 2016 اور 2017 کے Touch Bar MacBook Pros کے لیے pull requests کا ڈھیر ہے: speakers، Wi-Fi، ambient light sensor، خود Touch Bar۔ Randy Intel Macs پر Touch ID لانے کے لیے T2 security chip کو reverse-engineer کر رہا ہے، اور ساتھ ساتھ 2019 MacBook Pro کے ہر fix کو دستاویز کر رہا ہے۔ Jon Kinney ایک سال پہلے Omarchy کے لیے ARM support پر کام کر رہا تھا، اور اب پوری ٹیم میں ہم آہنگی رکھتا ہے کہ کون کیا کر رہا ہے۔

مل کر، وہ ایک زبردست گروپ ہیں۔ پندرہ لوگ جنہوں نے اجازت کا انتظار نہیں کیا، اور جو agents کا استعمال ایسی رفتار سے آگے بڑھنے کے لیے کر رہے ہیں جو ایک سال پہلے مضحکہ خیز لگتی۔

پہلی release کا ہدف M1 اور M2 کے ساتھ مکمل compatibility ہے، بشمول Pro اور Max variants:

  • ایک ہموار installer، جس میں install اور try دونوں options ہوں
  • مکمل GPU support
  • USB-C پر external monitors
  • Touch ID
  • MLX
  • Disk encryption

نئی مشینوں پر متوازی طور پر کام جاری ہے، لیکن M1 اور M2 وہ جگہ ہیں جہاں ہم پہلے جھنڈا گاڑ رہے ہیں۔ M مشینوں کے علاوہ، باہر لاکھوں پرانے laptops موجود ہیں، ان میں سے کئی Apple کی تازہ ترین macOS خواہشات سے پہلے ہی ریٹائر ہو چکے ہیں، اور ان میں سے ہر ایک ایک شاندار Omarchy computer بننے کا منتظر ہے۔

شروع کرنے کے لیے آپ کو polished release کا انتظار نہیں کرنا پڑے گا۔ Try Omarchy آپ کو چند منٹوں میں آپ کے Mac پر اصل desktop دکھا دے گا۔ اور اگر آپ commit کرنے کے لیے تیار ہیں، تو installer آج ہی M1 یا M2 پر macOS کے ساتھ Omarchy لگا دے گا۔

آخر میں، ایک گزارش۔ اگر آپ Apple hardware کے لیے Linux پر کام کرتے رہے ہیں، چاہے وہ kernel drivers ہو، firmware، packaging، installers، یا machine learning، تو ہم آپ سے سننا چاہیں گے۔ اچھا خاصا امکان ہے کہ آپ نے کوئی ایسی چیز حل کر رکھی ہو جس کے پیچھے ہم اب بھی بھاگ رہے ہیں، یا اس کے برعکس۔ apple@omarchy.org پر رابطہ کریں۔
