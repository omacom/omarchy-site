Apple nyieun hardware hébat. Salawasna (iwal hiji waktu jeung keyboard butterfly). Sarta loba jalma anu datang ka Omarchy asal ti Mac. Loba di antarana hoyong tetep mesinna sarta miceun sistem operasina. Jadi kami bakal ngaréngsékeun anu dimimitian Asahi: Omarchy jalan éndah dina Apple Silicon, kalawan karesep setup minimal.

Padamelan éta geus boga tim di balikna. Poé ieu resmi: Omarchy M, tim urang pikeun Mac Apple Silicon (tambah sababaraha anggota ngajaga Mac lawas tetep kaasup).

Mangga wanoh jeung anggota-anggotana.

Tukang pasang. Marcelo Alcantara nuju ngawangun installer Mac asli. Anjeun ngundeur aplikasi dina macOS, éta nyandak rilis Omarchy anu ditandatanganan, motong partisi, sarta boot ka Omarchy di gigireun macOS anu tos aya. Euweuh USB stick, euweuh mantra dina terminal. Anjeunna ogé motong build anu ngahurungkeun monitor éksternal liwat USB-C.

Omarchy Mac. Naeem Malik geus ngarawat Omarchy Mac sataun, nempatkeun Omarchy kana mesin M1 jeung M2 lila saméméh ieu resmi, sarta ngawangun komunitas Discord leuwih ti 800 jalma. Scott Jones satengah séjén proyék éta di sisi Linux instalasi. Anjeunna kakara ngajantenkeun tampilan M3 Air jalan dina display controller hardware Apple, anu ngarobah mesin éta ti teu bisa dipaké jadi bisa dipaké sapeuting.

Coba Omarchy. Eduardo Martinez ngawangun Try Omarchy: desktop Omarchy asli jalan salaku aplikasi asli hardware-accelerated dina Mac anjeun, kalawan kaméra, audio, clipboard, jeung polder babarengan disambungkeun. Euweuh nu kudu dipartisi. Ngan undeur sarta tingali hebohna.

Pakét. Shun Li mastikeun sagalana anu diperlukeun Omarchy aya salaku pakét aarch64, bareng image disk ARM64 generik pikeun mesin virtual jeung guest tools anu ngajantenkeun pikaresepeun dipaké.

Supir jeung kernel. Ryan Murray ngangkat Neo sarta ngawangun fondasi tempat tim séjén gawé. Anjeunna ngamekarkeun émulator SPTM anu ngamungkinkeun trace macOS dina chip M4 jeung leuwih anyar. Trace éta ésénsial pikeun ngajantenkeun tampilan, GPU, audio, nirkabel, jeung Bluetooth jalan. Dj nulis supir GPU, sarta ngajantenkeun Touch ID jalan ku ngomong langsung ka Secure Enclave. Miguel Cruz spesialis pagawéan M5: anjeunna reverse-engineered chip N1 proprietary Apple sarta ngajantenkeun Wi-Fi jeung Bluetooth-na jalan dina Linux. Anjeunna ogé nyumbang encoding jeung decoding pidéo hardware, Bluetooth, jeung pamutahiran desktop dina Neo. Liam ngangkat trackpad, manajemen daya, spiker, jeung output headphone Neo, kalawan trace macOS Ryan nyayogikeun fondasi ésénsial. Eryk Wieliczko ngarawat rojongan M4 jeung implementasi clean-room, sarta gawé dina integrasi jeung packaging. Jaidip Subedi ngaktipkeun tampilan éksternal liwat USB-C dina M2 MacBook Air.

MLX. Joshua Warren nuju ngawangun mlx-omarchy, anu mawa framework machine learning MLX Apple ka Linux dina GPU Apple liwat Vulkan. Kode anjeun tetep nyarios import mlx.core as mx, tapi ayeuna jalan dina Omarchy.

Mac lawas. Shawn Yeager boga tumpukan pull request pikeun MacBook Pro Touch Bar 2016 jeung 2017: spiker, Wi-Fi, sénsor cahaya ambient, Touch Bar sorangan. Randy reverse-engineering chip kaamanan T2 pikeun mawa Touch ID ka Intel Mac, sarta ngadokumentasikeun unggal perbaikan pikeun MacBook Pro 2019. Jon Kinney ngagarap rojongan ARM pikeun Omarchy sataun ka tukang, sarta ayeuna ngajaga sakabéh tim terkoordinasi saha ngalakukeun naon.

Babarengan, maranéhna grup tangguh. Lima belas jalma anu teu ngadagoan idin, sarta geus maké agén pikeun maju dina kagancangan anu karasa absurd sataun ka tukang.

Target rilis kahiji nyaéta kompatibilitas sampurna jeung M1 jeung M2, kaasup varian Pro jeung Max:

  • Installer mulus, jeung opsi install jeung coba
  • Rojongan GPU pinuh
  • Monitor éksternal liwat USB-C
  • Touch ID
  • MLX
  • Enkripsi disk

Mesin leuwih anyar digarap paralel, tapi M1 jeung M2 tempat nanjeubkeun bandéra heula. Salian mesin M, aya jutaan laptop vintage di luar, loba di antarana geus pensiun ti ambisi macOS panganyarna Apple, sarta unggal hijina komputer Omarchy éndah anu ngadagoan.

Anjeun teu kudu ngadagoan rilis poles pikeun ngamimitian. Try Omarchy bakal nempatkeun anjeun ningali desktop asli dina Mac dina menit. Sarta upami siap komitmen, installer bakal nempatkeun Omarchy di gigireun macOS dina M1 atawa M2 poé ieu.
