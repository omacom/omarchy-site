Omacom Foundation kakara ngarekrut pinuh waktu kahiji! Krzysztof Wilczyński gabung pikeun mingpin padamelan urang dina Omarchy Kernel. Ieu persis tujuan yayasan diadegkeun: mayar jalma hébat pikeun gawé dina masalah hésé pikeun kahadéan saréréa.

Krzysztof nyaéta developer kernel Linux lawas. Anjeunna ngarawat bareng subsistem PCI Endpoint sarta supir host bridge jeung endpoint PCI asli. Éta pipa anu nyambungkeun Linux ka GPU, drive NVMe, jeung kartu WiFi anjeun. Anjeunna ogé reviewer dina pagawéan PCI Rust anyar kernel. Saméméh jero dina kernel, anjeunna mangtaun-taun dina rékayasa sistem, gawé dina Kubernetes jeung runtime container.

Ayeuna anjeunna bakal mawa sadaya pangalaman éta ka Omarchy Kernel. Fokusna: kinerja, kompatibilitas, jeung kaamanan. Urang hoyong Linux ngapung dina laptop panganyarna jeung ThinkPad baheula. Urang hoyong jalan langsung tina kotak dina leuwih loba mesin. Sarta urang hoyong dikonci pageuh.

Krzysztof ogé gabung Omarchy Core, jadi bakal ngabantu nangtukeun arah distro sacara gembleng.

Wilujeng gabung, Krzysztof! Hayu jieun kernel ngajerit.
