Themes

Omarchy comes with twenty-two beautiful themes. You can select between them via Appearance > Theme in the Omarchy Menu (Super + Space) or hop directly to the theme selector using Super + Ctrl + T.

Each theme styles the desktop, terminal, neovim, activity screen (btop), Chromium, and the entire Omarchy shell: top bar, menu, notifications, OSD, and the lock screen. (For Obsidian, you must manually select the Omarchy theme via Appearance > Themes inside the app).

Themes have a set of background images that you can pick between using Super + Ctrl + W.

You can find even more themes on the extra themes page or even make your own theme.

App icons #

The icons in the app launcher and dock are drawn in the colors of your theme, so they change along with it. They come from an icon set, which you pick separately from the theme under Appearance > Icons, from previews of each set, the same way you pick a theme:

  • Papercraft is the default: everything that comes installed, drawn in one style. Apps known by their logo, like Chrome, HEY, or YouTube, keep its shape and take on the theme’s colors.
  • Arcade draws the same apps as 8-bit pixel art, like an old game console would.
  • Original shows every app with the icon its maker gave it.

You can install an icon set someone else has made with Install > Style > Icons (or omarchy icons install <git url>), and remove it again under Remove > Icons. Update > Extra Icons fetches the latest version of the sets you have installed.

To make your own, put your icons in ~/.config/omarchy/icons/<name>/, one file per app, named after the Icon= line of the app’s .desktop file. A file ending in .svg is shown as it is. A file ending in .svg.tpl is drawn in the theme’s colors: write {{ icon_main }}, {{ icon_mark }}, {{ icon_paper }}, {{ icon_body }}, {{ icon_edge }}, {{ icon_ink }} or {{ icon_shadow }} where a color goes. The default set in /usr/share/omarchy/icons/papercraft/ is a good place to start from. Add a preview.png to show your set in the picker; without one, Omarchy draws a preview from your icons. To change a single icon of the default set, put your version in ~/.config/omarchy/icons/papercraft/.
